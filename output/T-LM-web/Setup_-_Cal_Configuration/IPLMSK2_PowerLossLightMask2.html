1. Overview & Purpose

IPLMSK2 (PowerLossLightMask2) provides the second tier of fault-masking for dashboard warning light activation.

Where IPLMSK focuses predominantly on primary analog engine sensors, IPLMSK2 governs actuator driver circuits and critical system over-limits. Enabled bits in IPLMSK2 illuminate the dashboard lamp for conditions including wastegate solenoid electrical faults, fuel injector circuit open/shorts, and major internal processor faults.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated in conjunction with IPLMSK during diagnostic fault evaluation.
  • Bit assignments:
  • Bit 7 (0): Reserved / Bit 7
  • Bit 6 (0): Major Microprocessor Internal Fault
  • Bit 5 (1): Reserved / Bit 5
  • Bit 4 (1): Fuel Injector Circuit Driver Fault
  • Bit 3 (1): Wastegate Solenoid Circuit Fault
  • Bit 2 (1): Unused / Bit 2
  • Bit 1 (1): Unused / Bit 1
  • Bit 0 (1): Unused / Bit 0

3. Tuner's Guide & Real-World Calibration

  • Wastegate Solenoid Elimination: If you remove the factory electronic wastegate solenoid to install a standalone manual boost controller (MBC) or electronic boost controller, the ECU will detect an open circuit and set Fault Code 32. Clearing Bit 3 in IPLMSK2 prevents this code from illuminating the dashboard Power Loss light while keeping other diagnostic protections active.
