1. Overview & Purpose

CONFIG (CONFIG_ConfigurationFlags) is one of the most powerful and versatile calibration bytes in the entire ECU firmware. It serves as the master software toggle for major driveline architecture and Turbonator performance modifications.

In this stock factory manual transmission binary (T_LM_22_MTX_A171), CONFIG is initialized to 0x00. When building custom performance calibrations, tuners toggle specific bits in this byte to enable cutting-edge features: - Bit 7 (cfg_ATX, $80): Driveline selection. Set = Automatic transmission (ATX); Cleared = Manual transmission (MTX). - Bit 6 (cfg_FlashCE, $40): Flash Check Engine Light on knock detection. - Bit 5 (cfg_BankEnrich, $20): Enable selective bank fuel enrichment. - Bit 4 (cfg_ShiftLight, $10): Repurpose Purge solenoid driver as an adjustable RPM Shift Light. - Bit 3 (cfg_SwBoost, $08): Enable dual switchable boost stages via dash switch. - Bit 2 (cfg_BstSwPol, $04): Invert boost switch input polarity (normally open vs normally closed). - Bit 1 (cfg_StageLim, $02): Enable 2-step staging rev limiter for drag launches. - Bit 0 (cfg_AntiLag, $01): Enable anti-lag launch retard.

3. Tuner's Guide & Real-World Calibration

  • Manual vs Auto Swap: When swapping a manual transmission into an automatic car (or vice versa), toggle Bit 7 (cfg_ATX). This reconfigures idle decel dashpot routines, target idle tables, and rev limiters.
  • Knock CEL Flash: Enabling Bit 6 (cfg_FlashCE, +$40) provides real-time in-cockpit visual knock feedback without needing a scan tool or laptop.
  • Drag Racing 2-Step: Enable Bit 1 (+02) to activate staging limiter features using the clutch switch or an auxiliary staging button.
