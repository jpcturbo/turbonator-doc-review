1. Overview & Purpose

ERMSK3 (ErrorCodeBitMask3) is the fourth diagnostic trouble code mask, governing alternator field control (Code 41), automatic shutdown driver (Code 42), ignition coil primary driver (Code 44), and ROM checksum self-test integrity (Code 53).

Stock calibration sets ERMSK3 to 0xFF (all faults enabled), ensuring complete system monitoring of the power generation and ignition circuits.

2. Operating Conditions (When Does This Take Effect?)

  • Loaded into accumulator B by ldd ErrorCodeBitMask2 at line 704.
  • ANDed with ErrorBitRegisterStored3.

3. Tuner's Guide & Real-World Calibration

  • External Alternator Regulators: If an external high-amp racing alternator with its own mechanical/internal voltage regulator is installed, clearing the field fault bit in ERMSK3 prevents the ECU from setting charging system fault codes.
