1. Overview & Purpose

UNKWN (UnknownCodeBits) is a 16-bit word located at $C002 (offset $009F) in the calibration header.

Originally implemented by Chrysler Powertrain Electronics engineering, this word contains configuration bits utilized by factory automated end-of-line test fixtures and automated burn-in benches. In production vehicle operation, these bits are ignored by normal fuel and spark control routines.
