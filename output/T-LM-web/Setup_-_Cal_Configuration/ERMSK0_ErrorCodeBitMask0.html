1. Overview & Purpose

ERMSK0 (ErrorCodeBitMask0) is the first of four diagnostic fault masking bytes that govern whether detected hardware anomalies are logged into non-volatile error memory (ErrorBitRegisterStored0).

During engine operation, diagnostic subroutines continually evaluate sensors and circuits. When a fault occurs, the diagnostic routine sets a corresponding bit in temporary RAM. During the checksum and error processing routine ChecksumFinished, the temporary fault bits are logically ANDed with ErrorCodeBitMask0 (0xFF). If a bit is enabled (1), the fault code is saved to battery-backed RAM and can be flashed out on the Power Loss light (Key-On On-Off-On sequence) or retrieved via scan tool. If a bit is cleared (0), the fault is masked and never recorded.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated in ResetStartup / ChecksumFinished at line 700.
  • Loaded as a 16-bit word pair (ldd ErrorCodeBitMask0, covering ERMSK0 and ERMSK1).
  • ANDed against ErrorBitRegisterStored0.

3. Tuner's Guide & Real-World Calibration

  • Disabling Nuisance Fault Codes: If a modified engine has deleted certain emissions components or sensor circuits, clearing specific bits in ERMSK0 stops the ECU from logging those error codes into memory or flashing them on the Check Engine light.
  • Stock Value: 0xFF (all bits enabled in this byte).
