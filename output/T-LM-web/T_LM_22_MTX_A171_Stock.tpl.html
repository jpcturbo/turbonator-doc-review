8; ***********************************************************************
9;
10; This is the calibration template for T-LM.
11;
12; This template format will be used from T-LM v10 and later.
13;
14; I decided to switch to this format because it was getting clumsy
15; trying to define the switches for all of the build options (MTX/ATX,
16; 2.2/2.5, boost control, etc.). This way, all the calibration data can be
17; kept together in 1 place.
18;
19; T-SMEC, and T-SBEC have thier own template format and the 2 CAN NOT be
20; interchanged. This is due to the different code structures between the
21; LM, SMEC and SBEC.
22;
23; The relative positions of the data structures should not be changed.
24; But, the calibration values can be changed at will to any value you wish.
25; Or, to match any exsisting calibration.
26;
27; Filename format:
28;
29; T-LM_[displ]_[trans]_[ID]_[version].v16
30;
31; For example, the 1st tempalte file I made was from the 87 T2:
32;
33; T-LM_22_MTX_A171_T2.v10
34;
35; This way you can start your T-LM build with any calibration. Though,
36; you may have to build a template file if you want a calibration that
37; does not already have a tempalte file.
38;
39; If you modify a 'stock' calibration, please change the [version] part
40; of the filename so that it will not get confused. Of course, you can
41; name your custom calibrations anything you wish.
42;
43; Before building, this template file MUST be added to the .include
44; statement in the T-SMEC .asm file. Otherwise, you'll get an error.
45;

48; ***********************************************************************

249; ***********************************************************************
250;
251; ***********************************************************************
252;
253; *** Config/Option Constants ***
254;
255; These constants alow the user to enable/disable all of the
256; added special functions without having to re-assemble from the source.
257; These bits can be set/cleared in CHeM or D-Cal.
258;
259; ***********************************************************************
260;
261; *** Spark/Fuel Rev Limiters ***
262;
263; You can now enable/dis-able independantly the spark/fuel rev limiters.
264; The Spark-based rev limiter is new. The stock code onyl cut fuel for
265; the rev limiter (and overboost, speed limiter, etc.). This was a little
266; rough when used for the 2-step. So, I added an option to use a spark
267; limiter as well as -or in addition to- the fuel-based rev limiter.
268;
269; *** Switchable boost ***
270;
271; Switchable boost uses an additional boost from RPM table to limit the
272; boost when the switch is inactive. Depending on the switch used, it may
273; be active high or active low. The polarity flag is there to allow the
274; user to set the switch to function as intended regardless of the switch
275; used.
276;
277; *** Staging Limiter/2-Step ***
278;
279; The staging limiter has 2 activation/deactivation methods.
280; 1st, the limiter checks to see if it's active by looking for an "enable"
281; switch. This could be the brake or other input switch.
282; If the switch is "off", then the normal rev limiter values are used.
283; 2nd, the limiter checks to see if the vehicle speed is below the cutoff
284; point - STGSPD. If it is, then the normal rev limiter value is loaded.
285;
286; !!! RPM is used differently in the '89 T1 code than the previous codebases.
287; !!! Actual RPM is used, rather than the time between dist pulses (used in the
288; !!! LM and T2 SMEC codebases).
289;
290; *** Flash CE on Knock ***
291;
292; This option allows the user to flash the "Check Engine" lamp when knock is
293; indicated. The individual cylinder retards are used for knock detection.
294; In use, the lamp will flash proportionately to the amount of knock.
295; It is also possible to use the PTU/Upshift indicator as a knock light (this
296; ouput is not used on turbo cars). I may add that as an option in the future.
297;
298; *** Hi-Speed logger ***
299;
300; The hi-speed logger allows for much faster than stock datalogging rates
301; using an external logging program. It also disables all DRB routines, so
302; communication with a standard scantool will no longer be possible. The
303; option flag allows the feature to be turned on/off without losing
304; calibration data. the function is very simple in operation. It loads a
305; single byte memory address into B and then send the data stored at that
306; address to the serial port.
307;
308; *** Anti-lag ***
309;
310; See description at the anti-lag routine for the specifics.
311;
312; ***********************************************************************

1232; *****************************************
1233; O2 Controller Ramp Calibration
1234; *****************************************
1235; How it works:
1236; The O2 sensor is monitored but ONLY for "rich/lean". Even though
1237; the O2 sensor value is from 0 to 15, the only thing that counts
1238; for this system is whether it is "rich" or "lean". A change from one
1239; to the other is a "toggle". The system constantly toggles between
1240; rich and lean so that the overall average is around stoichiometric.
1241;
1242; Background information (from the net:)
1243; An "ideal" fuel/air mixture in which both the fuel and the oxygen in the air are
1244; completely consumed is called the "stoichiometric" mixture. The stoichiometric mixture
1245; is usually specified as the ratio of the mass of air to the mass of a particular fuel.
1246; For example, if a fuel required 10 kg of air to precisely burn 1 kg of the fuel (that is,
1247; all the fuel burned and there was no oxygen left in the air afterwards) then the
1248; stoichiometric ratio for that fuel would be 10:1.
1249;
1250; Chevron give the stoichiometric ratio of air mass to fuel mass for gasoline as 14.7:1,
1251; but don't specify the composition of this hypothetical gasoline.
1252;
1253; From http://www.faqs;;.org/faqs/autos/gasoline-faq/part2/ comes the following table
1254; of typical stoichiometric air-fuel ratios:
1255;
1256; Fuel | Stoichiometric air-fuel ratio
1257; -----------+------------------------------
1258; methanol | 6.4
1259; ethanol | 9.0
1260; MTBE | 11.7
1261; ETBE, TAME | 12.1
1262; gasoline | 14.6
1263;
1264; An oxygenated gasoline with 89% gasoline and 11% MTBE would then have a stoichiometric
1265; ratio of 14.281 (note that this would require a Wide Band O2 sensor to adjust, since the
1266; O2 sensor in our cars is designed for gasoline only, and is a very narrow range. In case
1267; you were wondering, this is one reason some people are interested in Wide Band O2 sensors.)
1268;
1269; *****************************************
1270; This system divides a range of RPMs and MAP readings into "cells". The number of
1271; "kicks", or increases/decreases in fuel required to toggle the O2 reading, is different
1272; for each of these cells. This allows some fairly powerful flexibility in tuning. The
1273; only time you might want to adjust these values is for different injector flow rates,
1274; or to speed or slow the adjustment being performed.
1275; *****************************************
1276; Note to tuners: DO NOT AIM FOR STOICHIOMETRY! Although it might be fine for idle or
1277; low speed operation, at higher RPMs and under boost you DEFINITELY want a RICH mixture.
1278; This is because stoichiometric combustion generates the most heat. No current engine
1279; would survive very long with the temperatures this would generate, hot enough to melt
1280; the engine.
1281; *****************************************
1282; Each cell has a kick value. This is the amount of change applied to the running fuel
1283; every eleven millisec until a rich/lean toggle occurs. The net result is the
1284; familiar rich/lean flashing that your O2 sensor gauge shows you.
1285; *****************************************
1286;
1287; (one kick per 11ms)
1288; Fudge factor: if an O2 toggle occurs before the primary ramp
1289; finishes, then the "first" step in the new direction is limited
1290; to the accumulated steps before the toggle.
