1. Overview & Purpose

CLTEMP_TempToStartCLTIMETimer defines the coolant temperature threshold that unlocks the closed-loop delay timer.

Before the ECU will consider running in closed-loop fuel feedback or adapting fuel tables, the engine must warm up past cold-enrichment levels. When coolant temperature reaches CLTEMP, the ECU starts the Timer_CLTIME_ClosedLoopTimer countdown. Once that timer reaches O2TIME, the ECU tests oxygen sensor activity and transitions into closed-loop control.

2. Operating Conditions (When Does This Take Effect?)

  • Warmup Progression:
  • Active during engine warmup from cold start.
  • If CoolantTemp < CLTEMP: The closed loop delay timer is inhibited from advancing. Fueling remains purely open-loop based on warmup curves (CURVEA and CURVEB).
  • If CoolantTemp >= CLTEMP: The closed loop timer begins ticking toward O2TIME.

3. Tuner's Guide & Real-World Calibration

  • Stock Setting: 0x9B (≈ 77°F). The factory cal enables closed-loop qualification early (at mild ambient temps) to reduce cold-start tailpipe emissions.
