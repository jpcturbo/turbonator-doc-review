1. Overview & Purpose

DCRPMH_NoWastegateDutyCycleCorrectionAboveThisRpm defines the upper engine speed threshold above which adaptive wastegate duty cycle correction is frozen.

Chrysler's adaptive wastegate algorithm was designed specifically to learn and compensate for low-RPM spool-up variations (1504 RPM to 2528 RPM). Above 2528 RPM, the turbo is already fully spooled, so adaptive duty cycle learning freezes to avoid interference with high-RPM closed-loop regulation.

2. Operating Conditions (When Does This Take Effect?)

  • Adaptive RPM Ceiling: Evaluated in ControlWastegate. If EngineRpm > DCRPMH, adaptive duty cycle learning stops.

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x4F (2528 RPM).
  • Big Turbo Upgrades: Large turbos (e.g. Holset HX35, Garrett GT30R) spool later (often between 3000 and 4200 RPM). Raising DCRPMH to 0x80 (4096 RPM) expands the adaptive spool-up learning window to match the spool RPM of the larger turbo.
