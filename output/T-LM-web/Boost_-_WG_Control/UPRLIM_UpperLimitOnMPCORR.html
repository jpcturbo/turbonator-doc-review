1. Overview & Purpose

UPRLIM_UpperLimitOnMPCORR specifies the maximum positive closed-loop duty cycle correction authority clamp (MPCORR).

Limits how much additional duty cycle the closed-loop feedback loop is allowed to add on top of the base table, preventing integral windup and massive boost spikes if a vacuum line leaks or tears.

2. Operating Conditions (When Does This Take Effect?)

  • Positive Correction Clamping: Clamps positive boost error adjustments in ControlWastegate.

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x10 (16 counts = 8% max duty cycle addition).
  • Tuning Guidance: Keeps the closed-loop controller within safe operating boundaries.
