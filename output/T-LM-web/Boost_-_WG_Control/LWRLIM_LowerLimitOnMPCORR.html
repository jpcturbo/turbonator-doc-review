1. Overview & Purpose

LWRLIM_LowerLimitOnMPCORR specifies the maximum negative closed-loop duty cycle reduction authority clamp (MPCORR).

Establishes how much duty cycle the closed-loop controller can pull out to suppress an overshooting boost spike. Notice that Chrysler configured negative authority (0x20 = 16%) twice as large as positive authority (0x10 = 8%) to ensure quick, decisive suppression of dangerous overboost spikes.

2. Operating Conditions (When Does This Take Effect?)

  • Negative Correction Clamping: Clamps negative duty cycle trims in ControlWastegate.

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x20 (32 counts = 16% DC drop).
  • Overshoot Control: Allows the ECU to decisively dump duty cycle if boost starts running away.
