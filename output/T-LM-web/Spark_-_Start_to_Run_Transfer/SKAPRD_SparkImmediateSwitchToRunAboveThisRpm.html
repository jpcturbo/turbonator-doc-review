1. Overview & Purpose

SKAPRD_SparkImmediateSwitchToRunAboveThisRpm is the instantaneous engine start-to-run transfer threshold.

When starting a car, the ECU remains in a dedicated "Cranking / Start Mode" (running locked distributor trigger timing and fixed cranking fuel pulse widths) until the engine flares to life. Under normal cranking, the ECU requires the engine to exceed a lower threshold (STRNTR, ~600 RPM) for a set number of consecutive cylinder pulses (SRTIME) before transferring to "Run Mode".

However, if the engine flares violently or catches immediately and revs past ~800 RPM, waiting for multiple cylinder pulses is unnecessary and could delay dynamic spark advance. SKAPRD provides an immediate bypass: if the distributor pulse period drops below SKAPRD (speed exceeds ~813 RPM), the ECU switches instantly into Run Mode.

2. Operating Conditions (When Does This Take Effect?)

SKAPRD is checked on every distributor ignition interrupt during cranking: * Measured Variable: TimerOverflowsBetweenDistPulses (the 16-bit timer duration between distributor reference pulses). * Inverse Period Relationship: In the 6803 timer, a shorter pulse period represents a higher engine speed. * Trigger Condition: If TimerOverflowsBetweenDistPulses < SKAPRD (engine speed > ~813 RPM), the ECU branches immediately to ENGINE_IDLING_FASTERTHAN_813RPM, bypassing pulse counters and entering Run Mode.

3. Tuner's Guide & Real-World Calibration

  • Increasing the Value (Lower RPM Threshold):
  • What it does: Allows a lower RPM flare to trigger immediate Run Mode.
  • Real-World Driving Feel: The ECU starts controlling dynamic spark advance sooner after cranking. However, if set too low (e.g., near starter cranking speeds of 300–400 RPM), the ECU could prematurely switch into Run Mode during a slow, struggling crank, causing kickback or stalling.
  • Decreasing the Value (Higher RPM Threshold):
  • What it does: Requires the engine to flare higher before immediate transfer occurs.
  • Real-World Driving Feel: Forces the ECU to rely on the consecutive pulse counters (STRNTR and SRTIME), which can make cold starts feel more deliberate but may slightly delay throttle catch.
