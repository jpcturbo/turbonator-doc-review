1. Overview & Purpose

RNSTTR_SparkRunStartTransferPointRpm is the stall-detection hysteresis threshold that drops the ECU back from Run Mode into Start Mode.

Once the engine is running normally, if a sudden RPM sag occurs (such as dropping the clutch too quickly, a severe electrical load, or stalling out), the ECU needs to recognize that the engine is no longer sustaining self-powered rotation. If engine speed falls below RNSTTR (approximately 410 RPM), the ECU disengages dynamic running spark advance and switches back to cranking Start Mode (fixed base timing and cranking fuel pulse widths) to attempt recovery or facilitate immediate restarting.

2. Operating Conditions (When Does This Take Effect?)

RNSTTR is evaluated while the engine is in Run Mode: * If TimerOverflowsBetweenDistPulses increases past RNSTTR (meaning engine speed has dropped below ~410 RPM): The ECU re-sets bit 1 of BitFlags_82 to 1, signaling that the engine has returned to Start/Cranking mode.

3. Tuner's Guide & Real-World Calibration

  • Increasing the Value (Lower RPM Threshold):
  • What it does: Allows the engine to drop lower in speed (e.g., 300 RPM) before conceding that it has stalled.
  • Real-World Driving Feel: Prevents premature switching into cranking mode when lugging the engine at very low speeds, but can cause sluggish recovery if the engine actually dies.
  • Decreasing the Value (Higher RPM Threshold):
  • What it does: Triggers stall recovery / cranking mode at a higher speed (e.g., 500 RPM).
  • Real-World Driving Feel: Drops back to cranking mode sooner. If set too high (too close to idle speed), an abrupt idle dip can trigger cranking mode, causing a sudden surge or stall.

5. Calibration Notes & System Dependencies

  • Hysteresis Band: The difference between STRNTR (~600 RPM) and RNSTTR (~410 RPM) forms a roughly 200 RPM hysteresis deadband. This prevents the ECU from rapidly oscillating between Start and Run modes when idling near the transfer point.
