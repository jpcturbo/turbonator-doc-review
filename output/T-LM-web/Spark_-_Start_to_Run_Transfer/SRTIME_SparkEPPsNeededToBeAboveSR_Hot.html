1. Overview & Purpose

SRTIME_SparkEPPsNeededToBeAboveSR_Hot defines the number of consecutive Engine Position Pulses (EPPs) that the engine must maintain above the start-to-run speed threshold (STRNTR) before transferring spark control to Run Mode when the engine is warm/hot.

When starting a warm engine, cylinder compression is consistent and combustion catches quickly. However, a single cylinder firing during a crank cycle can momentarily whip the crankshaft faster than 600 RPM before slowing down again. SRTIME ensures that the engine has truly caught and is spinning under its own power by requiring 4 consecutive distributor sync events (two full crankshaft revolutions on a 4-cylinder engine) above STRNTR before locking in Run Mode.

2. Operating Conditions (When Does This Take Effect?)

SRTIME is selected when: 1. Engine is Hot: Coolant temperature is at or above SRTMTP (typically ~176°F / 80°C). 2. Cranking Above Threshold: Engine speed is above STRNTR (~600 RPM) but below SKAPRD (~813 RPM).

3. Tuner's Guide & Real-World Calibration

  • Increasing the Value (More Pulses Required):
  • What it does: Keeps the engine in cranking spark mode longer when warm.
  • Real-World Driving Feel: Can help prevent premature transfer on high-compression or alcohol engines that exhibit erratic cranking pulses, but setting it too high causes sluggish startup flare and delayed throttle response.
  • Decreasing the Value (Fewer Pulses Required):
  • What it does: Allows the ECU to switch to normal running advance almost instantly once the engine catches.
  • Real-World Driving Feel: Delivers a fast, crisp warm restart. Stock value is 0x04 (4 pulses = 1 complete engine cycle).
