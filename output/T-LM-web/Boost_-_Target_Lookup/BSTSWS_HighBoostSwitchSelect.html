1. Overview & Purpose

BSTSWS_HighBoostSwitchSelect defines the hardware input pin bitmask used to toggle Turbonator Switchable Boost (High/Low Boost).

Turbonator firmware allows the driver to toggle between a daily-driver "Low Boost" setting and a race "High Boost" setting using a dashboard switch or steering wheel button. BSTSWS selects which physical wire on Logic Module Connector B senses this toggle.

2. Operating Conditions (When Does This Take Effect?)

  • Switchable Boost Check:
  • Enabled when cfg_SwBoost bit is set in CONFIG_ConfigurationFlags.
  • In CalcTargetBoost_MM:
  • Reads Z83_PortCdata and masks with BSTSWS.
  • If low boost is active, branches to LoadLoBoost to clamp target to SWBSLO.

3. Tuner's Guide & Real-World Calibration

  • Pin Bitmask Assignments:
  • 0x01: Cruise Set (Pin B9)
  • 0x02: Cruise Resume (Pin B10 — Factory Default)
  • 0x04: A/C Clutch Sense (Pin B11)
  • 0x08: Park/Neutral (Pin B12)
  • 0x10: Brake Switch (Pin B13)
  • 0x40: Cruise Enable (Pin B15)
  • Custom Toggle Switch: Wire a toggle switch between the chosen pin and ground/12V (matching polarity) to give instant dual-stage boost control.

4. Technical / Assembly Mechanics (Reference)

ldab Z83_PortCdata    ; Read Port C hardware input pins
        bita #cfg_BstSwPol    ; Check polarity bit
        beq  Polarity_Lo
Polarity_Hi:
        andb BSTSWS_HighBoostSwitchSelect ; Test chosen pin
        beq  NoLoBoost        ; If high, keep high boost!
        bra  LoadLoBoost      ; Else drop to low boost!
