1. Overview & Purpose

RESFAC_BoostMapCorrectionResponseFactor defines the proportional closed-loop response gain for wastegate duty cycle correction.

When actual manifold pressure deviates from target boost (Δ extBoost = extActual - extTarget), the closed-loop wastegate controller must modulate duty cycle to eliminate the error. RESFAC scales how aggressively the controller reacts based on the magnitude of the error.

2. Operating Conditions (When Does This Take Effect?)

  • Closed-Loop Boost Correction: Looked up in ControlWastegate using the boost error term.

3. Tuner's Guide & Real-World Calibration

  • Boost Stability vs. Hunting:
  • Higher values speed up wastegate correction, reducing initial boost spike/overshoot.
  • If set too high, the wastegate solenoid will oscillate, causing audible flutter and boost surge.
