1. Overview & Purpose

SSIPRD_ScatterInhibitBelowThisSpeed establishes the low-RPM lockout threshold below which spark scatter idle stabilization is inhibited.

If an engine speed sags severely (below ~565 RPM) toward an impending stall, dithering spark timing can cause erratic combustion torque and finalize the stall. Under near-stall conditions, the ECU inhibits spark scatter dithering and focuses on solid base dwell and maximum timing recovery.

2. Operating Conditions (When Does This Take Effect?)

SSIPRD is evaluated against TimerOverflowsBetweenDistPulses: * Evaluation: If pulse period exceeds SSIPRD (meaning engine speed has dropped below ~565 RPM): The ECU branches to LE312, completely bypassing spark scatter logic.

3. Tuner's Guide & Real-World Calibration

  • Increasing the Value (Lower RPM Lockout):
  • Allows spark scatter to operate down to even lower engine speeds (e.g., 450 RPM).
  • Decreasing the Value (Higher RPM Lockout):
  • Shuts off spark scatter at a higher speed (e.g., 750 RPM).
  • Mopar Performance (MP) MTX Calibration Trick:
  • As noted in the original template comments, official Mopar Performance calibrations occasionally set SSIPRD to 0xFE33 to inhibit scatter across the board and keep revs hanging slightly higher between manual gear shifts for improved drivability and rev-matching.

4. Technical / Assembly Mechanics (Reference)

Inside T-LMv13.asm (lines 4847–4849):

ldx  TimerOverflowsBetweenDistPulses ; Measured pulse period
        cpx  SSIPRD_ScatterInhibitBelowThisSpeed ; Compare to SSIPRD (0x00D0 ~ 565 RPM)
        bcc  LE312                          ; If period >= SSIPRD (RPM <= 565), inhibit scatter!

5. Calibration Notes & System Dependencies

  • Inverse RPM Scaling: Because pulse period is inversely proportional to engine speed, a larger word value corresponds to a lower engine speed lockout.
