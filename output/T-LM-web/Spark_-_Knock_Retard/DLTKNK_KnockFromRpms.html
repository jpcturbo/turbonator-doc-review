1. Overview & Purpose

DLTKNK_KnockFromRpms is the knock sensor sensitivity / noise threshold curve across engine RPM.

A piezoelectric knock sensor mounted to the engine block converts engine vibrations into an AC voltage signal, which the ECU rectifies and reads through an analog-to-digital (A/D) converter. Normal mechanical engine noise (valvetrain action, piston motion, rod bearing clearance) naturally increases with engine speed. To prevent normal mechanical noise from falsely triggering knock retard at high RPM, DLTKNK establishes the baseline noise floor: any knock sensor voltage reading above the curve at that RPM is flagged as real combustion detonation.

2. Operating Conditions (When Does This Take Effect?)

DLTKNK is looked up continuously in KnockDetect_MM: * Lookup Input: EngineRpm_HB. * Action: The result is stored in KnockLookup. When the knock sensor A/D voltage is sampled on each cylinder event, if KnockVolts > KnockLookup, the ECU flags active knock (BitFlags_7f bit 7 = 1) and triggers timing retard.

3. Tuner's Guide & Real-World Calibration

  • Increasing Table Values (Raising the Noise Threshold):
  • What it does: Desensitizes the knock sensor. Requires higher vibration amplitude before knock is flagged.
  • Real-World Driving Feel: Eliminates false knock retard caused by noisy mechanical modifications (forged pistons with loose piston-to-wall clearance, aggressive camshaft profiles, solid lifters, stiff valvetrain springs, or straight-cut timing gears).
  • Cautions: Setting the curve too high blinds the ECU to real detonation, risking engine damage without any protective timing retard!
  • Decreasing Table Values (Lowering the Noise Threshold):
  • What it does: Makes the knock detection system more sensitive.
  • Real-World Driving Feel: Catches faint, low-level detonation early, but risks false knock retard on noisy older engines.
