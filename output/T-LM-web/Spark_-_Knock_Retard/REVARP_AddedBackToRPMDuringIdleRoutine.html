1. Overview & Purpose

REVARP_AddedBackToRPMDuringIdleRoutine defines the reverse (underspeed) RPM deadband offset for the idle timing stabilization system.

If the engine speed dips below target idle, adding REVARP back to the negative error term determines whether the RPM drop is severe enough to warrant immediate timing advance to catch the engine and prevent an impending stall.

2. Operating Conditions (When Does This Take Effect?)

REVARP is evaluated when engine RPM is below target during closed-throttle idle: * If the underspeed delta exceeds REVARP (stock 30 RPM below target): The ECU applies idle underspeed timing advance to increase engine torque and recover engine speed.

3. Tuner's Guide & Real-World Calibration

  • Increasing the Value (Wider Deadband):
  • Tolerates larger RPM drops before kicking in idle advance.
  • Real-world feel: Smooths out lumpy cam idle, but reduces stall protection if the A/C compressor or power steering engages suddenly.
  • Decreasing the Value (Tighter Deadband):
  • Kicks in advance immediately on tiny RPM drops.
  • Real-world feel: Instant catch when coming off throttle or when loads engage, but can cause cyclic hunting on modified engines.

4. Technical / Assembly Mechanics (Reference)
