1. Overview & Purpose

MAXCNT (ProgramLoopsWithThrottleBelow_MINTHR_ToDecrement_MINTHR) is the integration filter counter (stock calibration = 16 loops / ~176 ms) that controls the ratcheting speed of learned closed-throttle baseline MINTHR.

If the throttle return spring pulls the throttle plate tighter against the stop, or as the aluminum throttle body cools down, the closed-throttle voltage might drop slightly below the currently stored MINTHR. If the ECU instantly changed MINTHR on a single spike, electrical noise or ground dips could corrupt the baseline. MAXCNT requires the TPS voltage to remain below MINTHR for 16 consecutive program loops before MINTHR is decremented by 1 step.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside CheckThrottle_AtFullThrottle at line 6768.
  • Decrements Timer_DelayBeforeUpdating_MINTHR whenever TpsVolts < MINTHR.
  • When timer reaches zero, MINTHR decrements by 1 count and reloads MAXCNT.

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x10 (16 loops).
  • Fast Adaptive Learning: Rarely needs modification. Provides rock-solid immunity to ignition coil firing noise on the sensor ground bus.
