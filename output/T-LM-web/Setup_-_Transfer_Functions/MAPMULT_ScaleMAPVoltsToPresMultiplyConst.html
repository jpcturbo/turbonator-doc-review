1. Overview & Purpose

MAPMULT (ScaleMAPVoltsToPresMultiplyConst) is the foundational slope multiplier in the mathematical transfer function that converts analog MAP sensor voltage (MapVolts) into calibrated internal pressure units (MapValue).

In the factory Chrysler 6803 assembly routine ConvertMAPVoltsToValue, the ECU executes:

Pressure = (MAPVolts × MAPMULT) + MAPVolts + MAPADD

  • Stock Mopar 2-Bar Sensor: Calibrated to 0x07. With a 2-Bar sensor, a 5.0V span corresponds to 0 - 208 kPa (~14.7 psi boost).
  • Mopar Super 60 / 3-Bar Sensor: When upgrading to a 3-Bar sensor (measuring up to 300 kPa / ~29 psi boost), the sensor output slope is shallower (1.5× more pressure per volt). Setting MAPMULT to 0x09 (in conjunction with MAPADD = 0x0700) recalibrates the entire ECU to read 3-Bar boost accurately without altering underlying table fuel/spark axes!

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside subroutine ConvertMAPVoltsToValue at line 1200.
  • Executed on every single analog-to-digital MAP conversion pass.
  • Directly determines the scaling of all fuel, spark, boost, and overboost tables.

3. Tuner's Guide & Real-World Calibration

  • 3-Bar MAP Sensor Conversion Guide:
  • For Mopar 2-Bar (Stock): Set MAPMULT = 0x07, MAPADD = 0x0361.
  • For Mopar Super 60 3-Bar: Set MAPMULT = 0x09, MAPADD = 0x0700.
  • For GM / MSD 3-Bar (12223861 / 16040749): May require fine-tuning MAPADD to 0x06C0 - 0x0720 depending on sensor manufacturer offset tolerances.
  • MPTuning Integration: In MPTune, selecting the '3-Bar MAP' option automatically updates MAPMULT and MAPADD to their correct values.

ConvertMAPVoltsToValue:
        staa Temp5                               ; Store raw MAP ADC voltage
        ldab MAPMULT_ScaleMAPVoltsToPresMultiplyConst ; Load slope multiplier ($137C, data 0x07)
        bpl  LC9F3                               
        clr  Temp5                               
LC9F3:  mul                                      ; Multiply: D = MAPVolts * MAPMULT
        adda Temp5                               ; Add MAPVolts (D = MAPVolts * (MAPMULT + 1))
        bcc  LC9FA                               
        ldaa #0xff                               ; Clamp on overflow
LC9FA:  addd MAPADD_ScaleMAPVoltsToPresAddConst  ; Add offset constant ($138B, data 0x0361)
        bcc  LCA01                               
        ldaa #0xff                               ; Clamp to 255 maximum
LCA01:  rts                                      ; Return calibrated MapValue!
