1. Overview & Purpose

PWADD_FuelPWModifierFromBaro provides an additive pulse width trim curve based on ambient barometric pressure (altitude).

At high elevations (low barometric pressure), atmospheric air density drops, reducing cylinder filling. While primary fuel tables (MAPTBL) account for manifold pressure directly, PWADD provides a dedicated offset table to add or subtract a fixed pulse width based on barometric pressure.

2. Operating Conditions (When Does This Take Effect?)

  • Running Fuel Pulse Width Tweaks:
  • Looked up during DetermineFuelTweaks_MM using the barometric pressure value captured at key-on or during WOT.

3. Tuner's Guide & Real-World Calibration

  • Stock Calibration: Flat zero (0x00). The speed-density algorithm and MAP sensor handle altitude compensation naturally without needing an additive barometric offset.
  • Tuning Guidance: Leave at stock zero unless specifically compensating for non-standard altitude-dependent fuel pressure regulators.
