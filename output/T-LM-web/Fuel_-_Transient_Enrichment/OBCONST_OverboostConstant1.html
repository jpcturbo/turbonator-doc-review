1. Overview & Purpose

OBCONST_OverboostConstant1 defines the baseline manifold pressure transition threshold used during running fuel pulse width and spark advance calculation to bifurcate moderate part-throttle fuel scheduling from higher-load boost fuel enrichment.

Despite its historical label name containing "Overboost", in the fuel assembly logic this constant is not the overboost fuel cut threshold (which is handled separately by boost limit routines). Instead, OBCONST serves as a critical manifold pressure breakpoint where the ECU branches its injector pulse width calculation into a dedicated high-load scaling branch.

2. Operating Conditions (When Does This Take Effect?)

  • Running Fuel Calculation:
  • In CalculateInjectorPulsewidthForEngineRunning:
  • Manifold pressure is tested against OBCONST.
  • If MapValue >= OBCONST: The engine has entered high-boost territory. The ECU subtracts OBCONST from MapValue and scales fuel using the dedicated high-load multiplier branch (FuelPulsewidthFunctionUnknown).
  • Spark Advance Calculation:
  • Also evaluated in CalculateSparkAdvance_MM for high-load spark timing compensation.

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0xAA (≈ 4.9 psig boost).
  • Transition Point: Below 4.9 psig boost, base running fuel pulse width scales according to the primary part-throttle equations. Above 4.9 psig boost, additional slope multipliers engage.
  • Tuning Guidance: Generally preserve at factory 0xAA unless re-scaling the entire boost fuel delivery architecture for 3-bar MAP sensors.
