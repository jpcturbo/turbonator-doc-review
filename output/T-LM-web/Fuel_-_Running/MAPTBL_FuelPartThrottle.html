1. Overview & Purpose

MAPTBL_FuelPartThrottle is the core part-throttle speed-density fuel pulse width table.

In Chrysler's speed-density architecture, fuel delivery is broken into a base volumetric pulse width looked up by manifold pressure (MAPTBL), which is subsequently scaled by engine volumetric pumping efficiency (PEFTBL), charge air temperature (AIRTMP), and warm-up modifiers. MAPTBL establishes the base fueling slope for light cruise and part-throttle acceleration from deep vacuum up to positive manifold boost.

2. Operating Conditions (When Does This Take Effect?)

MAPTBL is looked up during part-throttle warmed-up running: * Throttle State: Throttle is open off-idle (BitFlags_81 bit 7 = 1), but has not reached WOT (BitFlags_81 bit 0 = 0). * Closed-Throttle Bypass: If throttle is closed (idle/decel), the ECU bypasses MAPTBL and looks up MAPIDL. * WOT Ceiling: As boost builds, MAPTBL is blended with part-throttle enrichment (Timer_OpenLoopFraction), with WOTTBL acting as a hard upper ceiling clamp.

3. Tuner's Guide & Real-World Calibration

  • Increasing Table Values (Richer Part-Throttle Fuel):
  • Effect: Delivers longer injector pulse widths across the specified MAP range.
  • Real-World Feel: Enriches cruising air/fuel ratios, eliminates light-throttle lean stumbles, and cools down cruising exhaust gas temperatures (EGTs).
  • Decreasing Table Values (Leaner Part-Throttle Fuel):
  • Effect: Shortens injector pulse widths across the specified MAP range.
  • Real-World Feel: Leans out cruising AFR for improved fuel economy. If leaned excessively, causes cruising surge, lean hesitation, and elevated EGTs.
  • Injector Rescaling:
  • Marked with ;mpinjscale scale. When upgrading injector sizes in MPTune, MAPTBL is scaled globally by the injector constant.
