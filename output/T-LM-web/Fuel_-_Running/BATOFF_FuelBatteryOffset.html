1. Overview & Purpose

BATOFF_FuelBatteryOffset defines the injector dead time / battery latency compensation curve as a function of system electrical voltage.

An electronic fuel injector is an electromagnetic solenoid with mechanical inertia. When the ECU grounds the injector circuit, electrical magnetic field buildup and pintle opening take a finite duration (typically 0.6 to 1.5 milliseconds) before fuel actually begins spraying. At lower system voltages (such as during starter cranking at 9–10V or when the alternator fails), the coil builds magnetic flux much more slowly, resulting in a longer opening delay. BATOFF adds an additional voltage-dependent pulse width offset to ensure that the actual effective fuel delivery matches the ECU's calculated target regardless of electrical system fluctuations.

2. Operating Conditions (When Does This Take Effect?)

BATOFF is looked up continuously on every single injection calculation (both cranking and running): * Lookup Input: Current system voltage A/D reading. * Math: Looked-up latency is shifted left (asld, multiplied by 2) and added directly to the calculated base pulse width immediately before the final hardware timer load.

3. Tuner's Guide & Real-World Calibration

  • Aftermarket Injector Tuning:
  • When installing modern high-impedance or large aftermarket injectors (e.g., Bosch EV14s, Deka 60s, or RC injectors), setting accurate BATOFF values is critical. Different injector coils have vastly different opening latencies.
  • Symptoms of Incorrect BATOFF:
  • If BATOFF is set too low: The engine will run severely lean when radiator fans kick on, headlights are turned on, or during starter cranking.
  • If BATOFF is set too high: The engine will run excessively rich whenever system voltage drops.
  • Idle Stability:
  • Because idle pulse widths are small (~1.5–2.5 ms), dead time makes up nearly 50% of the total commanded pulse width at idle! Accurate BATOFF data is essential for stable idle AFR.
