1. Overview & Purpose

OFFPER (AisInstantlyClosesWhenAcDisengages) defines a fractional scalar (stock calibration = 0x80 = 128/256 = 50%) multiplied against the speed-dependent A/C table ACCTBL when calculating running AIS position with the A/C clutch disengaging during warm operation.

It provides a 50% intermediate attenuation factor to softly taper off the dynamic A/C bypass airflow rather than chopping it off abruptly.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside CalculateTargetIdleSpeedAndAisPosition_MM at line 5260.
  • Active when bit 3 of BitFlags_85 is set during warm A/C processing.
  • Multiplies looked-up ACCTBL value: ldab OFFPER; mul; adca #0x00.

3. Tuner's Guide & Real-World Calibration

  • Tuning Decel Feel: Setting to 0x80 gives a 50% airflow reduction upon clutch disengagement. Setting to 0x40 leaves 25% airflow; setting to 0xC0 leaves 75% airflow.
