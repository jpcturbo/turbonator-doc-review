1. Overview & Purpose

DCALTM (DacalInhibitTimeAfterStartup) specifies a lockout time delay immediately after the engine starts during which DACAL (Decel Adaptive Calibration) is forbidden from modifying adaptive idle airflow memories.

Immediately after an engine fires up, oil pressure is building, alternator charging voltage is fluctuating, and initial cylinder wall wetting is still stabilizing. Any adaptive learning performed during these initial seconds would learn transient friction instead of true throttle body leakage. DCALTM inhibits DACAL learning until KeyOnOrEngineRunningTime exceeds this threshold (stock calibration = 21 ticks / ~2.3 seconds).

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated in CalculateAisPosition_MM at line 3593.
  • Compares KeyOnOrEngineRunningTime against DCALTM.
  • If running timer is less than DCALTM (bcs LDA74), the routine exits without updating DACAL adaptive trims.

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x15 (~2.3 seconds).
  • Tuner Adjustments: Rarely needs alteration. If an engine has extreme cold-start flare or prolonged cranking recovery, increasing DCALTM to 0x30 (~5 seconds) ensures the engine has settled completely before idle learning activates.
