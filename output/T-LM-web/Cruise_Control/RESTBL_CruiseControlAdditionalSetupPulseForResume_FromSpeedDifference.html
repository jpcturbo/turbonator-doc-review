1. Overview & Purpose

RESTBL (CruiseControlAdditionalSetupPulseForResume_FromSpeedDifference) specifies an additional vacuum setup pulse added to the base setup pulse when the driver engages "RESUME".

When resuming cruise from a speed lower than the memorized target, the engine requires immediate additional throttle authority beyond a standard steady-state SET engagement. RESTBL calculates extra vacuum duration proportional to the deficit between current road speed and the stored target speed, pre-charging the servo bellows aggressively to begin pulling the vehicle back up to speed immediately.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside subroutine CruiseControlSet at line 2162.
  • Triggered upon receiving a valid RESUME switch signal while vehicle speed is below stored set speed.
  • Added directly to the baseline SETPW value.

3. Tuner's Guide & Real-World Calibration

  • Resume Hesitation: If tapping Resume produces an initial hesitation before the car begins accelerating, increase RESTBL.
  • Resume Kick: If hitting Resume causes an uncomfortably sharp jerk of the throttle, decrease the lower slope of RESTBL.
