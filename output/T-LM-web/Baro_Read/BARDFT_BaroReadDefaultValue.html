1. Overview & Purpose

BARDFT (BaroReadDefaultValue) defines the nominal sea-level fallback atmospheric pressure (stock calibration = 0x7F / 127 decimal = 29.92 inHg / 101.325 kPa standard atmosphere).

If the MAP sensor is disconnected, if the baro solenoid harness is damaged, or if an in-flight atmospheric reading fails either BAROHI or BAROLO boundary tests, the ECU loads BARDFT into BaroPressure. This ensures that all fuel modifier tables, baro-compensations (BARAIS, BARFLR), and target boost altitude calculations fall back to nominal sea-level operation, keeping the engine running safely with standard baseline fueling.

2. Operating Conditions (When Does This Take Effect?)

  • Loaded whenever BaroPressure fails plausibility checks in BaroReadIfRequired (line 4264) or CheckBaroPressure (line 4961).
  • Applied as the baseline barometric reference during sensor fault recovery.

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x7F (127 decimal = standard 1.0 atmosphere).
  • High Altitude Permanent Relocation: If a vehicle operates exclusively at high altitude (e.g. Denver, CO at 5,280 ft where average baro is ~25 inHg / 0x6A), and has a deleted or non-functional baro solenoid, changing BARDFT to 0x6A ensures that even during limp-home fallback, baseline altitude fuel and spark trims remain accurate.
