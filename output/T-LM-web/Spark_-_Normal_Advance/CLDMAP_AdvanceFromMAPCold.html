1. Overview & Purpose

CLDMAP_AdvanceFromMAPCold defines the base MAP-dependent ignition advance curve used exclusively when the engine coolant temperature is below normal operating temperature (TMPSWP).

During cold operation, fuel atomization is poor and combustion chamber wall quenching slows down the initial flame front speed. To ensure smooth combustion, prevent stalling, and provide adequate cold drive-away power without causing backfires, CLDMAP supplies a tailored spark curve as a function of intake manifold pressure.

2. Operating Conditions (When Does This Take Effect?)

CLDMAP is active when: 1. Engine is Cold: Coolant temperature is strictly below TMPSWP_EngTempSwitchPointForSparkAdvance (typically < 166°F / 74°C). 2. All Throttle Positions: Unlike warm operation (which splits into separate part-throttle and full-throttle curves), CLDMAP serves as the base MAP advance curve for both idle and off-idle when cold. - Exception: If the throttle is closed (idle/coast), advance from CLDMAP is capped at the ceiling defined by CLDLMT_LimitForColdMapAtClosedThrottle.

3. Tuner's Guide & Real-World Calibration

The value looked up from CLDMAP is placed into Temp0 and later combined with RPM advance (GOVNER) to calculate total ignition timing.

  • Increasing Table Values (Adding Timing in CLDMAP):
  • Effect on Total Timing: Advances cold-engine ignition timing across the corresponding manifold pressure range.
  • Real-World Driving Feel: Can improve cold throttle response and engine pep during the first few minutes of driving. However, excessive cold advance under boost or load can cause cold-engine detonation or spark scatter.
  • Decreasing Table Values (Pulling Timing in CLDMAP):
  • Effect on Total Timing: Retards cold-engine ignition timing across the corresponding manifold pressure range.
  • Real-World Driving Feel: Causes softer cold acceleration and slower warm-up. If retarded excessively, it can lead to cold hesitation, misfires, or popping through the intake.
  • Closed-Throttle Interaction:
  • If adjusting the vacuum portion of CLDMAP to modify cold idle, be aware that CLDLMT caps the maximum allowable advance when the throttle is closed.

Table Data (Stock A171 Calibration):

Number of points: 3
Point 1: MAP = 0x5E (~18 inHg vacuum) -> Advance = 0xF4 (-12 / 2 = -6.0°)
Point 2: MAP = 0x70 (~11 inHg vacuum) -> Advance = 0x0A (+10 / 2 = +5.0°)
Point 3: MAP = 0xB8 (~7.5 psi boost)  -> Advance = 0xFE (-2 / 2  = -1.0°)

(Values are signed 2's complement where 1 bit = 0.5° crankshaft advance).

5. Calibration Notes & System Dependencies

  • Park/Neutral Idle Offset: If the vehicle is an automatic transmission in Park or Neutral at low cold RPM, an additional offset (PNIDLE) is added to Temp0 downstream.
  • Cold Clamping: Always tune CLDMAP in conjunction with CLDLMT to ensure idle timing stays within stable bounds.
