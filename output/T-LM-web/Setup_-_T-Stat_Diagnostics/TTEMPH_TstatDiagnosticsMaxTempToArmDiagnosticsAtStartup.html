1. Overview & Purpose

TTEMPH (TstatDiagnosticsMaxTempToArmDiagnosticsAtStartup) defines the upper temperature boundary (stock calibration = 0xE4 / ~228°F) for arming the thermostat diagnostic monitor.

If the engine is restarted while already fully warmed up (e.g. stopping for fuel or restarting a warm engine), the thermostat diagnostic is redundant because the engine is already past operating temperature. If startup coolant temperature is at or above TTEMPH, the monitor is bypassed.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated in ResetRoutine at line 5760.
  • Compares CoolantTemp against TTEMPH.
  • If CoolantTemp >= TTEMPH (bcc LE9EB), arms are disabled.

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0xE4 (~228°F).
  • Tuner Usage: Retain stock setting. Prevents unnecessary diagnostic timer execution on hot engine restarts.
