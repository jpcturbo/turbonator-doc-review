1. Overview & Purpose

AMBHIG (BattTempHighWhenCold) establishes the upper electrical boundary (stock calibration = 0xFD / ~4.96V) for the battery temperature thermistor.

If the under-battery sensor is unplugged, the internal pull-up resistor pulls the circuit to 5.0V (> AMBHIG). The ECU detects the open circuit, logs Fault Code 43, and locks the internal voltage regulator to standard default 13.8V - 14.2V charging.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated in DetermineBattTemp at line 1048 and DetermineTargetBatteryVoltage_MM at line 1304.
  • Compares AmbientAirTempVolts against AMBHIG.
  • If AmbientAirTempVolts > AMBHIG (bhi LC94E), flags fault.

3. Tuner's Guide & Real-World Calibration

  • Diagnostics: A continuous Code 43 on a factory restoration typically indicates a missing battery tray sensor or corroded harness plug beneath the tray.
