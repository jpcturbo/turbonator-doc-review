1. Overview & Purpose

TMPHIG (OutOfRangeColdTooHighA2D) establishes the upper electrical limit for the Engine Coolant Temperature sensor input.

Because the ECU's 5V pull-up resistor pulls the circuit up to 5.0V when unplugged, an open circuit, disconnected sensor plug, or broken signal wire will cause the ADC to read 4.96V - 5.0V (0xFD - 0xFF). If the ADC reading equals or exceeds TMPHIG, the ECU flags an open-circuit fault, stores Fault Code 22, forces the radiator cooling fan ON continuously as a fail-safe, and substitutes default temperature DEFTMP.

3. Tuner's Guide & Real-World Calibration

  • Diagnostics: If the radiator cooling fan runs at full speed the instant the key is turned on, and Code 22 is stored, check whether the two-pin coolant temperature sensor on the thermostat housing is unplugged or has corroded connector pins.
