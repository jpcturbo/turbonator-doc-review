1. Overview & Purpose

FUELTR (FuelMonitorConversionFactor) is a 16-bit calibration constant (stock calibration = 0x0311 = 785 decimal) that calibrates the fuel consumption output signal sent from the ECU to the vehicle's dashboard Electronic Navigator / 12-button trip computer (often factory equipped in Daytona, Lancer, LeBaron, and Laser models).

The ECU monitors injector pulsewidth duration. Each time cumulative injector on-time integrates to equal FUELTR, the ECU toggles Port B bit 6 (Z83_PortBdata, line 6283), sending a discrete electrical pulse to the trip computer. The overhead console uses these pulses, combined with vehicle distance sensor pulses, to calculate live Instant MPG, Average MPG, and Gallons Consumed.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside subroutine A2DScan_MM at line 6279.
  • Subtracts FUELTR from accumulator Timer_FuelMonitorOutputTimer_HB.
  • Whenever the subtraction does not borrow, toggles Port B bit 6 output.

3. Tuner's Guide & Real-World Calibration

  • Upgraded Injectors (e.g. +20%, +40%, or 52 lb/hr): When installing larger fuel injectors, the trip computer will display absurdly optimistic fuel economy (e.g. 50+ MPG) because shorter pulsewidths are required to deliver the same fuel mass. To recalibrate the factory trip computer for larger injectors, increase FUELTR proportionally!
  • Formula: New FUELTR = Stock FUELTR × ((New Flow Rate / Stock Flow Rate)).
  • For example, installing +40% injectors (1.40× flow) requires increasing FUELTR by 40% (785 × 1.40 = 1099 / 0x044B). This restores 100% factory-accurate MPG readouts on the dashboard!
