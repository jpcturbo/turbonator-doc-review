1. Overview & Purpose

DFTOC2 (SomeKindOfDefaultValueForOCR2) is a 16-bit hardware timer reload constant (stock calibration = 0x07D0 = 2,000 clock cycles / ~2.0 milliseconds) loaded into the Motorola 6803 CPU's internal Output Compare Register 2 (OCR2).

The 6803 MCU utilizes internal hardware timer match interrupts to generate precise, jitter-free software clocks for injector pulsewidth scheduling, ignition coil dwell charging, and analog-to-digital converter multiplexing. DFTOC2 reloads the hardware compare match register during timer interrupt service routine HandleOtherTimerInterrupts.
