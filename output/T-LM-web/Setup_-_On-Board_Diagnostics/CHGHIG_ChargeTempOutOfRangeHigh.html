1. Overview & Purpose

CHGHIG (ChargeTempOutOfRangeHigh) sets the upper electrical threshold (stock calibration = 0xFE / ~4.98V) for the Intake Manifold Air Charge Temperature sensor.

If the ACT sensor connector is unplugged or a wire breaks, the ECU's internal pull-up resistor pulls the circuit up to 5.0V. When the ADC reading reaches or exceeds CHGHIG, the ECU flags an open-circuit condition, stores Fault Code 23, and substitutes default air charge temperature DEFCHG.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated in CheckAndFilterChargeTempSensor_MM at line 897.
  • Compares charge temp ADC against CHGHIG.
  • If ChargeTempADC >= CHGHIG (bcc), sets open-circuit fault flag.

3. Tuner's Guide & Real-World Calibration

  • Intercooler Piping / Sensor Relocation: When relocating the charge temp sensor into aftermarket intercooler plumbing, ensure the sensor body or harness connector makes solid contact. Disconnected sensors trigger Code 23 immediately.
