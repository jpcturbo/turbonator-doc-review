1. Overview & Purpose

THRHIG (ThrottleUpperLimit) sets the maximum valid electrical ceiling (stock calibration = 0xF0 / ~4.70V) for the Throttle Position Sensor signal.

Even at 100% wide open throttle, physical throttle linkage geometry and sensor potentiometer tracks rarely exceed 4.2V - 4.5V. If the sensor ground wire breaks or corrodes, the ECU's internal pull-up resistor or reference rail pulls the TPS signal pin up to 4.8V - 5.0V (> THRHIG). The ECU detects this out-of-range condition, logs Fault Code 24, and activates limp-home MAP substitution.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside CheckThrottleRoutine_MM at line 6709.
  • Compares TPSVolts_11msUpdate against THRHIG.
  • If TpsVolts >= THRHIG (bcc CheckThrottle_BadTpsSignal), triggers Code 24.

3. Tuner's Guide & Real-World Calibration

  • Aftermarket High-Angle Sensors: Ensure wide-open throttle voltage does not hit or exceed 4.70V on custom throttle quadrant linkages.
