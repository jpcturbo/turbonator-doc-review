1. Overview & Purpose

TMPLOW (OutOfRangeHotTooLowA2D) defines the lower electrical voltage limit for the Engine Coolant Temperature (ECT) sensor input.

The ECT sensor is a negative temperature coefficient (NTC) thermistor supplied by an internal 5V pull-up resistor inside the ECU. As coolant temperature rises, sensor resistance drops, causing the signal voltage to decrease. Under maximum engine operating temperatures, coolant voltage rarely drops below 0.6V (~240°F). If the signal voltage drops below TMPLOW (stock calibration = 0x1A / ~0.51V), the ECU detects that the signal wire is pinched, shorted to ground, or the sensor element has collapsed. The ECU logs Fault Code 22, turns on the Power Loss light (if masked in IPLMSK), and substitutes default temperature DEFTMP.

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x1A (~0.51V).
  • Diagnostics: If Code 22 is present and live scan tool data shows 250°F+, inspect the coolant sensor harness for a pinched wire touching the cylinder head or exhaust shield.
