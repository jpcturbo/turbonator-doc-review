1. Overview & Purpose

STTIME (AdditionalStartupIdleTime) sets the time duration during which the startup idle flare adder (DRIDHT) is added to the base target idle speed.

Once the engine transitions from cranking to running, the runtime timer KeyOnOrEngineRunningTime begins incrementing. While this counter is strictly less than STTIME, the ECU holds the target idle speed higher by DRIDHT. As soon as the timer reaches STTIME, the target idle speed immediately drops back to the steady-state coolant temperature curve (AISPN or AISCLD).

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated in DetermineTargetIdleSpeed_MM at line 5364.
  • Active while KeyOnOrEngineRunningTime < STTIME.
  • Applies equally across automatic and manual calibrations.

3. Tuner's Guide & Real-World Calibration

  • Increasing STTIME: Extends the post-start elevated idle period. Useful for cold-start stability in freezing climates or with large injectors where fuel puddling requires extra time to establish a steady wall film.
  • Decreasing STTIME: Shortens the flare period, allowing the engine to return to normal base idle faster.
  • Stock Value: 0x0B (~1.1 seconds). Tuning above 0x20 (~3.5 seconds) will cause an unnaturally prolonged high idle flare upon every startup.
