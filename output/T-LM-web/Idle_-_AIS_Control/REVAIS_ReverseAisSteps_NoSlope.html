1. Overview & Purpose

REVAIS (ReverseAisSteps_NoSlope) is a stepped lookup table that dictates how many reverse (closing) steps the ECU commands the AIS stepper motor to take when the engine is idling faster than target idle speed.

When external engine load is removed (such as A/C compressor cycling off, radiator fan turning off, or clutch disengagement), engine RPM floats above TargetIdleSpeed_HB. The ECU calculates the overspeed error (Actual - Target) / 4. REVAIS outputs negative step adjustments (-1, -2, -4 steps) to gently pull the engine back down to target speed without causing an underspeed sag.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside CalculateTargetIdleSpeedAndAisPosition_MM at line 5176.
  • Active when EngineRpm_HB > TargetIdleSpeed_HB (engine is above target).
  • Executed when Timer_AisChanges exceeds DCLRF2.

3. Tuner's Guide & Real-World Calibration

  • Slow Return to Idle: If the engine revs and takes an excessively long time to settle back down to idle after load is removed, increase the reverse steps in REVAIS.
  • Decel Dipping / Stumble: If the engine drops rapidly and undershoots idle speed when load turns off, REVAIS is closing the bypass valve too aggressively. Soften the reverse step counts.
