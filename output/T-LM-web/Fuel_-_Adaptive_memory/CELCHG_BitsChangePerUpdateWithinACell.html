1. Overview & Purpose

CELCHG_BitsChangePerUpdateWithinACell dictates the step increment size by which an adaptive fuel memory cell is modified each time an update condition is triggered.

Long-term fuel trims are designed to be a slow, steady integrator that adapts to gradual engine wear, air filter loading, or fuel seasonal blend shifts. CELCHG governs the learning rate of this integrator. A value of 1 bit ensures smooth, gradual long-term fuel adjustment without rapid jumps.

2. Operating Conditions (When Does This Take Effect?)

  • Cell Adaptation Trigger:
  • When all update prerequisites are satisfied (closed loop active, steady load, off-boost, short-term error > CALTHR, and event timer > AMUPDT).
  • If short-term trim is positive (lean mixture): CELCHG is added to the cell.
  • If short-term trim is negative (rich mixture): CELCHG is negated and subtracted from the cell.

3. Tuner's Guide & Real-World Calibration

  • Stock Setting: 0x01 (≈ 0.2% per step).
  • Increasing CELCHG (e.g. 2 or 3):
  • Accelerates adaptive learning speed after a battery disconnect.
  • Risk: Can lead to adaptive hunting or overshoot on bumpy roads.
  • Tuning Recommendation: Keep at 0x01 for maximum calibration stability.
