1. Overview & Purpose

MP1_AutoCalMapCellBoundary1 defines the first manifold pressure load boundary separating Adaptive Fuel Memory Cell 0/1 from Cell 2/3.

The Chrysler T-LM ECU divides off-idle part-throttle operation into a grid of 12 adaptive fuel memory cells (6 MAP load bands × 2 RPM bands). MP1 represents the lowest MAP transition point, dividing extreme high-vacuum decel/light-coast conditions from normal light-load cruise.

2. Operating Conditions (When Does This Take Effect?)

  • Cell Selection:
  • In AdaptiveMemory_DetermineWhichCellApplies_MM, when the throttle is open, MapValue is compared sequentially against MP1, MP2, MP3, MP4, and MP5.
  • If MapValue <= MP1: Adaptive cells 0 (low RPM) or 1 (high RPM) are selected.
  • If MapValue > MP1: Cell pointer advances toward higher load cells.
  • Hysteresis: DLTMAP is added to MP1 when exiting the cell to prevent boundary chatter.

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x24 (≈ 21.6 inHg vacuum).
  • Engine Dynamics: Cell 0/1 covers very light throttle cruise or downhill overrun.
  • Altering Boundaries: When running higher-duration performance camshafts with reduced idle and decel vacuum, MP1 may be adjusted higher to ensure light cruise does not bleed into the decel cell.
