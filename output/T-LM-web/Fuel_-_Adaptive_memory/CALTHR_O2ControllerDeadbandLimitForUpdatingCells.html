1. Overview & Purpose

CALTHR_O2ControllerDeadbandLimitForUpdatingCells defines the short-term fuel feedback deadband threshold required to trigger an update to long-term adaptive memory.

The ECU should only update long-term adaptive fuel trim cells when short-term closed loop feedback has accumulated a persistent, meaningful error. If short-term feedback is oscillating symmetrically near zero, the base calibration is already accurate, and no adaptive trim update is needed. CALTHR establishes the minimum error magnitude required before a cell is nudged richer or leaner.

2. Operating Conditions (When Does This Take Effect?)

  • Adaptive Memory Update Evaluation:
  • Evaluated inside UpdateAdaptive_OffIdle.
  • The short-term O2 feedback counter (Counter_PrimaryAndSecondaryRamp) is checked against CALTHR.
  • If the absolute value of the short-term feedback counter is less than CALTHR: The short-term trim is within acceptable deadband tolerance. Adaptive memory update is skipped!
  • If short-term feedback exceeds CALTHR: The base table is meaningfully off; the ECU proceeds to update the current cell by CELCHG.

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x09 (9 counts).
  • Increasing CALTHR:
  • Requires larger persistent fueling errors before adaptive trim shifts.
  • When to Use: If long-term trims wander around excessively due to weather changes or sensor noise, increasing CALTHR makes adaptive memory more conservative.
  • Decreasing CALTHR:
  • Causes adaptive cells to react and update to smaller deviations, making trims more aggressive. If set too small (e.g. 1 or 2), normal closed-loop cross-count ripple will cause adaptive cells to constantly drift.
