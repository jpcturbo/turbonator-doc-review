1. Overview & Purpose

STFTMP_FuelStartFuelFromCoolant is an additional coolant temperature weighting factor applied to the barometric starting fuel reduction calculation.

While STFBAR provides the primary baro-based reduction factor, STFTMP allows calibrators to scale how strongly that altitude reduction applies as the engine warms up. In the stock A171 calibration, this table is set to a constant 100% factor (0xFF), allowing STFBAR to apply full barometric reduction across all temperatures.

2. Operating Conditions (When Does This Take Effect?)

STFTMP is looked up during cranking: * Lookup Input: Current CoolantTemp. * Combination: Multiplied by STFBAR(BaroPressure):

Effective Reduction = (STFBAR(Baro) × STFTMP(CoolantTemp) / 256)

3. Tuner's Guide & Real-World Calibration

  • Stock Setting (0xFF): Multiplier is 1.0 (full barometric reduction allowed).
  • Decreasing Table Values: Dampens altitude fuel reduction at cold temperatures, preserving extra rich cranking fuel for cold morning mountain starts.
