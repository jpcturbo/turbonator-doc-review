1. Overview & Purpose

LTHTIM_IfNoO2SwitchForThisTimeThrowFault51or52 sets the diagnostic fault timeout for detecting a permanently stuck or unresponsive oxygen sensor during closed-loop operation.

If an oxygen sensor fails to toggle across stoichiometric for a sustained period while closed loop is active, it indicates an unrecoverable air/fuel control failureâ€”such as a massive vacuum leak, failed fuel pressure regulator, clogged injector, or dead sensor. When the inactivity timer reaches LTHTIM, the ECU logs Fault 51 (stuck lean) or Fault 52 (stuck rich), erases all learned adaptive fuel memory cells, and locks out closed-loop trimming.

2. Operating Conditions (When Does This Take Effect?)

  • Inactivity Counter Accumulation:
  • Evaluated inside EraseAdaptiveMemory_possiblySetErrorBit.
  • Counter_AdaptiveMem_Erase increments every 2.8 seconds whenever the O2 sensor remains on one side of stoichiometry without a cross-count toggle.
  • Fault Trigger Threshold:
  • When Counter_AdaptiveMem_Erase >= LTHTIM:
    • Evaluates whether the sensor was stuck rich or lean.
    • Calls ThrowNonCriticalError with Fault 51 (lean) or Fault 52 (rich).
    • Executes EraseAdaptiveMemoryLocations, resetting all 14 adaptive fuel memory cells (AutoCalCell0 through AutoCalCell12idle) back to baseline neutral.

3. Tuner's Guide & Real-World Calibration

  • Stock Setting: 0xFE (254 counts × 2.8 s ≈ 711 seconds ≈ 11.9 minutes).
  • Diagnostic Ramifications:
  • When Fault 51 or 52 is set, your learned adaptive fuel trims are instantly wiped out. The car will revert to pure baseline open-loop tables until the fault condition clears.
  • Tuning with Wideband / Open Loop Only:
  • If you disable closed-loop control or run an aftermarket standalone/piggyback wideband without narrow-band emulation, the inactivity timer will eventually expire if closed-loop flags remain set. Ensure closed-loop is cleanly disabled or that LTHTIM is configured to prevent erroneous CEL triggers.
