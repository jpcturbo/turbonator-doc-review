1. Overview & Purpose

RICHSA establishes the open-loop fuel enrichment factor injected whenever the engine controller enters mechanical basic ignition timing service mode.

To properly synchronize distributor orientation with true engine top dead center using a timing light, the technician disconnects the coolant temperature sensor, forcing a coolant sensor diagnostic fault. In response, the engine controller locks ignition advance to a fixed reference angle, commands a steady idle airflow, and loads RICHSA as a rich open-loop fueling multiplier.

In factory calibrations, RICHSA is set to 26 counts. This provides extra fuel dampening to stabilize combustion, prevent lean misfiring, and suppress engine speed oscillations while closed-loop oxygen sensor feedback and adaptive fuel memory updates are temporarily suspended.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosing Routine: DealWithSpecialIdle_SetBasicTiming_MM (T-SMEC_v19.asm:5813-5835).
  • Gating Conditions:
  • Throttle state must be closed; tested via BitFlags_4f bit b4f_OffIdle at line 5814. If set (off-idle), branches to THROTTLE_PRESSED1 and clears enrichment.
  • Coolant temperature sensor fault flag b45_BadCoolantTemp in b45_IPL1 must be set at line 5816 (triggered when the coolant sensor connector is unplugged or shorted to ground for timing setup).
  • Diagnostic enrichment timer Timer_OffThrottleFuelEnrich is loaded with RICHSA at line 5833, which in turn suspends oxygen sensor switching and adaptive trim updates.

3. Tuner's Guide & Real-World Calibration

  • Factory Baseline & Retention:
  • Retain RICHSA at its factory value of 26 counts for standard street engines to maintain predictable open-loop fueling during distributor synchronization.
  • Aftermarket Camshafts & Overlap:
  • Raising RICHSA slightly (up to 30 to 35 counts) helps stabilize erratic combustion on aggressive camshafts that generate poor idle manifold vacuum.
  • Large Injector Considerations:
  • When installing large aftermarket fuel injectors, ensure overall fuel scaling is trimmed so that the uncorrected multiplier in RICHSA does not saturate cylinders or foul spark plugs during timing light alignment.
  • Lowering & Lean Stumbles:
  • Lowering RICHSA below 20 counts can produce lean idle instability, causing the engine to surge or die when entering diagnostic basic timing mode.

5. Calibration Notes & System Dependencies

  • Companion Parameter: Operates directly alongside SPKSET, which locks spark timing to a static 12 degrees BTDC while RICHSA supplies rich open-loop fueling.
  • Service Procedure: Chrysler factory service manual instructions require unplugging the coolant temperature sensor on a fully warmed engine, which forces b45_BadCoolantTemp, setting timing to SPKSET and enrichment to RICHSA.
  • Lineage: Inherited directly from the Turbo Chrysler Logic Module architecture, where rich idle open-loop enrichment was standard protocol during service distributor alignment.
