1. Overview & Purpose

SPKSET defines the fixed reference spark advance angle commanded by the engine controller when operating in mechanical basic timing mode.

Under normal running conditions, the Chrysler SMEC constantly modulates ignition timing based on engine speed, manifold pressure, charge temperature, and knock feedback. However, during mechanical distributor installation or timing synchronization, electronic spark advance must be completely frozen so the technician can align the distributor housing with the engine timing pointer using a timing light.

When the coolant temperature sensor is disconnected, setting the sensor fault flag, the controller bypasses all advance tables and locks ignition timing precisely to SPKSET.

In factory calibrations, SPKSET is configured to 12 degrees BTDC, matching the physical timing marks stamped on the engine bellhousing window and flywheel rim.

3. Tuner's Guide & Real-World Calibration

  • Flywheel Mark Alignment:
  • Keep SPKSET at 12 degrees BTDC to correspond exactly with the Chrysler factory timing pointer and flywheel scribed mark.
  • Custom Triggering & Pointers:
  • If utilizing custom degree rings or non-standard engine balance marks (such as 10 degrees BTDC), reconfigure SPKSET to match the physical pointer precisely.
  • Tuning Pitfall:
  • Do not alter SPKSET in an attempt to add global ignition advance. Altering this value only distorts the calibration reference during distributor alignment, skewing all normal advance tables by that exact angular error.

  • Fixed Advance Architecture: Setting timing via SPKSET bypasses all MAP advance lookups (Lookup4ByteTable), knock retard, coolant modifiers, and spark scatter.
  • Companion Parameter: Works alongside RICHSA, ensuring stable open-loop combustion while timing is physically verified.
