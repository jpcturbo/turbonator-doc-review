1. Overview & Purpose

CALRAT defines the loop counter bitmask that paces how frequently the engine controller nudges the automatic idle speed stepper motor toward its nominal idle position.

When the engine is idling at steady state with engine speed within a narrow window around target idle, the ECU gradually converges the stepper motor toward the calibrated baseline step position set in CALPOS. To prevent this centering action from causing perceptible idle speed fluctuations or fighting closed-loop proportional corrections, updates must occur very slowly.

CALRAT masks the main program loop counter to enforce a deliberate update interval.

In factory calibrations, CALRAT is configured to 7 counts, which functions as a binary bitmask allowing an adjustment only once every 8 main loop cycles, or approximately every 88 milliseconds.

  • Motor desired and current position must match (DesiredNewAisPosition == CurrentAisPosition) at line 1968.

3. Tuner's Guide & Real-World Calibration

  • Pacing Centering Action:
  • Keep CALRAT at 7 counts for factory-like convergence pacing toward CALPOS.
  • Slowing Adaptive Wander:
  • On engines with aftermarket camshafts where idle airflow requirements drift slightly with engine temperature, raise CALRAT to 15 or 31 counts to slow down background position nudging.
  • Surge Hazard:
  • Do not set CALRAT to 0 or 1, as rapid position nudging will conflict directly with the FWDAIS/REVAIS feedback loops.

4. Technical / Assembly Mechanics (Reference)

Inside T-SMEC_v19.asm: In CalculateAisPosition_MM at line 1951, the CPU loads Counter_MainLoop into accumulator B. Line 1952 executes bitb CALRAT_AisAdjustRate. If any bit in the mask is non-zero, bne R1075 branches immediately to return, bypassing the adjustment. Only when the masked counter reaches zero does execution proceed to check RPM error and nudge the motor toward CALPOS.
