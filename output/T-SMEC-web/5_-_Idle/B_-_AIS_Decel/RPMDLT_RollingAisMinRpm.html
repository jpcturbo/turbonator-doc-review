1. Overview & Purpose

RPMDLT defines the engine speed tolerance adder above target idle speed that permits entry into rolling idle mode on manual transmission vehicles.

While coasting in neutral below the speed threshold set in AISMPH, the engine controller must decide whether engine speed is close enough to target idle to engage closed-loop rolling idle regulation. If actual engine speed is significantly higher than target idle (for instance, if the driver just downshifted or revved the engine), entering rolling idle mode prematurely would cause the controller to actively fight the descending revs.

RPMDLT is added to target idle speed to form an upper RPM boundary. Only when actual engine speed is below this combined threshold is rolling idle mode activated.

In factory calibrations, RPMDLT is set to 7 counts, corresponding to an RPM tolerance of approximately 56 RPM.

3. Tuner's Guide & Real-World Calibration

  • Earlier Rolling Idle Catch:
  • Increase RPMDLT to 100 to 150 RPM to allow rolling idle mode to engage earlier as engine speed drops toward idle while coasting.
  • Factory Tolerance:
  • Factory setting of 56 RPM (7 counts) requires engine speed to settle very close to target idle before rolling idle locks in.
  • Upper Boundary Warning:
  • Keep RPMDLT below 250 RPM to avoid false idle mode triggering during high-RPM coast-down.
