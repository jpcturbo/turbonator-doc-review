1. Overview & Purpose

DECAIS defines the loop counter bitmask that paces how frequently the target idle speed decay step ISPDCY is applied during rolling idle mode.

To prevent abrupt steps in engine speed while rolling or coasting, the reduction of target idle speed must occur across a measured time interval. DECAIS masks the main program loop counter to enforce a deliberate delay between each decay step.

In factory calibrations, DECAIS is set to 127 counts, representing a binary bitmask allowing one decay step every 128 main loop passes, or approximately every 1.4 seconds.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosing Routine: LoadDiagIdleSpeed (T-SMEC_v19.asm:2080-2133) within CalculateTargetIdleSpeedAndAisPosition_MM.
  • Gating Conditions:
  • Rolling idle mode active (b50_IdleSpeedMode set at line 2117).
  • Main loop counter masked with DECAIS at line 2119: andb DECAIS_RollingAisUpdateRate; bne L1092.
  • When masked counter is non-zero, jumps to L1092, skipping the decay step.

3. Tuner's Guide & Real-World Calibration

  • Accelerating Rolling Decay:
  • Lower DECAIS to 63 or 31 counts to step down elevated rolling idle twice or four times as fast.
  • Gradual Highway Coasting:
  • Retain factory 127 counts (every 128th loop) for a slow, imperceptible return to base idle during long highway coast-downs.
  • Mask Formatting:
  • Must be configured as a valid binary mask (15, 31, 63, 127, 255).
