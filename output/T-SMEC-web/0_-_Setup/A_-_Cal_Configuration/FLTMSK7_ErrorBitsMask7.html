1. Overview & Purpose

FLTMSK7 defines the seventh and final configurable error suppression slot in the diagnostic fault mask array.

Stored at index offset six from the base address, FLTMSK7 gives tuners the ability to suppress a seventh distinct diagnostic trouble code. When evaluated during error handling, if the incoming failure matches FLTMSK7, error storage is bypassed and the dashboard warning lamp remains off. Factory calibrations set FLTMSK7 to zero counts.
