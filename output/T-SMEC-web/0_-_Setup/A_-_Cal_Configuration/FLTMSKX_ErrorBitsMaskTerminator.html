1. Overview & Purpose

FLTMSKX is the mandatory end-of-list terminator byte for the diagnostic error suppression array.

Positioned at index offset seven immediately following FLTMSK7, FLTMSKX must strictly remain zero counts in all calibrations. In the error evaluation routine, the search loop tests each byte in the suppression table sequentially; when a zero byte is encountered, the controller recognizes that the end of the suppression list has been reached and exits the search to process the active diagnostic fault.

2. Operating Conditions (When Does This Take Effect?)

  • Subroutine & Line Numbers: ThrowNonCriticalError (T-SMEC_v19.asm:4440-4475), evaluated at line 4442 via indexed offset +7 from FLTMSK_ErrorBitsMask1.
  • Terminator Check:
  • brclr 0, X, #$%11111111, L1321 tests if the byte at index register X is zero.
  • When X reaches FLTMSKX_ErrorBitsMaskTerminator, the zero byte forces an immediate branch to L1321 to conclude search.

3. Tuner's Guide & Real-World Calibration

  • Strictly Mandatory Zero Terminator:
  • FLTMSKX must remain zero counts under all circumstances.
  • Buffer Overrun Prevention:
  • Setting a non-zero value causes the MCU to scan past the end of the suppression list into adjacent calibration tables.
  • Unpredictable Masking:
  • Corrupted terminator values cause arbitrary calibration bytes to be treated as error suppression masks.
