1. Overview & Purpose

FLTMSK4 provides the fourth configurable error suppression slot in the diagnostic fault mask array.

Located at index offset three from the base address, FLTMSK4 allows suppressing a fourth distinct diagnostic trouble code. When evaluated during the error handling loop, an internal code match causes the controller to exit the routine cleanly without storing the failure in memory or flagging the check engine light. Factory calibrations initialize FLTMSK4 to zero counts.
