1. Overview & Purpose

IPLMSK2 defines the second dashboard warning lamp mask register, focusing on actuator circuit failures and major system diagnostic faults.

Configured in factory calibrations to two hundred sixteen counts, IPLMSK2 evaluates error flags stored in memory register b46_IPL2. The switches in IPLMSK2 control dashboard check engine light illumination for turbocharger wastegate solenoid circuit faults, fuel injector driver failures, and major powertrain electrical faults. By evaluating IPLMSK2 after sensor faults in IPLMSK have been verified, the controller ensures that severe hardware failures alert the driver immediately.

2. Operating Conditions (When Does This Take Effect?)

  • Subroutine & Line Numbers: DetermineEngineRunningCELStatus (T-SMEC_v19.asm:4631-4654), instruction line 4645 (bita IPLMSK2_PowerLossLightMask2).
  • Gating Logic:
  • Checked after IPLMSK sensor faults evaluate clear.
  • If cfg_EGR is clear in CONFIG, bits 7 and b46_MajorFault are masked out (anda #~(b46_bit7 | b46_MajorFault)).
  • Comparison & Branch:
  • If bita IPLMSK2_PowerLossLightMask2 is zero (beq TurnCheckEngineLightOnAndOff), light is turned off.
  • If non-zero, falls through to clrb, illuminating the warning light.

3. Tuner's Guide & Real-World Calibration

  • Wastegate Solenoid Elimination:
  • Clearing the wastegate bit prevents the open-circuit condition from illuminating the dashboard check engine light when running an aftermarket boost controller.
  • Actuator Warning Control:
  • Selectively disables warning light illumination for actuator and driver circuits without disabling primary analog sensor alerts.
  • EGR Interaction:
  • The routine checks cfg_EGR in CONFIG; if EGR is disabled, major fault bits are masked out before checking IPLMSK2.
  • Factory Setting:
  • Set to two hundred sixteen counts in stock calibrations.
