1. Overview & Purpose

FLTMSK3 provides the third error suppression slot in the diagnostic fault mask array.

Stored at index offset two from the base mask address, FLTMSK3 is evaluated during the third iteration of the error suppression search loop. If an incoming fault code matches the value in FLTMSK3, the controller aborts diagnostic logging for that fault, leaving the fault bit clear in memory and keeping the dashboard check engine light off. Factory calibrations set FLTMSK3 to zero counts.
