1. Overview & Purpose

WB2AFR is the primary input transfer function in the Turbonator wideband conversion system, translating the analog 0 to 5 volt signal from an aftermarket wideband controller into internal engine air-fuel ratio.

Different wideband controllers (such as AEM, Innovate, or Zeitronix) output different linear voltage-to-AFR relationships. WB2AFR maps the raw analog voltage read on the oxygen sensor wiring into an exact air-fuel ratio value.

This value is saved to memory for high-speed datalogging and passed to AFR2NB to generate simulated narrowband feedback.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosed in subroutine LookupWB2NBXferFunc at lines 10315-10327 of cals/SMEC/T-SMEC_v19.asm.
  • Executed within ConvertWB2NBSignal_MM (line 7492) when opt_WB2NB is set in OPTN2_CalCustomOptionConfigFlags2.
  • Accumulator A holds raw wideband analog voltage from RawAirFuelSensInput.
  • Index register X points to #WB2AFR_WidebandToAFRTransferFunction and calls Lookup4ByteTable (lines 10317-10318).
  • Output is stored in RAM variable AFRatio at line 10319.

3. Tuner's Guide & Real-World Calibration

  • Controller Output Matching: Match the two calibration points to your wideband controller specifications (e.g., AEM UEGO: 0.0V = 10.0:1, 5.0V = 20.0:1; Innovate: 0.0V = 7.35:1, 5.0V = 22.39:1).
  • Datalogging Alignment: Compare gauge readings with the AFRatio channel in MPScan to confirm zero translation discrepancy across all operating ranges.
  • Electrical Grounding: Wire the wideband controller analog ground directly to the engine controller sensor ground to eliminate ground offset errors.
