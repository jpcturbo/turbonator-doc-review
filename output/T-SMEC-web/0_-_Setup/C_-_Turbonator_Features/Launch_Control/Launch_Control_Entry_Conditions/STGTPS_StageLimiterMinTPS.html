1. Overview & Purpose

STGTPS defines the minimum throttle opening required above the closed-throttle idle baseline before the staging rev limiter will engage.

Without a throttle opening check, a vehicle stopped in traffic or idling in the staging lanes could inadvertently trigger launch control rev limiting. By requiring throttle position to exceed the closed-throttle baseline by this calibrated threshold, the controller guarantees that launch control only arms when the driver intentionally steps on the accelerator pedal.

The factory setting corresponds to approximately 0.76 volts above idle baseline, representing roughly 15 to 20 percent throttle opening.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosed in subroutine LaunchControl_CheckTPS at lines 10147-10153 of cals/SMEC/T-SMEC_v19.asm.
  • Evaluated in LaunchControl_MM after switch verification passes.
  • TpsVolts is loaded into accumulator B and closed-throttle baseline MINTHR_LowestSessionTPS is subtracted (lines 10148-10149).
  • If TpsVolts < MINTHR (bcs LaunchControl_Off), launch control terminates immediately.
  • If delta throttle voltage is less than STGTPS (cmpb STGTPS_StageLimiterMinTPS; bcs LaunchControl_Off), launch control disengages.

3. Tuner's Guide & Real-World Calibration

  • Factory Threshold: 39 counts corresponds to approximately 0.76 volts above idle baseline, requiring deliberate pedal depression.
  • Wide-Open Throttle Arming: Raising to 80-120 counts ensures launch control activates only when the throttle is pinned to the floor.
  • False Trigger Prevention: Avoid setting below 15 counts (approx 0.3 volts) to prevent throttle baseline drift from triggering launch cuts at idle.

4. Technical / Assembly Mechanics (Reference)

Inside T-SMEC_v19.asm: At line 10148 within LaunchControl_CheckTPS, accumulator B loads instantaneous throttle voltage TpsVolts. Line 10149 executes subb MINTHR_LowestSessionTPS, subtracting the learned closed-throttle baseline. If a borrow occurs (bcs LaunchControl_Off), throttle position is invalid and launch control terminates. Line 10151 executes cmpb STGTPS_StageLimiterMinTPS. If delta throttle opening is less than STGTPS, branch bcs LaunchControl_Off exits the routine. Only when throttle depression meets or exceeds STGTPS does execution proceed to speed verification.

  • Relative Voltage Offset: Evaluated relative to MINTHR_LowestSessionTPS, automatically compensating for throttle body mechanical idle stop adjustments.
  • Sensor Scaling: Scaled at approximately 19.5 millivolts per count across 0 to 5 volts (39 counts = ~0.76 V).
  • Option Dependency: Active when opt_StageLim is set in OPTN2.
