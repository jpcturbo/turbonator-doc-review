1. Overview & Purpose

KNKMIN defines the minimum engine coolant temperature required before the engine controller will flash the instrument cluster Check Engine or Power Loss light upon detecting detonation knock.

Turbonator firmware includes a real-time knock alert feature: whenever the knock sensor registers detonation and the controller retards ignition timing on any individual cylinder, the Check Engine light flashes to alert the driver. However, cold engines naturally produce mechanical valvetrain clatter and piston slap that can register as false knock.

KNKMIN suppresses knock light flashing until the engine warms up to normal operating temperature, with the factory setting corresponding to approximately 160 degF.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosed in subroutine UseCELForKnockIndication_MM at lines 10100-10121 of cals/SMEC/T-SMEC_v19.asm (invoked via main loop at line 7545).
  • Requires custom option flag opt_FlashCE (bit 4) to be enabled in OPTN1_CalCustomOptionConfigFlags1 (line 10102).
  • Bypassed if engine is not running (BitFlags_54 bit b54_FuelEngineNotRunning is set at line 10103).
  • Temperature comparison: cmpa KNKMIN_FlashCEMinTemp against CoolantTemp (line 10105).
  • If CoolantTemp < KNKMIN (bcs FlashCEL_OnKnock_return), knock light flashing is suppressed.
  • If CoolantTemp >= KNKMIN, lines 10107-10114 check individual cylinder knock retard variables (Cylinder1Retard through Cylinder4Retard). If any cylinder has active retard, bit pia1abuf_CELight in PIA1_A_Buffer is cleared to illuminate the lamp.

3. Tuner's Guide & Real-World Calibration

  • Stock Cast Pistons: Factory setting of approximately 160 degF effectively filters cold start clatter while providing prompt alerts as soon as the thermostat opens.
  • Forged Racing Pistons: Forged 2618 or 4032 pistons with loose clearances produce mechanical slap when cold. Raise KNKMIN to 175 degF to suppress false alerts until the engine reaches operating temperature.
  • Diagnostic Value: Provides immediate real-time driver feedback during road or dyno tuning without needing a laptop connected.

UseCELForKnockIndication_MM:
        ldx   #OPTN1_CalCustomOptionConfigFlags1
	brclr 0, X, #opt_FlashCE, FlashCEL_OnKnock_return
	brset *BitFlags_54, #b54_FuelEngineNotRunning, FlashCEL_OnKnock_return	  ; branch if bit(s) set
	ldaa  CoolantTemp
	cmpa  KNKMIN_FlashCEMinTemp
	bcs   FlashCEL_OnKnock_return; cold motor creates a LOT of false positives
	ldaa  Cylinder2Retard	 ; load a with memory contents
	bne   KnockDetect_LightCEL	    ; branch if not equal (not zero)
	ldaa  Cylinder1Retard	 ; load a with memory contents
	bne   KnockDetect_LightCEL	    ; branch if not equal (not zero)
	ldaa  Cylinder3Retard	 ; load a with memory contents
	bne   KnockDetect_LightCEL	    ; branch if not equal (not zero)
	ldaa  Cylinder4Retard	 ; load a with memory contents
	bne   KnockDetect_LightCEL	    ; branch if not equal (not zero)
NoKnockDetect_UnlightCEL:		; fallthrough, extinguish light
	bset	*PIA1_A_Buffer, #pia1abuf_CELight
	bra	FlashCEL_OnKnock_return
KnockDetect_LightCEL:
	bclr	*PIA1_A_Buffer, #pia1abuf_CELight
FlashCEL_OnKnock_return:
	rts

5. Calibration Notes & System Dependencies

  • Hardware Inversion: Check Engine light output driver in PIA1_A_Buffer is active-low (clearing the bit turns the lamp on).
  • Option Dependency: Enabled via custom option bit opt_FlashCE in OPTN1.
  • Non-linear Temperature Curve: Evaluated using raw coolant temperature counts where 168 counts equals approximately 160 degF.
