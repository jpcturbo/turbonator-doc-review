1. Overview & Purpose

MDLCDE defines the vehicle model year, engine architecture, and transmission configuration in the calibration header.

Arranged as a sixteen-bit word, the first byte encodes the model year (such as ninety-nine for nineteen eighty-nine, zero-zero for nineteen ninety, or zero-one for nineteen ninety-one), while the second byte encodes the powertrain configuration (such as zero-one for a two-point-five-liter turbo automatic, ten for a two-point-two-liter turbo four, or forty-one for a manual transmission). Diagnostic scan tools query MDLCDE to configure data display menus, sensor ranges, and diagnostic trouble code tables for the specific vehicle.

2. Operating Conditions (When Does This Take Effect?)

  • Subroutine & Line Numbers: SendECUIDToSCI (T-SMEC_v19.asm:3829-3841), accessed via indexed offset +6 from ENDIT1_PNPrefix.
  • Serial Transmission:
  • Transmitted across the SCI data link when DRB command 0x16 requests ECU identification.
  • Encoding Scheme:
  • High byte (0x8006): Model Year (0x99 = 1989, 0x00 = 1990, 0x01 = 1991, 0x02 = 1992, 0x03 = 1993).
  • Low byte (0x8007): Powertrain (0x01 = 2.5L T1, 0x10 = 2.2L T4, 0x21 = 2.5L Van ATX, 0x40 = 2.2L VNT MTX, 0x41 = 2.5L T1 MTX).

3. Tuner's Guide & Real-World Calibration

  • Scan Tool Model Identification:
  • Modifying MDLCDE allows diagnostic scan tools to correctly report vehicle model year, engine displacement, and transmission type.
  • Transmission & Engine Swaps:
  • Updating the low byte when swapping powertrains (e.g., automatic to manual) keeps diagnostic reporting consistent.
  • No Engine Control Impact:
  • Actual powertrain behavior is governed by CONFIG and calibration tables, not MDLCDE.
