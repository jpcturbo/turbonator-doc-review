1. Overview & Purpose

HUNTSV holds the Huntsville manufacturing test code within the calibration identification header.

Manufactured at Chrysler's Huntsville Electronics division in Alabama, each engine control unit underwent automated functional testing on the assembly line before shipment to vehicle assembly plants. HUNTSV contains a sixteen-bit code word configured to C92D in the factory calibration. During factory end-of-line verification, automated testing equipment interrogated the controller via serial communications to verify correct program loading, module hardware revision, and circuit board manufacturing compliance.
