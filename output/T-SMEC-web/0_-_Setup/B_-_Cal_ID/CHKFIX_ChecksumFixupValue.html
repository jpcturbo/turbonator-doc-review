1. Overview & Purpose

CHKFIX is the single-byte calibration checksum fixup constant located in the engine controller ROM header.

To safeguard against memory corruption, defective memory chips, or unauthorized modifications, the engine controller executes an internal checksum routine during startup initialization. This routine computes an arithmetic eight-bit sum across all calibration memory locations and compares the final sum against the expected checksum target stored in the calibration identifier. CHKFIX is specifically calculated and placed in the calibration so that the cumulative sum of all bytes across the entire calibration space matches the expected target byte exactly.
