1. Overview & Purpose

SRCID defines the Turbonator custom codebase version and controller family identifier within the calibration header.

In custom firmware, SRCID replaces unused factory plant testing codes to provide positive identification of the underlying firmware architecture. Encoded as a sixteen-bit word, the upper byte designates the engine controller architecture (such as zero B for the SMEC family, zero A for logic modules, and zero C for SBEC controllers), while the lower byte indicates the firmware version in hexadecimal (such as nineteen in hexadecimal to designate version nineteen). Tuning editors query SRCID to automatically verify table compatibility and unlock platform-specific features.
