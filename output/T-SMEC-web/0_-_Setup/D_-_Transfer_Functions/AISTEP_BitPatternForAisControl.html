1. Overview & Purpose

AISTEP defines the four-byte electromagnetic commutation sequence that drives the bipolar stepper motor inside the automatic idle speed actuator.

The Chrysler automatic idle speed motor uses two independent electrical coils to position the idle air pintle. To rotate the motor armature and extend or retract the pintle, the controller must energize and reverse the magnetic polarity of these coils in an exact sequential order. Stored in factory calibrations as the four consecutive pattern bytes zero-six, zero-five, zero-nine, and zero-A, AISTEP is read by the idle motor drive routine to step the motor armature forward or backward by one increment per cycle.

2. Operating Conditions (When Does This Take Effect?)

  • Subroutine & Line Numbers: AisDriveRoutine (T-SMEC_v19.asm:1369-1400), instruction line 1384 (ldx #AISTEP_...). Also line 7328.
  • Sequencing Logic:
  • Current step phase stored in the lower two bits of BitFlags_2d (0 to 3).
  • If motor needs to advance, adds or subtracts 1 count to phase index.
  • Driver Output:
  • The pattern byte is masked and written into the lower four bits of PIA1_PortB_DataDirection at lines 1397-1400.

3. Tuner's Guide & Real-World Calibration

  • Fixed Hardware Commutation Table:
  • Never modify this table when using the standard Chrysler idle air stepper motor.
  • Phase Sequence Disruption:
  • Altering any of the four bytes destroys the magnetic step sequence, preventing the stepper armature from rotating.
  • Drivability Impact:
  • Corrupted commutation patterns cause the motor to freeze or vibrate, completely disabling idle speed regulation.
  • Factory Sequence:
  • Four sequential coil states configured in calibration memory.

4. Technical / Assembly Mechanics (Reference)

Inside T-SMEC_v19.asm: In AisDriveRoutine at lines 1383-1400, index register X loads #AISTEP_BitPatternForAisControl. Line 1385 adds the lower two bits of BitFlags_2d (andb #b2d_both) to index register X via abx. Line 1397 reads PIA1_PortB_DataDirection, masks out the lower four bits (anda #0xf0), and logical-ORs the new coil pattern from 0x00,x at line 1399 before writing back to PIA1_PortB_DataDirection.

5. Calibration Notes & System Dependencies

  • 4-Byte Pattern Array: Type 9 table at calibration address 0x1DDA.
  • Bipolar Commutation: Drives H-bridge driver transistors connected to the dual AIS motor coils.
  • Bidirectional Operation: Incrementing phase steps the motor open; decrementing phase steps the motor closed.
