1. Overview & Purpose

DLTRPM2 establishes the engine speed delta filter threshold evaluated during manifold pressure averaging updates.

Under rapid engine deceleration, when manifold pressure drops quickly, the engine controller calculates the rate of change of engine speed between consecutive calculation loops. If the change in engine speed exceeds DLTRPM2, the controller immediately updates the running average manifold pressure variable to match instantaneous manifold pressure. In factory calibrations, DLTRPM2 is set to two hundred fifty-five counts, which is the maximum eight-bit value. This high threshold keeps the delta filter disabled under normal conditions so deceleration filtering operates uninterrupted.

2. Operating Conditions (When Does This Take Effect?)

  • Subroutine & Line Numbers: CALCULATE_RPM_SPEED_AND (T-SMEC_v19.asm:9012-9031), instruction line 9023 (cmpa DLTRPM2_RPMDeltaForRPMFilter).
  • Gating Conditions:
  • Evaluated when MapValue < AverageMAPValue (manifold pressure is decreasing).
  • Comparison & Branch:
  • Accumulator A holds engine speed difference (EngineRpm_HB - Temp2).
  • Line 9023 executes cmpa DLTRPM2_RPMDeltaForRPMFilter.
  • If lower (bcs R1809), branches to return without resetting AverageMAPValue.
  • If higher or equal, copies instantaneous MapValue directly into AverageMAPValue.

3. Tuner's Guide & Real-World Calibration

  • Leave at Maximum Setting:
  • Keep DLTRPM2 at two hundred fifty-five counts to maintain stock deceleration filtering behavior.
  • Avoid Premature Baseline Overwrites:
  • Lowering this threshold causes unnecessary resets of AverageMAPValue during gear shifts and overrun deceleration.
  • Drivability Impact:
  • Factory maximum setting provides smooth return to idle and consistent deceleration dashpot operation.
