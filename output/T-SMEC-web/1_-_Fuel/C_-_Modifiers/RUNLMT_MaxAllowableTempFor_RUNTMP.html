1. Overview & Purpose

RUNLMT defines the maximum allowable coolant temperature ceiling below which post-stall heat soak temperature modeling (RUNTMP) is permitted.

If an engine stalls when coolant temperature is already above RUNLMT, the engine is recognized as fully warmed up, and heat soak modeling is bypassed completely. Additionally, RUNLMT serves as the upper clamp for the simulated temperature calculation, ensuring that adding RUNTMP offset never raises effective temperature above normal warm operating levels.

In factory calibrations, RUNLMT is set to 160 counts, representing approximately 145 degF.
