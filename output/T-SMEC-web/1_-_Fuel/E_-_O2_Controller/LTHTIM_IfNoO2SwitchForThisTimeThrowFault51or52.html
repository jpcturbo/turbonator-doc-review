1. Overview & Purpose

LTHTIM defines the timeout duration that the oxygen sensor is permitted to remain on one side (stuck rich or stuck lean) without toggling before the engine controller initiates its two-strike fault sequence.

When closed loop is active, the controller expects the sensor to oscillate continuously across the stoichiometric threshold. If the sensor fails to switch for the duration specified by LTHTIM, the first strike triggers an internal warning and erases all 15 adaptive fuel memory cells.

If the timeout expires a second consecutive time, fault code 51 (lean) or code 52 (rich) is latched, adaptive memory is cleared again, and closed loop is locked out. In stock calibrations, LTHTIM is set to 43 counts (approximately 480 milliseconds across 43 main loop passes).

3. Tuner's Guide & Real-World Calibration

  • Header & Relocated Sensor Tuning:
  • Moving the O2 sensor downstream increases exhaust transport delay. Raising LTHTIM to 60-80 counts prevents false fault codes 51/52 and stops constant adaptive memory erasing.
  • Two-Strike Fault Logic:
  • Strike one sets internal warning bit b2e_BadO2Read and erases adaptive cells. Strike two sets fault code 51 or 52 and locks out closed loop.
  • Wideband Simulation:
  • Simulated narrowband outputs from wideband controllers often switch more slowly; raise LTHTIM to accommodate signal delay.
