1. Overview & Purpose

O2TLMH establishes the upper boundary of the delayed closed-loop entry voltage band.

If the oxygen sensor voltage is not high enough to exceed O2HIGH for immediate closed-loop entry, but falls between O2TLML and O2TLMH, the sensor is demonstrating partial activity as it warms up. The controller marks this condition and starts the delayed qualification timer O2TIME rather than locking out closed loop completely.

In factory calibrations, O2TLMH is set to 31 counts, corresponding to approximately 0.61 volts.

  • Enclosing Subroutine: HandleO2Processing_MM / O2_InvalidSignal_InMiddleRange (T-SMEC_v19.asm:3019-3038), instruction line 3021.
  • Gating Conditions: Signal failed immediate validation checks (O2LOW <= O2SensorValue < O2HIGH).
  • Comparison & Branch Polarity:
  • Line 3021 executes cmpb O2TLMH_HighLimitForDelayedSwitchToClosedLoop.
  • If O2SensorValue >= O2TLMH (bcc), execution branches to line 3025 (L1206), setting bit 7 of Timer_CLTIME_ClosedLoopTimer.
  • If O2SensorValue < O2TLMH, execution proceeds to test O2TLML.

3. Tuner's Guide & Real-World Calibration

  • Warmup Window Upper Edge:
  • Defines the upper limit of the delayed qualification zone (0.61V).
  • Relocated Sensor Troubleshooting:
  • On downpipe-mounted sensors with slower warmup, raising O2TLMH allows the qualification countdown to begin earlier.
  • Relationship to O2HIGH:
  • Must be maintained strictly lower than O2HIGH.
