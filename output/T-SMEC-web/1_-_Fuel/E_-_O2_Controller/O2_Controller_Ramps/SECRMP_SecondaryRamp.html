1. Overview & Purpose

SECRMP is a specialized 22-word secondary ramp rate table that functions as a closed-loop recovery failsafe when the oxygen sensor remains on one side (rich or lean) longer than expected.

While PRIRMP handles smooth incremental corrections during normal switching, SECRMP activates when Timer_O2ToggleDuration exceeds the calibrated cell timeout limit, applying aggressive secondary fuel kicks to rapidly drive the mixture back toward stoichiometric.

SECRMP defines the RPM and MAP grid boundaries, the secondary kick values (with lean corrections represented in two's complement format), and the duration limits for each operating cell.

  • Enclosing Subroutine: WorkWithSecondaryRamp (T-SMEC_v19.asm:3195-3212), instruction line 3196.
  • Gating Conditions: Closed loop active (b4f_O2Valid set, b50_StayOpenLoop clear), and primary ramp has not toggled.
  • Comparison & Branch Polarity:
  • Line 3196 loads index register X with #SECRMP_SecondaryRamp.
  • DetermineRampCellFromRPMandMAP selects the active cell.
  • Line 3199 loads Timer_O2ToggleDuration into register A.
  • Evaluates timeout limit; if timer expired (bcc O2_SensorStuckOnOneSideTooLong), secondary ramp kick is loaded and applied.

3. Tuner's Guide & Real-World Calibration

  • Mitigating Surging on Cammed Engines:
  • Aggressive secondary kicks can cause harsh surging when an exhaust sensor is slow to respond. Softening kick values in SECRMP eliminates abrupt overcorrections.
  • Recovery Failsafe:
  • Operates only when the oxygen sensor has failed to toggle across the stoichiometric threshold within the cell's duration limit.
  • Two's Complement Lean Kicks:
  • Rich kicks are positive values; lean kicks are stored as negative two's complement signed values.
  • Companion Constants:
  • Interacts with SCRMP1 and SCRMP2 subtractor constants during timer evaluation.

5. Calibration Notes & System Dependencies

  • Table Structure (Type 11):
  • Word 1: RPM Low / High boundary (0x293F).
  • Word 2: MAP Low / High boundary (0x335E).
  • Words 3-11: Cruise Cells 0-8 Secondary Ramp Steps (Rich high byte, Lean signed low byte).
  • Word 12: Idle Cell Secondary Ramp Step.
  • Words 13-21: Cruise Cells 0-8 Duration Timeout Limits.
  • Word 22: Idle Cell Duration Timeout Limit.
  • Companion Parameters: Works with SCRMP1 (secondary ramp subtractor) and PRIRMP.
  • Persistence: Triggered dynamically by RAM timer Timer_O2ToggleDuration.
