1. Overview & Purpose

AMLIMH establishes the maximum allowable positive fuel enrichment ceiling for all long-term adaptive fuel memory cells (AutoCal cells).

The SMEC firmware applies adaptive fuel trims as a signed modifier where each bit equals approximately 0.1953 percent of base fuel delivery.

In stock calibrations, AMLIMH is set to 127 counts (positive 127), which limits maximum learned enrichment to approximately +24.8 percent above the base calibration. This cap prevents vacuum leaks, failing fuel pumps, or dirty injectors from causing the engine controller to excessively enrich base fuel calculations into runaway conditions.

  • Enclosing Subroutine: AdaptiveMemory_UpdateCellIfRequired_MM / UpdateAdaptive_OffIdle (T-SMEC_v19.asm:3314-3335), instruction line 3318.
  • Gating Conditions: Adaptive update triggered; signed addition to AutoCalCell completed.
  • Comparison & Branch Polarity:
  • Line 3318 loads AMLIMH_MaxMultiplierCannotBeAbove7F into register B.
  • If 2's complement overflow occurs (bvc Adaptive_Overflowed not taken), cell is clamped to AMLIMH.
  • Line 3327 compares updated cell against AMLIMH via cba.
  • If cell >= AMLIMH (bge), execution branches to Adaptive_SetCellToMaxOrMinValue (line 3332), clamping cell to AMLIMH.

3. Tuner's Guide & Real-World Calibration

  • Constraining Adaptive Authority:
  • Clamping AMLIMH to 25-50 counts limits positive fuel trim learning to +5% to +10%, preventing runaway enrichment.
  • Zeroing for Wideband Tuning:
  • Setting AMLIMH to 0 disables positive long-term fuel trim learning, essential when mapping base fuel tables.
  • Formula & Resolution:
  • Maximum fuel modifier is 1 + (AMLIMH / 512). 127 counts represents +24.8% enrichment.
