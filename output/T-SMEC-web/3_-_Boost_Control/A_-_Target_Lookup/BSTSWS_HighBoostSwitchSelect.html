1. Overview & Purpose

BSTSWS defines the digital input pin bitmask on the switch input port used by the engine controller to read a driver-operated dual-boost selection switch.

When switchable boost is enabled in the calibration option registers, the controller tests this bit against the hardware switch register during every main program loop pass. If the switch state indicates that low-boost mode is selected, the controller overrides the primary engine-speed boost target curve with the low-boost ceiling constant. This mechanism allows the driver to alternate between high-power boost and conservative low-boost settings on the fly for varying weather, traction, or fuel availability.

2. Operating Conditions (When Does This Take Effect?)

  • Subroutine & Line Numbers: CheckBoostSwitch (T-SMEC_v19.asm:9469-9492), called from CalcTargetBoost_MM (T-SMEC_v19.asm:9423-9504).
  • Gating Conditions:
  • Switchable boost option bit opt_SwBoost must be set in OPTN1_CalCustomOptionConfigFlags1 (line 9476).
  • If opt_SwBoost is clear, execution branches directly to StoreBoostTarget (line 9477), bypassing the switch.
  • Polarity Evaluation:
  • Polarity flag opt_SwBstPol in OPTN1 selects Polarity_Hi (line 9483) or Polarity_Lo (line 9488).
  • Register B loads SwitchPortAccessReg and tests bitb BSTSWS_HighBoostSwitchSelect (lines 9484, 9489).
  • If the test resolves to low-boost mode, execution branches to LoadLoBoostAndLookup (line 9493) to clamp boost target to LOWBST.

3. Tuner's Guide & Real-World Calibration

  • Switch Input Pin Configuration:
  • Sets the digital input bitmask on the controller switch port corresponding to the physical boost switch.
  • Factory calibrations default to bitmask 2 (bit 1) for the dedicated switch input circuit.
  • Polarity Coordination:
  • Must be coordinated with opt_SwBstPol in OPTN1 to ensure switch toggle positions match high and low modes.
  • Disabling & Bypassing:
  • If switchable boost opt_SwBoost is disabled in OPTN1, this switch bitmask is completely bypassed.
  • Hardware Integrity:
  • Ensure clean wiring and debounced switch contacts to avoid rapid toggling between boost limits under road vibration.

4. Technical / Assembly Mechanics (Reference)

Inside T-SMEC_v19.asm: In CheckBoostSwitch, the controller first reads OPTN1_CalCustomOptionConfigFlags1 and executes bita #opt_SwBoost at line 9476. If clear, it branches to StoreBoostTarget. If set, it loads SwitchPortAccessReg into accumulator B, checks polarity bit opt_SwBstPol, and branches to Polarity_Hi or Polarity_Lo. At lines 9484 and 9489, the instruction bitb BSTSWS_HighBoostSwitchSelect tests the configured bitmask against the physical switch port. 5. Calibration Notes & System Dependencies

  • Option Flag Dependency: Requires opt_SwBoost (bit 4) to be enabled in OPTN1_CalCustomOptionConfigFlags1.
  • Polarity Inversion: Paired directly with opt_SwBstPol (bit 5) in OPTN1, allowing normal-open or normal-closed cockpit switches.
  • Target Clamping: When active, low-boost mode does not replace the primary table blindly; it passes LOWBST into KeepSmallerBoostGoal to enforce the minimum.
