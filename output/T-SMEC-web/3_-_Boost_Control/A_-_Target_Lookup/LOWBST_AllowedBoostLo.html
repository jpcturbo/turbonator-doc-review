1. Overview & Purpose

LOWBST sets the fixed turbocharger gauge boost target ceiling enforced when switchable dual-boost control is enabled and the external boost switch is toggled to the low-boost position.

When active, the engine controller compares this constant against the running minimum boost target calculated from the tables and enforces whichever value is lower. In factory Turbonator calibrations, this constant is set to 87 counts, corresponding to approximately 10.0 psi of positive boost pressure. This allows the driver to instantly reduce engine output for inclement weather, fuel conservation, valet operation, or pump-gas daily driving while retaining high boost on demand.

3. Tuner's Guide & Real-World Calibration

  • Low-Boost Target Ceiling:
  • Defines the upper boost limit enforced when the cockpit toggle switch selects low-boost mode.
  • Useful for valet modes, wet-weather driving, or running on lower-octane pump gasoline.
  • Base Spring Boost Calibration:
  • Setting LOWBST equal to base actuator spring pressure (e.g. 6 to 7 psi) disables solenoid duty cycle in low mode for mechanical spring boost.
  • Race vs. Pump Gas Switching:
  • Set LOWBST for safe pump-gas boost (12 to 14 psi) while calibrating WSGRPM for race-gas boost (20 to 25 psi).
  • Hierarchical Minimum Interaction:
  • LOWBST cannot force boost higher than WSGRPM or cold engine limits; it only restricts boost downward via KeepSmallerBoostGoal.

5. Calibration Notes & System Dependencies

  • Option Gating: Relies on opt_SwBoost and BSTSWS in CheckBoostSwitch.
  • Minimum Clamping: Enforces a ceiling; it will never raise boost if another limiter (such as WSGCLT or WSGTIM) commands a lower value.
  • 3-Bar MAP Scaling: In 3-bar calibrations, must be rescaled to prevent commanding twice the intended low-boost pressure.
