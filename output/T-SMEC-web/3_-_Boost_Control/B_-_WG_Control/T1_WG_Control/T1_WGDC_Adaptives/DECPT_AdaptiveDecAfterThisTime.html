1. Overview & Purpose

DECPT specifies the dwell time threshold that a sustained overboost condition must persist before the controller decrements the active adaptive wastegate cell.

Brief turbocharger pressure spikes during rapid throttle opening or quick upshifts are normal physical phenomena that should not permanently alter steady-state calibration trims. DECPT ensures that the error timer must accumulate a steady duration of continuous overboost before the controller trims down the baseline duty cycle cell. Note that this constant is shared between both T1 and T2 control routines.

3. Tuner's Guide & Real-World Calibration

  • Overboost Dwell Time Threshold:
  • Number of consecutive error timer counts that overboost must persist before the adaptive cell is decremented.
  • Factory setting is 32 counts (approximately 0.35 seconds).
  • Suppressing False Adaptation on Spikes:
  • Raising DECPT to 45 to 60 counts (0.5 to 0.7 seconds) prevents momentary gear-shift boost spikes from trimming baseline duty cycle.
  • Accelerating Boost Creep Correction:
  • Lowering DECPT to 15 to 20 counts speeds up downward duty cycle trimming if steady-state boost consistently runs too high.
  • Shared Code Anomaly:
  • Used in both CalcWGDutyCycleT1 (line 9688) and CalcWGDutyCycleT2 (line 9997); modifying DECPT affects both algorithms.
