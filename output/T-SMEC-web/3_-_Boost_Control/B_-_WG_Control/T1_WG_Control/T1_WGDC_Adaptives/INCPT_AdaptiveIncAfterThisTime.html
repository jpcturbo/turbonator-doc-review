1. Overview & Purpose

INCPT specifies the dwell time threshold that an underboost condition must continuously persist before the controller increments the active adaptive wastegate cell in T1 control.

When the throttle is initially opened, turbocharger spool lag naturally creates a temporary underboost condition. INCPT ensures that the error timer must accumulate a steady duration of underboost before the controller concludes that baseline duty cycle is truly insufficient, preventing transient spool-up lag from corrupting steady-state adaptive trims.

2. Operating Conditions (When Does This Take Effect?)

  • Subroutine & Line Numbers: WGDC_IncrementWGAdaptive (T-SMEC_v19.asm:9717-9720), called from CalcWGDutyCycleT1 (T-SMEC_v19.asm:9512-9753).
  • Gating Conditions: Underboost must satisfy MPROOF, TPSLIM, MPDEL2, zero knock penalty, and EngineRpm_HB >= DCRPML.
  • Timer Comparison:
  • Line 9717 loads Timer_BoostErrTimer and increments it (inca).
  • Line 9719 executes cmpa INCPT_AdaptiveIncAfterThisTime.
  • If timer is below INCPT (bcs), branches to WGDC_StoreBoostErrTimer (line 9720) to save timer state without updating memory.

3. Tuner's Guide & Real-World Calibration

  • Underboost Dwell Time Threshold:
  • Number of consecutive error timer counts that underboost must persist before the adaptive cell is incremented.
  • Factory setting is 32 counts (approximately 0.35 seconds).
  • Preventing Premature Adaptation on Lag:
  • Higher values (40 to 60 counts, 0.45 to 0.7 seconds) prevent the ECU from adding duty cycle while a large turbo is naturally spooling.
  • Fast Convergence for Sluggish Spool:
  • Lowering INCPT to 15 to 20 counts speeds up adaptive duty cycle additions if steady-state boost consistently falls short.
