1. Overview & Purpose

DCWBST provides a proportional duty cycle boost offset based on the error delta between target boost and actual manifold pressure in T1 control.

When the driver snaps the throttle open and actual manifold pressure is far below the target ceiling, this table adds significant duty cycle to clamp the wastegate tightly closed and spool the turbocharger as rapidly as possible. As manifold pressure climbs and approaches the target boost, the error delta diminishes toward zero, progressively reducing the duty cycle addition and transitioning smoothly onto base open-loop and adaptive regulation.

3. Tuner's Guide & Real-World Calibration

  • Spool-Up Proportional Gain:
  • Adds wastegate duty cycle based on how far manifold pressure lags below target boost (Target - Actual).
  • Clamps wastegate shut during initial spool-up to build boost with minimal turbo lag.
  • Preventing Spool-Up Overshoot:
  • Ensure duty cycle tapers to 0% when the boost error reaches 1 to 2 psi, allowing actuator pressure to stabilize before hitting target.
  • T1 Additive vs. T2 Negated Polarity:
  • In T1 control, lookup results are added directly to duty cycle; in T2 control, the lookup result is negated before application.
  • Negative Error Clamping:
  • If actual boost exceeds target, the error delta is clamped to zero, ensuring DCWBST never adds duty cycle during overboost.

5. Calibration Notes & System Dependencies

  • Turbonator Feature Lineage: Replaced legacy delta-boost algorithms in Turbonator v19 with a progressive spool-up table.
  • Zero Delta Transition: Must taper smoothly to 0% duty cycle at 0 psi delta to allow smooth handoff to adaptive cells.
