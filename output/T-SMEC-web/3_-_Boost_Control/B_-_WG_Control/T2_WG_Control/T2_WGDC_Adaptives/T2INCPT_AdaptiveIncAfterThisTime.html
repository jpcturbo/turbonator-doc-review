1. Overview & Purpose

T2INCPT defines the error timer dwell duration required before incrementing an adaptive wastegate cell in T2 control.

In T2 pressure-source plumbing, incrementing duty cycle raises the solenoid drive to bleed actuator pressure and correct for sustained boost errors. T2INCPT specifies the number of consecutive main loop error timer counts that must elapse while boost error persists before the controller permanently adds a correction count to the active adaptive cell.

2. Operating Conditions (When Does This Take Effect?)

  • Gating Conditions: Manifold rate of change must be within T2MPDEL1.
  • Timer Comparison:
  • Line 9965 loads Timer_BoostInErrorTimer and increments it (inca).
  • Line 9967 executes cmpa T2INCPT_AdaptiveIncAfterThisTime.
  • If timer is below T2INCPT (bcs), execution branches to T2WGDC_StoreBoostErrTimer (line 9968) to save timer state without adapting.

3. Tuner's Guide & Real-World Calibration

  • T2 Error Timer Dwell Threshold:
  • Consecutive error timer counts required before an adaptive cell increment is committed.
  • Factory setting is 16 counts (approximately 0.18 seconds in template, 10 counts / 0.11 seconds in ASM).
  • Fast Convergence vs. Stability:
  • Lower values (8 to 10 counts) speed up closed-loop boost convergence on steady highway pulls.
  • Higher values (20 to 30 counts) prevent false learning during transient gear changes and spool-up.
  • Clamping Interlock:
  • Increments only if the active cell value is below upper limit INCLIM.
