1. Overview & Purpose

T2KNOKMP specifies the minimum manifold gauge pressure threshold required before the controller registers detonation events toward wastegate duty cycle reduction in T2 control.

At low boost levels below this threshold (such as light vacuum or low cruise), detonation is managed exclusively via ignition timing retard rather than by altering wastegate duty cycle. Once gauge boost exceeds T2KNOKMP, the controller activates the boost knock timer and begins tracking knock events for pneumatic boost reduction.

3. Tuner's Guide & Real-World Calibration

  • Knock Boost Reduction Minimum Threshold:
  • Minimum boost above barometric pressure required before knock events trigger wastegate duty cycle modifications.
  • Factory setting is 35 counts (approximately 4.0 psi boost above atmospheric pressure).
  • Locking Out Off-Boost False Knock:
  • Prevents valvetrain noise or tip-in spark knock from altering wastegate duty cycle at light load.
  • 3-Bar MAP Sensor Rescaling:
  • Rescale T2KNOKMP to half count value on 3-bar conversions to maintain the 4.0 psi boost activation threshold.
