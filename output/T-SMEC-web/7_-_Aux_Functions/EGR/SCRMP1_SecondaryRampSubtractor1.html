1. Overview & Purpose

SCRMP1 (SecondaryRampSubtractor1) establishes the closed-loop oxygen sensor toggle duration modifier used specifically while Phase 2 of the Exhaust Gas Recirculation diagnostic verification routine is active.

In normal closed-loop operation, the engine controller looks up secondary ramp timing from a 2D table to pace how rapidly the oxygen sensor feedback counter toggles rich and lean. However, during Phase 2 EGR flow verification, the controller needs heightened sensitivity to detect the rapid exhaust gas composition change when the EGR valve shuts off.

At line 3201 in the secondary ramp handler, if Phase 2 is active, the controller subtracts SCRMP1 from the toggle timer instead of the standard table lookup value. The factory setting of 2 counts accelerates the oxygen sensor switching rate, ensuring rapid feedback response during the diagnostic test.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosing Routine: WorkWithSecondaryRamp (lines 3195–3207), specifically at line 3201.
  • Called From: ModifyO2FeedbackCountVarToMaintainStoich_MM (line 3190).
  • Precondition Flag: Bit 7 of EGRVar2 set (brclr *EGRVar2, #bit_bit7, L1226 falls through to line 3201).
  • Calculation: Timer_O2ToggleDuration - SCRMP1_SecondaryRampSubtractor1 evaluated in accumulator A.
  • Branch Behavior: Always executes bra L1227 to check for toggle duration expiration (bcc O2_SensorStuckOnOneSideTooLong).

3. Tuner's Guide & Real-World Calibration

  • Raising SCRMP1: Accelerates the closed-loop oxygen sensor toggle rate during Phase 2 testing, improving detection speed on older or slower-responding narrowband sensors.
  • Lowering SCRMP1: Slows down the closed-loop integrator adjustment rate during Phase 2. Useful on modified engines with large fuel injectors to avoid overshooting stoichiometric fueling during the test.
  • EGR Diagnostic Cross-Coupling: Directly linked to EGRVar2 bit 7; has no effect during normal driving outside of active Phase 2 flow verification.
  • Factory Calibration: 2 counts provides an optimal balance between fast transient detection and closed-loop fuel stability.

4. Technical / Assembly Mechanics (Reference)

Inside T-SMEC_v19.asm: In subroutine WorkWithSecondaryRamp, after looking up the ramp cell, line 3199 loads Timer_O2ToggleDuration into accumulator A. Line 3200 tests bit 7 of EGRVar2 (brclr *EGRVar2, #bit_bit7, L1226). During normal driving, bit 7 is clear, branching to L1226 to subtract the standard table value B (sba). However, when Phase 2 EGR diagnostic testing is active, bit 7 is set; execution falls into line 3201, which executes suba SCRMP1_SecondaryRampSubtractor1 (factory 0x02 = 2 counts). Line 3202 branches via bra L1227 to line 3205 (bcc O2_SensorStuckOnOneSideTooLong), evaluating whether the toggle timer has expired and advancing the closed-loop fuel feedback integrator.
