1. Overview & Purpose

EGR33 (ExhGasRecircConstFromMAPBelowBaro) establishes the minimum intake manifold vacuum threshold below barometric pressure required to permit Exhaust Gas Recirculation diagnostic testing (Fault Code 32).

The onboard diagnostic routine can only evaluate EGR flow when the engine is drawing sufficient manifold vacuum to pull exhaust gas into the cylinders. At line 5419, the controller subtracts manifold absolute pressure from barometric pressure. If the difference is less than EGR33, the engine is operating either in positive boost or under heavy load near atmospheric pressure.

Under these conditions, the diagnostic sequence aborts and resets. The factory calibration of 13 counts corresponds to approximately 1.5 psi (roughly 3.1 inHg) of intake manifold vacuum below baro.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosing Routine: ExhGasRecirc_MM (lines 5383–5545), specifically at line 5422.
  • Vacuum Math: Evaluates BaroPressure - MapValue in accumulator A at lines 5419–5420.
  • Boost Inhibit: Line 5421 branches via bcs EGR_ResetEGRVars if MapValue > BaroPressure (positive turbo boost).
  • Comparison: cmpa EGR33_ExhGasRecircConstFromMAPBelowBaro at line 5422.
  • Branch Behavior: If manifold vacuum < EGR33 (bcs EGR_ResetEGRVars), aborts Phase 1/Phase 2 and jumps to EGR_ResetEGRVars.

3. Tuner's Guide & Real-World Calibration

  • Raising EGR33: Demands deeper intake manifold vacuum (e.g. 20 counts = ~2.3 psi / 4.7 inHg vacuum) before EGR diagnostic flow testing can proceed.
  • Lowering EGR33: Allows diagnostic testing under lighter vacuum closer to atmospheric baro.
  • 3-Bar MAP Sensor Conversions: Multiply EGR33 by 0.667 (two-thirds). Because 3-bar sensors compress the vacuum voltage range, a stock value of 13 counts would require 2.2 psi (4.6 inHg) of vacuum on a 3-bar sensor; scaling to 9 counts restores the stock 1.5 psi (3.1 inHg) threshold.
  • EGR Elimination (255 counts): Setting EGR33 to 255 requires 29.4 psi of vacuum below baro, which is physically impossible. This halts the diagnostic state machine forever, permanently preventing Fault Code 32.
  • Factory Calibration: 13 counts (approx 1.5 psi / 3.1 inHg vacuum) guarantees valid cruising vacuum.
