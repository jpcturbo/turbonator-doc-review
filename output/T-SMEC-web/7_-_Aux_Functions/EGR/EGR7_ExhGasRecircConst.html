1. Overview & Purpose

EGR7 (ExhGasRecircConst) establishes the minimum closed-loop oxygen sensor fuel trim shift threshold required to confirm Exhaust Gas Recirculation valve flow and pass the onboard diagnostic test (Fault Code 32).

During Phase 2, the engine controller commands the EGR valve closed, cutting off inert exhaust gas into the cylinders. This causes combustion air/fuel ratio to shift lean, forcing the closed-loop integrator to ramp richer to restore stoichiometry. The controller subtracts the filtered Phase 1 baseline trim (EGRVar5) from the peak Phase 2 trim (EGRVar6) and compares the delta against EGR7 at line 5506.

The factory setting of 0 counts requires any positive fuel trim shift to confirm gas flow and pass the test.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosing Routine: ExhGasRecirc_MM (lines 5383–5545), specifically at line 5506.
  • State Condition: Phase 2 active (EGRVar2 bit 7 set) and all Phase 2 window checks passed.
  • Calculated Delta: Counter_PrimaryAndSecondaryRamp - EGRVar5 stored in EGRVar7 (RAM address 0x00A1).
  • Comparison: cmpa EGR7_ExhGasRecircConst at line 5506.
  • Branch Behavior: If delta >= EGR7, advances to L1469 (clears failure counter EGRVar1, sets pass bit 6 in EGRVar2, clears fault bit 7 in b46_IPL2, and restores EGR to on). If delta < EGR7, branches to L1474 to keep checking until timeout.

3. Tuner's Guide & Real-World Calibration

  • Raising EGR7: Demands a more pronounced fuel trim shift (richer integration) when the EGR valve shuts off. Enhances diagnostic stringency on stock engines, but can trigger false failures if EGR passages are moderately carbon-fouled.
  • Factory Setting (0 counts): Any positive shift between peak Phase 2 ramp and Phase 1 baseline passes the test, maximizing monitor completion under varied weather and fuel conditions.
  • EGR Block-Off Reality: When an EGR block-off plate is installed, no exhaust gas flows; closing the valve produces zero fuel trim shift, causing the delta to stay below EGR7 and eventually setting Fault Code 32 unless EGR1 or cfg_EGR is adjusted.
  • Diagnostic Pass Actions: Passing the test immediately clears EGRVar1 (failure counter), latches bit 6 in EGRVar2, and clears bit 7 in b46_IPL2 (clearing active Fault Code 32).

4. Technical / Assembly Mechanics (Reference)

Inside T-SMEC_v19.asm: At line 5500, accumulator A loads Counter_PrimaryAndSecondaryRamp and compares it against peak Phase 2 tracker EGRVar6 at line 5501. If higher, line 5503 updates EGRVar6. At line 5504, accumulator A subtracts the Phase 1 baseline EGRVar5 (suba EGRVar5), and stores the difference into EGRVar7 at line 5505. Line 5506 executes cmpa EGR7_ExhGasRecircConst. If accumulator A is lower than EGR7 (factory 0x00 = 0), bcs L1474 branches to continue Phase 2. If A meets or exceeds EGR7, execution falls into L1469 (line 5508): EGRVar1 is cleared (clr EGRVar1), bit 6 is set in EGRVar2 (bset *EGRVar2, #bit_bit6), bit 7 is cleared in EGRVar2, and bit 7 is cleared in b46_IPL2, clearing Fault Code 32 and restoring normal EGR operation via bra EGR_SetEGRtoOn.
