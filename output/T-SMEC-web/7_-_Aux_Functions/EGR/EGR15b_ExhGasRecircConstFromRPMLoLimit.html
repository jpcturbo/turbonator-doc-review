1. Overview & Purpose

EGR15B (ExhGasRecircConstFromRPMLoLimit15b) establishes the upper engine speed boundary for the Phase 1 Exhaust Gas Recirculation diagnostic baseline sampling window.

Located immediately following EGR15 in calibration memory, this parameter defines the maximum engine speed under which Phase 1 baseline oxygen sensor tracking is permitted to operate. Evaluated at offset +1 from the EGR15 base pointer during the boundary check at line 5437, EGR15B ensures that baseline sampling does not take place under high engine RPM conditions.

In the factory calibration, EGR15B is set to 255 counts (8160 RPM), allowing baseline tracking up to maximum engine speed provided other cruising criteria are met.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosing Routine: ExhGasRecirc_MM (lines 5383–5545), specifically via call at line 5438.
  • Subroutine Called: EGR_CheckHiLoLimits (lines 5462–5468), specifically line 5465.
  • Input Variable: EngineRpm_HB evaluated in accumulator A against offset 0x01,x.
  • Register Pointer: Index register X loaded with #EGR15_ExhGasRecircConstFromRPMLoLimit.
  • Branch Behavior: If EngineRpm_HB > EGR15B (bhi L1464), subroutine pulls stack (pulx) and branches to EGR_ResetEGRVars.

3. Tuner's Guide & Real-World Calibration

  • Lowering EGR15B: Caps the maximum engine speed for Phase 1 baseline sampling. Useful to restrict testing strictly to moderate highway cruising speeds (e.g. 80 counts = 2560 RPM).
  • Factory Ceiling (255 counts): Allows Phase 1 to sample across all normal operating speeds up to 8160 RPM.
  • Window Polarity Requirement: Must remain greater than or equal to EGR15 to ensure a valid operating range.
  • Resolution: Scaled at 32 RPM per count based on the high byte of the engine speed register.
