1. Overview & Purpose

EGR13 (ExhGasRecircConstFromRPM) establishes the manual transmission engine speed enable threshold for Exhaust Gas Recirculation solenoid control.

In vehicles equipped with a manual transmission, the engine controller checks whether engine speed is high enough to support EGR dilution without causing engine bucking or hesitation in gear.

At line 5390, the controller tests the automatic transmission configuration bit. If the vehicle is an automatic, this logic is bypassed entirely. On manual transmission configurations, the controller loads EGR13 and compares it against the high byte of engine speed (EngineRpm_HB). The factory calibration setting of 0 counts enables EGR operation across all off-idle engine speeds on manual vehicles.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosing Routine: ExhGasRecirc_MM (lines 5383–5545), specifically at line 5393.
  • Precondition: CONFIG_ConfigurationFlags bit cfg_ATX clear (manual transmission).
  • Throttle Check: Line 5392 tests b4f_OffIdle; if clear (at idle), branches to turn EGR off.
  • Input Variable: EngineRpm_HB evaluated against EGR13 (or EGR13 + EGR10 if EGR currently off).
  • Branch Behavior: If EngineRpm_HB >= threshold (bls L1456), permits EGR to proceed to runtime check.

3. Tuner's Guide & Real-World Calibration

  • Transmission Specificity: Active only when cfg_ATX is clear (manual transmission vehicles). Bypassed completely on automatic transmission calibrations.
  • Raising EGR13 (MTX): Sets a minimum engine speed floor for EGR activation (32 RPM per count). Setting 50 counts (1600 RPM) eliminates low-RPM surge with aggressive camshafts.
  • EGR Elimination (255 counts on MTX): Permanently disables EGR on manual transmission calibrations by creating an unachievable 8160 RPM turn-on threshold.
  • Factory Calibration: 0 counts allows EGR operation at any engine speed once the throttle opens off idle.

4. Technical / Assembly Mechanics (Reference)

Inside T-SMEC_v19.asm: In ExhGasRecirc_MM, line 5390 tests cfg_ATX in CONFIG_ConfigurationFlags. If set, bne L1456 skips manual transmission checks. If clear (MTX), line 5392 verifies b4f_OffIdle (brclr *BitFlags_4f, #b4f_OffIdle, L1457). Line 5393 loads EGR13_ExhGasRecircConstFromRPM into accumulator A, and line 5394 loads EGR11 into B. Line 5395 tests if EGR is already on (brset *BitFlags_2d, #b2d_EGR, L1455). If EGR is currently off, line 5396 adds hysteresis EGR10 to accumulator A. Line 5398 compares A against EngineRpm_HB. If EngineRpm_HB is greater than or equal to A, line 5399 branches via bls L1456 to allow EGR. Otherwise, it checks MAP.
