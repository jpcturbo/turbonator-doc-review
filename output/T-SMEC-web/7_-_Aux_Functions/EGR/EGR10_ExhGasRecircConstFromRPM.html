1. Overview & Purpose

EGR10 (ExhGasRecircConstFromRPM) establishes the manual transmission engine speed hysteresis adder for Exhaust Gas Recirculation solenoid control.

On manual transmission vehicles, if the EGR valve were to switch on and off at the exact same engine speed, minor RPM fluctuations during cruise would cause annoying solenoid clicking and vehicle surging.

To prevent this cycling, the engine controller adds EGR10 to base threshold EGR13 whenever the EGR solenoid is currently off. This creates a higher turn-on threshold (EGR13 + EGR10) while allowing EGR to remain on until engine speed drops below EGR13. The factory calibration setting of 0 counts disables engine speed hysteresis on manual calibrations.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosing Routine: ExhGasRecirc_MM (lines 5383–5545), specifically at line 5396.
  • Precondition: cfg_ATX clear (manual transmission) and b4f_OffIdle set.
  • State Test: Line 5395 tests b2d_EGR in BitFlags_2d; if clear (EGR currently off), executes line 5396.
  • Arithmetic: A = EGR13 + EGR10_ExhGasRecircConstFromRPM.
  • Branch Behavior: If EngineRpm_HB >= (EGR13 + EGR10) (bls L1456), permits EGR to engage.

3. Tuner's Guide & Real-World Calibration

  • Manual Transmission Hysteresis: Operates exclusively on manual transmission vehicles (cfg_ATX clear). Has no function on automatic calibrations.
  • Raising EGR10: Widens the engine speed deadband between turn-on and turn-off. For example, 6 counts provides a 192 RPM deadband (6 x 32 RPM).
  • Solenoid Chatter Prevention: Eliminates rapid solenoid cycling when cruising near the base EGR13 enable threshold.
  • Factory Calibration: 0 counts provides zero hysteresis in stock configurations.

4. Technical / Assembly Mechanics (Reference)

Inside T-SMEC_v19.asm: In ExhGasRecirc_MM, if cfg_ATX is clear and b4f_OffIdle is set, line 5393 loads EGR13 into accumulator A.
