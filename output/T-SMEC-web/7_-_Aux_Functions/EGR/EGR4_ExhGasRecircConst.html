1. Overview & Purpose

EGR4 (ExhGasRecircConst) establishes the cumulative diagnostic failure threshold before the engine controller logs Fault Code 32 (EGR System Failure) and illuminates the Check Engine lamp.

During Phase 2 flow verification, if the diagnostic timer expires without detecting the required oxygen sensor shift, the controller increments a dedicated failure counter in RAM (EGRVar1).

At line 5520, the controller compares this failure counter against EGR4. The factory setting of 235 attempts provides substantial filtering against transient driving disturbances, requiring the EGR monitor to fail repeatedly across multiple driving sequences before setting an active trouble code.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosing Routine: ExhGasRecirc_MM (lines 5383–5545), specifically at line 5520.
  • Trigger Condition: Phase 2 diagnostic timer timeout (EGRVar3 >= EGR6_ExhGasRecircConst at line 5485) branching to L1470.
  • State Counter: EGRVar1 (RAM address 0x00A0), incremented at line 5518.
  • Comparison: cmpa EGR4_ExhGasRecircConst at line 5520.
  • Fault Trigger: If EGRVar1 >= EGR4, executes ThrowNonCriticalError with error code 0x2E01 (Fault Code 32) and sets bit 7 of b46_IPL2.

3. Tuner's Guide & Real-World Calibration

  • Raising EGR4 (to 255): Maximizes fault filtering, requiring 255 failed test cycles before setting Fault Code 32. Effective for silencing intermittent fault codes on high-mileage EGR valves or modified camshaft engines.
  • Lowering EGR4: Speeds up fault reporting. Setting this parameter to 1 or 2 causes Fault Code 32 to trigger on the very first or second failed test attempt.
  • EGR Delete Applications: Setting EGR4 to 255 complements physical EGR block-off plates, preventing Fault Code 32 from latching during normal driving.
  • Factory Calibration: 235 attempts provides factory-grade noise immunity against road and load fluctuations.

4. Technical / Assembly Mechanics (Reference)

Inside T-SMEC_v19.asm: When Phase 2 times out without satisfying the oxygen sensor shift delta (EGR7), the CPU branches to L1470 (line 5514). It clears EGRVar3 via stD *EGRVar3, loads failure counter EGRVar1 into accumulator A, increments it via inca, and stores it back (staa EGRVar1). At line 5520, the CPU executes cmpa EGR4_ExhGasRecircConst. If A is less than EGR4 (factory 0xEB = 235 counts), bcs L1471 skips fault generation. If A meets or exceeds EGR4, line 5522 loads double-word 0x2E01 into register D, calls ThrowNonCriticalError at line 5523, and sets bit 7 in b46_IPL2 at line 5524, activating the Check Engine lamp for Fault Code 32.

5. Calibration Notes & System Dependencies

  • Single-Byte Type 3 Constant: Located at calibration address 0x1A96 (calculated ROM address 0x86E5 / template org 0x882D).
  • Error Code Coupling: Directly governs invocation of diagnostic trouble code 32 (0x2E01) in the SMEC diagnostic reporting subsystem.
  • Non-Volatile Fault Latching: Setting bit 7 in b46_IPL2 causes the fault to be mirrored to EEPROM error memory during controller shutdown.
