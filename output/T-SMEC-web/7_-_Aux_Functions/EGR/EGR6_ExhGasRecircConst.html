1. Overview & Purpose

EGR6 (ExhGasRecircConst) establishes the high byte of the 16-bit Phase 2 diagnostic timeout timer threshold for the Exhaust Gas Recirculation flow verification routine.

During Phase 2, the engine controller de-energizes the EGR solenoid to shut off exhaust gas flow into the intake manifold and waits for closed-loop oxygen sensor feedback to register a lean shift. The controller requires an upper time limit on this test so that prolonged solenoid de-energization does not unnecessarily alter emissions or driveability if the valve is stuck.

Although defined in calibration templates as an 8-bit constant, the CPU reads EGR6 with a 16-bit comparison instruction at line 5485, pairing EGR6 (1 count) as the high byte with adjacent byte EGR15A (108 counts) as the low byte. This combined 16-bit threshold of 364 loop iterations corresponds to approximately 3.6 to 5.5 seconds.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosing Routine: ExhGasRecirc_MM (lines 5383–5545), specifically at line 5485.
  • State Condition: Phase 2 active (EGRVar2 bit 7 set).
  • Input Variable: 16-bit RAM loop counter EGRVar3 evaluated in index register X.
  • Comparison: 16-bit index comparison cpx EGR6_ExhGasRecircConst.
  • Branch Behavior: If EGRVar3 >= 0x016C (bcc L1470), Phase 2 times out, branching to L1470 to increment failure counter EGRVar1. If EGRVar3 < 0x016C, increments EGRVar3 and proceeds to window checks.

3. Tuner's Guide & Real-World Calibration

  • 16-Bit Firmware Anomaly: In T-SMEC_v19.asm line 5485, the CPU executes a 16-bit comparison against EGR6_ExhGasRecircConst. EGR6 serves as the high byte (1 count) and contiguous byte EGR15A serves as the low byte (108 counts), forming the 16-bit threshold of 364 counts.
  • Raising EGR6: Adds 256 loop counts (roughly 2.5 to 3.8 seconds) per integer increase to the Phase 2 timeout window. Highly beneficial for headers or high-flow plenums where exhaust gas transport delay is longer.
  • Lowering EGR6 (to 0): Reduces the timeout window to strictly the low byte EGR15A (108 counts / ~1.1 to 1.6 seconds), which risks false diagnostic failures.
  • Calibration Protocol: When adjusting Phase 2 timeout, calculate (EGR6 * 256) + EGR15A to determine the exact 16-bit threshold.

4. Technical / Assembly Mechanics (Reference)

Inside T-SMEC_v19.asm: In ExhGasRecirc_MM, when EGRVar2 bit 7 is set, line 5425 branches to L1467 (line 5485). At line 5485, index register X (holding 16-bit counter EGRVar3) is evaluated via cpx EGR6_ExhGasRecircConst. The 6811 CPU reads a 16-bit word from the calibration address: the high byte is loaded from EGR6 (ROM address 0x1AB0 / org 0x882F, data 0x01), and the low byte is loaded from adjacent address EGR15A (ROM address 0x1ABD / org 0x8830, data 0x6C), yielding 0x016C (364 decimal). If X meets or exceeds 0x016C, bcc L1470 branches to line 5514 to process a diagnostic failure. If X is less than 0x016C, line 5487 increments X (inx), stores it back to EGRVar3 (stx EGRVar3), and checks MAP window EGR16.

L1467:	cpx  EGR6_ExhGasRecircConst	;  (data is 016c)
	bcc  L1470	    ; branch if greater or equal
L1468:	inx		    ; increment index (x=x+1)
	stx  EGRVar3    ; store index into memory
	ldaa MapValue	    ; load a with memory contents

5. Calibration Notes & System Dependencies

  • 16-Bit Firmware Anomaly: Documented in smec_anomaly.md. Defined in templates as Type 3 single-byte constant, but the firmware reads it as the upper half of a 16-bit operand via cpx.
  • Paired with EGR15A: Must be modified in coordination with EGR15A, which supplies the low byte (0x6C).
  • Physical Time Equivalent: 364 counts represents roughly 3.6 to 5.5 seconds depending on background loop execution time.
