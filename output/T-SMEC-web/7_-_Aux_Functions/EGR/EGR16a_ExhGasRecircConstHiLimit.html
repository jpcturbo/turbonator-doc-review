1. Overview & Purpose

EGR16A (ExhGasRecircConstHiLimit16a) establishes the upper manifold absolute pressure boundary for the Phase 2 Exhaust Gas Recirculation diagnostic verification window (Fault Code 32).

Positioned immediately following EGR16 in calibration ROM, this constant caps the maximum intake manifold pressure allowed while the engine controller tests for oxygen sensor response following EGR valve shutoff. If the driver accelerates moderately and intake manifold pressure rises above EGR16A, the boundary checking routine detects the violation, aborts Phase 2, and resets the diagnostic counters.

The factory calibration sets EGR16A to 255 counts, ensuring that the upper ceiling does not prematurely interrupt diagnostic testing during steady-state cruising.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosing Routine: ExhGasRecirc_MM (lines 5383–5545), specifically via call at line 5491.
  • Subroutine Called: EGR_CheckHiLoLimits (lines 5462–5468), specifically line 5465.
  • Input Variable: MapValue evaluated in accumulator A against offset 0x01,x from #EGR16_ExhGasRecircConstLoLimit.
  • State Condition: Phase 2 active (EGRVar2 bit 7 set).
  • Branch Behavior: If MapValue > EGR16A (bhi L1464), pulls return address off stack (pulx) and branches to EGR_ResetEGRVars.

3. Tuner's Guide & Real-World Calibration

  • Lowering EGR16A: Imposes a ceiling on intake manifold pressure during Phase 2 flow verification. If pressure rises above this limit, Phase 2 terminates immediately.
  • Factory Calibration (255 counts): Maximizes monitor completion by keeping the upper boundary at full-scale pressure.
  • 3-Bar MAP Sensor Calibration: When converting to a 3-bar sensor, multiply custom MAP thresholds by 0.667 (two-thirds) to preserve the intended manifold vacuum operating range.
  • Consistency Rule: Never set EGR16A lower than EGR16, which creates an unachievable window that resets the diagnostic state machine continuously.
