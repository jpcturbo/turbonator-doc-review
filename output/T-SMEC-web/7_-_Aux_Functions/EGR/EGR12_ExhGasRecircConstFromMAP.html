1. Overview & Purpose

EGR12 (ExhGasRecircConstFromMAP) establishes the manual transmission manifold absolute pressure hysteresis adder for Exhaust Gas Recirculation solenoid control.

On manual transmission vehicles, if intake manifold pressure fluctuates near the base enable threshold (EGR11), rapid solenoid cycling can occur. To provide a stable pressure deadband, the engine controller adds EGR12 to EGR11 whenever the EGR solenoid is currently off. This requires manifold pressure to rise to a higher turn-on threshold (EGR11 + EGR12) before engaging EGR, while allowing EGR to remain active until pressure drops below EGR11.

The factory calibration setting of 0 counts disables pressure hysteresis on manual vehicles.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosing Routine: ExhGasRecirc_MM (lines 5383–5545), specifically at line 5397.
  • Precondition: cfg_ATX clear (manual transmission) and b4f_OffIdle set.
  • State Test: Line 5395 tests b2d_EGR in BitFlags_2d; if clear (EGR currently off), executes line 5397.
  • Arithmetic: B = EGR11 + EGR12_ExhGasRecircConstFromMAP.
  • Branch Behavior: If MapValue < (EGR11 + EGR12) (bhi L1457), branches to turn EGR off via EGR_SetEGRtoOff.

3. Tuner's Guide & Real-World Calibration

  • Manual Transmission Hysteresis: Operates exclusively on manual transmission vehicles (cfg_ATX clear). Has no effect on automatics.
  • Raising EGR12: Widens the manifold pressure turn-on hysteresis band. For example, 10 counts provides ~1.1 psi hysteresis in a 2-bar calibration.
  • 3-Bar MAP Scaling: If modified for custom 3-bar calibrations, multiply by 0.667 (two-thirds) to compensate for sensor scaling.
  • Factory Calibration: 0 counts provides zero pressure hysteresis in stock calibrations.
