1. Overview & Purpose

EGR15A (ExhGasRecircConstFromRPMHiLimit15a) represents the low byte of the 16-bit Phase 2 diagnostic timeout timer threshold in the Exhaust Gas Recirculation verification routine.

Although labeled in calibration templates as an engine speed high limit, firmware reverse engineering of T-SMEC_v19.asm confirms that this label is a complete misnomer. The actual RPM limits are governed by EGR15/EGR15B (Phase 1) and EGR17/EGR17A (Phase 2).

In executable firmware, EGR15A resides in calibration memory directly following EGR6. When the CPU executes line 5485, it reads a 16-bit word where EGR6 is the high byte (1 count) and EGR15A is the low byte (108 counts), combining into the 364-count diagnostic timeout threshold.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosing Routine: ExhGasRecirc_MM (lines 5383–5545), specifically line 5485.
  • Execution Context: Evaluated as part of the 16-bit instruction cpx EGR6_ExhGasRecircConst.
  • Input Variable: Index register X holding 16-bit diagnostic counter EGRVar3.
  • Memory Address: Stored at ROM address 0x1ABD (calculated address 0x86E8 / org 0x8830), which is the low byte of operand EGR6.
  • Branch Behavior: If EGRVar3 >= 0x016C (bcc L1470), branches to timeout failure handler.

3. Tuner's Guide & Real-World Calibration

  • Template Misnomer Anomaly: Labeled in MPTune as ExhGasRecircConstFromRPMHiLimit, but has no connection to RPM. It is the low byte of 16-bit constant EGR6.
  • Fine-Tuning Timeout: Each count added or subtracted adjusts the Phase 2 timeout window by approximately 10 to 15 milliseconds.
  • Combined Math: Total Phase 2 timeout counts equal (EGR6 * 256) + EGR15A. Factory settings: (1 * 256) + 108 = 364 counts (approx 3.6 to 5.5 seconds).
  • Diagnostic Tuning: If installing headers causes delayed oxygen sensor response, raising EGR15A to 200 or raising EGR6 to 2 provides extra response headroom.

4. Technical / Assembly Mechanics (Reference)

Inside T-SMEC_v19.asm: At line 5485, the CPU encounters opcode 0x8C (cpx), followed by the 16-bit absolute address of EGR6_ExhGasRecircConst (0x882F in stock ROM mapping). The CPU fetches the high byte from 0x882F (EGR6, data 0x01) and the low byte from 0x8830 (EGR15A, data 0x6C), constructing the 16-bit comparison operand 0x016C (364 decimal). This value is compared against index register X (EGRVar3). EGR15A is never referenced by any RPM checking code; RPM checking is handled exclusively by EGR15/EGR15B and EGR17/EGR17A.

; --- ExhGasRecirc_MM (T-SMEC_v19.asm:5485-5491) ---
L1467:	cpx  EGR6_ExhGasRecircConst	;  (data is 016c)
	bcc  L1470	    ; branch if greater or equal
L1468:	inx		    ; increment index (x=x+1)
	stx  EGRVar3    ; store index into memory
	ldaa MapValue	    ; load a with memory contents
	ldx  #EGR16_ExhGasRecircConstLoLimit	; load index with value
	bsr  EGR_CheckHiLoLimits    ; call subroutine

5. Calibration Notes & System Dependencies

  • Firmware Anomaly: Documented in smec_anomaly.md. The template label EGR15a_ExhGasRecircConstFromRPMHiLimit is erroneous; it functions as the low byte of EGR6.
  • Adjacent Storage: Located immediately between EGR6 (0x882F) and EGR7 (0x8831).
  • Resolution: 1 count represents a single background loop iteration (approx 10 to 15 milliseconds).
