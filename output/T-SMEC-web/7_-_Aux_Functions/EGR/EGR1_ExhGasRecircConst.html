1. Overview & Purpose

EGR1 (ExhGasRecircConst) establishes the Phase 1 diagnostic sampling timer threshold for the onboard Exhaust Gas Recirculation flow verification system (Fault Code 32).

During closed-loop cruising, the engine controller requires stable operating conditions before testing whether the EGR valve actually delivers exhaust gas to the intake manifold. The controller tests that manifold pressure, throttle angle, and engine speed remain within prescribed test windows while the EGR solenoid is energized. While these conditions hold, an internal diagnostic counter increments once per background execution loop pass.

The factory setting of 455 loop counts corresponds to approximately 4.5 to 6.8 seconds of continuous, undisturbed cruising. If the vehicle operates steadily for this entire period, the controller freezes its filtered baseline oxygen sensor fuel trim and advances to Phase 2 of the diagnostic test.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosing Routine: ExhGasRecirc_MM (lines 5383–5545), specifically at line 5426.
  • Preconditions Checked: Closed-loop fueling active (b50_StayOpenLoop clear), oxygen sensor valid (b4f_O2Valid set), off-idle throttle (b4f_OffIdle set), purge solenoid active (pia1abuf_PurgeSolenoid set), no active limiter/fault masks (IPLMSK_PowerLossLightMask), and intake manifold vacuum (BaroPressure - MapValue >= EGR33).
  • State Variable: EGRVar2 bit 7 clear (Phase 1 active).
  • Comparison: Evaluates 16-bit diagnostic loop counter EGRVar3 against EGR1_ExhGasRecircConst.
  • Branch Behavior: If EGRVar3 > EGR1 (bhi L1466), branches to enter Phase 2 (clears loop index, sets EGRVar2 bit 7, copies baseline EGRVar5 to EGRVar6). If EGRVar3 <= EGR1, continues Phase 1 window checks.

3. Tuner's Guide & Real-World Calibration

  • Raising EGR1: Increases the duration of steady cruising required to satisfy Phase 1 baseline sampling. This reduces diagnostic test frequency during stop-and-go driving, requiring longer highway cruises to complete.
  • Lowering EGR1: Shortens the required Phase 1 sampling window, accelerating the transition to Phase 2 EGR shutoff testing. If lowered excessively below 200 counts (roughly 2 seconds), baseline fuel trim may not stabilize, increasing the risk of false Fault Code 32 triggers.
  • EGR Elimination Scenarios: Setting EGR1 to its maximum 16-bit ceiling (65535 counts) ensures the diagnostic timer never elapses during ordinary driving cycles. This cleanly prevents Phase 2 testing and suppresses Fault Code 32 when an EGR block-off plate is installed on modified turbo builds.
  • Stock Applications: Retaining the factory calibration of 455 counts preserves complete OBD-I emissions compliance and provides robust immunity against false diagnostic failures.

4. Technical / Assembly Mechanics (Reference)

Inside T-SMEC_v19.asm: In the foreground EGR executive routine ExhGasRecirc_MM, the CPU loads the 16-bit RAM counter EGRVar3 into index register X and tests bit 7 of EGRVar2. When bit 7 is clear, Phase 1 baseline tracking is underway. The CPU performs a 16-bit comparison cpx EGR1_ExhGasRecircConst at line 5426. If X exceeds EGR1 (factory 0x01C7 = 455 counts), the routine branches via bhi L1466 to initialize Phase 2: register X is cleared, bit 7 of EGRVar2 is set to latch Phase 2 mode, and the filtered oxygen sensor fuel trim accumulator EGRVar5 is latched into EGRVar6. If X remains less than or equal to EGR1, the CPU evaluates the Phase 1 stability windows (EGR18, EGR14, EGR15) and increments EGRVar3 via inx; stx EGRVar3.
