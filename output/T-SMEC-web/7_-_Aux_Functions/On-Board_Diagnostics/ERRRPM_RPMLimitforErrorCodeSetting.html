1. Overview & Purpose

ERRRPM defines the minimum engine speed threshold required before the engine controller latches major system fault codes and illuminates the check engine lamp.

In Chrysler SMEC firmware, minor transient electrical faults are filtered and held in pending registers, while major system faults that affect emissions and drivability must be confirmed before escalating to a latched error state. During low-speed operation or idle, minor sensor fluctuations or engine speed dips could trigger nuisance error codes.

In factory calibrations, ERRRPM is set to 56 counts, corresponding to approximately 1792 RPM. The engine controller requires engine speed to reach or exceed ERRRPM before it will escalate qualifying pending faults into a confirmed major fault state.

3. Tuner's Guide & Real-World Calibration

  • Major Fault Code Escalation Gate:
  • Confirms pending error flags into latched b46_MajorFault status, turning on the check engine lamp.
  • Raising for Stumble Suppression:
  • Raising ERRRPM to 2200 RPM prevents rough low-speed cruising on radical cam engines from latching major trouble codes.
  • Lowering & Edge Cases:
  • Lowering ERRRPM below 1000 RPM allows major codes to set during idle.
  • Setting ERRRPM to maximum (255 counts / 8160 RPM) prevents major fault code confirmation and keeps the check engine light off for these checks.
