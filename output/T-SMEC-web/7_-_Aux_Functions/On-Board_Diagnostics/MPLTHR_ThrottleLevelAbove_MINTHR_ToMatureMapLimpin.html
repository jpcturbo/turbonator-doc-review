1. Overview & Purpose

MPLTHR defines the throttle angle threshold above closed throttle above which electrical diagnostic checking of the manifold absolute pressure sensor is bypassed.

During large or rapid throttle openings, intake manifold pressure changes rapidly as turbo boost develops, causing brief transient electrical fluctuations. To prevent transient throttle stomps from falsely triggering electrical fault codes, the engine controller restricts electrical MAP range checks to low-throttle operating conditions.

In factory calibrations, MPLTHR is set to 66 counts, representing approximately 1.29 volts above closed-throttle resting voltage. If measured throttle position exceeds minimum session throttle by more than MPLTHR, the engine controller bypasses the electrical MAPLOW and MAPHIG checks on that loop.

3. Tuner's Guide & Real-World Calibration

  • Transient Fault Suppression:
  • If rapid throttle stomps trigger false Fault Code 14 on highly modified engines, lowering MPLTHR slightly confines electrical checks strictly to lower throttle angles.
  • Diagnostic Coverage:
  • Raising MPLTHR allows the engine controller to verify sensor integrity at higher throttle openings.
  • Edge Cases:
  • Setting MPLTHR to zero suspends electrical MAP testing anytime the throttle is cracked open.
  • Setting MPLTHR to 255 counts subjects wide-open throttle boost operation to electrical low/high screening.
