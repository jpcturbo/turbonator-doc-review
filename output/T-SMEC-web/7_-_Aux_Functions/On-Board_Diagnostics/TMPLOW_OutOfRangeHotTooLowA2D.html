1. Overview & Purpose

TMPLOW defines the lower electrical voltage boundary for the engine coolant temperature sensor analog input circuit.

Because the coolant temperature sensor is a negative temperature coefficient thermistor, its electrical resistance decreases as engine temperature rises, pulling the signal voltage toward ground. Under extreme overheating or in the event of a wiring short circuit to ground or an internal thermistor short, the signal voltage drops close to zero volts.

In factory calibrations, TMPLOW is set to 26 counts, which corresponds to approximately 0.51 volts (roughly equivalent to a coolant temperature exceeding 250 deg F). If sensor voltage drops below TMPLOW, the engine controller flags Fault Code 22, latches a sensor fault, activates the radiator fan continuously, and initiates temperature substitution.

3. Tuner's Guide & Real-World Calibration

  • Track & Heavy Load Headroom:
  • For road-course racing where sustained coolant temperatures reach 230 to 240 deg F, keep TMPLOW at or slightly below 26 counts to avoid premature short-circuit fault setting.
  • Short Circuit Troubleshooting:
  • If Fault Code 22 sets when the sensor is plugged in, inspect for a chafed signal wire grounded to the thermostat housing or intake manifold.
  • Lowering & Edge Cases:
  • Zeroing TMPLOW disables short-to-ground detection.
  • Raising TMPLOW too high causes the engine controller to flag Fault Code 22 under normal engine operating temperatures (195 to 210 deg F).
