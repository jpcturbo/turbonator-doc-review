1. Overview & Purpose

MPRPMH defines the upper engine speed limit for the manifold absolute pressure sensor steady-state rationality validation window.

The engine controller continuously monitors the health of the primary pressure sensor during engine operation. However, at elevated engine speeds during rapid acceleration or varying road load, manifold pressure changes rapidly and transiently, making steady-state rationality validation inaccurate.

In factory calibrations, MPRPMH is configured to 12000 counts, corresponding to exactly 1500 RPM. If engine speed equals or exceeds MPRPMH, the engine controller suspends the steady-state MAP sensor check, confining sensor health validation to stable idle and gentle off-idle operation.

  • Gating Conditions:
  • Checked immediately after confirming engine speed >= MPRPML at line 7052.

  • If greater or equal (bcc), branches to L1595 at line 7055, bypassing assertion of b47_MapOK.
  • If lower, continues to verify manifold pressure within [MPDAGL, MPDAGH].

3. Tuner's Guide & Real-World Calibration

  • Window Ceiling Adjustment:
  • Raising MPRPMH to 2000 RPM allows steady-state sensor validation during gentle neighborhood cruising.
  • Lowering MPRPMH to 1200 RPM restricts validation strictly to warm idle.
  • Boundary Consistency:
  • Never set MPRPMH lower than MPRPML (600 RPM); doing so permanently disables the steady-state MAP rationality test.
  • Edge Cases:
  • Setting MPRPMH to maximum (e.g., 6000 RPM) attempts steady-state validation during wide-open throttle acceleration, leading to false diagnostic flags.
