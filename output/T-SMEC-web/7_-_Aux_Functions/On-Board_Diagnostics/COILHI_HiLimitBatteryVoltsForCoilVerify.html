1. Overview & Purpose

COILHI defines the upper battery voltage boundary for enabling the secondary ignition coil driver diagnostic routine.

This secondary ignition diagnostic is specifically designed to monitor ignition coil behavior during engine cranking and low battery voltage operation prior to full alternator charging. Once the engine starts and the alternator charges the electrical system up to normal running voltage (13.5 to 14.5 volts), primary coil verification shifts to direct driver sense feedback.

In factory calibrations, COILHI is set to 186 counts, corresponding to approximately 11.6 volts. If battery voltage equals or exceeds COILHI, the secondary coil verification check is bypassed, ensuring that the test operates strictly under sub-charging voltage conditions.

  • Gating Conditions:

  • Math & Comparison:

  • If greater or equal (bcc), branches to R1424 at line 5175, exiting without running secondary coil checks.
  • If lower, continues to evaluate manifold pressure disturbance against COILLO.

3. Tuner's Guide & Real-World Calibration

  • Voltage Window Boundary:
  • Confines secondary coil testing between 6.5 volts and 11.6 volts.
  • Ensures the secondary test automatically turns off once the alternator charges the electrical system above 11.6 volts.
  • Cranking Diagnostics:
  • If false Fault Code 43 codes occur during prolonged cranking on strong batteries, verify that COILHI is not set excessively high.
  • Edge Cases:
  • Setting COILHI below 6.5 volts permanently disables this secondary ignition coil diagnostic.
  • Setting COILHI to 255 counts leaves the secondary check active continuously even during normal highway driving.
