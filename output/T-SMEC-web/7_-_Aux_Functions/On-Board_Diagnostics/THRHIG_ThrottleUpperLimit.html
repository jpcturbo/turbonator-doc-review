1. Overview & Purpose

THRHIG defines the upper electrical voltage boundary for the throttle position sensor analog input circuit.

Under wide-open throttle conditions, a correctly adjusted factory throttle potentiometer typically delivers an output between 3.8 and 4.4 volts. If the sensor signal wire chafes and shorts directly to the 5.0-volt supply rail or if an internal sensor failure connects the wiper directly to the high reference pin, the signal voltage saturates near 5.0 volts.

In factory calibrations, THRHIG is configured to 240 counts, representing approximately 4.71 volts. When the sensor signal equals or exceeds THRHIG, the engine controller flags Fault Code 24, latches a defective throttle sensor flag, and replaces live throttle readings with synthetic values derived from manifold pressure.

3. Tuner's Guide & Real-World Calibration

  • Full Throttle Clearance:
  • Verify that wide-open throttle voltage on aftermarket throttle bodies does not exceed THRHIG.
  • If wide-open throttle reaches 4.6 volts, raise THRHIG slightly to 248 counts (4.86 volts) to prevent false fault logging.
  • Short Circuit Detection:
  • If Fault Code 24 sets immediately upon key-on and live TPS voltage reads 4.9 to 5.0 volts, inspect for a harness short between the 5.0-volt reference wire and signal wire.
  • Lowering & Edge Cases:
  • Lowering THRHIG below wide-open throttle voltage triggers limp-in mode under wide-open throttle.
  • Setting THRHIG to 255 counts disables 5.0-volt short-circuit detection.
