1. Overview & Purpose

TTEMPH defines the maximum engine coolant temperature allowed at engine startup to arm the thermostat warm-up diagnostic monitor.

If a vehicle is restarted shortly after being driven, the engine block, cylinder head, and coolant are already hot. Under warm restart conditions, evaluating how fast the engine warms up is meaningless because operating temperature has already been reached.

In factory calibrations, TTEMPH is set to 228 counts, corresponding to approximately 165 deg F. If coolant temperature at key-on equals or exceeds TTEMPH, the engine controller leaves the thermostat diagnostic timer disabled, ensuring the warm-up check only executes on legitimate cold or lukewarm starts.

3. Tuner's Guide & Real-World Calibration

  • Warm Restart Lockout:
  • Prevents warm engine restarts from arming the thermostat warm-up countdown timer.
  • Low-Temp Thermostat Tuning:
  • If running a 160 deg F thermostat, lower TTEMPH to 145 deg F so warm restarts on a 160-degree engine do not falsely re-arm the timer.
  • Edge Cases:
  • Setting TTEMPH below TTEMPL completely disables Fault Code 17.
  • Setting TTEMPH to 255 counts allows arming even when starting a fully heat-soaked engine.
