1. Overview & Purpose

TMPHIG defines the upper electrical voltage boundary for the engine coolant temperature sensor analog input circuit.

The engine controller uses an internal 5.0-volt pull-up resistor connected to the negative temperature coefficient coolant sensor thermistor. As coolant temperature increases, thermistor resistance drops, lowering the measured voltage. Conversely, if the sensor harness is unplugged, a wire breaks, or the sensor develops an internal open circuit, the input voltage is pulled up to the 5.0-volt rail.

In factory calibrations, TMPHIG is configured to 253 counts, representing approximately 4.96 volts (equivalent to a sub-zero reading colder than -40 deg F). If sensor voltage equals or exceeds TMPHIG, the engine controller flags Fault Code 22, commands the radiator cooling fan to run continuously as a safeguard, and substitutes default temperature values.

3. Tuner's Guide & Real-World Calibration

  • Diagnostics & Field Service:
  • If the radiator cooling fan engages at high speed immediately upon key-on and Fault Code 22 is stored, check whether the two-pin coolant sensor plug is disconnected or corroded.
  • Cold Climate Headroom:
  • Lowering TMPHIG risks triggering false open-circuit faults during extreme sub-zero winter starts (colder than -30 deg F).
  • Raising & Edge Cases:
  • Setting TMPHIG to 255 counts blinds the open-circuit detection logic.
  • Setting TMPHIG lower than normal warm engine voltage locks the engine controller permanently into Fault Code 22 failsafe mode.
