1. Overview & Purpose

SRTMTP defines the engine coolant temperature switch point that selects between the warm start pulse counter (SRTIME) and the cold start pulse counter (SRTIME2).

It establishes the controller's definition of a warm restart versus a cold start specifically for the start-to-run spark transfer routine. In factory calibrations, SRTMTP is calibrated to 176 counts, corresponding to approximately 198 degF. If coolant temperature exceeds SRTMTP, the controller executes the warm start-to-run logic (SRTIME); if coolant temperature is at or below SRTMTP, it steps index register X to select the cold start pulse counter (SRTIME2).

3. Tuner's Guide & Real-World Calibration

  • Warm Restart Definition:
  • Factory setting of 198 degF (176 counts) reserves SRTIME strictly for fully heat-soaked restarts, applying SRTIME2 to all lukewarm and cold starts.
  • Lowering for Lukewarm Restarts:
  • Lowering SRTMTP to ~160 degF (150 counts) allows warm restart logic to engage after short stops at the gas station or staging lanes.
  • Pointer Selection Mechanism:
  • Directly controls whether index register X is incremented to point to SRTIME2.
