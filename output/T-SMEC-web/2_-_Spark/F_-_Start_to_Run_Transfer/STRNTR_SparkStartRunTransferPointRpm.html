1. Overview & Purpose

STRNTR defines the engine speed distributor pulse period threshold required to transfer ignition control from cranking Start Mode to normal running Run Mode.

During engine cranking with the starter motor, crankshaft rotation is slow and irregular (typically 150 to 250 RPM). The engine controller holds fixed base trigger spark advance and cranking dwell until the engine catches and spins past STRNTR. In period-based timing logic, smaller count values represent faster engine speeds. In factory calibrations, STRNTR is set to 49 counts, corresponding to approximately 612 RPM. Once the distributor pulse period drops below STRNTR for the consecutive pulse count specified by SRTIME or SRTIME2, the controller formally transitions ignition into Run Mode.

3. Tuner's Guide & Real-World Calibration

  • Period-vs-RPM Inverse Relationship:
  • Increasing STRNTR lowers the target transfer RPM (RPM ≈ 30000 / count); decreasing STRNTR raises the required RPM flare.
  • Cold Start Flare Tuning:
  • If an engine catches on cold mornings but stumbles and stalls when releasing the key, raising STRNTR slightly can help bridge the transfer into running spark tables sooner.
  • Starter Kickback Prevention:
  • Keep STRNTR comfortably above maximum starter cranking speed (at least 550 to 600 RPM) to prevent premature advance during cranking.

  • Consecutive Pulses Required: Crossing STRNTR does not transfer instantly; engine must sustain speed for SRTIME or SRTIME2 pulses.
