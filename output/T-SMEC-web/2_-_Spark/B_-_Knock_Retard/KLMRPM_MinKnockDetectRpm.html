1. Overview & Purpose

KLMRPM defines the engine speed transition boundary that separates the restricted low-RPM knock retard limit (KNKLIM) from the standard dynamic knock retard curve (RETMAX).

While KNKRPM completely turns off knock retard below 1024 RPM, KLMRPM establishes the speed threshold below which the controller enforces the restricted low-RPM knock clamp (KNKLIM) during high-throttle transitions. In factory calibrations, KLMRPM is calibrated to 32 counts, corresponding to 1024 RPM. Once engine speed meets or exceeds KLMRPM, the controller unlocks full knock retard authority using the load-dependent RETMAX curve.

3. Tuner's Guide & Real-World Calibration

  • Extending False Knock Protection:
  • On engines with noisy forged pistons or loud valvetrain assemblies, raise KLMRPM to 1500 RPM (47 counts) to suppress false knock retard during off-idle acceleration.
  • Unlocking Full Retard Sooner:
  • For whisper-quiet stock engines, keeping KLMRPM low ensures full RETMAX retard authority is available as soon as the engine leaves idle.
  • Architecture Symmetry:
  • In stock calibrations, KLMRPM and KNKRPM are both set to 1024 RPM (32 counts).
