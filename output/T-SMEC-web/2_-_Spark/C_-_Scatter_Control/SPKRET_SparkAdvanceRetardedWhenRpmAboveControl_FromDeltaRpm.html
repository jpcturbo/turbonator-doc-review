1. Overview & Purpose

SPKRET defines the spark advance retard curve applied by the spark scatter algorithm when engine speed flares above target idle speed.

Just as SPKADD adds ignition timing when engine speed sags, SPKRET pulls ignition timing when engine speed overshoots target idle. When engine speed exceeds target idle speed, SPKRET is looked up using the positive RPM error delta (divided into 16 RPM increments). The looked-up retard value (up to 16.5 degrees in factory calibrations) is immediately subtracted from calculated spark advance on the next cylinder firing, reducing cylinder combustion pressure and pulling engine speed promptly back down to target.

3. Tuner's Guide & Real-World Calibration

  • Taming Idle Flare:
  • Increasing SPKRET pulls timing more aggressively when idle speed flares, arresting RPM rise before the idle air motor can react.
  • Oscillation Damping:
  • If the engine bounces rhythmically between high and low idle, lower SPKRET to soften the timing drop.
  • Complementary Action:
  • Works symmetrically with SPKADD to form a fast-acting closed-loop timing window around target idle speed.
