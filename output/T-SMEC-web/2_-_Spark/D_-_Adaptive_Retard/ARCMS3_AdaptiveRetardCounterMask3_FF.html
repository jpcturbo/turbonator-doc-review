1. Overview & Purpose

ARCMS3 defines the subtraction decrement value applied to the boost knock persistence timer (Timer_Over5PsiBoostMaxFF) whenever all cylinders are clear of knock retard.

When no cylinders are experiencing detonation, the controller decrements the boost knock timer to eliminate accumulated history. In factory calibrations, ARCMS3 is set to 255 counts (maximum). Subtracting 255 instantly resets Timer_Over5PsiBoostMaxFF to zero on the very first non-knocking loop pass, ensuring that the timer only accumulates when knock is truly continuous and unbroken.

2. Operating Conditions (When Does This Take Effect?)

  • Subroutine & Line Numbers: WGDC_LookAtCylRetards (T-SMEC_v19.asm:9545-9551), called from CalcWGDutyCycleT1.
  • Execution Flow:
  • Reached when all cylinders have zero knock retard and ARCMS2 mask test passes.
  • ldaa Timer_Over5PsiBoostMaxFF loads the current timer.
  • suba ARCMS3_AdaptiveRetardCounterMask3_FF at line 9546.
  • If carry clear (bcc WGDC_Store5psiBoostTimer), remaining value is stored; if carry set (underflow), branches to clear timer to 0.

3. Tuner's Guide & Real-World Calibration

  • Instant Timer Clearing:
  • Factory setting of 255 resets Timer_Over5PsiBoostMaxFF to zero immediately when knock ceases, preventing intermittent ping from accumulating.
  • Gradual Decay Alternative:
  • Lowering ARCMS3 to a small value (e.g., 1 to 5 counts) allows the timer to decay gradually, linking intermittent knock events together.
  • Standard Recommendation:
  • Retain factory setting of 255 for predictable, reliable adaptive knock behavior.
