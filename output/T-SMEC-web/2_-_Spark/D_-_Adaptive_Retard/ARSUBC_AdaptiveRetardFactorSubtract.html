1. Overview & Purpose

ARSUBC defines the decay step size subtracted from the adaptive retard index (AdaptiveRetardIndex) every time the engine undergoes a successful start-to-run transition.

Once adaptive retard has accumulated in response to knock, the controller needs a systematic method to decay the learned retard back toward zero as fresh, higher-octane fuel is introduced. Rather than clearing learned retard instantly when the ignition key is cycled, the controller decrements AdaptiveRetardIndex by ARSUBC on each engine start. In factory calibrations, ARSUBC is set to 64 counts, representing a 25% reduction in learned adaptive retard per engine restart.

2. Operating Conditions (When Does This Take Effect?)

  • Subroutine & Line Numbers: HandleFuelStartRunStartTransfer (T-SMEC_v19.asm:6985-6990).
  • Gating Conditions:
  • Triggered when engine speed crosses above RNFPRD_FuelStartRunTransferPointRpm during cranking.
  • Engine running flag must have been previously clear (b54_FuelEngineNotRunning set in BitFlags_54).
  • Subtraction & Floor:
  • AdaptiveRetardIndex is loaded and ARSUBC_AdaptiveRetardFactorSubtract is subtracted.
  • If result underflows (bcc L1588 not taken), accumulator A is clamped to zero before storing.

3. Tuner's Guide & Real-World Calibration

  • Restart Decay Pacing:
  • Factory setting of 64 counts clears learned adaptive retard in four consecutive key cycles if no further knock occurs.
  • Instant Reset on Restart:
  • Setting ARSUBC to 255 clears all learned adaptive retard on every restart, providing a fresh baseline on each drive.
  • Extended Memory for Safety:
  • Lowering ARSUBC to 16 or 32 counts retains learned retard across 8 to 16 restarts, providing safety if lower octane fuel is persistent.
