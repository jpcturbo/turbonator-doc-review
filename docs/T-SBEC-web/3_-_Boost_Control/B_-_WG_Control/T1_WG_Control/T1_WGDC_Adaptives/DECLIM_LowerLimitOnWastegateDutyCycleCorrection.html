1. Overview & Purpose

DECLIM establishes the lower clamp boundary for adaptive wastegate cell values, preventing the adaptive system from trimming baseline duty cycle below a safe authority limit. In Chrysler's adaptive wastegate grid, each cell byte is centered at 128 counts (representing zero correction offset), with values below 128 subtracting duty cycle and values above 128 adding duty cycle. DECLIM prevents the adaptive system from learning an excessively low duty cycle that could cause severe underboost or sluggish spool-up if atmospheric conditions change. Shared between T1 and T2 control routines.

2. Tuner's Guide & Real-World Calibration

  • Maximum Downward Adaptive Authority: * Clamps the lowest value an adaptive cell can reach (offset below 128 counts). * Factory setting is 68 counts (-60 counts offset, or -30.0 percent duty cycle reduction below base table).
  • Correcting Authority Limits on Boost Creep: * Lowering DECLIM allows more downward duty cycle reduction if an engine experiences persistent overboost. * Large negative offsets indicate that DCWOT base table values are too high and should be corrected directly.
  • Shared Code Architecture: * Referenced in both CalcWGDutyCycleT1 (line 9690) and CalcWGDutyCycleT2 (line 10002).
