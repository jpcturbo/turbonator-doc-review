1. Overview & Purpose

MPROOF sets the underboost deadband threshold below target boost where the controller permits adaptive duty cycle incrementing in T1 control. When manifold pressure is below target, the engine controller calculates the underboost delta. If manifold pressure is within MPROOF of target boost, the boost level is considered sufficiently accurate, and the controller freezes adaptive incrementing to avoid continuous hunting and trim oscillation around the target pressure.

2. Tuner's Guide & Real-World Calibration

  • Underboost Deadband Threshold: * Minimum error delta below target (Target - Actual) required to trigger an adaptive duty cycle increment. * Factory setting is 0 counts (adapts whenever actual boost is below target).
  • Eliminating Table Churn: * Setting MPROOF to 2 to 3 counts (0.23 to 0.35 psi) creates a small deadband that stops adaptive hunting when boost is close to target.
  • Upward Adaptation Gating: * Only affects the upward adaptive branch (WGDC_IncrementWGAdaptive).

3. Operating Conditions (When Does This Take Effect?)

Takes effect as manifold pressure approaches target boost, disabling adaptive wastegate increments to prevent overshooting boost.
