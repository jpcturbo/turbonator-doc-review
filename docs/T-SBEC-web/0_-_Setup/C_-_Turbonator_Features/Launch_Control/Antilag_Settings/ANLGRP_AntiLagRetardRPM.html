1. Overview & Purpose

ANLGRP defines the engine speed threshold required before anti-lag ignition timing takes effect during staging launch control. When staging a turbocharged engine, ignition timing must remain normal at low speeds to allow the engine to rev cleanly off idle without stumbling. Once engine speed surpasses ANLGRP, the engine controller activates the anti-lag absolute timing schedule, transferring combustion heat into the exhaust manifold to spool the turbocharger. The factory setting of 69 counts corresponds to approximately 2208 RPM, providing a smooth transition window well below the staging rev limiter.

2. Tuner's Guide & Real-World Calibration

  • Threshold Placement: Set ANLGRP approximately 200 to 400 RPM below the lower staging limiter threshold (STGRON). For example, if staging launch speed is set to 3800 RPM, configure ANLGRP between 3400 and 3600 RPM.
  • Setting Too Low: Retards ignition timing immediately off idle, causing hesitation, severe misfiring, and poor throttle response while trying to stage.
  • Setting Too High: Setting this threshold higher than the lower staging limiter prevents anti-lag from ever activating, resulting in lack of boost on the starting line.
