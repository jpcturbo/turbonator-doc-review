1. Overview & Purpose

NBOFFS provides a fine-tuning voltage offset added to the simulated narrowband oxygen sensor voltage in the wideband conversion routine. During closed-loop fueling, the engine controller continuously trims injector pulse width to oscillate sensor voltage across a fixed 0.45-volt switching threshold. By adding a calibrated positive or negative voltage offset to the simulated sensor signal, NBOFFS shifts the effective closed-loop target air-fuel ratio richer or leaner without requiring modification of the main AFR2NB transfer curve. The factory setting of 128 counts represents zero voltage offset.

2. Tuner's Guide & Real-World Calibration

  • Biasing Richer: Lowering below 128 counts subtracts voltage, prompting closed-loop feedback to trim fueling richer (useful for smoothing lumpy idle on large camshafts).
  • Biasing Leaner: Raising above 128 counts adds voltage, prompting closed-loop feedback to trim fueling leaner for highway economy.
  • Neutral Setting: 128 counts represents zero offset, maintaining the exact stoichiometric crossover points programmed in AFR2NB.
