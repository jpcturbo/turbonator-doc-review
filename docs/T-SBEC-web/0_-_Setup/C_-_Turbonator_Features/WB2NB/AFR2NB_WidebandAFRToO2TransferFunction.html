1. Overview & Purpose

AFR2NB is the second stage transfer function in the Turbonator wideband-to-narrowband emulation system, translating calculated air-fuel ratio into simulated narrowband oxygen sensor voltage. Stock Chrysler engine controllers expect a non-linear switching signal from a factory zirconium oxygen sensor that transitions sharply between 0.1 volts (lean) and 0.9 volts (rich) around stoichiometry. By passing the measured air-fuel ratio from a wideband controller through AFR2NB, the controller synthesizes this classic switching voltage curve. This allows the factory closed-loop fueling and adaptive memory systems to operate normally while receiving input from an accurate wideband oxygen sensor.

2. Tuner's Guide & Real-World Calibration

  • Factory Curve Profile: Four calibration points generate a steep sigmoidal switching curve centered precisely at 14.7:1 stoichiometric air-fuel ratio.
  • Target Air-Fuel Ratio Shifting: Shifting the steep transition region left or right allows closed-loop cruising to target rich (e.g., 14.2:1) or lean (e.g., 15.2:1) mixtures.
  • Alternative Fuel Tuning: For ethanol blends (E85), re-scale the transition points to match the fuel's stoichiometric ratio (approx 9.8:1 for E85) if the wideband controller outputs true AFR rather than lambda.

3. Operating Conditions (When Does This Take Effect?)

Takes effect when wideband O2 tracking is enabled, converting wideband air-fuel ratio voltage into a simulated narrowband signal for the ECU feedback loop.
