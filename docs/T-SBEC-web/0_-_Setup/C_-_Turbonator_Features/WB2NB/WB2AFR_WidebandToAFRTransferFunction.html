1. Overview & Purpose

WB2AFR is the primary input transfer function in the Turbonator wideband conversion system, translating the analog 0 to 5 volt signal from an aftermarket wideband controller into internal engine air-fuel ratio. Different wideband controllers (such as AEM, Innovate, or Zeitronix) output different linear voltage-to-AFR relationships. WB2AFR maps the raw analog voltage read on the oxygen sensor wiring into an exact air-fuel ratio value. This value is saved to memory for high-speed datalogging and passed to AFR2NB to generate simulated narrowband feedback.

2. Tuner's Guide & Real-World Calibration

  • Controller Output Matching: Match the two calibration points to your wideband controller specifications (e.g., AEM UEGO: 0.0V = 10.0:1, 5.0V = 20.0:1; Innovate: 0.0V = 7.35:1, 5.0V = 22.39:1).
  • Datalogging Alignment: Compare gauge readings with the AFRatio channel in MPScan to confirm zero translation discrepancy across all operating ranges.
  • Electrical Grounding: Wire the wideband controller analog ground directly to the engine controller sensor ground to eliminate ground offset errors.

3. Operating Conditions (When Does This Take Effect?)

Takes effect continuously during wideband O2 monitoring, converting 0-5V wideband sensor input voltage into real-world air-fuel ratio (AFR) values.
