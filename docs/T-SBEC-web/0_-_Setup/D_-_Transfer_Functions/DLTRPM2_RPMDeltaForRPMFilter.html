1. Overview & Purpose

DLTRPM2 establishes the engine speed delta filter threshold evaluated during manifold pressure averaging updates. Under rapid engine deceleration, when manifold pressure drops quickly, the engine controller calculates the rate of change of engine speed between consecutive calculation loops. If the change in engine speed exceeds DLTRPM2, the controller immediately updates the running average manifold pressure variable to match instantaneous manifold pressure. In factory calibrations, DLTRPM2 is set to two hundred fifty-five counts, which is the maximum eight-bit value. This high threshold keeps the delta filter disabled under normal conditions so deceleration filtering operates uninterrupted.

2. Tuner's Guide & Real-World Calibration

  • Leave at Maximum Setting: * Keep DLTRPM2 at two hundred fifty-five counts to maintain stock deceleration filtering behavior.
  • Avoid Premature Baseline Overwrites: * Lowering this threshold causes unnecessary resets of AverageMAPValue during gear shifts and overrun deceleration.
  • Drivability Impact: * Factory maximum setting provides smooth return to idle and consistent deceleration dashpot operation.
