1. Overview & Purpose

WOTDLT defines the throttle position sensor voltage delta required to command wide-open throttle mode. Rather than relying on a fixed absolute voltage that could be skewed by sensor wear, thermal drift, or bracket flex, the engine controller measures throttle position relative to the dynamically learned closed-throttle baseline. Factory calibrations set WOTDLT to one hundred thirty-three counts, which corresponds to approximately two point six one volts above closed throttle. When throttle position sensor voltage exceeds the learned closed-throttle baseline by this delta, the controller declares wide-open throttle, disabling closed-loop oxygen sensor feedback and engaging maximum target boost and rich power enrichment fueling.

2. Tuner's Guide & Real-World Calibration

  • Earlier Power Enrichment: * Lowering WOTDLT to one hundred ten or one hundred twenty counts (~2.1 to 2.3 Volts) triggers wide-open throttle fueling and max boost earlier in pedal travel for heightened throttle response.
  • Preventing Premature Enrichment: * Setting WOTDLT too low drops the ECU out of stoichiometric closed-loop cruising during moderate highway grades, increasing fuel consumption.
  • Hysteresis Mechanics: * The firmware incorporates a three-count (~0.059V) hysteresis window below WOTDLT to prevent rapid flickering at the wide-open throttle boundary.
  • Factory Setting: * Set to one hundred thirty-three counts (~2.61 Volts delta) in factory calibrations.
