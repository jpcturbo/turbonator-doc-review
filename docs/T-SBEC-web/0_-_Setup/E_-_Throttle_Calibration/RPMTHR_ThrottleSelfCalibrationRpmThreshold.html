1. Overview & Purpose

RPMTHR defines the minimum engine speed boundary required to permit upward adaptive learning of the closed-throttle baseline voltage. When an engine decelerates, the vehicle must be traveling at sufficient speed with the engine spinning above idle to ensure high manifold vacuum and verify that the throttle plate is completely closed against its mechanical stop. In factory calibrations, RPMTHR is configured to forty-eight counts, which corresponds to approximately fifteen hundred RPM. As long as engine speed remains above fifteen hundred RPM while braking under high vacuum, the controller validates closed-throttle conditions and increments the learned minimum throttle voltage.

2. Tuner's Guide & Real-World Calibration

  • Minimum Engine Speed for Learning: * Ensures deceleration learning occurs strictly while coasting down in gear above idle speed.
  • High Idle Applications: * If idle speed target is elevated above 1100 RPM for wild camshafts, raise RPMTHR proportionally (e.g., 1800 to 2000 RPM).
  • Prevents Low-Speed False Learning: * Prevents erratic minimum throttle updates when the engine is lugging or recovering from an idle dip.
  • Factory Default: * Set to forty-eight counts (~1500 RPM) in stock calibrations.
