1. Overview & Purpose

UNLOAD establishes the throttle position sensor delta threshold that activates clear-flood mode during engine cranking. When an engine fails to start due to saturated cylinders or fuel-fouled spark plugs, pressing the accelerator pedal to the floor signals the controller to purge excess fuel. Configured in factory calibrations to one hundred thirty-three counts (approximately two point six one volts above closed throttle), UNLOAD is evaluated by the starting fuel calculation routine. If throttle position sensor voltage exceeds the learned closed-throttle baseline by UNLOAD while cranking, the controller branches to clear-flood mode, cutting fuel injection pulsewidths to zero so fresh air can clear the combustion chambers.

2. Tuner's Guide & Real-World Calibration

  • Clear-Flood Protection: * Flooring the throttle while cranking cuts fuel delivery, allowing flooded engines to purge raw fuel.
  • Aftermarket Throttle Bodies: * Verify that aftermarket throttle linkages produce enough voltage sweep to cross UNLOAD at full pedal depression.
  • Lower Limit Warning: * Setting UNLOAD below eighty counts risks cutting cranking fuel during light-throttle starting attempts.
  • Factory Setting: * Set to one hundred thirty-three counts (~2.61 Volts delta) in factory calibrations.
