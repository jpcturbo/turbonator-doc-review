1. Overview & Purpose

PIAMSK defines the diagnostic output driver circuit mask for Port A of the Peripheral Interface Adapter. In Chrysler SBEC engine controllers, high-current inductive drivers and relays are driven through a 6821 Peripheral Interface Adapter. To detect open wiring harnesses, blown solenoid coils, or shorted circuits, the controller periodically cycles each driver line and reads back the electrical logic level. Configured in factory calibrations to fifty-eight counts, PIAMSK establishes which output driver circuits on Port A are actively evaluated for electrical continuity faults. Monitored circuits include the radiator fan relay, air conditioning clutch relay, automatic shutdown relay, canister purge solenoid, check engine light, part throttle unlock solenoid, and cruise control solenoids.

2. Tuner's Guide & Real-World Calibration

  • Auxiliary Driver Deletions: * Clearing specific bits in PIAMSK disables hardware circuit integrity tests on removed relays or solenoids.
  • Monitored Port A Circuits: * Purge solenoid, A/C clutch relay, radiator fan relay, ASD relay, check engine lamp, and cruise solenoids.
  • Ghost Error Prevention: * Prevents open-circuit error codes when eliminating comfort accessories or evaporative purge hardware.
  • Factory Default: * Set to fifty-eight counts, actively monitoring purge, fan, A/C, and ASD circuits.
