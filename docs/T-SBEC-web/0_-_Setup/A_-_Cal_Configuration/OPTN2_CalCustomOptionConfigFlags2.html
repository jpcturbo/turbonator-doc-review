1. Overview & Purpose

OPTN2 serves as the second custom feature configuration register in the Turbonator codebase, controlling rev limiter mechanics, launch control, turbocharger anti-lag, boost algorithms, and wideband oxygen sensor emulation. In factory baseline files, OPTN2 is configured to five counts, enabling spark-based rev limiting and two-step launch control. Unlike factory firmware that solely cut fuel during over-rev conditions, OPTN2 provides independent toggles for spark cut and fuel cut rev limiting. It also enables stationary drag racing launch control, bang-bang exhaust pop, launch spark retard, second-generation proportional wastegate duty cycle logic, and wideband-to-narrowband oxygen sensor conversion.

2. Tuner's Guide & Real-World Calibration

  • Spark Cut vs Fuel Cut Limiters: * Bit 0 enables spark-based rev limiting, while Bit 1 enables fuel-based limiting. Running spark cut alone provides crisper staging limiter operation and rapid boost building on the two-step.
  • Stationary Launch Control (Two-Step): * Enabling Bit 2 engages the launch control routine when vehicle speed is below the launch speed threshold, holding engine speed at the launch setpoint.
  • Anti-Lag & Bang-Bang Options: * Bit 3 enables bang-bang spark cut patterns and Bit 5 enables anti-lag timing retards to spool large turbochargers.
  • Second-Generation Boost Control: * Bit 6 switches the boost solenoid algorithm from early duty cycle logic to advanced proportional wastegate control.
  • Wideband to Narrowband Conversion: * Bit 7 enables live transfer function lookup that converts wideband input voltages into simulated narrowband signals.
