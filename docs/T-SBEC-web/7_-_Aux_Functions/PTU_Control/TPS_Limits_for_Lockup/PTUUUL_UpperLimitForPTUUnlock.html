1. Overview & Purpose

PTUUUL defines the upper throttle position sensor delta threshold curve as a function of vehicle speed when the torque converter is currently in the unlocked state. Automatic transmission torque converter clutch management uses a dual-curve hysteresis structure: one pair of curves governs transitions when currently unlocked, while a second pair governs transitions when currently locked. When the transmission is currently unlocked, the controller looks up PTUUUL using vehicle speed. If throttle position delta exceeds this upper threshold curve at a given road speed, the controller commands the torque converter to lock. In factory calibrations, PTUUUL is configured as a 4-point curve spanning 0 to 127.5 MPH.

2. Tuner's Guide & Real-World Calibration

  • Acceleration Responsiveness: * Raise curve points to allow more throttle angle before lockup engages, extending torque converter stall multiplication.
  • Fuel Economy Optimization: * Lower curve points to lock the torque converter earlier at light cruise throttle, reducing fluid coupling slip losses.
  • Hysteresis Deadband Spacing: * Maintain separation above PTUULL across all vehicle speeds to prevent rapid cycling between lock and unlock states.
