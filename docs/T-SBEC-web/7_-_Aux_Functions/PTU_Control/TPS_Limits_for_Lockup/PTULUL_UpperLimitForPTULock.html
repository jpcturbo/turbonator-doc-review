1. Overview & Purpose

PTULUL defines the upper throttle position sensor delta threshold curve as a function of vehicle speed when the torque converter is currently in the locked state. To prevent rapid torque converter clutch cycling, the controller evaluates separate threshold tables depending on current clutch state. When the torque converter is already locked, PTULUL dictates the upper throttle limit required to initiate the unlock sequence. In factory calibrations, PTULUL is configured as a 4-point curve spanning 0 to 127.5 MPH. If throttle delta rises above this curve while locked, the controller initiates the unlock debounce timer to allow the converter to unlock for acceleration.

2. Tuner's Guide & Real-World Calibration

  • Highway Boost Pulling: * Raise curve points to keep converter locked under moderate boost climb, preventing annoying RPM flare.
  • Quick Passing Kickdown: * Lower curve points to allow earlier converter unlocking when stepping on the gas.
  • Hysteresis Stagger: * Ensure PTULUL is positioned above PTUUUL to create an effective hysteresis gap between locked and unlocked modes.
