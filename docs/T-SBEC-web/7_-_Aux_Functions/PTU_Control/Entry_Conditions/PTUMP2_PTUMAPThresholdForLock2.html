1. Overview & Purpose

PTUMP2 defines the secondary manifold absolute pressure delta threshold for Part Throttle Unlock lockup enforcement under gentle throttle modulation. In the assembly source, PTUMP2 is stored immediately following PTUMP1 in ROM and is accessed via an indexed increment (inx) off base pointer PTUMP1_PTUMAPThresholdForLock1. When throttle delta is below PTUDTP, the controller sets state flag b52_PTU_A and advances the pointer to evaluate PTUMP2. In factory calibrations, PTUMP2 is configured to 86 counts, corresponding to approximately 9.9 psi on the 0 to 29.4 psi MAP scale. If manifold pressure change exceeds this lower threshold under light pedal application, the torque converter is locked to maintain smooth cruise coupling.
