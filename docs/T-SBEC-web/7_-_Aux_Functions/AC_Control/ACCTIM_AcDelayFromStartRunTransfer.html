1. Overview & Purpose

ACCTIM defines the post-start time delay enforced after the engine transitions into run mode before the controller allows the air conditioning compressor clutch to engage. When starting an engine with the climate control switch left in the ON position, immediately engaging the compressor clutch while the starter motor is cranking or disengaging would place severe mechanical drag on the starter drive, battery voltage, and cold engine combustion. In factory calibrations, ACCTIM is set to 4 counts, representing approximately 0.4 seconds. This holds the A/C clutch disengaged until the engine has cleanly established oil pressure and stable idle flare control.

2. Tuner's Guide & Real-World Calibration

  • Startup Idle Settling: * Increase ACCTIM to 1.0 to 2.0 seconds (10 to 20 counts) on performance engines to allow idle flare to settle smoothly.
  • Starter Motor Protection: * Prevents heavy mechanical cranking drag when starting with the dashboard A/C button depressed.
  • Zeroing Caution: * Do not set ACCTIM to zero to avoid engaging the compressor clutch while oil pressure is still building.

3. Operating Conditions (When Does This Take Effect?)

Takes effect immediately after engine startup when the dashboard A/C switch is turned on, holding off compressor clutch engagement for a brief delay until the engine reaches run mode and oil pressure stabilizes.
