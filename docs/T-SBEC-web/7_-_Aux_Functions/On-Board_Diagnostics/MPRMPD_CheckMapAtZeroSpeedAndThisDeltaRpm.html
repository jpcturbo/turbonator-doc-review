1. Overview & Purpose

MPRMPD defines the maximum allowable engine speed deviation from target idle speed permitted when evaluating manifold absolute pressure sensor pneumatic health at closed throttle. To verify that the manifold pressure sensor is physically connected and sensing intake manifold vacuum rather than atmospheric air, the engine controller performs a pneumatic vacuum check when the vehicle is stationary at idle. However, if engine speed is surging or flaring away from target idle, manifold vacuum changes unpredictably, making the pneumatic check inaccurate. In factory calibrations, MPRMPD is configured to 512 counts, representing an engine speed delta of approximately 64 RPM. If the absolute difference between actual engine speed and target idle speed exceeds MPRMPD, the engine controller suspends the idle vacuum rationality check.

2. Tuner's Guide & Real-World Calibration

  • Camshaft Idle Hunting Tuning: * Performance camshafts produce rhythmic idle speed hunting that often exceeds 64 RPM. * Raising MPRMPD to 800 to 1200 counts (100 to 150 RPM delta) accommodates natural camshaft lope and prevents false Fault Code 13 errors.
  • Code Recovery Tuning: * MPRMPD is also used when clearing Fault Code 13; an engine unable to settle within 64 RPM of target idle will never clear a latched stuck MAP code.
  • Edge Cases: * Setting MPRMPD to zero prevents the idle vacuum test from ever running. * Setting MPRMPD excessively high (e.g., 500 RPM) allows the test to evaluate MAP during throttle blips, falsely setting vacuum error codes.
