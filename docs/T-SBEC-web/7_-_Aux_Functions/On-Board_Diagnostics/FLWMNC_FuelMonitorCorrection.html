1. Overview & Purpose

FLWMNC defines the fuel injector dead-time offset correction historically subtracted from calculated fuel pulse width prior to broadcasting fuel consumption data over the Chrysler Collision Detection network bus. Electromechanical fuel injectors exhibit opening dead-time delays during which no fuel flows. To ensure that fuel consumption broadcast over the vehicle serial network reflects actual fuel mass rather than electrical opening delays, FLWMNC was subtracted before pulse widths were accumulated into the serial fuel register. In factory calibrations, FLWMNC is set to 102 counts, corresponding to approximately 102 microseconds (0.102 milliseconds). However, in T-SBEC firmware v17.0 and later, the assembly instructions referencing FLWMNC are commented out to save CPU execution cycles, leaving the parameter inactive in firmware execution.

2. Tuner's Guide & Real-World Calibration

  • Firmware Inactive Status: * The assembly instructions referencing FLWMNC at line 6310 of T-SBEC_v19.asm are commented out with semicolons. * Modifying this parameter in MPTune has no operational effect on engine performance or trip computer accuracy.
  • Active Parameter Reference: * To calibrate dashboard navigator or trip computer fuel economy after an injector upgrade, use FUELTR.
  • Edge Cases: * Changes to FLWMNC alter only the checksum byte in ROM; no runtime behaviors are affected.
