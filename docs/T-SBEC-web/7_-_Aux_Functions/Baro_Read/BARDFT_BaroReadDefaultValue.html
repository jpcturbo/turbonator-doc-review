1. Overview & Purpose

BARDFT defines the failsafe default atmospheric barometric pressure value loaded into memory whenever a measured barometric reading fails sensor plausibility verification. If an atmospheric reading falls below BAROLO or exceeds BAROHI, the engine controller identifies the measurement as untrustworthy and immediately substitutes BARDFT. In factory calibrations, BARDFT is set to 127 counts, corresponding to approximately 14.6 psi absolute (29.7 inHg), representing standard nominal sea level atmospheric pressure. This ensures that in the event of a pressure sensor disconnect, pinched hose, or solenoid failure, the engine continues running safely with predictable sea level fuel and spark parameters.

2. Tuner's Guide & Real-World Calibration

  • Mandatory 3-Bar Rescaling: * Set BARDFT to ~85 counts on 3-bar MAP conversions to represent standard 14.7 psi atmospheric pressure.
  • Failsafe Fueling Anchor: * Acts as the emergency anchor for fuel, spark, and overboost protection if sensor wiring is damaged.
  • Elevation Bias Tuning: * For vehicles operated exclusively at high elevation (e.g. Denver at 5,000 feet), BARDFT can be adjusted to 12.2 psi.

3. Operating Conditions (When Does This Take Effect?)

Takes effect as a failsafe default whenever barometric pressure cannot be read or a MAP sensor fault occurs, defaulting atmospheric pressure to sea level (29.92 inHg) to keep fueling safe.
