1. Overview & Purpose

VNTAB2 defines the intermediate overspeed error threshold for commanding a fixed half-maximum vent pulse duration. When vehicle speed climbs above target cruise speed on rolling highway terrain, gentle proportional venting from VENTRG may be outpaced by vehicle momentum. If speed error exceeds VNTAB2, the controller commands a stepped, half-authority vent duration to check speed increase more quickly. In factory calibrations, VNTAB2 is set to 240 counts, representing approximately 120 miles per hour of speed error, positioning it immediately below the maximum vent threshold.

2. Tuner's Guide & Real-World Calibration

  • Stepped Vent Authority: * Commands a fixed half-authority vent pulse when overspeed exceeds VNTAB2 but remains below VNTAB1. * Bridges the gap between gentle proportional curve venting and emergency full vent.
  • Downhill Speed Stability: * Lowering VNTAB2 to 20 to 30 counts helps curb vehicle acceleration when cresting moderate highway hills.
  • Factory Calibration: * Set to 240 counts in production calibrations, keeping stepped venting dormant during normal minor speed variations.

3. Operating Conditions (When Does This Take Effect?)

Takes effect when cruise control overspeeds down a highway descent, setting an intermediate vent solenoid pulse duration clamp to prevent throttle hunting.
