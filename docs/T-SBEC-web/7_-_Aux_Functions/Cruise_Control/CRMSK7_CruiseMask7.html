1. Overview & Purpose

CRMSK7 defines the step increment added to the adaptive integrator trim when accumulated servo error exceeds CRMSK2. When a vehicle begins climbing an extended highway grade, proportional gain increases throttle opening, but some speed droop may persist. To eliminate this steady-state offset, the cruise controller slowly steps up the baseline throttle trim by CRMSK7 on each evaluation pass. In factory calibrations, CRMSK7 is set to 1 count, delivering a gradual, steady ramp rate that prevents step-induced throttle oscillations.

2. Tuner's Guide & Real-World Calibration

  • Integrator Ramp-Up Rate: * Governs the step increment added to BitFlags_27 when climbing steady highway grades. * Factory 1 count provides gentle, seamless throttle adjustment.
  • Mountain & Heavy Load Tuning: * Increasing to 2 counts helps heavy vehicles adapt to steep grades more quickly.
  • Clamp Boundary: * Ramp-up is bounded by upper clamp ceiling CRMSK6 (30 counts).
