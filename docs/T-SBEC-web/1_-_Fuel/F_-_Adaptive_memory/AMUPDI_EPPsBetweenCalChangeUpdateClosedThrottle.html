1. Overview & Purpose

AMUPDI specifies the number of engine pulse periods (distributor rising edges) required between adaptive fuel memory updates while operating at closed-throttle idle in Cell 12. At 800 RPM, 26 distributor pulses elapse in approximately one second. In stock calibrations, AMUPDI is set to 26 counts, matching the part-throttle rate. This establishes a steady, controlled update pace for the dedicated idle fuel trim cell, allowing the oxygen sensor to toggle several times between each long-term trim step.

2. Tuner's Guide & Real-World Calibration

  • Idle Fuel Trim Stability: * Increasing AMUPDI slows down idle cell updates, preventing aggressive camshafts from destabilizing idle trims.
  • Large Injector Tuning: * Larger injectors require a slower idle update rate to prevent hunting around stoichiometric targeting.
  • Units & Timing: * Measured in distributor pulse edges (2 per engine revolution). At 800 RPM, 26 counts represents approximately 1.0 second.

3. Operating Conditions (When Does This Take Effect?)

Takes effect during closed-throttle idle, setting the update interval between learned idle adaptive fuel trim adjustments.
