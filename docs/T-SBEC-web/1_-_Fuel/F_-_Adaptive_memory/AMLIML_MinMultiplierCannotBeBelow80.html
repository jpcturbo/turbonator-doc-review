1. Overview & Purpose

AMLIML defines the maximum allowable negative fuel leanout floor for all long-term adaptive fuel memory cells (AutoCal cells). When an engine runs rich due to high fuel pressure or vapor recovery purging, the controller removes fuel by decrementing the active cell. In factory calibrations, AMLIML is set to signed -77 counts (stored as 179 unsigned), which corresponds to approximately -15.0 percent maximum fuel reduction. This lower boundary ensures that a stuck-rich oxygen sensor or leaky injector cannot cause the controller to pull excessive fuel and cause severe lean engine misfires.

2. Tuner's Guide & Real-World Calibration

  • Constraining Negative Authority: * Clamping AMLIML to -25 to -30 counts limits maximum leanout to -5% to -6%, protecting modified engines from excessive lean trimming.
  • Disabling Long-Term Trims: * Setting both AMLIML and AMLIMH to 0 disables adaptive fuel trims entirely without software modifications.
  • Formula & Resolution: * Minimum fuel modifier is 1 + (AMLIML / 512). Factory -77 counts represents -15.0% fuel leanout.

3. Operating Conditions (When Does This Take Effect?)

Takes effect whenever adaptive fuel trims are updated during driving, capping the maximum allowable negative leanout to prevent excessive leaning.
