1. Overview & Purpose

O2MIDH defines the upper voltage limit of the stuck-in-the-middle diagnostic zone for active closed-loop operation. A healthy narrowband oxygen sensor constantly swings between rich (above 0.6V) and lean (below 0.3V). If the sensor voltage remains trapped between O2MIDL and O2MIDH, it indicates that the sensor is cold, poisoned, unplugged, or suffering from a high-resistance wiring fault. In factory calibrations, O2MIDH is set to 28 counts, corresponding to approximately 0.55 volts. If the signal remains in this middle zone, the controller increments a fault timer toward clearing adaptive memory and setting diagnostic codes.

2. Tuner's Guide & Real-World Calibration

  • Stuck Sensor Diagnostics: * Defines the upper edge (0.55V) of the inactive sensor detection zone.
  • Idle Exhaust Cooling: * If free-flowing exhaust causes sensor cooling at idle that dampens voltage swings, lowering O2MIDH slightly prevents false fault timers.
  • Switching Threshold Hierarchy: * Must be maintained higher than O2HSWP (0.49V) to preserve normal switching.

3. Operating Conditions (When Does This Take Effect?)
