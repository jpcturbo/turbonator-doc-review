1. Overview & Purpose

O2ITIM defines the duration that closed-loop oxygen sensor feedback is inhibited when transitioning from a rich idle state back to standard closed-throttle closed-loop operation. During specific idle diagnostic routines, such as setting basic ignition distributor timing or calibrating minimum throttle plate airflow opening via a diagnostic scan tool, the engine controller commands deliberate rich open-loop fueling for combustion stability. When these test routines finish, residual fuel vapors in the intake manifold and cylinder ports require time to clear. O2ITIM provides a calibrated delay timer that prevents the oxygen sensor from prematurely trying to lean out the mixture, ensuring a smooth transition back to stoichiometric closed-loop control without engine surging. In factory calibrations, O2ITIM is set to 255 counts.

2. Tuner's Guide & Real-World Calibration

  • Idle Stability Tuning: * Lengthening the delay by raising O2ITIM helps prevent idle hunting on cammed engines with low intake vacuum when returning from rich idle conditions.
  • Lowering the Value: * Commands the engine controller to re-engage closed-loop stoichiometric feedback more quickly after idle diagnostic testing or throttle closures.
  • Zeroing Out: * Disables the delay timer completely, immediately restoring closed loop once test flags clear.
  • Diagnostic Relevance: * Active specifically after disengaging basic timing lock mode (coolant sensor disconnect or scan tool command).
