1. Overview & Purpose

WOTTBL defines the wide-open throttle base fuel delivery curve indexed by manifold absolute pressure. Whenever the driver presses the accelerator pedal to wide-open throttle, the controller activates open-loop fueling and looks up base injector pulsewidth from WOTTBL. In addition to controlling full-power fuel delivery, WOTTBL serves as the universal upper ceiling for both closed-throttle (MAPIDL) and part-throttle (MAPTBL) calculations. This table supplies rich, safe air-fuel mixtures under maximum engine load and positive turbocharger boost.

2. Tuner's Guide & Real-World Calibration

  • Boost Fueling Adjustment: * Adjust WOTTBL points under positive manifold pressure to achieve target wideband air-fuel ratios (typically 11.2:1 to 12.0:1 on turbo setups).
  • Injector Scaling: * Scale the entire table downward when swapping to larger injectors to maintain desired air-fuel ratios.
  • 3-Bar MAP Sensor Calibration: * Re-index pressure points to support boost up to 29 psi gauge on a 3-bar sensor.
  • Universal Fuel Ceiling: * Because WOTTBL clamps MAPIDL and MAPTBL, ensure WOTTBL values in vacuum regions remain above part-throttle values to prevent unintended lean limiting.
