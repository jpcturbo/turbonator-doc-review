1. Overview & Purpose

MAPIDL defines the base fuel delivery curve indexed by intake manifold pressure when operating at closed throttle. Chrysler speed-density engine controllers isolate closed-throttle fueling from part-throttle fueling to achieve ultra-smooth idle stability and clean coast-down decel without disturbing off-idle drivability. MAPIDL maps manifold absolute pressure directly to injector pulsewidth across deep intake manifold vacuum levels. This table active whenever the throttle plate is fully closed and the engine is idling or coasting in gear.

2. Tuner's Guide & Real-World Calibration

  • Injector Scaling: * Scale the entire table down by the injector flow multiplier (original flow divided by new flow) to preserve correct air-fuel ratios at idle.
  • 3-Bar MAP Sensor Conversion: * Rescale table pressure break points to reflect the expanded 44.1 psi absolute sensor calibration range.
  • Camshaft Idle Tuning: * Performance camshafts produce erratic, low idle vacuum; raising MAPIDL values in the idle pressure region stabilizes idle speed and prevents stalling.
  • Emissions and Spark Plug Life: * Lowering values eliminates rich surging, dark exhaust soot, and plug wetting during extended idling.
