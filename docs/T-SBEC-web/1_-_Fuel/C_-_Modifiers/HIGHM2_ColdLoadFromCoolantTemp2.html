1. Overview & Purpose

HIGHM2 defines the part-throttle cold load enrichment curve indexed by engine coolant temperature. When the driver depresses the accelerator pedal and moves off-idle (setting flag b4f_OffIdle), the engine transitions from idle loading to driving load. The controller automatically switches from HIGHMP to HIGHM2, tailoring cold enrichment specifically for part-throttle acceleration and cruising while the engine is warming up. HIGHM2 provides independent temperature scaling that multiplies against part-throttle manifold pressure curve HMPMU2.

2. Tuner's Guide & Real-World Calibration

  • Cold Part-Throttle Acceleration: * Increase HIGHM2 if the vehicle hesitates or stumbles under light acceleration while warming up.
  • Off-Idle Transition: * Selected automatically whenever b4f_OffIdle is set, isolating driving enrichment from closed-throttle idle enrichment.
  • Injector Size Compensation: * Scale table values down proportionally with injector flow increases to avoid rich loading on cold acceleration.
  • Bypass at WOT: * Automatically bypassed when full throttle is reached, preventing double-enrichment over WOTTBL.
