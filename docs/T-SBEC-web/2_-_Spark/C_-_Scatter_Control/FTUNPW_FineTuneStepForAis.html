1. Overview & Purpose

FTUNPW defines the Automatic Idle Speed (AIS) stepper motor fine-tuning step size driven by spark scatter tracking register overflow. While spark scatter provides instantaneous cycle-by-cycle ignition timing adjustments to counter rapid idle speed fluctuations, the engine controller tracks long-term idle bias through the SparkScatter tracking variable. If ignition timing corrections persistently saturate in one direction (indicating that timing alone cannot bring idle speed back to the target), the tracking variable overflows. When overflow occurs, the controller steps the mechanical AIS motor by FTUNPW steps to alter baseline bypass airflow, bringing the engine back into the active spark scatter timing authority window. In factory calibrations, FTUNPW is set to 1 step.

2. Tuner's Guide & Real-World Calibration

  • Fast Airflow Convergence: * Raising FTUNPW to 2 or 3 steps allows the AIS motor to adjust more rapidly when high electrical or air conditioning loads push idle speed off target.
  • Surge Prevention: * If the engine develops a slow, rhythmic 1 to 2 Hz idle surge, ensure FTUNPW is set to the factory 1 step.
  • Disabling AIS Integration: * Setting FTUNPW to 0 prevents spark scatter from commanding stepper motor movement, leaving idle airflow purely to nominal proportional-integral AIS routines.
