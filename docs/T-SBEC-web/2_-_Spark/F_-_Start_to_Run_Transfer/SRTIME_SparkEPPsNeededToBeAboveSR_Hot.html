1. Overview & Purpose

SRTIME defines the number of consecutive Engine Position Pulses (EPPs) that engine speed must remain above the start-to-run threshold (STRNTR) before transferring spark control to Run Mode when the engine is warm. During engine cranking, a single cylinder firing can momentarily accelerate the crankshaft past 600 RPM before compression on the next cylinder slows it back down. To verify that the engine is truly self-sustaining and not merely experiencing an isolated combustion event, the engine controller requires consecutive distributor pulses above STRNTR. In factory calibrations, SRTIME is set to 4 pulses, corresponding to one complete engine revolution (two distributor pulses per revolution on a 4-cylinder engine), before locking in warm Run Mode.

2. Tuner's Guide & Real-World Calibration

  • Warm Restart Verification: * Factory setting of 4 pulses (one full crank revolution) ensures the engine is spinning under its own power before enabling running spark advance.
  • Fast Warm Restarts: * Lowering SRTIME to 2 pulses reduces post-crank delay on warm restarts, making the engine catch and transition instantly.
  • High-Compression Applications: * On high-compression or alcohol engines with uneven cranking pulses, raising SRTIME to 6 pulses prevents false-start stalls.
