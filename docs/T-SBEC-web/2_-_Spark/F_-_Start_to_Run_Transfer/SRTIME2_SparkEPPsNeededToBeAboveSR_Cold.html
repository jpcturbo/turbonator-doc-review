1. Overview & Purpose

SRTIME2 defines the number of consecutive Engine Position Pulses (EPPs) above STRNTR required to transfer ignition control into Run Mode when the engine is cold (coolant temperature below or equal to SRTMTP). Cold engines have cold cylinder walls, high oil viscosity drag, and imperfect fuel vaporization, making them prone to false-start stalls where an initial cylinder firing spins the engine momentarily before dying. SRTIME2 allows calibrators to set a distinct pulse duration requirement for cold conditions. In factory calibrations, SRTIME2 is set to 4 pulses, requiring one complete crankshaft revolution above STRNTR before engaging cold running spark tables. The firmware accesses SRTIME2 via a one-byte pointer offset from SRTIME.

2. Tuner's Guide & Real-World Calibration

  • Cold False-Start Prevention: * Raising SRTIME2 to 6 or 8 pulses keeps the engine in cranking spark mode longer during freezing starts, preventing stalls when releasing the starter key.
  • Pointer Offset Architecture: * Evaluated via a one-byte pointer offset from SRTIME when CoolantTemp is at or below SRTMTP.
  • Starter Momentum Verification: * Guarantees that multiple cylinders are firing under their own power before transitioning off cranking ignition control.

3. Operating Conditions (When Does This Take Effect?)

Takes effect during cold engine startup, dictating how many engine revolutions must pass before the ECU transitions ignition timing from cranking to running mode.
