1. Overview & Purpose

REVLMT2 establishes the upper engine speed fuel cutout threshold enforced whenever the manifold absolute pressure sensor experiences a circuit fault and the throttle is opened past 25 percent. Under MAP limp-in conditions, the engine controller synthesizes intake manifold pressure using the throttle position sensor and engine speed. Because synthetic fueling cannot account for dynamic airflow variations or turbocharger boost spikes, allowing high engine speeds under load could cause severe engine damage. In factory calibrations, REVLMT2 is set to 62 counts, representing approximately 2000 RPM. When engine speed climbs to this upper boundary under MAP limp-in with the throttle depressed, the controller immediately cuts fuel injection to govern the engine safely.

2. Tuner's Guide & Real-World Calibration

  • Limp Ceiling Adjustment: * Raising REVLMT2 expands the allowable engine speed window when running on synthetic MAP limp-in.
  • Hysteresis Gap: * Keep REVLMT2 at least 150 to 200 RPM above REVLMT to guarantee clean recovery without fuel cut chattering.
  • Safety Margin: * Keeping REVLMT2 near 2000 to 2500 RPM prevents high-load operation on unverified synthetic MAP estimations.

3. Operating Conditions (When Does This Take Effect?)

Takes effect under MAP limp-in conditions, the engine controller synthesizes intake manifold pressure using the throttle position sensor and engine speed.
