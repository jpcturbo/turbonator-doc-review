1. Overview & Purpose

MININC defines the incremental voltage offset added to the stored minimum closed-throttle position sensor reading at key-on initialization. The Chrysler engine controller employs a dynamic closed-throttle learning strategy that continuously monitors the lowest throttle sensor voltage observed during a drive cycle and stores it in MINTHR_LowestSessionTPS. Because mechanical throttle bodies and sensor brackets expand and contract with underhood temperature changes, the physical throttle stop voltage may vary slightly between cold starts and hot restarts. At every ignition key-on, MININC adds 3 counts (approximately 0.059 volts) to the learned minimum throttle voltage. This slight upward nudge guarantees that closed throttle is not falsely locked below the current mechanical position, allowing the controller to dynamically learn down to the true closed-throttle voltage as the engine idles.

2. Tuner's Guide & Real-World Calibration

  • Thermal Drift Compensation: * The factory 3-count offset provides reliable closed-throttle relearning across ambient temperature swings.
  • Aftermarket Throttle Bodies: * Increase MININC to 5 to 6 counts if an aftermarket throttle body binds slightly when warm, ensuring the idle switch engages reliably.
  • Zero Setting Hazard: * Setting MININC to 0 prevents the controller from re-establishing an accurate closed-throttle datum on key-on restarts.
