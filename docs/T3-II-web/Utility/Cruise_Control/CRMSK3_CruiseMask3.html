1. Overview & Purpose

CRMSK3 defines the negative accumulated servo error threshold for decrementing the adaptive integrator trim. When descending long highway grades or following sustained tailwinds, vehicle momentum causes speed to sit persistently above target. If accumulated error falls below CRMSK3, the engine controller recognizes that the vehicle is overspeeding and decrements the learned integrator trim by CRMSK4. In factory calibrations, CRMSK3 is set to 244 counts (representing negative 12 signed counts), establishing the trigger boundary for shedding learned uphill throttle trim.

2. Tuner's Guide & Real-World Calibration

  • Downhill Trim Shedding: * Initiates ramp-down of adaptive trim BitFlags_27 when negative error falls below CRMSK3. * Sheds extra throttle angle learned while climbing previous hills.
  • Signed Arithmetic: * Stored as negative 12 signed counts, evaluated with signed comparison instructions.
  • Companion Parameter: * Pairs with positive error threshold CRMSK2.
