1. Overview & Purpose

VNTAB1 defines the maximum overspeed error threshold above which the cruise control system bypasses proportional vent curve calculations and forces continuous maximum vent solenoid pulse duration. When vehicle speed exceeds the target setpoint by an extreme margin, such as during severe downhill coasting or following aggressive driver wide-open throttle acceleration, proportional modulation is insufficient to slow the car down quickly. In factory calibrations, VNTAB1 is configured to 255 counts, corresponding to approximately 127.5 miles per hour of speed error. If speed error exceeds this ceiling, the controller bypasses normal table lookup and commands maximum vent pulse duration to drop throttle angle immediately.

2. Tuner's Guide & Real-World Calibration

  • Full-Vent Cutout Ceiling: * Establishes the hard overspeed threshold where proportional venting is abandoned in favor of maximum vent solenoid duty cycle. * Factory setting of 255 counts reserves this mode for extreme overspeed events.
  • Mountain Grade Retardation: * Lowering VNTAB1 to 30 to 40 counts provides assertive engine braking on steep downhill slopes by venting the servo immediately.
  • Edge Cases & Driveline Lash: * Setting VNTAB1 excessively low produces harsh throttle closure when driver accelerates slightly past set speed to pass a vehicle.

3. Operating Conditions (When Does This Take Effect?)

Takes effect when cruise control overspeeds down a highway descent, clamping the maximum allowable vent solenoid pulse duration to prevent throttle surging.
