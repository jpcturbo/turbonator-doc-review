1. Overview & Purpose

MAPHIG defines the upper electrical voltage boundary for the manifold absolute pressure sensor analog input circuit. Under maximum turbocharger boost pressure, a 2-bar manifold pressure sensor generates output voltages approaching 4.60 volts. If the sensor signal wire chafes and shorts directly to the 5.0-volt supply rail or if the sensor develops an internal electrical short circuit, the signal voltage saturates near 5.0 volts. In factory calibrations, MAPHIG is set to 238 counts, corresponding to approximately 4.67 volts (roughly 14.2 psi boost on a 2-bar sensor). When sensor voltage equals or exceeds MAPHIG, the engine controller flags Fault Code 14, latches an electrical MAP failure, illuminates the check engine lamp, and activates emergency throttle-based limp-in mode.

2. Tuner's Guide & Real-World Calibration

  • High Boost Spikes & 2-Bar Limits: * On aggressive 2-bar calibrations running 14+ psi boost, momentary boost spikes can drive sensor voltage above 4.67 volts. * Elevating MAPHIG to 248 counts (4.86 volts) prevents false Fault Code 14 triggers during boost overshoot.
  • 3-Bar MAP Headroom: * On 3-bar MAP conversions, MAPHIG at 238 counts represents 28.5 psi boost, eliminating false over-voltage fault codes for typical street boost levels.
  • Lowering & Edge Cases: * Lowering MAPHIG causes premature limp-home triggering under moderate boost. * Setting MAPHIG to 255 counts disables short-to-reference fault logging.

Takes effect continuously during sensor diagnostic checks, flagging fault codes if the MAP sensor voltage shorts to 5V.
