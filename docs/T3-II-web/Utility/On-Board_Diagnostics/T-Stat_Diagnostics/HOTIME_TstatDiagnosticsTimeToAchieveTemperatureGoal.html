1. Overview & Purpose

HOTIME defines the maximum allowable vehicle driving time permitted for the engine to achieve the TDAGTP warm-up temperature goal before the engine controller declares a thermostat fault. To ensure that the thermostat diagnostic only measures active engine operation under road load, the timer increments only when the vehicle is moving at or above approximately 3.5 mph. Idling at traffic lights does not advance the timer, preventing extended idle periods from prematurely expiring the warm-up budget. In factory calibrations, HOTIME is configured to 174 counts, representing approximately 11.6 minutes of active vehicle travel. If the vehicle is driven for this duration without coolant temperature reaching TDAGTP, the engine controller flags Fault Code 17, turns on the check engine lamp, and records a stuck-open thermostat code.

2. Tuner's Guide & Real-World Calibration

  • Extended Warm-Up Accommodation: * If cold weather commutes or large aluminum radiators cause premature Fault Code 17 triggers, raise HOTIME from 174 counts (11.6 min) to 210-230 counts (14-16 min).
  • Disabling Fault Code 17: * Setting HOTIME to 255 counts (maximum byte) effectively disables the thermostat diagnostic test.
  • Speed Gating Mechanism: * The timer advances only when vehicle speed is at or above 3.5 mph; extended warm-up idling does not advance HOTIME.
  • Edge Cases: * Setting HOTIME to 1 or 2 counts sets Fault Code 17 within seconds of pulling away from the curb.

3. Operating Conditions (When Does This Take Effect?)

Takes effect if the vehicle is driven for this duration without coolant temperature reaching TDAGTP, the engine controller flags Fault Code 17, turns on the check engine lamp, and records a stuck-open thermostat code.
