1. Overview & Purpose

CHGHIG establishes the upper electrical voltage boundary for the charge air temperature sensor circuit. Like the coolant sensor, the charge temperature input incorporates an internal 5.0-volt pull-up resistor inside the engine controller. If the sensor is disconnected, a wire breaks, or the thermistor element cracks internally, the input voltage is pulled up to the 5.0-volt supply rail. In factory calibrations, CHGHIG is configured to 253 counts, representing approximately 4.96 volts (equivalent to an extreme cold reading colder than -40 deg F). When measured sensor voltage exceeds CHGHIG, the engine controller flags Fault Code 23, latches a charge temperature sensor fault, and substitutes default value DEFCHG.

2. Tuner's Guide & Real-World Calibration

  • Diagnostic Troubleshooting: * If Fault Code 23 is set, inspect the charge air temperature sensor plug on the intake manifold for loose pins, corrosion, or disconnected wiring.
  • Cold Weather Headroom: * Lowering CHGHIG below 250 counts risks false open-circuit fault triggers during sub-zero winter cold starts.
  • Raising & Edge Cases: * Setting CHGHIG to 255 counts disables open-circuit fault detection. * Setting CHGHIG lower than normal operating sensor voltage locks the ECU into permanent Fault Code 23 limp-in mode.

3. Operating Conditions (When Does This Take Effect?)

Takes effect if the sensor is disconnected, a wire breaks, or the thermistor element cracks internally, the input voltage is pulled up to the 5.0-volt supply rail.
