1. Overview & Purpose

COILLO defines the minimum intake manifold pressure disturbance threshold evaluated during the secondary ignition coil driver verification routine. Although the parameter label mentions battery volts due to historical template naming, firmware reverse engineering proves that it evaluates the difference between instantaneous and filtered manifold pressure. During engine cranking and low battery voltage operation, every successful ignition firing produces a distinct intake valve depression and manifold pressure ripple. If the ignition coil driver fails to fire the primary winding, combustion ceases and the expected manifold pressure pulsation disappears. In factory calibrations, COILLO is configured to 5 counts, corresponding to approximately 0.58 psi of pressure difference. If battery voltage is in the low-voltage test window and the manifold pressure deviation equals or exceeds COILLO, the controller flags Fault Code 43.

2. Tuner's Guide & Real-World Calibration

  • 3-Bar MAP Sensor Rescaling: * Multiply COILLO by 0.667 (from 5 counts down to 3 counts) when converting from a 2-bar to a 3-bar MAP sensor.
  • Aggressive Camshaft Tuning: * High-overlap performance camshafts generate erratic intake pressure pulses that can trigger false Fault Code 43 codes. * Raise COILLO to 7 or 8 counts (0.80 to 0.92 psi delta) to filter out camshaft-induced pressure fluctuations.
  • Edge Cases: * Setting COILLO to zero flags Fault Code 43 on nearly every low-voltage cranking cycle. * Setting COILLO to maximum (255 counts) disables this secondary ignition coil verification test.
