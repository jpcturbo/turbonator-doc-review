1. Overview & Purpose

MAPMULT is the foundational mathematical slope multiplier in the transfer function that converts analog manifold absolute pressure sensor voltage into calibrated internal pressure units. In the Chrysler engine controller, manifold pressure conversion follows a linear equation where sensor voltage is multiplied by MAPMULT and added to MAPADD. Factory calibrations set MAPMULT to seven counts to match the standard Mopar two-bar pressure sensor, which spans zero to twenty-nine point four psi absolute. When upgrading to a three-bar pressure sensor to support higher boost, MAPMULT is configured to nine counts to compress the broader pressure range into the internal pressure representation.

2. Tuner's Guide & Real-World Calibration

  • Three-Bar MAP Sensor Conversion: * Set MAPMULT to nine counts and MAPADD to seventeen hundred counts when converting to a 3-bar sensor.
  • Two-Bar Stock Calibration: * Factory setting is seven counts paired with MAPADD at eight hundred sixty-five counts.
  • Load Calculation Dependency: * Because every fuel and spark advance table in the ECU is indexed against manifold pressure, correct MAPMULT scaling is mandatory.
  • Companion Offset: * Must always be calibrated in direct coordination with MAPADD_ScaleMAPVoltsToPresAddConst.
