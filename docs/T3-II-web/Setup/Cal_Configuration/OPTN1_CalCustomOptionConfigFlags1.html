1. Overview & Purpose

OPTN1 is the first custom feature configuration register introduced in the Turbonator codebase to unlock advanced performance enhancements. Configured in factory baseline files to sixteen counts, OPTN1 provides software toggles that allow tuners to enable or disable custom features without recompiling the assembly source code. The switches in OPTN1 govern switchable dual-stage boost control, boost switch input electrical polarity, flashing the dashboard check engine light upon knock detection, nitrous oxide ignition retard activation, and nitrous switch polarity. When these options are enabled, the firmware activates dedicated routines to monitor external switches and modify engine operations in real time.

2. Tuner's Guide & Real-World Calibration

  • Switchable Dual-Stage Boost: * Set the switchable boost enable bit to activate dual boost levels, toggling between low wastegate boost and full target boost via an external dashboard switch.
  • Boost Switch Polarity: * Toggle the boost switch polarity bit if the physical switch is normally closed rather than normally open.
  • Knock Alert Check Engine Light: * Enabling the flash check engine on knock bit pulses the dashboard warning lamp whenever individual cylinder retard is active, providing immediate visual feedback of combustion knock.
  • Nitrous Timing Retard: * Enable nitrous retard and set nitrous switch polarity to apply instant ignition retard when nitrous solenoids fire.
