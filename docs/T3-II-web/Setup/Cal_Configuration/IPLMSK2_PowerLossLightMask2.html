1. Overview & Purpose

IPLMSK2 defines the second dashboard warning lamp mask register, focusing on actuator circuit failures and major system diagnostic faults. Configured in factory calibrations to two hundred sixteen counts, IPLMSK2 evaluates error flags stored in memory register b46_IPL2. The switches in IPLMSK2 control dashboard check engine light illumination for turbocharger wastegate solenoid circuit faults, fuel injector driver failures, and major powertrain electrical faults. By evaluating IPLMSK2 after sensor faults in IPLMSK have been verified, the controller ensures that severe hardware failures alert the driver immediately.

2. Tuner's Guide & Real-World Calibration

  • Wastegate Solenoid Elimination: * Clearing the wastegate bit prevents the open-circuit condition from illuminating the dashboard check engine light when running an aftermarket boost controller.
  • Actuator Warning Control: * Selectively disables warning light illumination for actuator and driver circuits without disabling primary analog sensor alerts.
  • EGR Interaction: * The routine checks cfg_EGR in CONFIG; if EGR is disabled, major fault bits are masked out before checking IPLMSK2.
  • Factory Setting: * Set to two hundred sixteen counts in stock calibrations.
