1. Overview & Purpose

MTHROP defines the return-to-idle threshold above the learned minimum closed-throttle position. After an engine has been driven off-idle, releasing the accelerator pedal causes throttle position sensor voltage to drop back toward the mechanical stop. In factory calibrations, MTHROP is set to one count, representing approximately zero point zero two zero volts above the learned closed-throttle baseline. Throttle voltage must fall below the sum of minimum learned throttle plus MTHROP before the engine controller clears the off-idle flag and re-engages closed-loop idle speed regulation and idle spark advance feedback.

2. Tuner's Guide & Real-World Calibration

  • Sticky Throttle Recovery: * If weak return springs or thermal expansion prevent the throttle blade from returning to within 0.02V of the stop, increasing MTHROP to two or three counts cures hanging idle.
  • Return-to-Idle Deadband: * Because MTHROP (1 count) is lower than MTHRCL (2 counts), the system creates a 1-count hysteresis preventing idle flutter.
  • Idle Control Re-Engagement: * Clearing the off-idle flag re-activates closed-loop AIS stepper motor control and idle spark advance stabilization.
  • Factory Default: * Set to one count (~0.020 Volts) in stock calibrations.

3. Operating Conditions (When Does This Take Effect?)

Takes effect as the driver presses the gas pedal, establishing the throttle voltage threshold above idle required to transition the ECU from closed-throttle idle into off-idle running mode.
