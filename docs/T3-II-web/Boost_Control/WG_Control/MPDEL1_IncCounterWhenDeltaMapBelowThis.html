1. Overview & Purpose

MPDEL1 defines the minimum positive boost error threshold (overboost) required before the engine controller begins timing an adaptive duty cycle reduction in T1 control. If actual manifold pressure exceeds the target boost by at least MPDEL1, the controller starts incrementing an internal error timer (Timer_BoostErrTimer). If the overboost condition persists continuously until the timer expires, the active adaptive wastegate cell is decremented, reducing base duty cycle to bring sustained boost back down to target.

2. Tuner's Guide & Real-World Calibration

  • Overboost Adaptive Sensitivity: * Minimum pressure delta above target (Actual - Target) required to start timing an adaptive cell decrement. * Factory setting is 2 counts (approximately 0.23 psi overboost).
  • Preventing False Downward Trims: * Setting MPDEL1 higher (0.5 to 1.0 psi) prevents brief gear-change spikes from causing downward adaptation of base WGDC.
  • 3-Bar MAP Scaling: * On 3-bar MAP conversions, divide the count value in half to preserve the same physical psi sensitivity threshold.

3. Operating Conditions (When Does This Take Effect?)

Takes effect during boost control, setting the first manifold pressure delta threshold for incrementing the boost control counter.
