1. Overview & Purpose

KDCMAX defines the upper ceiling on total cumulative wastegate duty cycle reduction that can be commanded by the knock protection system in T1 control. When severe or persistent detonation occurs under boost, repeated knock events add incremental duty cycle reductions to the knock reduction variable. KDCMAX prevents this reduction variable from winding down indefinitely, capping total knock-induced duty cycle reduction to a safe maximum that typically returns the wastegate straight to mechanical base actuator spring pressure.

2. Tuner's Guide & Real-World Calibration

  • Maximum Knock Boost Reduction Authority: * Caps total cumulative duty cycle reduction commanded by knock protection. * Factory setting is 60 counts (30.0 percent duty cycle reduction).
  • High-Boost Calibration Adjustment: * When running 20+ psi where base WGDC is 80%, increase KDCMAX to 100 to 120 counts (50% to 60% reduction) to ensure boost drops to base spring.
  • Fail-Safe Operation: * Prevents excessive boost penalty while ensuring severe knock pulls enough boost to save pistons and head gaskets.

3. Operating Conditions (When Does This Take Effect?)

Takes effect under boost when spark knock is detected, capping the maximum total duty cycle reduction that knock protection can command.
