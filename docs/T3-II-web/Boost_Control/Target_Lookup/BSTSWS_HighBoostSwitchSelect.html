1. Overview & Purpose

BSTSWS defines the digital input pin bitmask on the switch input port used by the engine controller to read a driver-operated dual-boost selection switch. When switchable boost is enabled in the calibration option registers, the controller tests this bit against the hardware switch register during every main program loop pass. If the switch state indicates that low-boost mode is selected, the controller overrides the primary engine-speed boost target curve with the low-boost ceiling constant. This mechanism allows the driver to alternate between high-power boost and conservative low-boost settings on the fly for varying weather, traction, or fuel availability.

2. Tuner's Guide & Real-World Calibration

  • Switch Input Pin Configuration: * Sets the digital input bitmask on the controller switch port corresponding to the physical boost switch. * Factory calibrations default to bitmask 2 (bit 1) for the dedicated switch input circuit.
  • Polarity Coordination: * Must be coordinated with opt_SwBstPol in OPTN1 to ensure switch toggle positions match high and low modes.
  • Disabling & Bypassing: * If switchable boost opt_SwBoost is disabled in OPTN1, this switch bitmask is completely bypassed.
  • Hardware Integrity: * Ensure clean wiring and debounced switch contacts to avoid rapid toggling between boost limits under road vibration.

3. Operating Conditions (When Does This Take Effect?)

Takes effect during boost target calculation when switchable boost is enabled, reading the driver's dashboard toggle switch to alternate between high and low boost profiles.
