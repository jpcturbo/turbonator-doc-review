1. Overview & Purpose

ARSUBC defines the decay step size subtracted from the adaptive retard index (AdaptiveRetardIndex) every time the engine undergoes a successful start-to-run transition. Once adaptive retard has accumulated in response to knock, the controller needs a systematic method to decay the learned retard back toward zero as fresh, higher-octane fuel is introduced. Rather than clearing learned retard instantly when the ignition key is cycled, the controller decrements AdaptiveRetardIndex by ARSUBC on each engine start. In factory calibrations, ARSUBC is set to 64 counts, representing a 25% reduction in learned adaptive retard per engine restart.

2. Tuner's Guide & Real-World Calibration

  • Restart Decay Pacing: * Factory setting of 64 counts clears learned adaptive retard in four consecutive key cycles if no further knock occurs.
  • Instant Reset on Restart: * Setting ARSUBC to 255 clears all learned adaptive retard on every restart, providing a fresh baseline on each drive.
  • Extended Memory for Safety: * Lowering ARSUBC to 16 or 32 counts retains learned retard across 8 to 16 restarts, providing safety if lower octane fuel is persistent.
