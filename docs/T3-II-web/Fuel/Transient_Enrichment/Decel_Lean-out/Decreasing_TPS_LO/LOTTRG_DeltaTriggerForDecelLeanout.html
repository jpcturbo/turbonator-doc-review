1. Overview & Purpose

LOTTRG establishes the primary trigger threshold for throttle-based deceleration lean-out. When the driver begins closing the throttle, the engine controller calculates the rate of throttle voltage decrease relative to rolling average throttle voltage. If the closing rate exceeds LOTTRG, the controller initiates progressive deceleration lean-out, incrementing the lean-out factor each loop pass. In the stock calibration, this value is set to 255 counts, ensuring that the closing throttle delta never exceeds the threshold and keeping throttle-based decel lean-out completely inactive.

2. Tuner's Guide & Real-World Calibration

  • Enabling Trigger Threshold: In calibrations where throttle deceleration lean-out is desired, lower LOTTRG from 255 to a sensible threshold such as 5 to 10 counts (0.10 to 0.20 volts).
  • Surging Prevention: Setting the trigger too low causes minor pedal modulations during cruising to trigger unwanted fuel reductions, causing noticeable surging and hesitation.
  • Disabling Option: If tuning for crisp throttle response or if experiencing deceleration stumbling, keep LOTTRG maxed out at 255 counts to prevent any throttle-based fuel cuts.
  • Threshold Hierarchy: Must always be set lower than LOTRG2.
