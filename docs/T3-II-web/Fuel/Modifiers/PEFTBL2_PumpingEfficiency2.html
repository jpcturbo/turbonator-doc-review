1. Overview & Purpose

PEFTBL2: PEFTBL2 defines the off-idle engine pumping efficiency (volumetric efficiency) curve versus engine speed (RPM) for the Lotus 16-valve DOHC Turbo III engine. In factory Turbo III calibrations (T-T3v1 and T-T3_II), PEFTBL2 is configured as a single-point flat 100% curve (.byte 0x01, .byte 0xFF, 0xFF). On the Lotus 16V engine, the factory Chrysler/Lotus calibration engineers did not shape volumetric efficiency using an RPM-based multiplier table as was done on Chrysler 8-valve engines. Instead, volumetric efficiency and base fuel pulsewidths are mapped directly into the primary 2D speed-density MAP tables (PRTTBL, PRTTBH, and WOTTBL). During part-throttle off-idle driving, the 68HC11 CPU selects PEFTBL2 via the b66_OffIdle bit in BitFlags66 and calls ScaleYbyA. Because the table data is 0xFF (100% unity multiplier), it passes through fuel calculations without modification.

2. Tuner's Guide & Real-World Calibration

  • Tuning Strategy: In factory Turbo III calibrations, PEFTBL2 is set to a flat 100% (0xFF) and is effectively neutralized. When tuning a Turbo III engine with stock or mildly ported Lotus cylinder heads, leave PEFTBL2 at 100% flat and perform all fuel shaping directly in the primary speed-density MAP tables (PRTTBL for light cruise, PRTTBH for heavy part throttle, and WOTTBL for full boost). However, if high-lift aftermarket camshafts significantly reshape the Lotus engine's breathing profile—creating a low-RPM torque deficit or an aggressive high-RPM airflow surge—tuners can expand PEFTBL2 into an active multi-point curve in MPTune to scale fueling across RPM without having to manually rescale every manifold pressure row across the 2D MAP fuel tables.
  • Raising the Value: Commands higher volumetric efficiency multiplier, richening fueling across all manifold pressures at that RPM.
  • Lowering the Value: Commands lower volumetric efficiency multiplier, leaning out fueling across all manifold pressures at that RPM.

3. Operating Conditions (When Does This Take Effect?)

Takes effect continuously during off-idle part-throttle operation on the Lotus 16-valve Turbo III engine once running, scaling base fuel delivery across engine RPM. In stock calibrations, its flat 100% multiplier renders it neutral.

5. Calibration Notes & System Dependencies

  • Factory 100% Neutral Setting: Factory setting is a 1-point table at 0xFF (100% multiplier), meaning volumetric efficiency is not scaled by RPM in stock form.
  • Lotus 16V Fuel Architecture: Engine breathing characteristics are mapped directly into the 2D speed-density MAP tables (PRTTBL, PRTTBH, WOTTBL) rather than using an RPM pumping efficiency curve.
  • Off-Idle Gating: Evaluated when b66_OffIdle (bit 7 of BitFlags66) is set; when at closed throttle / idle, PEFTBL is selected instead.
