1. Overview & Purpose

MP2 establishes the second manifold absolute pressure boundary in the adaptive memory system, separating Cell 2 and 3 from Cell 4 and 5. This boundary distinguishes light-load level cruise from moderate part-throttle acceleration. In factory calibrations, MP2 is set to 55 counts, corresponding to approximately 6.3 psia or 17.1 inHg of vacuum. The engine controller evaluates MP2 by stepping its index register through the boundary table during cell determination, ensuring that fueling adaptations learned during steady-state highway cruising remain isolated from moderate acceleration load zones.
