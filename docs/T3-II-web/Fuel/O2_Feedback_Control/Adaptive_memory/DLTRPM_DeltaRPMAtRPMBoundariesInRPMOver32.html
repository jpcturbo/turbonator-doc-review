1. Overview & Purpose

DLTRPM establishes the directional engine speed hysteresis applied to the R1 boundary when transitioning between low-RPM and high-RPM adaptive fuel cells. When the engine is operating in a low-RPM cell, DLTRPM is added to R1 before evaluating whether engine speed has climbed into the upper cell. In stock calibrations, DLTRPM is set to 2 counts, which corresponds to 64 RPM (2 counts multiplied by 32 RPM per count). This deadband prevents continuous cell swapping when engine speed hovers around the boundary during steady cruise.

2. Tuner's Guide & Real-World Calibration

  • Boundary Stability: * Prevents rapid hunting between even and odd adaptive cells when cruising near R1.
  • Increasing Hysteresis: * Raising to 3 or 4 counts (96 to 128 RPM) smooths cell switching on vehicles with manual transmissions or driveline lash.
  • Lowering Hysteresis: * Makes the transition between low and high RPM cells sharper, but setting to zero causes boundary chatter.

3. Operating Conditions (When Does This Take Effect?)

Takes effect when operating near adaptive cell boundaries, providing engine RPM hysteresis deadband to prevent erratic jumping between adjacent adaptive cells.
