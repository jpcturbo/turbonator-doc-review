1. Overview & Purpose

MAPLIM defines the upper manifold absolute pressure limit above which closed-loop oxygen sensor feedback is inhibited and adaptive memory cell updates are blocked. Under higher engine loads and positive boost pressure, maintaining closed-loop stoichiometric fuel targeting is undesirable because engines require rich mixtures for cylinder cooling and detonation suppression. In the stock A283 calibration, MAPLIM is set to 153 counts, corresponding to approximately 17.6 psia or 2.9 psi of positive boost pressure, locking out closed loop whenever manifold pressure exceeds this threshold.

2. Tuner's Guide & Real-World Calibration

  • Boost Lockout Calibration: * Lowering MAPLIM to atmospheric pressure (approx 128 counts or 0 psi gauge) ensures immediate exit from closed-loop feedback as the turbo spools.
  • 3-Bar MAP Sensor Rescaling: * Must be rescaled down from 153 counts to approximately 102 counts on a 3-bar sensor to prevent closed loop under boost.
  • Upper Boundary Interaction: * Acts as the hard ceiling for AutoCal adaptive cell updates; must be calibrated higher than MP5.
