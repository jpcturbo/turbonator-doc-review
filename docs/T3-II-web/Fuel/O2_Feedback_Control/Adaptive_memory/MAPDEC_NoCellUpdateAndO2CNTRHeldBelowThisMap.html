1. Overview & Purpose

MAPDEC defines the minimum manifold absolute pressure floor below which closed-loop oxygen sensor feedback is held in open loop and adaptive cell updates are blocked. During deep deceleration overrun, manifold pressure drops to high vacuum levels where combustion is unstable and deceleration fuel cutoff or extreme leanout may occur. The narrowband oxygen sensor reads false lean during overrun, which would corrupt adaptive trims if feedback remained active. In factory calibrations, MAPDEC is set to 20 counts, corresponding to approximately 2.3 psia or 25.3 inHg of vacuum.

2. Tuner's Guide & Real-World Calibration

  • High-Vacuum Deceleration Overrun: * When lifting off the throttle at speed, manifold pressure plunges below MAPDEC, forcing open loop and freezing the O2 feedback counter to prevent false lean trims.
  • Disabling Closed-Loop Globally: * Setting MAPDEC to 255 counts locks the engine permanently in open loop across all operating conditions.
  • 3-Bar MAP Sensor Rescaling: * On a 3-bar sensor, 2.3 psia sits at approximately 13 counts; failing to rescale causes the decel threshold to shift upward into light cruise vacuum.
  • Camshaft Upgrades: * If a high-overlap cam reduces overrun vacuum, raise MAPDEC slightly to ensure deceleration fuel cut and open-loop lockout engage cleanly.
