1. Overview & Purpose

O2HIGH defines the upper voltage threshold required for immediate validation of the narrowband oxygen sensor signal during the closed-loop entry sequence. When cold, a zirconium oxygen sensor has very high internal electrical impedance and generates an inert mid-range voltage. Once the sensor heats up and begins generating an active voltage swing above O2HIGH, the engine controller confirms the sensor is fully operational and immediately enables closed loop without waiting for delay timers. In stock calibrations, O2HIGH is set to 38 counts, corresponding to approximately 0.74 volts.

2. Tuner's Guide & Real-World Calibration

  • Heated Sensor Upgrades: * When converting to a heated 4-wire oxygen sensor, lowering O2HIGH slightly allows faster closed-loop engagement after cold starts.
  • Signal Noise Immunity: * On unheated single-wire setups, keeping O2HIGH at 38 counts (0.74V) prevents electrical ground noise from prematurely triggering closed loop.
  • Setting Too High: * If set above 0.85V, cool idle exhaust temperatures may prevent the sensor from ever satisfying immediate closed-loop entry.

3. Operating Conditions (When Does This Take Effect?)

Takes effect during oxygen sensor signal validation, setting the upper (rich) voltage threshold that verifies the O2 sensor is active and switching.
