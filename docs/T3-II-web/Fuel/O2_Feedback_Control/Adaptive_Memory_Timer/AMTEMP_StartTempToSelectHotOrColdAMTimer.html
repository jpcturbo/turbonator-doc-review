1. Overview & Purpose

AMTEMP defines the engine coolant temperature threshold that switches the adaptive fuel memory system between cold warmup delay timing and fully warmed hot engine operation. Before long-term adaptive fuel trim cells are permitted to learn and update, the engine must reach thermal equilibrium so that temporary cold warmup enrichment does not distort learned fuel tables. In factory calibrations, AMTEMP is configured to 205 counts, corresponding to approximately 196 degF. When coolant temperature is below AMTEMP, the controller repeatedly reloads the adaptive delay timer from the coolant temperature curve; once coolant temperature reaches or reaches beyond AMTEMP, the delay timer decrements toward zero to unlock adaptive cell learning.

2. Tuner's Guide & Real-World Calibration

  • Thermostat Compatibility: * When replacing the factory 195 degF thermostat with a 180 degF or 160 degF unit, AMTEMP must be lowered to approximately 170 to 175 degF (185 to 190 counts); otherwise, the engine will never enable adaptive learning.
  • Locking Out Adaptive Learning: * Setting AMTEMP to 255 counts prevents adaptive trims from updating under any operating temperature, functioning as a global lock on long-term trim updates.
  • Lowering the Threshold: * Allows adaptive memory to start adapting sooner during warmup, but setting it below 160 degF risks corrupting fuel trims with uncalibrated warmup enrichment.

3. Operating Conditions (When Does This Take Effect?)

Takes effect during engine startup and warm-up, establishing the coolant temperature threshold that switches between hot and cold adaptive learning timers.
