1. Overview & Purpose

SECRMP is a specialized 22-word secondary ramp rate table that functions as a closed-loop recovery failsafe when the oxygen sensor remains on one side (rich or lean) longer than expected. While PRIRMP handles smooth incremental corrections during normal switching, SECRMP activates when Timer_O2ToggleDuration exceeds the calibrated cell timeout limit, applying aggressive secondary fuel kicks to rapidly drive the mixture back toward stoichiometric. SECRMP defines the RPM and MAP grid boundaries, the secondary kick values (with lean corrections represented in two's complement format), and the duration limits for each operating cell.

2. Tuner's Guide & Real-World Calibration

  • Mitigating Surging on Cammed Engines: * Aggressive secondary kicks can cause harsh surging when an exhaust sensor is slow to respond. Softening kick values in SECRMP eliminates abrupt overcorrections.
  • Recovery Failsafe: * Operates only when the oxygen sensor has failed to toggle across the stoichiometric threshold within the cell's duration limit.
  • Two's Complement Lean Kicks: * Rich kicks are positive values; lean kicks are stored as negative two's complement signed values.
  • Companion Constants: * Interacts with SCRMP1 and SCRMP2 subtractor constants during timer evaluation.

3. Operating Conditions (When Does This Take Effect?)

Takes effect during closed-loop operation, controlling the secondary fuel trim ramp rate as the oxygen sensor switches.
