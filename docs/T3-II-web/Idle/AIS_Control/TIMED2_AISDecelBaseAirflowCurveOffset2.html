1. Overview & Purpose

TIMED2 is a 2D lookup curve that provides a time-decaying target idle speed adder following engine startup. When an engine first fires, extra intake air and elevated idle speed are beneficial to help clear fuel puddling, build oil pressure, and ensure smooth operation while initial combustion heat begins warming the cylinder walls. As engine run time accumulates, this elevated startup flare target must smoothly decay back down to the normal steady-state idle speed determined by coolant temperature. TIMED2 is indexed by engine running time in seconds and adds an RPM offset directly to the base target idle speed. In factory calibrations, TIMED2 provides an initial boost of approximately 36 to 40 RPM that decays smoothly to 0 RPM over the first 25 seconds of continuous engine run time.

2. Tuner's Guide & Real-World Calibration

  • Post-Start Flare Shaping: * Increase initial RPM offset points in TIMED2 to 80 to 150 RPM if modified engines suffer from lean stumble or low vacuum in the first 15 seconds after firing.
  • Extended Warm-Up Drivability: * Lengthening the decay time beyond 25 seconds provides a gentle, gradual ramp down to base idle, improving cold morning drivability.
  • Quick Idle Drop: * Zeroing TIMED2 causes the engine idle target to drop directly to base temperature-curve RPM immediately upon starting.
