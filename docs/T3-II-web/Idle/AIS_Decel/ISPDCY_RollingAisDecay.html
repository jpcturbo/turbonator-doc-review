1. Overview & Purpose

ISPDCY defines the RPM decrement step size subtracted from target idle speed during rolling idle decay. When a vehicle is operating in rolling idle mode, target idle speed is held at an elevated level. As the vehicle slows or steady rolling conditions continue, this elevated target speed must gently decay back down toward the baseline stationary idle target set in AISPN or AISCLD. ISPDCY sets the step reduction in target engine speed applied on each decay interval paced by DECAIS. In factory calibrations, ISPDCY is set to 4 counts, which decrements the target idle speed by approximately 32 RPM on each decay step until the base target is reached.

2. Tuner's Guide & Real-World Calibration

  • Faster Rolling Idle Ramp-Down: * Increase ISPDCY from 4 to 6 to 8 counts if elevated rolling idle lingers too long during coasting.
  • Smoother Idle Landing: * Lower ISPDCY to 2 counts (16 RPM) to smooth out the step-down transition on sensitive drivetrains.
  • Companion Tuning: * Adjust in concert with DECAIS, which controls the time interval between these decay steps.

3. Operating Conditions (When Does This Take Effect?)

Takes effect when a vehicle is operating in rolling idle mode, target idle speed is held at an elevated level.
