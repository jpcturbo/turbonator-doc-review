1. Overview & Purpose

AISMPH defines the maximum vehicle speed ceiling for active rolling idle mode on manual transmission Chrysler vehicles. When coasting in neutral with the clutch disengaged, maintaining a slightly elevated rolling idle speed prevents the engine from stalling, provides vacuum assist for power brakes, and facilitates smooth rev-matching when shifting back into gear. However, above moderate driving speeds, the vehicle is coasting at highway velocity and should operate under normal deceleration dashpot rules rather than holding an elevated rolling idle target. AISMPH establishes this upper speed boundary. In factory calibrations, AISMPH is set to 0 counts (disabled in some automatic calibrations) or 16 counts (approximately 16 mph in manual variants), bounding rolling idle regulation to low-speed coasting.

2. Tuner's Guide & Real-World Calibration

  • Manual Transmission Coasting Stall Fix: * Set AISMPH to 15 to 20 mph to keep rolling idle active when coasting in neutral, stabilizing power steering and brake assist.
  • Disabling Rolling Idle: * Set AISMPH to 0 mph if you want engine RPM to drop immediately to base stationary idle whenever the throttle is released, regardless of road speed.
  • Manual Only: * Bypassed on automatic transmission vehicles (bitb #cfg_ATX branch at line 8451).
