1. Overview & Purpose

MPSHFA defines the instantaneous or absolute overboost fuel cutout threshold in the Chrysler engine controller. While MPSHFT allows a temporary boost spike by decrementing a countdown timer, MPSHFA serves as an emergency upper boundary where fuel injection is cut immediately without waiting for any timer to expire. In factory 2.5L calibrations, MPSHFA is calibrated to 153 counts, representing approximately 17.6 psi of boost above atmospheric pressure. If severe turbocharger runaway occurs and boost shoots past this absolute ceiling, the controller bypasses all timer delays, stores non-critical diagnostic fault code 45, and shuts off fuel injection for the current engine rotation to protect pistons, head gasket, and valvetrain.

2. Tuner's Guide & Real-World Calibration

  • Raising for High-Boost Tuning: * When targeting 18+ psi boost, MPSHFA must be elevated above planned boost overshoot levels, or set to 255 counts to prevent instant fuel shutoff. * Leaving MPSHFA at stock 17.6 psi on an upgraded turbo results in harsh, sudden fuel cuts on rapid spool.
  • 3-Bar MAP Sensor Calibration: * Rescale MPSHFA to reflect the 44.1 psi total sensor span when upgrading from the factory 2-bar MAP sensor.
  • Lowering & Protection: * Lowering MPSHFA provides an immediate cutoff ceiling for engine dyno testing or conservative safety configurations.
