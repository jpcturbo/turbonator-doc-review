1. Overview & Purpose

DCELTM defines the duration for which closed-loop oxygen sensor feedback is inhibited following maximum deceleration lean-out. When an engine decelerates with leaned-out fuel delivery, the exhaust gas stream temporarily goes very lean. If closed-loop feedback remains active, the oxygen sensor would detect this excess oxygen and command large rich fuel trim corrections, causing the engine to surge rich upon re-opening the throttle. DCELTM freezes oxygen sensor feedback integration during and immediately following deceleration. The factory setting is 0 counts in this calibration, but performance calibrations often incorporate a hold timer.

2. Tuner's Guide & Real-World Calibration

  • Preventing False Rich Trims: Increase DCELTM to 10 to 30 counts (approximately 110 to 330 milliseconds) if wideband data logging shows rich overshooting or fuel trim distortion immediately after deceleration events.
  • Exhaust Scavenging Interval: Inhibiting closed-loop feedback gives the exhaust system time to scavenge fresh air and return to normal stoichiometric conditions before the controller resumes adaptive learning.
  • Fuel Economy Considerations: Setting this timer excessively high keeps the engine in open-loop mode longer than necessary, slightly reducing fuel economy.
  • Timing Resolution: Each count provides 11 milliseconds of inhibit delay.

3. Operating Conditions (When Does This Take Effect?)

Takes effect following deceleration leanout, setting the lockout time before oxygen sensor closed-loop integration is allowed to resume.
