1. Overview & Purpose

ADMEMA (ValueFromAdaptivememoryAdder1) establishes an adaptive memory fuel trim modifier offset applied specifically while Phase 2 of the Exhaust Gas Recirculation diagnostic verification routine is running. During Phase 2, the engine controller commands the EGR valve closed to observe whether closed-loop oxygen sensor feedback registers a corresponding shift. In the adaptive memory calculation at line 6180, if Phase 2 is active, the controller adds ADMEMA directly to the closed-loop integrator before applying final fuel pulsewidth scaling. The factory calibration setting of 0 counts injects zero offset, allowing the closed-loop feedback loop to respond naturally to the change in cylinder gas composition without artificial fuel trim bias.

2. Tuner's Guide & Real-World Calibration

  • Diagnostic Impact: Artificially inflating the integrator during Phase 2 distorts the delta calculation (EGR7), creating a risk of false pass results on vehicles with inoperative or blocked EGR valves.

  • Factory Recommendation: Keep at 0 counts to maintain accurate stoichiometric closed-loop feedback.
