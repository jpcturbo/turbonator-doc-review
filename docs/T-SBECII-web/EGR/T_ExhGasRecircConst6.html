1. Overview & Purpose

EGR6 (ExhGasRecircConst) establishes the high byte of the 16-bit Phase 2 diagnostic timeout timer threshold for the Exhaust Gas Recirculation flow verification routine. During Phase 2, the engine controller de-energizes the EGR solenoid to shut off exhaust gas flow into the intake manifold and waits for closed-loop oxygen sensor feedback to register a lean shift. The controller requires an upper time limit on this test so that prolonged solenoid de-energization does not unnecessarily alter emissions or driveability if the valve is stuck. Although defined in calibration templates as an 8-bit constant, the CPU reads EGR6 with a 16-bit comparison instruction at line 5485, pairing EGR6 (1 count) as the high byte with adjacent byte EGR15A (108 counts) as the low byte. This combined 16-bit threshold of 364 loop iterations corresponds to approximately 3.6 to 5.5 seconds.

2. Tuner's Guide & Real-World Calibration

  • 16-Bit Firmware Anomaly: In T-SBECII_v19.asm line 5485, the CPU executes a 16-bit comparison against EGR6_ExhGasRecircConst. EGR6 serves as the high byte (1 count) and contiguous byte EGR15A serves as the low byte (108 counts), forming the 16-bit threshold of 364 counts.
  • Raising EGR6: Adds 256 loop counts (roughly 2.5 to 3.8 seconds) per integer increase to the Phase 2 timeout window. Highly beneficial for headers or high-flow plenums where exhaust gas transport delay is longer.
  • Lowering EGR6 (to 0): Reduces the timeout window to strictly the low byte EGR15A (108 counts / ~1.1 to 1.6 seconds), which risks false diagnostic failures.
  • Calibration Protocol: When adjusting Phase 2 timeout, calculate (EGR6 * 256) + EGR15A to determine the exact 16-bit threshold.
