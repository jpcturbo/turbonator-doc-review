1. Overview & Purpose

EGRR18A (ExhGasRecircConstHiLimit18a) establishes the upper manifold absolute pressure boundary for the Phase 1 Exhaust Gas Recirculation diagnostic sampling window. Located immediately following EGR18 in calibration memory, this parameter defines the maximum intake manifold pressure under which Phase 1 baseline oxygen sensor tracking is permitted to operate. When the boundary checking routine is called at line 5429, the controller verifies that manifold pressure does not exceed the value stored at offset +1 from the EGR18 base pointer. The factory setting of 255 counts represents full-scale pressure (approximately 14.7 psi boost in a 2-bar system), which ensures that the upper limit check never aborts the diagnostic sequence under normal driving conditions.

2. Tuner's Guide & Real-World Calibration

  • Lowering EGRR18A: Imposes an upper manifold pressure ceiling on Phase 1 baseline sampling. Useful if tuners wish to ensure baseline oxygen sensor readings are gathered strictly under deep manifold vacuum.
  • Factory Ceiling (255 counts): Maximizes diagnostic window availability by setting the upper boundary to full-scale pressure.
  • 3-Bar MAP Sensor Scaling: When implementing a 3-bar MAP sensor, if a specific vacuum or pressure ceiling is calibrated, scale down the threshold by 0.667 (two-thirds) to preserve the intended manifold pressure window.
  • Pair Synchronization: Ensure EGRR18A is always greater than or equal to EGR18; setting EGRR18A lower than EGR18 creates an impossible condition that immediately aborts every Phase 1 attempt.
