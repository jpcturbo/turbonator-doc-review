1. Overview & Purpose

EGR18 (ExhGasRecircConstLoLimit) establishes the lower manifold absolute pressure boundary for the Phase 1 Exhaust Gas Recirculation diagnostic sampling window. To measure baseline closed-loop oxygen sensor behavior with the EGR valve operating, the engine controller requires intake manifold pressure to fall within a bounded window. At line 5429, the controller points an index register to EGR18 and calls the common boundary checking routine. In the factory calibration, EGR18 is set to 255 counts (maximum scale, corresponding to full boost / wide open throttle). Because its companion upper limit is also set to 255, the factory calibration effectively disables the lower MAP window restriction during Phase 1, allowing baseline sampling at any manifold pressure where the other entry gates are satisfied.

2. Tuner's Guide & Real-World Calibration

  • Lowering EGR18: Establishes a real lower manifold pressure floor for Phase 1 baseline tracking. For example, setting 50 counts creates a requirement for at least moderate intake load before baseline sampling proceeds.
  • Stock Calibration (255 counts): Acts as an open gate in stock firmware because EGR18 and companion EGRR18A are both set to full scale (255), relying on EGR33 to enforce minimum manifold vacuum.
  • 3-Bar MAP Sensor Conversions: If custom manifold pressure windows are defined, scale all MAP count thresholds by multiplying by 0.667 (two-thirds). This accounts for the expanded 3-bar pressure span (0 to 44.1 psi absolute vs 0 to 29.4 psi absolute).
  • EGR Delete Applications: Altering EGR18 is not necessary when disabling EGR; use the configuration bit cfg_EGR or raise EGR1 to 65535 instead.

3. Operating Conditions (When Does This Take Effect?)

Takes effect during warm, part-throttle cruising, modulating the exhaust gas recirculation (EGR) solenoid duty cycle to control combustion temperatures.
