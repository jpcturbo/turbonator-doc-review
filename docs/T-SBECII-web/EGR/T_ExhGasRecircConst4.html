1. Overview & Purpose

EGR4 (ExhGasRecircConst) establishes the cumulative diagnostic failure threshold before the engine controller logs Fault Code 32 (EGR System Failure) and illuminates the Check Engine lamp. During Phase 2 flow verification, if the diagnostic timer expires without detecting the required oxygen sensor shift, the controller increments a dedicated failure counter in RAM (EGRVar1). At line 5520, the controller compares this failure counter against EGR4. The factory setting of 235 attempts provides substantial filtering against transient driving disturbances, requiring the EGR monitor to fail repeatedly across multiple driving sequences before setting an active trouble code.

2. Tuner's Guide & Real-World Calibration

  • Raising EGR4 (to 255): Maximizes fault filtering, requiring 255 failed test cycles before setting Fault Code 32. Effective for silencing intermittent fault codes on high-mileage EGR valves or modified camshaft engines.
  • Lowering EGR4: Speeds up fault reporting. Setting this parameter to 1 or 2 causes Fault Code 32 to trigger on the very first or second failed test attempt.
  • EGR Delete Applications: Setting EGR4 to 255 complements physical EGR block-off plates, preventing Fault Code 32 from latching during normal driving.
  • Factory Calibration: 235 attempts provides factory-grade noise immunity against road and load fluctuations.

3. Operating Conditions (When Does This Take Effect?)

Takes effect during warm, part-throttle cruising, modulating the exhaust gas recirculation (EGR) solenoid duty cycle to control combustion temperatures.
