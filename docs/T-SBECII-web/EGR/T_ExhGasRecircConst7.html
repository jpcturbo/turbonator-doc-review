1. Overview & Purpose

EGR7 (ExhGasRecircConst) establishes the minimum closed-loop oxygen sensor fuel trim shift threshold required to confirm Exhaust Gas Recirculation valve flow and pass the onboard diagnostic test (Fault Code 32). During Phase 2, the engine controller commands the EGR valve closed, cutting off inert exhaust gas into the cylinders. This causes combustion air/fuel ratio to shift lean, forcing the closed-loop integrator to ramp richer to restore stoichiometry. The controller subtracts the filtered Phase 1 baseline trim (EGRVar5) from the peak Phase 2 trim (EGRVar6) and compares the delta against EGR7 at line 5506. The factory setting of 0 counts requires any positive fuel trim shift to confirm gas flow and pass the test.

2. Tuner's Guide & Real-World Calibration

  • Raising EGR7: Demands a more pronounced fuel trim shift (richer integration) when the EGR valve shuts off. Enhances diagnostic stringency on stock engines, but can trigger false failures if EGR passages are moderately carbon-fouled.
  • Factory Setting (0 counts): Any positive shift between peak Phase 2 ramp and Phase 1 baseline passes the test, maximizing monitor completion under varied weather and fuel conditions.
  • EGR Block-Off Reality: When an EGR block-off plate is installed, no exhaust gas flows; closing the valve produces zero fuel trim shift, causing the delta to stay below EGR7 and eventually setting Fault Code 32 unless EGR1 or cfg_EGR is adjusted.
  • Diagnostic Pass Actions: Passing the test immediately clears EGRVar1 (failure counter), latches bit 6 in EGRVar2, and clears bit 7 in b46_IPL2 (clearing active Fault Code 32).

3. Operating Conditions (When Does This Take Effect?)

Takes effect during warm, part-throttle cruising, modulating the exhaust gas recirculation (EGR) solenoid duty cycle to control combustion temperatures.
