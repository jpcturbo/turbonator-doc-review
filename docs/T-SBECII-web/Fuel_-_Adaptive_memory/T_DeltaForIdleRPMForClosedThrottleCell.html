1. Overview & Purpose

IDLOFS defines the engine speed window above the target idle speed that qualifies the engine to use Cell 12, the dedicated closed-throttle idle adaptive fuel trim cell. When the throttle is closed, the engine controller checks whether actual engine speed is below target idle speed plus IDLOFS. If engine speed is below this calculated ceiling, Cell 12 is selected; if engine speed exceeds it (such as during closed-throttle coasting at speed), the controller bypasses Cell 12 and uses the regular MAP-RPM grid cells. In factory calibrations, IDLOFS is set to 4 counts, corresponding to 128 RPM above target idle speed.

2. Tuner's Guide & Real-World Calibration

  • Camshaft Tuning & Idle Flaring: * High-duration camshafts with choppy idle require raising IDLOFS to 5-7 counts (160-224 RPM) to prevent idle flare-ups from kicking the ECU out of Cell 12.
  • Idle Cell Qualification: * Defines the maximum engine speed allowed above target idle speed (TargetIdleSpeed + IDLOFS) to engage Cell 12.
  • Coasting Fuel Trim Isolation: * Keeps high-speed closed-throttle coastdown from corrupting the stationary idle fuel trim cell.
