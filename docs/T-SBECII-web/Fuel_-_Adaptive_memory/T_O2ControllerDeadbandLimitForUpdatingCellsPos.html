1. Overview & Purpose

CALTHP: CALTHP establishes the positive (lean) voltage error deadband limit for the closed-loop oxygen sensor adaptive fuel memory subsystem. To prevent normal narrow-band O2 sensor switching oscillations from corrupting long-term learned fuel tables, the ECU requires O2 error to exceed this deadband before updating adaptive cell multipliers.

2. Tuner's Guide & Real-World Calibration

  • Calibration Strategy: Raising the deadband requires larger fueling errors before long-term fuel trims update, stabilizing adaptive memory on engines with high-overlap camshafts. Lowering the deadband makes adaptive fuel learning more responsive.
  • Raising the Value: Increases commanded threshold or extends gating limits in the controller.
  • Lowering the Value: Decreases commanded threshold or restricts operational bounds.

3. Operating Conditions (When Does This Take Effect?)

Takes effect during closed-loop steady-state cruising, gating adaptive fuel table cell updates.
