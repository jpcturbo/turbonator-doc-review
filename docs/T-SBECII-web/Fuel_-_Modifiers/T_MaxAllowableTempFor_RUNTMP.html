1. Overview & Purpose

RUNLMT defines the maximum allowable coolant temperature ceiling below which post-stall heat soak temperature modeling (RUNTMP) is permitted. If an engine stalls when coolant temperature is already above RUNLMT, the engine is recognized as fully warmed up, and heat soak modeling is bypassed completely. Additionally, RUNLMT serves as the upper clamp for the simulated temperature calculation, ensuring that adding RUNTMP offset never raises effective temperature above normal warm operating levels. In factory calibrations, RUNLMT is set to 160 counts, representing approximately 145 degF.

2. Tuner's Guide & Real-World Calibration

  • Heat Soak Upper Ceiling: * Sets the maximum coolant temperature threshold where post-stall heat soak modeling is allowed to operate.
  • Clamping Function: * Clamps CoolantTemp + RUNTMP so simulated temperature cannot exceed RUNLMT.
  • Factory Setting Retention: * 160 counts (approx 145 degF) correctly bounds heat soak modeling to the warm-up transition phase.
  • Disabling Heat Soak Logic: * Setting RUNLMT to zero disables heat soak addition entirely, causing the ECU to always use raw sensor temperature.

3. Operating Conditions (When Does This Take Effect?)

Takes effect if an engine stalls when coolant temperature is already above RUNLMT, the engine is recognized as fully warmed up, and heat soak modeling is bypassed completely.
