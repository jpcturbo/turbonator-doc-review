1. Overview & Purpose

RUNTMP defines a coolant temperature offset curve that simulates engine heat soak following an engine stall or brief key-off. When an engine stalls while warming up, coolant circulation stops, causing the coolant temperature sensor to cool faster than the hot cylinder block, cylinder head, and intake valves. If restarted immediately, the sensor would report a lower temperature than the physical metal surfaces, causing the ECU to inject excessive cold-start enrichment that floods the engine. RUNTMP adds an artificial temperature boost based on stall duration, preventing hot restart flooding.

2. Tuner's Guide & Real-World Calibration

  • Preventing Post-Stall Flooding: * If stalling during warm-up causes flooded plugs and difficult restarting, increase RUNTMP values for stall times between 5 and 30 seconds.
  • Lean Stall Recovery: * If the engine pops lean when restarted immediately after a stall, lower RUNTMP to preserve needed restart fuel.
  • Upper Boundary Gating: * Gated by RUNLMT; if coolant temperature is already above RUNLMT, RUNTMP lookup is bypassed completely.
  • Added Directly to Coolant Temp: * The resulting offset is added directly to CoolantTemp before starting and cold enrichment table lookups.

3. Operating Conditions (When Does This Take Effect?)

Takes effect when an engine stalls while warming up, coolant circulation stops, causing the coolant temperature sensor to cool faster than the hot cylinder block, cylinder head, and intake valves.
