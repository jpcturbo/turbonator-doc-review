1. Overview & Purpose

INCSRT controls the recovery and decay rate of ignition timing after a knock event has ended. When the engine controller detects detonation, it retards ignition timing immediately. Once detonation ceases, the controller must gradually return (decay) the timing back toward the base advance curve. If timing is restored too quickly, the engine will immediately re-detonate; if returned too slowly, the vehicle remains sluggish with elevated exhaust gas temperatures long after the knock event has passed. INCSRT acts as a loop counter bitmask: every time the main program loop counter matches this mask, the controller restores 0.5 degrees of timing to each cylinder until all per-cylinder knock retards reach zero. In factory calibrations, INCSRT is set to 31 counts (binary mask 31), triggering timing recovery once every 32 main loops (approximately 352 milliseconds, or 1.4 degrees per second).

2. Tuner's Guide & Real-World Calibration

  • Strict Bitmask Values: * INCSRT must strictly be set to binary power-of-two minus one masks: 0, 1, 3, 7, 15, 31, 63, 127, or 255. Non-mask values produce irregular decay pacing.
  • Slower Recovery for Safety: * Setting INCSRT to 63 (decay every 64 loops / ~700 ms per half-degree) provides extended protection against repeat knock.
  • Faster Recovery for Track / Drag: * Lowering INCSRT to 15 (decay every 16 loops / ~176 ms per half-degree) restores peak timing and power quickly after transient spikes.
  • Decay Asymmetry: * Timing is pulled in instantly upon knock detection but returns slowly via INCSRT, creating a protective asymmetric hysteresis.
