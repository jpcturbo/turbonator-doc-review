1. Overview & Purpose

PRIRMP is a specialized 22-word ramp configuration table that governs short-term oxygen sensor feedback fuel corrections across a 3 by 3 grid of engine speed and manifold pressure load cells, plus a dedicated closed-throttle idle cell. When closed-loop operation is active, the engine controller continuously toggles the air-fuel ratio above and below stoichiometric 14.7:1 by applying rich and lean fuel pulsewidth steps (kicks). PRIRMP defines the RPM and MAP grid boundaries, the individual kick magnitudes for rich and lean corrections, and the accumulation limits for each cell. This table prevents the short-term fuel trim counter from slamming to extremes while ensuring fast, responsive closed-loop tracking.

2. Tuner's Guide & Real-World Calibration

  • Curing Rich Closed-Loop Bias: * Factory Mopar Performance calibrations frequently exhibited a rich closed-loop bias due to asymmetrical kick steps. Equalizing rich and lean kick values across cells 0-8 centers feedback precisely at 14.7:1.
  • Relocated O2 Sensor & Header Tuning: * Long-tube headers increase exhaust transit delay. Slightly raising ramp steps prevents sluggish response, while adjusting limits maintains oscillation stability.
  • Table Structure (Type 11): * 22 words total: 1 word RPM boundaries, 1 word MAP boundaries, 10 words ramp kick steps (9 cruise + 1 idle), 10 words accumulation limits.

3. Operating Conditions (When Does This Take Effect?)

Takes effect during closed-loop operation, controlling the primary fuel trim ramp rate as the oxygen sensor switches.
