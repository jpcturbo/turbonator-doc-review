1. Overview & Purpose

RESTBL2 defines the secondary resume setup pulse duration added directly to the cruise servo command based on the difference between current vehicle speed and the saved target setpoint. When resuming cruise control from a substantially lower vehicle speed, the engine must overcome both driveline inertia and aerodynamic drag to start accelerating promptly. RESTBL2 looks up an auxiliary vacuum pulse duration scaled to the size of the speed deficit and adds it directly to the servo output command, providing an immediate assertive pull on the throttle cable before normal closed-loop speed tracking takes over.

2. Tuner's Guide & Real-World Calibration

  • Resume Initial Bite: * Increasing RESTBL2 provides stronger initial vacuum servo authority when resuming from wide speed differentials. * Recommended for heavy vehicles or low-compression engines that hesitate when resuming.
  • Drivability & Smoothness: * If resuming feels abrupt or jerks the vehicle forward violently, reduce RESTBL2 values.
  • Additive Mechanics: * Unlike RESTBL which scales the base pulse, RESTBL2 is added directly to CruiseControlVar3, providing immediate additive vacuum duty cycle.
