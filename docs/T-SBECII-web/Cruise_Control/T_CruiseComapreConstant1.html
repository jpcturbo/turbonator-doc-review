1. Overview & Purpose

CRSCN1 defines the evaluation interval timer threshold determining how frequently adaptive servo integration and cable slack updates occur. In the SBEC-II cruise control algorithm, background counter Counter_Cruise increments on each execution pass. While Counter_Cruise is below CRSCN1, the controller updates cable adaptive delta calculations. Once Counter_Cruise reaches CRSCN1, the controller enters the adaptive integrator routine to evaluate speed error against CRMSK2 and CRMSK3, updates BitFlags_27, and resets the counter. In factory calibrations, CRSCN1 is configured to 21 counts.

2. Tuner's Guide & Real-World Calibration

  • Integrator Update Period: * Governs the elapsed time between adaptive trim adjustments in BitFlags_27. * Factory 21 counts provides stable long-term integration without hunting.
  • Fast Hill Adaptation: * Lowering CRSCN1 to 14 to 16 counts speeds up integrator reaction for steep mountainous terrain.
  • Counter Mechanism: * In CalculateVehicleSpeed, Counter_Cruise counts up to CRSCN1 before triggering integrator evaluations.
