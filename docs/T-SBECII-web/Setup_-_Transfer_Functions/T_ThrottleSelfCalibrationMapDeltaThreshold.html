1. Overview & Purpose

MAPTHR defines the manifold pressure ceiling required to permit upward adaptive learning of the closed-throttle baseline voltage. To maintain accurate idle and off-idle detection across temperature extremes and component aging, the engine controller dynamically learns the physical resting closed-throttle voltage. When the vehicle decelerates with the brake pedal pressed and engine speed above idle, the controller checks intake manifold vacuum. Configured in factory calibrations to forty-nine counts (approximately eighteen to nineteen inches of mercury vacuum, or five point six psi absolute), MAPTHR ensures the engine is pulling strong manifold vacuum before allowing the learned zero-throttle voltage baseline to increment upward.

2. Tuner's Guide & Real-World Calibration

  • High-Duration Camshaft Tuning: * Performance camshafts produce lower manifold vacuum on deceleration; raise MAPTHR to sixty or seventy counts to ensure closed-throttle learning continues to function.
  • Adaptive Throttle Ratchet: * If deceleration vacuum is deeper than MAPTHR and RPM is above RPMTHR, MINTHR increments toward the mechanical stop.
  • False Learning Protection: * Setting MAPTHR too high on an engine with a binding throttle cable risks learning an artificially elevated idle voltage.
  • Factory Default: * Set to forty-nine counts (~18-19 inHg vacuum / 5.6 psi absolute).
