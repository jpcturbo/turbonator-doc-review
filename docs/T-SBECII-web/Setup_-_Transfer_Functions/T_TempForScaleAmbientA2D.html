1. Overview & Purpose

TMPAMB: TMPAMB (TempForScaleAmbientA2D) defines the axis coordinate transfer function and breakpoint scaling curve for Temperature or Split Point used by the ECU's 3D table interpolation routines. The engine management microprocessor reads raw sensor signals from the analog-to-digital converter (ADC) and passes them through TMPAMB to generate normalized X and Y table axis indices for ignition advance, fuel pulsewidth, and wastegate lookup tables.
