1. Overview & Purpose

RIDLST establishes the open-loop fuel enrichment multiplier commanded when entering diagnostic service mode to calibrate the mechanical minimum throttle plate stop screw. Chrysler throttle bodies incorporate a mechanical stop screw that establishes the minimum closed-throttle bypass airflow around the throttle plate. When calibrating this baseline airflow using a Chrysler DRB scan tool (mode 14/10), the engine controller parks the automatic idle speed stepper motor, disables closed-loop oxygen sensor feedback, and engages diagnostic open-loop idle enrichment defined by RIDLST. In factory calibrations, RIDLST is set to 26 counts. This provides extra fuel dampening to stabilize idle combustion while the technician adjusts the throttle stop screw to achieve the factory base mechanical airflow specification.

2. Tuner's Guide & Real-World Calibration

  • Factory Calibration Setting: * Keep RIDLST at 26 counts for standard maintenance and throttle body setup procedures.
  • High-Overlap Camshafts: * Raising RIDLST to 30 to 35 counts stabilizes combustion when performing base throttle stop screw adjustments on engines with aggressive aftermarket camshafts.
  • Injector Rescaling Interaction: * When running larger aftermarket injectors, verify proper base injector constants so that the open-loop multiplier in RIDLST does not drown the spark plugs during diagnostic mode.
