1. Overview & Purpose

SFDCAY defines the initial fuel enrichment pulsewidth loaded at the instant the engine catches and transfers from cranking into running mode. When the engine first fires and engine speed exceeds the cranking threshold, intake manifold airflow undergoes a sudden surge while manifold vacuum is not yet stable. SFDCAY provides a rich fuel bridge that decays smoothly into the steady-state running fuel tables, cushioning the abrupt physical transition and preventing lean hesitation, idle sag, or stall. The initial decay value is looked up based on engine coolant temperature.

2. Tuner's Guide & Real-World Calibration

  • Curing Start-and-Stall: * If an engine starts readily but immediately stumbles or dies when the key returns to the run position, increase SFDCAY at that coolant temperature.
  • Aftermarket Camshafts: * Performance camshafts have poor low-speed vacuum and sluggish air velocity; raise SFDCAY to provide extra fuel cushioning until idle stabilizes.
  • Injector Scaling: * Scale SFDCAY downward when installing higher-flow injectors to prevent rich loading upon start-to-run transition.
  • Warm Restart Drivability: * Lowering values above 140 degF cleans up exhaust smell and stabilizes hot idle flare.

3. Operating Conditions (When Does This Take Effect?)

Takes effect immediately when the engine catches and enters run mode, smoothly decaying heavy startup fuel enrichment down toward normal running fuel levels based on coolant temperature.
