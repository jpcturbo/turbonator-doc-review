1. Overview & Purpose

STFTM2: STFTM2 defines the secondary starter cranking fuel pulsewidth curve versus coolant temperature. While cranking, fuel delivery is governed strictly by coolant temperature rather than MAP vacuum; STFTM2 provides secondary fuel calibration for cold-crank injector firing.

2. Tuner's Guide & Real-World Calibration
