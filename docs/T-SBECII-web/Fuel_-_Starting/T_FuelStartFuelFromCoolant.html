1. Overview & Purpose

STFTMP defines a temperature-dependent reduction factor that subtracts fuel from the cranking calculation as the engine warms up. While STRTFL sets the cold base starting fuel, warm and hot engines require significantly less fuel to start because hot metal surfaces promote immediate fuel vaporization. Working in direct multiplication with the barometric reduction factor (STFBAR), STFTMP calculates a combined reduction percentage. This percentage subtracts fuel from the cranking pulsewidth, ensuring hot restarts are clean and rapid without flooding or black smoke.

2. Tuner's Guide & Real-World Calibration

  • Warm Restart Flooding: * Increasing STFTMP values at warm temperatures (above 140 degF) removes excess cranking fuel, curing hot restart flooding.
  • Lean Hot-Start Pop: * Lowering STFTMP values retains more cranking pulsewidth if warm restarts pop lean or crank excessively before catching.
  • Altitude Compounding: * Because STFTMP is multiplied by STFBAR, changes here interact directly with high-elevation starting behavior.
  • Injector Upgrades: * When running large aftermarket injectors, higher STFTMP reduction factors prevent rich hot-cranking stumbles.

  • Subtractive Product: The reduction factor functions as (1 - STFBAR * STFTMP). At cold temperatures where STFTMP is zero, no reduction occurs.
