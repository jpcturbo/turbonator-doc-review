1. Overview & Purpose

DCWADJ supplies an engine-speed-dependent signed duty cycle adjustment to the base wastegate duty cycle in T1 control. Turbocharger volumetric flow characteristics and exhaust backpressure shift considerably between low engine speeds and redline; smaller turbine housings often create rising exhaust backpressure that blows the wastegate valve open at high RPM, while larger turbines may build boost progressively. The engine controller uses DCWADJ to add or subtract solenoid duty cycle across the rev range, keeping boost steady and flat from initial spool through redline.

2. Tuner's Guide & Real-World Calibration

  • High-RPM Boost Sag Correction: * If boost drops off above 5000 RPM due to exhaust backpressure opening the flapper, add positive duty cycle in the high-RPM bins.
  • High-RPM Boost Creep Damping: * If boost creeps above target near redline, apply negative duty cycle values at high RPM to vent actuator pressure.
  • Signed Adjustment Range: * Signed Type 2 curve spans -64.0 percent to +63.5 percent duty cycle adjustment.
  • Shared Clamping Helper: * Resulting sum in Temp4 is clamped to 0 to 200 counts (0 to 100 percent) via WGDC_AdjustWGDutyCycle.

Takes effect during full-throttle boost control, adjusting baseline wastegate duty cycle across engine RPM to compensate for turbine flow changes.
