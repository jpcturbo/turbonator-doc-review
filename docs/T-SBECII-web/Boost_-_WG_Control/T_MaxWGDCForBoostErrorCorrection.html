1. Overview & Purpose

WGMXER: WGMXER (MaxWGDCForBoostErrorCorrection) calibrates adaptive wastegate closed-loop duty cycle learning parameters. The ECU monitors boost error over time and learns long-term duty cycle adjustments, locking out learning when coolant temperature is cold or limiting maximum single-step error corrections.
