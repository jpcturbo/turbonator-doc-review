1. Overview & Purpose

MAPPT sets the manifold gauge pressure switch point that divides low-load adaptive wastegate learning from high-load RPM-split adaptive learning in T1 control. In Chrysler's 5-cell adaptive wastegate architecture, Cell 1 handles boost levels below MAPPT across all engine speeds. Once target boost exceeds barometric pressure plus MAPPT, the controller switches into Cells 2 through 5, which are partitioned by engine speed. In factory calibrations, MAPPT is set to 68 counts (approximately 7.8 psi of boost).

2. Tuner's Guide & Real-World Calibration

  • Adaptive Cell Switch Point: * Boost threshold dividing low-load Cell 1 from RPM-split high-load Cells 2 through 5. * Factory setting is 68 counts (approximately 7.8 psi boost above atmospheric pressure).
  • Positioning Relative to Spring Pressure: * Set MAPPT 1 to 2 psi above mechanical wastegate spring pressure so low-load spooling stays in Cell 1.
  • 3-Bar MAP Sensor Rescaling: * When converting to a 3-bar MAP sensor, divide count value by approximately 1.5 to maintain proper physical psi switching.

3. Operating Conditions (When Does This Take Effect?)

Takes effect once target boost exceeds barometric pressure plus MAPPT, the controller switches into Cells 2 through 5, which are partitioned by engine speed.
