1. Overview & Purpose

MPDEL2 defines the manifold pressure stability threshold required to permit adaptive wastegate duty cycle incrementing when boost is below target. Similar to MPDEL1 on the overboost side, MPDEL2 verifies that manifold pressure is steady and not undergoing violent fluctuations or throttle transients before allowing the error timer to advance toward an adaptive duty cycle increase. If the difference between instantaneous manifold pressure and rolling average manifold pressure exceeds MPDEL2, adaptive learning is inhibited. Shared between T1 and T2 control routines.

2. Tuner's Guide & Real-World Calibration

  • Underboost Manifold Stability Gate: * Requires |MapValue - AverageMAPValue| to be within MPDEL2 to permit adaptive incrementing. * Factory setting is 2 counts (approximately 0.23 psi variance).
  • Filtering Transient Spool Lag: * Prevents rapid throttle tip-in or spool-up transients from triggering upward adaptive duty cycle learning.
  • Shared Code Usage: * Evaluated in both CalcWGDutyCycleT1 (line 9710) and CalcWGDutyCycleT2 (line 9992).
