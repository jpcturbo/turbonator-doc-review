1. Overview & Purpose

DEFTMP specifies the fixed default engine coolant temperature value substituted into the engine controller's temperature calculation whenever the primary coolant sensor is faulted. If the coolant temperature sensor circuit suffers an open circuit or short to ground (Fault Code 22), the engine controller first attempts to substitute the charge air temperature sensor reading. However, if the vehicle is not equipped with a charge temperature sensor or if the charge temperature sensor is also faulted, the controller falls back to DEFTMP. In factory calibrations, DEFTMP is set to 149 counts, corresponding to approximately 125 deg F. This intermediate temperature represents a lukewarm, partially warmed-up engine, providing adequate fuel enrichment for drivability without severely flooding a warm engine.

2. Tuner's Guide & Real-World Calibration

  • Failsafe Fueling Calibration: * Factory setting of 125 deg F strikes a compromise between cold-start ability and warm-engine drivability. * For warm summer climates or dedicated track cars, raising DEFTMP to 160 deg F avoids rich bogging if the coolant sensor fails.
  • Cold Climate Starting: * In sub-freezing winter operation, lowering DEFTMP to 100 deg F provides sufficient fuel enrichment to start a cold engine under sensor failure.
  • Edge Cases: * Setting DEFTMP to 0 deg F causes severe spark plug flooding. * Setting DEFTMP to 210 deg F causes lean backfiring and stalling during cold starting.
