1. Overview & Purpose

MPTHR defines the manifold absolute pressure switch point where the engine controller toggles its synthetic throttle calculation between closed-throttle idle and wide-open throttle when the throttle position sensor is faulted. When the throttle sensor circuit suffers an open circuit or short to ground (Fault Code 24), the controller cannot read physical accelerator pedal movement. To maintain vehicle drivability, the controller substitutes synthetic throttle values based entirely on measured intake manifold pressure. In factory calibrations, MPTHR is configured to 104 counts, which corresponds to approximately 12.0 psi absolute pressure (equivalent to -2.7 psi gauge pressure or roughly 5.5 inHg of manifold vacuum). When manifold pressure is below MPTHR, the controller simulates closed-throttle idle; when manifold pressure reaches or exceeds MPTHR, the controller immediately forces the wide-open throttle flag.

2. Tuner's Guide & Real-World Calibration

  • 3-Bar MAP Sensor Rescaling: * Rescale MPTHR by multiplying by 0.667 when upgrading to a 3-bar MAP sensor (from 104 counts down to 69 counts) to keep the 12.0 psi absolute transition point accurate.
  • Limp-In Drivability Tuning: * Lowering MPTHR provides richer, safer failsafe fueling earlier in the pedal travel under sensor failure conditions. * Raising MPTHR preserves part-throttle economy in limp-in mode but delays wide-open throttle enrichment.
  • Edge Cases: * Setting MPTHR below base idle manifold pressure permanently locks the engine into simulated wide-open throttle. * Setting MPTHR above atmospheric pressure prevents simulated wide-open throttle from engaging without positive boost.
