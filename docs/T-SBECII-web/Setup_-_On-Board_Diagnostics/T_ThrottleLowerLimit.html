1. Overview & Purpose

THRLOW defines the lower electrical voltage boundary for the throttle position sensor analog input circuit. The throttle position sensor is a potentiometer powered by a 5.0-volt reference supply that produces an output voltage proportional to throttle plate angle. Under normal operating conditions, a fully closed throttle plate produces a signal between 0.50 and 0.90 volts. If the signal wire breaks, the wiper loses contact, or the sensor circuit shorts directly to ground, the input voltage drops below THRLOW. In factory calibrations, THRLOW is set to 8 counts, corresponding to approximately 0.16 volts. If sensor voltage drops below THRLOW, the engine controller flags Fault Code 24, latches a bad throttle signal error, and activates synthetic throttle emulation from manifold pressure.

2. Tuner's Guide & Real-World Calibration

  • Throttle Stop Adjustment & False Codes: * If an aftermarket throttle body is adjusted so the closed-throttle resting voltage drops near 0.30 volts, raising THRLOW can cause false Fault Code 24 triggers. * Keep THRLOW at or below 8 counts (0.16 volts) to maintain an adequate safety margin below base idle voltage.
  • Sensor Wiring Diagnostics: * A continuous Fault Code 24 with 0.0 volts measured at the sensor signal pin typically indicates a broken signal wire or cracked potentiometer wiper.
  • Lowering & Edge Cases: * Zeroing THRLOW disables short-to-ground detection. * Setting THRLOW higher than base idle voltage forces the vehicle into permanent limp-home throttle emulation.
