1. Overview & Purpose

PTUDTP defines the throttle position sensor voltage delta threshold used to classify throttle application as either gentle or aggressive in the Part Throttle Unlock system. When evaluating entry conditions for lockup retention, the controller subtracts learned closed-throttle MINTHR from current TPS voltage to calculate throttle opening delta. In factory calibrations, PTUDTP is configured to 52 counts, corresponding to approximately 1.02 Volts above closed throttle. If throttle delta is below PTUDTP, the controller sets state flag b52_PTU_A and checks secondary MAP threshold PTUMP2. If throttle delta equals or exceeds PTUDTP, the controller sets flag b52_PTU_B and evaluates primary MAP threshold PTUMP1.

2. Tuner's Guide & Real-World Calibration

  • Pedal Sensitivity Classification: * Establishes the 1.02 V boundary dividing light throttle modulation from aggressive throttle application.
  • Tuning Lockup Sensitivity: * Raise PTUDTP to 60 to 70 counts (~1.2 to 1.4 V) to allow more throttle movement before aggressive lockup logic engages.
  • State Flag Routing: * Sets b52_PTU_A (below threshold) or b52_PTU_B (above threshold) to select between PTUMP2 and PTUMP1.
