1. Overview & Purpose

DADRPM defines the engine speed error deadband window within which adaptive idle airflow learning is permitted to operate. If engine speed is significantly above or below target idle, the engine is experiencing a transient disturbance (such as an accessory load engaging or disengaging) rather than reflecting true steady-state mechanical airflow needs. Allowing adaptive learning to adjust idle trim during an RPM disturbance would skew the learned calibration in the wrong direction. DADRPM enforces an RPM stability window: only when actual engine speed is within DADRPM of target idle speed will the controller adjust the adaptive trim integrator. In factory calibrations, DADRPM is set to 4 counts, representing an RPM deadband window of 32 RPM.

2. Tuner's Guide & Real-World Calibration

  • Lumpy Camshaft Idle Accommodation: * Increase DADRPM to 8 to 12 counts (64 to 96 RPM) on engines with significant valve overlap to allow adaptive learning to tolerate normal lope dither.
  • Stock Camshaft Tightness: * Retain factory 4 counts (32 RPM) on smooth-idling stock or mild street camshafts.
  • Excessive Window Warning: * Do not widen DADRPM beyond 16 counts (128 RPM), as the ECU may mistake an active idle flare or sag for a stable idle condition.
