1. Overview & Purpose

SPKADD defines the spark advance addition curve applied by the spark scatter algorithm when engine speed drops below target idle speed. Because the mechanical automatic idle speed stepper motor reacts relatively slowly to airflow demands, the engine controller uses ignition timing advance as an instantaneous torque actuator. When engine RPM falls below target idle speed, SPKADD looks up an advance adder indexed by the RPM undershoot delta (scaled in 16 RPM increments). The looked-up advance (up to 8.0 degrees BTDC) is added immediately on the very next distributor firing pulse, boosting combustion cylinder pressure and generating immediate torque to arrest the RPM dip.

2. Tuner's Guide & Real-World Calibration

  • Arresting Idle Dips: * Increasing SPKADD delivers instantaneous torque recovery when heavy loads (such as electric cooling fans or power steering) drag idle speed down.
  • Over-Correction Oscillation: * If the engine bounces or rhythmically lopes between high and low idle, reduce SPKADD values to dampen the advance kick.
  • 16 RPM Table Indexing: * Table delta RPM is shifted right 4 times (divided by 16); each table breakpoint represents 16 RPM of undershoot.
