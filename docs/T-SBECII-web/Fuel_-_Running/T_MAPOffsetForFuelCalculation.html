1. Overview & Purpose

MAPOFS_BoostMapOffsetForDCWOT establishes the manifold pressure threshold below target boost where wastegate solenoid closed-loop modulation begins. While manifold pressure is far below the boost target (e.g. during initial spool-up), the wastegate should remain clamped 100% shut to achieve the fastest possible spool. Once manifold pressure climbs within MAPOFS of target boost, the ECU transitions into modulating wastegate duty cycle to prevent overshooting.
