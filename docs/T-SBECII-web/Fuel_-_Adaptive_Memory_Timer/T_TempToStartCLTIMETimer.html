1. Overview & Purpose

CLTEMP defines the absolute minimum engine coolant temperature required before the engine controller will start the closed-loop countdown timer and allow closed-loop oxygen sensor feedback. Below this coolant temperature, the engine is considered completely cold, and fuel condensation on runner walls necessitates dedicated open-loop cold enrichment. In factory calibrations, CLTEMP is set to 146 counts, which corresponds to approximately 70 degF. If coolant temperature is lower than CLTEMP, closed-loop feedback is strictly locked out and fuel pulse width is governed entirely by open-loop base and warmup tables.

2. Tuner's Guide & Real-World Calibration

  • Cold Climate Optimization: * In freezing conditions, raising CLTEMP to 85 or 90 degF ensures thorough engine warmup before closed-loop trimming engages.
  • Warm Climate Tuning: * Lowering CLTEMP toward 55 or 60 degF allows faster closed-loop engagement, improving fuel economy.
  • Open-Loop Racing Setup: * Setting CLTEMP to 255 counts locks the ECU permanently in open loop across all operating temperatures, which is useful for drag racing on race gas or methanol.
