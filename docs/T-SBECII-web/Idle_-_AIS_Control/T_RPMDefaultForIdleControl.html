1. Overview & Purpose

RPMDEF defines the default baseline engine speed target utilized by the idle control logic during engine cranking and initial stall recovery. When the starter motor is turning the crankshaft, actual engine speed is typically only 150 to 250 RPM, which is well below normal operating idle speed. If the closed-loop idle control routines were allowed to calculate an error delta against true engine cranking speed, the proportional and integral feedback loops would saturate, commanding maximum opening steps and causing severe over-fueling or high-RPM flare upon catching. To prevent this control loop windup, whenever engine speed is below the threshold set in RPMTHS, the SBEC-II substitutes RPMDEF as a synthetic engine speed target. In factory calibrations, RPMDEF is set to 160 counts, representing an equivalent engine speed target of approximately 1280 RPM.

2. Tuner's Guide & Real-World Calibration

  • Factory Baseline: * Keep RPMDEF at 160 counts (1280 RPM) for stock and mild street calibrations.
  • Aggressive Camshaft Catch: * For race camshafts with significant overlap, raising RPMDEF to 1350 to 1450 RPM can help the engine bridge the transition from cranking to steady idle.
  • Overshoot & Flare Warning: * Setting RPMDEF higher than 1500 RPM produces excessive throttle flare upon initial firing.
