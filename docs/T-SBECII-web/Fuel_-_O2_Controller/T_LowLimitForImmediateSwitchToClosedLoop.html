1. Overview & Purpose

O2LOW defines the lower voltage threshold for immediate validation of the narrowband oxygen sensor signal. If the sensor produces a clear lean reading below O2LOW during warmup, the controller knows the sensor has reached operating temperature and is capable of full amplitude swings. The controller immediately validates the sensor flag without waiting for delay timers. In stock calibrations, O2LOW is set to 15 counts, corresponding to approximately 0.29 volts.

2. Tuner's Guide & Real-World Calibration

  • Lean Signal Validation: * Any signal below O2LOW (approx 0.29V) proves the sensor is hot and swinging lean, immediately triggering closed loop.
  • Ground Offset Mitigation: * If wiring resistance creates a ground voltage offset, raising O2LOW to 18-20 counts (0.35-0.39V) prevents delayed closed-loop entry.
  • Interaction with O2HIGH: * Together, O2LOW and O2HIGH define the active boundaries outside the intermediate warmup zone.

3. Operating Conditions (When Does This Take Effect?)

Takes effect during oxygen sensor signal validation, setting the lower (lean) voltage threshold that verifies the O2 sensor is active and switching.
