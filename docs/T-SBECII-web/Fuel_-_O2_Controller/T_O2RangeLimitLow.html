1. Overview & Purpose

O2LIML defines the absolute minimum negative fuel trim limit for short-term oxygen sensor feedback. When the oxygen sensor detects a rich mixture, the controller decrements the feedback counter to remove fuel. O2LIML provides a hard lower clamp, preventing the controller from subtracting more fuel than calibrated. In stock calibrations, O2LIML is set to signed -77 counts (stored as 179 unsigned), which corresponds to approximately -15.0 percent maximum fuel reduction. This prevents a failing sensor from dangerously leaning out the engine.

2. Tuner's Guide & Real-World Calibration

  • Capping Negative STFT: * Clamping O2LIML to -25 to -30 counts limits short-term leanout to -5% to -6%, preventing lean misfires on cammed engines.
  • Preventing False Leanout: * Large cams with unburned oxygen at idle cause false rich readings; restricting O2LIML prevents the ECU from pulling needed fuel.
  • Mathematical Authority: * Factory signed -77 counts represents -15.0% maximum fuel reduction (-77 / 512).
