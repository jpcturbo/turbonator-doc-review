1. Overview & Purpose

ARMAP defines the manifold pressure-indexed adaptive spark retard curve. In parallel with ARRPM, ARMAP establishes a learned timing reduction based on manifold load. When persistent detonation under boost causes AdaptiveRetardIndex to accumulate, the engine controller looks up ARMAP using manifold pressure, scales the value by the adaptive retard index, and subtracts the resulting retard from the manifold advance curve (HOTMAP or WOTMAP). In factory calibrations, ARMAP provides up to 2.0 degrees of load-dependent retard under positive boost pressure.

2. Tuner's Guide & Real-World Calibration

  • Load-Based Retard Authority: * ARMAP pulls additional timing as boost pressure rises if the controller has learned persistent knock history.
  • Disabling for Dyno Calibration: * Setting ARMAP to zero ensures that spark timing under boost is not dynamically offset by learned knock history during calibration.
  • 3-Bar MAP Scaling: * Rescale table pressure points when converting to a 3-bar sensor to align retard properly with positive boost levels.
