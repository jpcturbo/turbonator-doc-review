1. Overview & Purpose

AMLIMH establishes the maximum allowable positive fuel enrichment ceiling for all long-term adaptive fuel memory cells (AutoCal cells). The Turbo III controller firmware applies adaptive fuel trims as a signed modifier where each bit equals approximately 0.1953 percent of base fuel delivery. In stock calibrations, AMLIMH is set to 127 counts (positive 127), which limits maximum learned enrichment to approximately +24.8 percent above the base calibration. This cap prevents vacuum leaks, failing fuel pumps, or dirty injectors from causing the engine controller to excessively enrich base fuel calculations into runaway conditions.

2. Tuner's Guide & Real-World Calibration

  • Constraining Adaptive Authority: * Clamping AMLIMH to 25-50 counts limits positive fuel trim learning to +5% to +10%, preventing runaway enrichment.
  • Zeroing for Wideband Tuning: * Setting AMLIMH to 0 disables positive long-term fuel trim learning, essential when mapping base fuel tables.
  • Formula & Resolution: * Maximum fuel modifier is 1 + (AMLIMH / 512). 127 counts represents +24.8% enrichment.

3. Operating Conditions (When Does This Take Effect?)

Takes effect whenever adaptive fuel trims are updated during driving, capping the maximum allowable positive enrichment to prevent runaway rich conditions.
