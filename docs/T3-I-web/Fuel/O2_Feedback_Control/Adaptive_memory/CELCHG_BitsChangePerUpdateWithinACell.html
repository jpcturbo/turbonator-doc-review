1. Overview & Purpose

CELCHG defines the incremental step size in bits by which an active adaptive fuel memory cell is adjusted whenever an update event occurs. The Turbo III controller applies long-term fuel trim using a signed mathematical modifier where one unit in an AutoCal cell represents approximately 0.1953 percent (about 0.2 percent) of base fuel delivery. In stock calibrations, CELCHG is set to 1 count (1 bit). When the update timer expires and short-term trim indicates a rich or lean bias, the active cell is stepped by exactly CELCHG toward stoichiometric balance, ensuring gradual and stable long-term learning without sudden fueling jumps.

2. Tuner's Guide & Real-World Calibration

  • Adaptation Speed: * Higher values (2-3 counts) speed up the rate at which adaptive cells correct for fuel delivery errors, useful when testing new calibrations.
  • Fuel Trim Stability: * The factory setting of 1 count ensures very smooth, non-intrusive adaptation (approx 0.2% per update).
  • Freezing Adaptive Memory: * Setting CELCHG to 0 freezes all 13 adaptive cells in their current state, preventing further updates while retaining existing trim offsets.

3. Operating Conditions (When Does This Take Effect?)

Takes effect when transitioning between adaptive fuel cells, enforcing a delay timer before the new cell's adaptive trim begins updating.
