1. Overview & Purpose

LOTTHR specifies the coolant temperature-dependent fuel multiplier applied when the throttle closes rapidly during vehicle deceleration. When the driver lifts off the accelerator pedal at speed, manifold airflow drops immediately, leaving residual fuel film on the intake runner walls that can cause excessively rich mixtures and exhaust popping if fuel delivery is not cut back. When qualifying throttle-drop triggers are met, the engine controller looks up LOTTHR and applies it as a fractional multiplier to base pulse width. In the factory calibration for automatic-transmission calibrations, the table contains a factor of zero representing a neutral 1.00 multiplier, effectively keeping throttle-based decel lean-out disabled.

2. Tuner's Guide & Real-World Calibration

  • Enabling Deceleration Lean-out: Increasing table values above zero engages deceleration fuel leaning, multiplying the base fuel pulse width by less than 1.00 to reduce fuel consumption and prevent rich exhaust burble on deceleration.
  • Manual Transmission Braking: In manual transmission performance calibrations, enabling subtle throttle decel lean-out improves engine braking and reduces tailpipe emissions.
  • Preventing Shift Bucking: Setting this factor too aggressively can cause bucking, lean surging, or exhaust backfiring when getting back on the throttle after a shift.
  • Exhaust Crackle Tunes: Leave at zero if using aggressive crackle-pop exhaust tunes or if low-RPM deceleration stalling occurs.
