1. Overview & Purpose

AISFRQ defines the closed-loop feedback update period that governs how frequently the automatic idle speed stepper motor can make corrective position changes based on RPM error. Because an internal combustion engine has physical intake manifold volume and delayed torque response to airflow changes, making stepper motor adjustments too rapidly causes control loop instability, where the controller constantly overshoots and hunts around target idle. AISFRQ acts as a rate-limiting filter, requiring a minimum elapsed timer duration between successive closed-loop step corrections from FWDAIS or REVAIS. In factory calibrations, AISFRQ is set to 63 counts (or 127 counts in some variants), which enforces a settling delay of approximately 0.7 to 1.4 seconds between motor adjustments. This deliberate pacing allows the engine to respond and manifold vacuum to stabilize before the controller evaluates whether another step correction is needed.

2. Tuner's Guide & Real-World Calibration

  • Curing Rhythmic Idle Surging: * If idle speed oscillates up and down in an endless cycle, increase AISFRQ from 63 up to 90 to 127 counts to slow down the feedback response and allow manifold pressure to settle.
  • Sharpening Sluggish Recovery: * If the idle air controller takes too long to recover from an accessory load drop, reduce AISFRQ to 45 to 50 counts to allow more frequent stepper nudges.
  • Minimum Stability Boundary: * Do not set AISFRQ below 30 counts, as rapid corrections outpace engine mechanical response time, triggering severe hunting.
