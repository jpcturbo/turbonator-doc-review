1. Overview & Purpose

RPMLO: RPMLO (LoRPM3DInputModifierFromRPM) defines the axis coordinate transfer function and breakpoint scaling curve for Engine Speed (RPM) used by the ECU's 3D table interpolation routines. The engine management microprocessor reads raw sensor signals from the analog-to-digital converter (ADC) and passes them through RPMLO to generate normalized X and Y table axis indices for ignition advance, fuel pulsewidth, and wastegate lookup tables.

2. Tuner's Guide & Real-World Calibration

  • Calibration Strategy: This is a fundamental axis transfer function. In standard tuning, RPMLO should remain at its factory calibration unless rescaling the ECU for non-standard sensor ranges (such as converting to a 3-bar MAP sensor or custom high-RPM scaling). Modifying this table alters axis lookup indexing across all linked 3D tables.
  • Raising the Value: Increases commanded threshold or extends gating limits in the controller.
  • Lowering the Value: Decreases commanded threshold or restricts operational bounds.
