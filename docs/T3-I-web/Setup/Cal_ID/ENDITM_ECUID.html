1. Overview & Purpose

ENDITM defines the primary electronic calibration identifier word within the engine controller ROM header. In production vehicles, this numerical identifier differentiates specific powertrain calibrations across model years, engine displacements, turbocharger packages, and transmission configurations, such as calibration A283 for the nineteen eighty-nine two-point-five-liter turbo automatic. Handheld diagnostic scan tools read ENDITM during the initial communication handshake to automatically identify the vehicle calibration. Crucially, the low-order byte of ENDITM also serves as the expected target value for the internal memory checksum verification algorithm, which verifies calibration ROM integrity during startup.

2. Tuner's Guide & Real-World Calibration

  • Scan Tool Recognition: * Factory scan tools query ENDITM to identify vehicle powertrain calibration; altering this word may require manual vehicle selection on legacy diagnostic equipment.
  • Hardware Checksum Target: * The low-order byte (ENDITM_ECUID+1, 131 counts in stock A283) is the exact target compared against the calculated memory checksum in CaculateChecksum.
  • Calibration Integrity: * Whenever calibration constants or tables are edited, CHKFIX must be adjusted so the total byte sum matches the target byte in ENDITM, preventing error code 53.
