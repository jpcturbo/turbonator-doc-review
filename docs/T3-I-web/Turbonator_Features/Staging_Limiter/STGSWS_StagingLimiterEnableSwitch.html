1. Overview & Purpose

STGSWS defines the digital input switch bitmask used to arm the launch control staging limiter. Rather than requiring staging control to be permanently engaged at low vehicle speeds, this parameter allows the driver to trigger launch control via an external electrical switch, such as a clutch pedal switch, handbrake switch, steering wheel push-button, or cruise control switch. When set to zero (the factory default), no external switch is required; the engine controller automatically arms launch control whenever vehicle speed and throttle position meet the staging criteria.

2. Tuner's Guide & Real-World Calibration

  • Clutch Interlock Wiring: Wire a clutch pedal switch to a digital input (such as Brake Switch or Cruise Control On/Off) and select that bitmask in STGSWS for seamless manual transmission staging.
  • Hands-Free Automatic Arming: Setting STGSWS to zero allows automatic arming whenever vehicle speed is below STGSPD and throttle exceeds STGTPS, requiring no external switches.
  • Diagnostic Verification: Datalog the staging flag in MPScan to confirm that the selected switch reliably engages and disengages launch control logic.

3. Operating Conditions (When Does This Take Effect?)

Takes effect when staging at the starting line, selecting the physical toggle switch or clutch input used to activate the 2-step launch rev limiter.
