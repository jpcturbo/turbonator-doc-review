1. Overview & Purpose

MPRPML defines the lower engine speed limit for the manifold absolute pressure sensor steady-state rationality validation window. To confirm that the MAP sensor is operating accurately and providing trustworthy load signals, the engine controller validates the sensor reading against expected manifold pressure boundaries under steady idle and light cruising conditions. However, during engine cranking, initial startup flare, or unstable low-speed chugging below normal idle speed, manifold vacuum fluctuates wildly. In factory calibrations, MPRPML is configured to 4800 counts, corresponding to exactly 600 RPM. If engine speed is below MPRPML, the controller suspends steady-state sensor validation, preventing false rationality errors during engine start.

2. Tuner's Guide & Real-World Calibration

  • Camshaft & High Idle Tuning: * If installing performance camshafts that require an elevated idle target (e.g., 950 RPM), raise MPRPML from 600 RPM to 750 RPM to avoid erratic validation during lope.
  • Startup Stability: * Keeping MPRPML above cranking speed (600 RPM vs 200-250 RPM cranking) prevents false rationality judgments during engine startup.
  • Edge Cases: * Zeroing MPRPML forces validation during engine cranking when manifold vacuum is completely unstable. * Setting MPRPML higher than normal cruising RPM disables MAP steady-state validation entirely.
