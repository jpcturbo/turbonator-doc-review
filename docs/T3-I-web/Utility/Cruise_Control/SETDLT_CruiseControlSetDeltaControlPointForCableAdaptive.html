1. Overview & Purpose

SETDLT defines the calibration offset bias added to speed error during evaluation of the throttle cable adaptive delta variable. In Chrysler Turbo III controller engine management, the cruise controller continuously monitors mechanical throttle linkage compliance and cable stretch by calculating the difference between commanded speed and measured vehicle velocity. SETDLT is added to this delta, allowing calibrators to introduce an intentional bias into the cable compensation routine. In factory calibrations, SETDLT is configured to 0 counts, providing pure symmetrical calculation.

2. Tuner's Guide & Real-World Calibration

  • Symmetrical Error Baseline: * Factory 0 counts provides unbiased calculation of throttle cable slack.
  • Linkage Compliance Compensation: * Offset feeds into CruiseControlVar6, which tracks mechanical hysteresis in the throttle linkage.
  • Offset Errors: * Non-zero values induce persistent steady-state speed offsets; keep at 0 counts.
