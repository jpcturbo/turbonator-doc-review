1. Overview & Purpose

BAROLO defines the minimum credible atmospheric pressure threshold used during barometric pressure validation. When the engine controller reads ambient barometric pressure, it verifies that the measurement is above BAROLO before storing it into RAM. Atmospheric pressure at 14,000 feet elevation (such as Pikes Peak highway) is approximately 8.6 psi absolute (17.5 inHg). In factory calibrations, BAROLO is set to 69 counts, representing approximately 7.9 psi absolute (16.1 inHg). Any ambient reading below BAROLO indicates a defective sensor, pinched vacuum line, or a baro read solenoid that failed to open to atmosphere. If a reading falls below BAROLO, it is rejected and BARDFT is loaded instead.

2. Tuner's Guide & Real-World Calibration

  • 3-Bar MAP High-Altitude Operation: * Rescale BAROLO to ~44 to 46 counts on 3-bar sensors to prevent false fault substitution when driving above 6,000 feet.
  • Fault Detection Integrity: * Setting BAROLO too low allows a stuck-shut baro solenoid to feed engine vacuum into BaroPressure undetected.
  • Default Substitution: * Rejection of a reading below BAROLO forces immediate fallback to BARDFT.

3. Operating Conditions (When Does This Take Effect?)

Takes effect during key-on and in-flight barometric pressure reads, establishing the acceptable low voltage limit for a valid atmospheric reading.
