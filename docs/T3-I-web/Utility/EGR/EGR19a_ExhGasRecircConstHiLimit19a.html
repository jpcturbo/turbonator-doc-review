1. Overview & Purpose

EGR19A (ExhGasRecircConstHiLimit19a) establishes the upper throttle position boundary for the Phase 2 Exhaust Gas Recirculation diagnostic flow verification window (Fault Code 32). During Phase 2, the engine controller de-energizes the EGR solenoid to test for a corresponding lean shift in the oxygen sensor feedback loop. To prevent transient acceleration enrichment from mimicking or obscuring an EGR flow shift, the controller enforces a strict upper throttle ceiling. Evaluated at offset +1 from EGR19 during the boundary check at line 5495, EGR19A sets the maximum throttle angle allowed during testing. The factory setting of 41 counts corresponds to approximately 0.80 volts (roughly 16 percent throttle opening). Depressing the throttle beyond this limit aborts Phase 2 immediately.

2. Tuner's Guide & Real-World Calibration

  • Raising EGR19A: Expands the upper throttle boundary for Phase 2 shutoff flow testing. Helpful on heavier vehicles where steady highway cruise requires slightly more throttle opening.
  • Lowering EGR19A: Narrows the allowable throttle window, ensuring testing only proceeds under strictly controlled light-load cruising.
  • Window Polarity: Must always be set higher than EGR19 (8 counts) to maintain a valid operating window.
  • Stock Calibration: 41 counts (approx 0.80 volts / ~16 percent throttle above idle) provides a robust upper limit that rejects acceleration transients.

3. Operating Conditions (When Does This Take Effect?)

Takes effect during warm, part-throttle cruising, modulating the exhaust gas recirculation (EGR) solenoid duty cycle to control combustion temperatures.
