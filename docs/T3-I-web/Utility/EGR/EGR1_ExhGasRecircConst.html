1. Overview & Purpose

EGR1 (ExhGasRecircConst) establishes the Phase 1 diagnostic sampling timer threshold for the onboard Exhaust Gas Recirculation flow verification system (Fault Code 32). During closed-loop cruising, the engine controller requires stable operating conditions before testing whether the EGR valve actually delivers exhaust gas to the intake manifold. The controller tests that manifold pressure, throttle angle, and engine speed remain within prescribed test windows while the EGR solenoid is energized. While these conditions hold, an internal diagnostic counter increments once per background execution loop pass. The factory setting of 455 loop counts corresponds to approximately 4.5 to 6.8 seconds of continuous, undisturbed cruising. If the vehicle operates steadily for this entire period, the controller freezes its filtered baseline oxygen sensor fuel trim and advances to Phase 2 of the diagnostic test.

2. Tuner's Guide & Real-World Calibration

  • Raising EGR1: Increases the duration of steady cruising required to satisfy Phase 1 baseline sampling. This reduces diagnostic test frequency during stop-and-go driving, requiring longer highway cruises to complete.
  • Lowering EGR1: Shortens the required Phase 1 sampling window, accelerating the transition to Phase 2 EGR shutoff testing. If lowered excessively below 200 counts (roughly 2 seconds), baseline fuel trim may not stabilize, increasing the risk of false Fault Code 32 triggers.
  • EGR Elimination Scenarios: Setting EGR1 to its maximum 16-bit ceiling (65535 counts) ensures the diagnostic timer never elapses during ordinary driving cycles. This cleanly prevents Phase 2 testing and suppresses Fault Code 32 when an EGR block-off plate is installed on modified turbo builds.
  • Stock Applications: Retaining the factory calibration of 455 counts preserves complete OBD-I emissions compliance and provides robust immunity against false diagnostic failures.

3. Operating Conditions (When Does This Take Effect?)

Takes effect during warm, part-throttle cruising, modulating the exhaust gas recirculation (EGR) solenoid duty cycle to control combustion temperatures.
