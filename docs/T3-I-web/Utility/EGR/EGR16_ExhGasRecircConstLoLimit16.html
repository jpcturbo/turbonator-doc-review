1. Overview & Purpose

EGR16 (ExhGasRecircConstLoLimit) establishes the lower manifold absolute pressure boundary for the Phase 2 Exhaust Gas Recirculation diagnostic verification window (Fault Code 32). During Phase 2, the engine controller de-energizes the EGR solenoid to shut off exhaust gas flow, and monitors closed-loop oxygen sensor feedback to verify that the fuel mixture shifts in response. To ensure that this shift is caused by the EGR valve closing rather than external load variations, manifold pressure must stay strictly within the window bounded by EGR16 and EGR16A. In the factory calibration, EGR16 is set to 255 counts, disabling lower pressure window gating during Phase 2 and allowing flow verification across the available vacuum operating range.

2. Tuner's Guide & Real-World Calibration

  • Lowering EGR16: Establishes a lower manifold pressure boundary during Phase 2 flow verification. If manifold pressure dips below this setting, the test sequence aborts immediately.
  • Factory Wide-Open Setting (255 counts): Allows Phase 2 testing across the full pressure range, relying on EGR33 to guarantee sufficient manifold vacuum below barometric pressure.
  • 3-Bar MAP Sensor Conversions: If non-default values are chosen, scale the setting by 0.667 (two-thirds) to prevent pressure window drift on 3-bar sensor installations.
  • EGR Block-Off Considerations: When blocking off the EGR valve, modifying EGR16 will not prevent Fault Code 32 because the code is triggered by a lack of oxygen sensor delta (EGR7), not window violations. Use EGR1 or cfg_EGR to disable testing.

3. Operating Conditions (When Does This Take Effect?)

Takes effect during warm, part-throttle cruising, modulating the exhaust gas recirculation (EGR) solenoid duty cycle to control combustion temperatures.
