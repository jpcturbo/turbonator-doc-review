1. Overview & Purpose

DCRPM1 establishes the first engine speed boundary dividing the RPM-split adaptive wastegate cells in high-boost operation. When target boost exceeds the MAPPT switch point, the controller assigns adaptive duty cycle trims across four separate RPM cells (Cells 2 through 5). DCRPM1 defines the boundary between Cell 2 (low-to-mid RPM spool-up) and Cell 3 (mid-range torque band). Shared between T1 and T2 control routines.

2. Tuner's Guide & Real-World Calibration

  • First RPM Adaptive Boundary: * Engine speed threshold separating adaptive Cell 2 from Cell 3 in high-boost mode. * Factory setting is 125 counts (approximately 4000 RPM in template, or 4200 RPM in ASM).
  • Spool-Up Partitioning: * Keep DCRPM1 positioned at the top of the initial spool-up curve so spool transients stay isolated in Cell 2.
  • Shared Code Usage: * Evaluated in both CalcWGDutyCycleT1 (line 9656) and CalcWGDutyCycleT2 (line 9936).
