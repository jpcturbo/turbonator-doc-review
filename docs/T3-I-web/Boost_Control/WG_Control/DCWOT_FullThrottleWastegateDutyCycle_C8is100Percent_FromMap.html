1. Overview & Purpose

DCWOT provides the open-loop base wastegate solenoid duty cycle curve as a function of target boost pressure for T1 wastegate control. In Chrysler T1 bleed-style wastegate plumbing, the solenoid bleeds pressurized air away from the wastegate actuator canister; higher duty cycle bleeds more pressure to hold the wastegate valve closed and raise boost, while lower duty cycle vents less air, forcing the actuator open to lower boost. The engine controller looks up this base duty cycle from target boost as the foundational starting point for closed-loop regulation, scaled so that 200 counts represents 100 percent duty cycle.

2. Tuner's Guide & Real-World Calibration

  • Feed-Forward Base Duty Cycle: * Sets the foundational open-loop solenoid duty cycle before RPM, delta-boost, and adaptive corrections are applied. * Scaled such that 200 counts equals 100 percent duty cycle (0.5 percent duty cycle per count).
  • Correcting Boost Overshoot & Spikes: * If boost spikes past target on initial spool, lower DCWOT in the target boost region by 5 to 10 percent.
  • Stiff Actuator Spring Rescaling: * Aftermarket wastegates with stiff base springs (10 to 14 psi) require substantially lower DCWOT values than stock 6 psi springs.
  • Bleed-Style Plumbing Mechanics: * T1 hardware bleeds air away from the canister; higher duty cycle holds the wastegate shut, while zero duty cycle runs base spring boost.
