1. Overview & Purpose

DCRPM2 defines the second engine speed boundary dividing high-load adaptive wastegate cells, separating Cell 3 (mid-range torque) from Cell 4 (upper mid-range). Partitioning adaptive trims across distinct RPM bands enables the controller to compensate for nonlinear turbine flow, changing exhaust backpressure, and volumetric efficiency variations without compromising boost stability in adjacent RPM zones. Shared between T1 and T2 control routines.
