1. Overview & Purpose

INCPT specifies the dwell time threshold that an underboost condition must continuously persist before the controller increments the active adaptive wastegate cell in T1 control. When the throttle is initially opened, turbocharger spool lag naturally creates a temporary underboost condition. INCPT ensures that the error timer must accumulate a steady duration of underboost before the controller concludes that baseline duty cycle is truly insufficient, preventing transient spool-up lag from corrupting steady-state adaptive trims.

2. Tuner's Guide & Real-World Calibration

  • Underboost Dwell Time Threshold: * Number of consecutive error timer counts that underboost must persist before the adaptive cell is incremented. * Factory setting is 32 counts (approximately 0.35 seconds).
  • Preventing Premature Adaptation on Lag: * Higher values (40 to 60 counts, 0.45 to 0.7 seconds) prevent the ECU from adding duty cycle while a large turbo is naturally spooling.
  • Fast Convergence for Sluggish Spool: * Lowering INCPT to 15 to 20 counts speeds up adaptive duty cycle additions if steady-state boost consistently falls short.

3. Operating Conditions (When Does This Take Effect?)

Takes effect during part-throttle boost control, establishing the adaptive duty cycle increment time delay.
