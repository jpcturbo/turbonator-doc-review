1. Overview & Purpose

EMRETB: EMRETB defines the emergency spark retard curve applied under excessive boost pressure on the Lotus 16-valve Turbo III engine. In factory calibrations, this 1-point table is set to 0.0 degrees (.byte 0x01, .byte 0xFF, 0x00), acting as a dormant safety hook. When calibrated, it aggressively pulls timing if boost spikes above safe thresholds.

2. Tuner's Guide & Real-World Calibration

  • Calibration Strategy: Factory calibrated at zero retard. When running high boost on pump fuel, tuners can populate EMRETB with an aggressive retard curve (e.g., -4° to -8°) to save the engine if wastegate lines fail.
  • Raising the Value: Increases commanded threshold or extends gating limits in the controller.
  • Lowering the Value: Decreases commanded threshold or restricts operational bounds.
