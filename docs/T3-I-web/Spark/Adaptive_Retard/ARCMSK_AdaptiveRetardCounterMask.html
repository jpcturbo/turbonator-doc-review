1. Overview & Purpose

ARCMSK defines the background program loop counter bitmask controlling how frequently the engine controller samples cylinder knock retards during wastegate control and adaptive retard evaluation. Rather than evaluating adaptive retard on every single program loop pass, the controller executes a bitwise test against Counter_MainLoop using ARCMSK. In factory calibrations, ARCMSK is set to 63 counts (binary mask 63, or 00111111). When Counter_MainLoop matches this mask (once every 64 main loops, approximately every 704 milliseconds), the controller inspects all cylinder retard variables and increments the boost knock timer if knock is present.

2. Tuner's Guide & Real-World Calibration

  • Sampling Pacing: * Factory setting of 63 samples cylinder knock retards once every 64 main loops (~704 ms), filtering out brief transient noise.
  • Strict Bitmask Configuration: * Must strictly be set to 2^N - 1 values: 0, 1, 3, 7, 15, 31, 63, 127, or 255.
  • Faster Adaptation: * Lowering ARCMSK to 31 (evaluating every ~352 ms) speeds up boost knock accumulation on high-boost race applications.
