1. Overview & Purpose

RNFPRD defines the fuel injection start-to-run transfer distributor pulse period threshold. During starter cranking, the engine controller delivers rich, fixed-duration cranking priming pulses to wet the intake manifold runners and spark ignition. Once the engine catches and spins past RNFPRD, the controller cuts off cranking enrichment pulses and initiates normal running speed-density fuel calculation. In period-based logic, smaller count values represent faster engine speeds. In factory calibrations, RNFPRD is set to 48 counts, corresponding to approximately 625 RPM. Grouped under the Start-to-Run Transfer category in calibration templates, RNFPRD synchronizes the fueling transition with the ignition transition.

2. Tuner's Guide & Real-World Calibration

  • Preventing Large Injector Flooding: * When running large aftermarket injectors, raising RNFPRD cuts off rich cranking priming pulses earlier, preventing cylinder flooding on hot restarts.
  • Cold Start Flare Support: * On alcohol or E85 conversions, lowering RNFPRD keeps rich cranking fuel active higher into the start flare to prevent cold die-out.
  • Period Scaling: * Period is inversely related to RPM: RPM ≈ 30,000 / count. Factory setting 48 counts = 625 RPM.

3. Operating Conditions (When Does This Take Effect?)

Takes effect during engine cranking, defining the engine speed threshold where the ECU transitions from cranking fuel into normal running mode.
