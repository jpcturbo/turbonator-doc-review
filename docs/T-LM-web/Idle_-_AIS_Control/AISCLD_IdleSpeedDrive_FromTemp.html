1. Overview & Purpose

AISCLD (IdleSpeedDrive_FromTemp) defines the target idle speed curve across engine coolant temperatures when an automatic transmission is engaged in gear (Drive, Reverse, 1st, or 2nd).

When an automatic vehicle is shifted from Neutral into Drive, the torque converter impeller imposes substantial hydrodynamic drag on the engine crankshaft. AISCLD typically calibrates target idle speed approximately 50 to 100 RPM lower than AISPN to prevent excessive vehicle creep at stoplights while still providing adequate airflow to resist stalling.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated in DetermineTargetIdleSpeed_MM at line 5357.
  • Selected when bit 3 of Z83_PortCdata is high (1), indicating the transmission gear selector is in Drive/Reverse.
  • In manual transmission vehicles, the P/N input is grounded, so this table is ordinarily bypassed in favor of AISPN.

3. Tuner's Guide & Real-World Calibration

  • Automatic Trans Conversions / Retuned ATX: If running an automatic calibration, match or stagger AISCLD against AISPN. If shifting into Drive causes harsh engagement or vehicle lunging, lower AISCLD. If shifting into Drive stalls the engine due to torque converter load, raise AISCLD by 50-80 RPM.
  • Manual Calibrations: On dedicated MTX cals, this table exists in ROM as legacy code/data but is not reached unless the Port C sense pin state is altered.
