1. Overview & Purpose

AMTMH_SelectedAMTimerInitHi is the coolant temperature threshold that distinguishes a fully hot restart from a warm restart for adaptive timer selection.

If the engine is started with coolant temperature at or above AMTMH, the ECU selects the longer delay (AMTML, ~3 minutes) to account for severe engine bay heat soak. If below AMTMH, the shorter delay (AMTPSW, ~34 seconds) is selected.
