1. Overview & Purpose

AMTEMP_StartTempToSelectHotOrColdAMTimer specifies the engine operating temperature threshold that selects between hot and cold adaptive memory timer countdowns.

The engine thermal environment differs significantly depending on whether the engine was started cold or warm. When the engine reaches full operating temperature (AMTEMP), the adaptive timer begins counting down, unlocking adaptive fuel memory trimming once the timer expires.
