1. Overview & Purpose

AMTPSW_TempPointToEnableSelectedAMTimer specifies the alternate (shorter) countdown duration loaded into the adaptive memory inhibit timer when starting the engine at intermediate coolant temperatures.

If the engine is started below the full heat-soak threshold (AMTMH), fuel rail vaporization is not an issue, so a much shorter hold time (approx. 33 seconds) is applied before adaptive memory updates can proceed.

2. Operating Conditions (When Does This Take Effect?)

  • Startup Initialization:
  • When CoolantTemp < AMTMH at key-on/start, AMTPSW (0x0C) is stored into the adaptive countdown timer instead of AMTML (0x40).

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x0C (12 × 2.8 s ≈ 34 seconds).
  • Tuning Guidance: Stock values provide a well-balanced delay for warm restarts.
