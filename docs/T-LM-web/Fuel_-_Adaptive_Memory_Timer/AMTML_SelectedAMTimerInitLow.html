1. Overview & Purpose

AMTML_SelectedAMTimerInitLow defines the initial countdown timer duration used to inhibit adaptive memory learning after a hot engine restart.

When restarting an already warm engine, heat soak can cause temporary vapor bubbles in the fuel rail or distorted intake charge temperatures. To ensure the fuel rail purges and intake airflow stabilizes, AMTML holds adaptive memory updates off for approximately 3 minutes after hot restart.

2. Operating Conditions (When Does This Take Effect?)

  • Hot Start Initialization:
  • Loaded into Timer_O2CNTR_CountdownFromAbove196FtoEnableClosedLoop during startup when coolant temperature is elevated above AMTMH.

3. Tuner's Guide & Real-World Calibration

  • Stock Setting: 0x40 (64 counts ≈ 3.0 minutes).
  • Tuning Guidance: Shortening AMTML allows quicker adaptive learning resumption after hot restarts if heat soak is well managed.
