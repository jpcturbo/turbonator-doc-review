1. Overview & Purpose

RETTPS_RetardFromTPS is the lookup table that defines how many degrees of ignition timing are pulled out as a function of throttle opening speed (\DeltaTPS).

When the throttle is snapped open rapidly under boost, the rate of throttle movement reflects the suddenness of air mass change entering the intake manifold. RETTPS scales the protective retard proportionally: a slow, gradual roll into the throttle produces almost zero retard, while a violent, rapid stomp to full throttle extracts substantial ignition advance (up to ~25° in stock tables) for a brief instant to quench transient detonation before fuel film dynamics stabilize.

2. Operating Conditions (When Does This Take Effect?)

RETTPS is looked up only when all preceding enable gates are satisfied: 1. MapValue > RTMAPE (~1.5 psi boost). 2. EngineRpm_HB > RTRPME (~2,496 RPM). 3. AverageTPSVolts > RTTPSE (~1.57 V). 4. \DeltaTPS = TpsVolts - AverageTPSVolts > 0.

3. Tuner's Guide & Real-World Calibration

The value looked up from RETTPS is subtracted directly from intermediate total advance:

Total Advance = \max(0, Advance - RETTPS(\DeltaTPS))

  • Increasing Table Values (More Retard per \DeltaTPS):
  • Effect on Total Timing: Retards ignition timing more aggressively during rapid throttle stabs.
  • Real-World Driving Feel: Completely eliminates tip-in knock and pinging on gear shifts or rapid accelerator stomps, but excessive retard causes a brief "flat spot" or delayed power delivery.
  • Decreasing Table Values (Less Retard per \DeltaTPS):
  • Effect on Total Timing: Maintains higher ignition advance during throttle stabs.
  • Real-World Driving Feel: Delivers explosive, immediate tip-in acceleration and throttle response. Highly desirable for responsive autocross or road racing applications, provided fuel octane or water/methanol injection prevents tip-in detonation.
  • Zeroing Out the Table:
  • Setting all Y-axis values to 0x00 disables TPS transient retard completely while leaving all other spark tables active.

4. Technical / Assembly Mechanics (Reference)

Inside T-LMv13.asm (lines 6674–6683):

ldaa TpsVolts       ; Instantaneous TPS voltage
        sba                 ; A = TpsVolts - AverageTPSVolts
        bcs  LF092          ; If negative delta, bypass
        ldx  #RETTPS_RetardFromTPS
        jsr  Lookup4ByteTable ; A = RETTPS(Delta TPS)

        ldaa Temp0          ; Load current advance from Temp0
        sba                 ; A = Temp0 - RETTPS(Delta TPS)
        bpl  LF090          ; If positive, branch to store
        clra                ; Else clamp to zero advance
LF090:  staa Temp0          ; Store final advance into Temp0
LF092:  ...

Table Data (Stock A171 Calibration):

Number of points: 3
Point 1: Delta TPS = 0x05 (Slow opening)    -> Retard = 0x00 (0.0°)
Point 2: Delta TPS = 0x1E (Moderate opening) -> Retard = 0x1E (30 / 2 = 15.0°)
Point 3: Delta TPS = 0x4B (Rapid snap)       -> Retard = 0x32 (50 / 2 = 25.0°)

(Retard values are scaled at 1 bit = 0.5° crankshaft retard).

5. Calibration Notes & System Dependencies

  • Transient Duration: Because AverageTPSVolts continuously tracks toward TpsVolts with a software filter, \DeltaTPS naturally decays back to zero within 100–300 milliseconds after throttle movement stops, restoring normal steady-state ignition advance automatically.
