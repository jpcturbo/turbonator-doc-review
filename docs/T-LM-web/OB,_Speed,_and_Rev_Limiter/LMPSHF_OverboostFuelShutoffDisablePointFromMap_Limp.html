1. Overview & Purpose

LMPSHF_OverboostFuelShutoffDisablePointFromMap_Limp defines the overboost fuel shutoff threshold applied when the ECU is in Limp Mode (due to a detected wastegate or MAP sensor fault).

If the ECU flags a wastegate electrical problem or MAP sensor out-of-range condition (BitFlags_80 bit 4 set), standard boost targeting cannot be trusted. LMPSHF enforces a dedicated, conservative overboost ceiling to protect the vehicle in limp mode.

2. Operating Conditions (When Does This Take Effect?)

  • Limp Mode Gate: Active when BitFlags_80 bit 4 = 1.

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x73 (13.2 psig).
  • Tuning Guidance: Should never be disabled; ensures limp mode safety if boost control wiring fails.
