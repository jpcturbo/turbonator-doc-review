1. Overview & Purpose

TMPHLD_TempSwitchPointForCurveAHoldDecay is the coolant temperature switch point that selects between the Cold Hold/Decay parameters (CLDHLD & DCYTMC) and the Hot Hold/Decay parameters (HOTHLD & DCYTMH).

2. Operating Conditions (When Does This Take Effect?)

  • If CoolantTemp >= TMPHLD (colder than ~178°F): The ECU applies the Cold parameters (CLDHLD = 90s hold, DCYTMC = slow decay).
  • If CoolantTemp < TMPHLD (warmer than ~178°F): The ECU applies the Hot parameters (HOTHLD = 15s hold, DCYTMH = fast decay).

3. Tuner's Guide & Real-World Calibration

  • Thermostat Matching: In stock calibrations, 0xB2 corresponds to ~178°F, matching the OEM 180°F thermostat. If using a cooler 160°F thermostat, adjusting TMPHLD ensures the ECU correctly classifies warm restarts under hot decay rules.
