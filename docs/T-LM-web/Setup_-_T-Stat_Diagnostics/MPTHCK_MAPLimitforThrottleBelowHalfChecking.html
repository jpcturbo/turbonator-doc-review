1. Overview & Purpose

MPTHCK (MAPLimitforThrottleBelowHalfChecking) defines the manifold pressure ceiling (stock calibration = 0x5E / ~75 kPa) evaluated during throttle sensor rationality routines in CheckThrottle_AtFullThrottle.

Under normal engine operation, if the throttle is truly near closed idle, manifold vacuum should be deep (low manifold absolute pressure). If engine RPM is moderate and manifold pressure is higher than MPTHCK, the ECU checks whether the throttle linkage is mechanically stuck or if the TPS voltage baseline has shifted.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside subroutine CheckThrottle_AtFullThrottle at line 6832.
  • Compares MapValue against MPTHCK.
  • Used to validate learned closed-throttle baseline updates.

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x5E.
  • Large Duration Camshafts: Radical racing camshafts have poor idle vacuum (high idle MAP, e.g. 70-80 kPa). If a big camshaft causes erratic TPS learning or unintended closed-throttle baseline shifts, raising MPTHCK accommodates the lower idle vacuum.
