1. Overview & Purpose

TTEMPL (TstatDiagnosticsMinTempToArmDiagnosticsAtStartup) defines the lower temperature boundary (stock calibration = 0x63 / ~70°F) required for the ECU to arm the onboard thermostat functional diagnostic monitor (Timer_ThermostatDiagnostics).

The thermostat diagnostic routine checks whether the engine warms up to operating temperature within a reasonable time window. However, in extreme sub-zero winter temperatures, a perfectly good thermostat may take very long to warm the engine block, especially if the cabin heater is running on high. To prevent false trouble codes, the ECU requires ambient startup coolant temperature to be at or above TTEMPL before it will arm the warmup monitor.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside startup reset routine ResetRoutine at line 5758.
  • Compares CoolantTemp against TTEMPL.
  • If CoolantTemp < TTEMPL (bcs LE9EB), the thermostat diagnostic timer is not armed.

3. Tuner's Guide & Real-World Calibration

  • Cold Climate Tuning: In freezing climates, keeping TTEMPL at stock (~70°F) ensures that cold winter starts do not trigger false Code 17 trouble codes.
