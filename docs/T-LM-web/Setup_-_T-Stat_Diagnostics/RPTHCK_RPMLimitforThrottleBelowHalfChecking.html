1. Overview & Purpose

RPTHCK (RPMLimitforThrottleBelowHalfChecking) specifies the lower engine speed limit (stock calibration = 0x18 / 24 × 32 = 768 RPM) for throttle sensor rationality evaluation.

Prevents the ECU from adjusting learned closed-throttle baselines while the engine is cranking or running at sub-idle stall speeds.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated in CheckThrottle_AtFullThrottle at line 6829.
  • Compares EngineRpm_HB against RPTHCK.
  • If EngineRpm_HB < RPTHCK (bcs LF1C5), rationality adjustments are bypassed.

3. Tuner's Guide & Real-World Calibration

  • High Target Idle Tuning: If target idle speed is raised to 950 - 1,050 RPM for a race engine, RPTHCK can be left stock or raised proportionally to 0x1E (960 RPM).
