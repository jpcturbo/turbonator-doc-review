1. Overview & Purpose

TDAGTP (TstatDiagnosticsTemperatureGoalWithin_HOTIME) is the target coolant temperature threshold (stock calibration = 0xC7 / ~190°F / 88°C) that the engine is required to reach during warm-up driving.

Inside subroutine VerifyOperationOfThermostat_MM, the ECU monitors coolant temperature as the vehicle is driven at road speed (> VehicleSpeed ≥ 7). If the engine coolant warms up and reaches TDAGTP, the thermostat is verified as functioning correctly, and the diagnostic timer is cleared (LC79E). If the vehicle is driven continuously and fails to reach TDAGTP before HOTIME expires, the ECU determines that the thermostat is stuck open or missing, setting OBD Trouble Code 17.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside VerifyOperationOfThermostat_MM at line 839.
  • Compares live CoolantTemp against TDAGTP.
  • If CoolantTemp >= TDAGTP (bcc LC79E), the thermostat test passes.

3. Tuner's Guide & Real-World Calibration

  • 160°F / 180°F Low-Temperature Thermostats: This is a classic false trouble code trigger on modified cars! If you install a 160°F or 180°F performance thermostat, the engine may stabilize at 165°F - 175°F. Because this is below TDAGTP (~190°F), the ECU will eventually set Fault Code 17 and turn on the Check Engine light!
  • Solution for Cool Thermostats: Lower TDAGTP to 0xB0 (~170°F) for 180°F thermostats, or 0x98 (~150°F) for 160°F thermostats.
