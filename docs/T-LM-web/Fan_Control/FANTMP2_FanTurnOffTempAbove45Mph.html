1. Overview & Purpose

FANTMP2 (FanTurnOffTempAbove45Mph) establishes the radiator cooling fan turn-OFF temperature threshold (stock calibration = 0xE8 / ~208°F) when cruising above 45 MPH.

Once high-speed coolant temperature triggers the fan ON (FANTMP1 at 218°F), the fan continues running until ram airflow and forced convection pull engine coolant down below FANTMP2. The 10°F hysteresis deadband between FANTMP1 (218°F) and FANTMP2 (208°F) prevents the heavy-duty radiator fan relay from rapidly chattering on and off.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside subroutine ControlFan2_MM at line 6908-6920.
  • Active when the radiator fan is currently running and vehicle speed is above 45 MPH.
  • When CoolantTemp < FANTMP2, the ECU de-energizes the fan relay.

3. Tuner's Guide & Real-World Calibration

  • Hysteresis Staggering: Always calibrate FANTMP2 roughly 8°F to 12°F below FANTMP1. If FANTMP2 is set too close to FANTMP1, relay contacts will arc and wear prematurely.
  • Thermostat Floor: Never set FANTMP2 below the opening temperature of your mechanical thermostat (e.g. never set below 185°F for a 180°F thermostat), otherwise the electric fan will run continuously and never turn off on the highway!
