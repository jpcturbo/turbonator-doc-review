1. Overview & Purpose

ERMSK2 (ErrorCodeBitMask2) controls the diagnostic validation of powertrain solenoid output drivers, including canister purge solenoid (Code 31), wastegate solenoid electrical circuit (Code 32), EGR solenoid (Code 33), and radiator fan relay driver (Code 35).

In stock configuration, bit 0 is cleared (0xFE = binary 11111110), masking an unequipped hardware sensor line.

2. Operating Conditions (When Does This Take Effect?)

  • Loaded as the high byte of ldd ErrorCodeBitMask2 at line 704 in ChecksumFinished.
  • ANDed directly with ErrorBitRegisterStored2.

3. Tuner's Guide & Real-World Calibration

  • Aftermarket Boost Controller / Solenoid Removal: If the factory wastegate solenoid is disconnected when converting to an aftermarket electronic boost controller or external gate, clear Bit 1 to completely suppress Fault Code 32 from being logged into memory.
