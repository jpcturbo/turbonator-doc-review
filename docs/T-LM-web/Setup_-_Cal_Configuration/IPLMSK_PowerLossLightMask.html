1. Overview & Purpose

IPLMSK (PowerLossLightMask) is an 8-bit diagnostic control mask that determines which electronic sensor and circuit faults cause the dashboard 'Power Loss' / 'Check Engine' lamp to illuminate.

While the ECU logs dozens of minor diagnostic anomalies into memory, not every fault warrants alerting the driver. Minor faults (such as a temporary A/C switch glitch) are stored silently as fault codes for mechanics to read later. Critical faults that directly compromise emissions or engine survival (such as a disconnected MAP sensor, dead coolant sensor, or charging system failure) are filtered through IPLMSK. If an active fault matches an enabled bit in IPLMSK, the ECU immediately grounds the lamp driver to illuminate the dashboard warning light.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated during OBD background diagnostic executive processing.
  • Bit assignments:
  • Bit 7 (1): Charge Temperature Sensor Fault
  • Bit 6 (1): Coolant Temperature Sensor Fault
  • Bit 5 (1): Charging System / Voltage Regulator Fault
  • Bit 4 (0): Unused / Bit 3
  • Bit 3 (1): Battery Voltage Out of Range
  • Bit 2 (0): MAP Signal Electrical Fault
  • Bit 1 (0): TPS Signal Electrical Fault
  • Bit 0 (1): MAP Pneumatic / Overboost Fault

3. Tuner's Guide & Real-World Calibration

  • Custom Warning Light Setup: If running a dedicated race car or custom conversion and you want to prevent non-critical sensor faults from turning on the dashboard light, you can selectively clear corresponding bits in IPLMSK.
  • CEL Knock Warning: Note that in Turbonator custom code, the Check Engine Light can also be repurposed to flash on knock detection via CONFIG (cfg_FlashCE).
