1. Overview & Purpose

ERMSK1 (ErrorCodeBitMask1) is the second diagnostic masking byte, located at $1020 directly following ERMSK0.

It selectively enables or suppresses OBD trouble codes associated with oxygen sensor switching (Code 21), coolant sensor voltage (Code 22), throttle position sensor voltage (Code 24), and automatic shutdown (ASD) relay sensing (Code 27). In this stock binary, bit 6 is cleared (0xBF = binary 10111111), intentionally disabling diagnostic reporting for an unused circuit variant.

2. Operating Conditions (When Does This Take Effect?)

  • Loaded as the low byte of ldd ErrorCodeBitMask0 at line 700.
  • ANDed with ErrorBitRegisterStored1.

3. Tuner's Guide & Real-World Calibration

  • O2 Sensor Deletion (Track Cars): For off-road race cars running open-loop without an oxygen sensor, clearing the O2 diagnostic bit in ERMSK1 prevents the ECU from continuously storing Code 21.
