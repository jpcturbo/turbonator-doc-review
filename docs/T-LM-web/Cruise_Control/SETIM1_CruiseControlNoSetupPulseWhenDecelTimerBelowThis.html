1. Overview & Purpose

SETIM1 (CruiseControlNoSetupPulseWhenDecelTimerBelowThis) sets the lower timer boundary for cruise control deceleration pulse qualification.

In conjunction with SETIME, SETIM1 establishes a precise timing window used by the cruise state machine to verify how long the driver held the Coast button before releasing it. This prevents momentary electrical switch contact bounce or brief switch taps from falsely corrupting the deceleration state logic.

2. Operating Conditions (When Does This Take Effect?)

3. Tuner's Guide & Real-World Calibration
