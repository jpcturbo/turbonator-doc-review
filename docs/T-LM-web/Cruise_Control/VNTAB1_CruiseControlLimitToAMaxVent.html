1. Overview & Purpose

VNTAB1 (CruiseControlLimitToAMaxVent) defines the maximum allowable pulse width duration limit for the cruise control vent solenoid.

When the vehicle encounters an overspeed condition (e.g. cresting a hill), the vent solenoid opens to dump vacuum from the actuator. If the ECU vented vacuum too rapidly or held the vent open continuously, the throttle butterfly would slam shut abruptly against its idle stop, causing severe driveline bucking and passenger discomfort. VNTAB1 establishes an absolute clamp on single vent pulses, ensuring throttle retraction is smooth and controlled.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside subroutine CruiseControlSet at line 2276.
  • Compared against the calculated vent pulse width.
  • If Vent_Pulse > VNTAB1, the vent pulse is clamped to VNTAB1.

3. Tuner's Guide & Real-World Calibration

  • Factory Setting: Stock value is 0x70 (112 counts). Retain stock setting for factory vacuum actuator diaphragms.
  • Lightweight Actuators: If using an aftermarket or smaller vacuum servo actuator that vents faster than stock, reducing VNTAB1 prevents harsh throttle closing.
