1. Overview & Purpose

SCNVHI (CruiseControlForBrakeFlagManualTransmissionClutchDisable) defines the upper analog voltage threshold used to detect brake pedal application or manual transmission clutch pedal depression.

On manual transmission vehicles (MTX), depressing either the brake pedal or the clutch pedal must instantly disengage cruise control to prevent engine over-revving when the clutch is disengaged. The pedal switch circuit feeds an analog-to-digital input channel. SCNVHI establishes the upper boundary of the valid pedal switch disengagement window.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside subroutine CruiseIsSwitchedOn at line 2013.
  • Checked continuously on every execution loop while cruise control is active.
  • If the sensor input voltage enters the disengage window, cruise drops out immediately.

3. Tuner's Guide & Real-World Calibration

  • Clutch / Brake Switch Calibration: If cruise disengages intermittently over highway bumps, inspect switch alignment at the pedal bracket before altering calibration constants.
  • Automatic vs Manual Conversion: Crucial calibration parameter when converting an automatic wiring harness to manual transmission.
