1. Overview & Purpose

VENTRG (CruiseControlVentRegularGainCurve_FromDeltaSpeed) establishes the vent solenoid pulse duration gain curve used to bleed vacuum from the cruise servo when vehicle speed exceeds the set target.

When descending a highway incline or following an acceleration event, vehicle speed rises above the target cruise setting (Current_Speed > Target_Speed). The ECU calculates the positive speed error and looks up VENTRG. The resulting pulse energizes the vent solenoid, venting vacuum from the actuator diaphragm to atmospheric pressure so the return spring pulls the throttle blade closed.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside subroutine CruiseControlSet at line 2259.
  • Active during cruise control engagement whenever vehicle speed exceeds the target set speed.
  • Subject to minimum throttle angle gate CLOTHR and maximum vent duration clamp VNTAB1.

3. Tuner's Guide & Real-World Calibration

  • Downhill Speed Creep: If the vehicle gains significant speed on downhill stretches with cruise engaged, increase VENTRG values to vent vacuum more aggressively.
  • Throttle Jerkiness: Setting VENTRG excessively high causes the throttle to snap shut abruptly, inducing driveline lash on manual transmission vehicles.
