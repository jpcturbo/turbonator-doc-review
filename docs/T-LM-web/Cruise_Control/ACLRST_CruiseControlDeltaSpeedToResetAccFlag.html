1. Overview & Purpose

ACLRST (CruiseControlDeltaSpeedToResetAccFlag) defines the speed error delta threshold below which the ECU disengages accelerated cruise gain mode and returns to regular steady-state gain mode.

When resuming cruise speed, the ECU operates in high-gain accelerated mode (VACACC) to pull the vehicle back up toward target speed rapidly. Once vehicle speed climbs close enough to the set speed such that the remaining deficit (Target_Speed - Current_Speed) is less than ACLRST (~2.5 MPH), the accelerated cruise flag is cleared. The controller switches back to VACREG, smoothly settling onto the target speed without overshooting.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside subroutine CruiseControlSet at line 2292.
  • Active while the cruise system is in accelerated pull-up mode.
  • When delta speed drops below ACLRST, the accelerated flag is reset to 0.

3. Tuner's Guide & Real-World Calibration

  • Resume Overshoot: If the vehicle consistently overshoots set speed when resuming, increase ACLRST to e.g. 0x07 or 0x08 (3.5 - 4.0 MPH). This forces the controller to drop out of accelerated gain earlier and settle smoothly.
  • Resume Undershoot: If the car accelerates aggressively on resume but stalls out 2-3 MPH below set speed and takes forever to climb the last bit, decrease ACLRST slightly.
