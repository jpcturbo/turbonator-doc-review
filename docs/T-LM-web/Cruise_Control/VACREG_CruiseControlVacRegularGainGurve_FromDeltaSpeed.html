1. Overview & Purpose

VACREG (CruiseControlVacRegularGainGurve_FromDeltaSpeed) defines the primary proportional vacuum servo gain curve used by the cruise control system under steady-state cruising.

When road speed falls slightly below the target set speed (e.g. encountering a moderate highway grade or headwind), the ECU calculates the delta speed error (Target_Speed - Current_Speed). VACREG maps this speed deficit into a proportional vacuum solenoid pulse width. Applying vacuum draws on the throttle actuator diaphragm, opening the throttle blade smoothly to restore the target cruising speed without hunting or surging.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside subroutine CruiseControlSet at line 2251.
  • Active during cruise control engaged mode when the accelerated gain flag is clear.
  • Looked up whenever vehicle speed is below the set target speed.

3. Tuner's Guide & Real-World Calibration

  • Speed Droop on Hills: If the vehicle loses 2-4 MPH on highway hills before recovering, increase the upper points of VACREG to command more aggressive vacuum pull.
  • Throttle Surging / Hunting: If the cruise control oscillates or pulses the accelerator pedal while driving on flat roads, reduce the slope of VACREG around zero delta speed.
