1. Overview & Purpose

RPMBST_MinimumRpmToTrackBoostCreep defines the minimum engine speed required before the ECU begins tracking boost error and boost creep.

At very low engine speeds (under 1216 RPM), turbo boost is non-existent, and exhaust pulses are widely spaced. Tracking boost error at low RPM would generate false error signals. RPMBST locks boost error integration out below 1216 RPM.
