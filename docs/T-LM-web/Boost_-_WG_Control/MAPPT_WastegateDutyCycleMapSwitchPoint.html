1. Overview & Purpose

MAPPT_WastegateDutyCycleMapSwitchPoint defines the boost pressure breakpoint dividing low-load wastegate duty cycle correction from high-load adaptive duty cycle learning.

When manifold pressure crosses above MAPPT (11.2 psi), the ECU switches its closed-loop boost logic into Stage 2 adaptive wastegate duty cycle learning.
