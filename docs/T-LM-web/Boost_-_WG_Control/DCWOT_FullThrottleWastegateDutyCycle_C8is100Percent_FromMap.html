1. Overview & Purpose

DCWOT_FullThrottleWastegateDutyCycle_C8is100Percent_FromMap is the primary feed-forward (open-loop baseline) wastegate duty cycle curve used by the Chrysler boost control system.

The Chrysler wastegate solenoid bleeds control pressure away from the wastegate actuator can: * 0% Duty Cycle (Solenoid De-energized): Full boost pressure reaches the actuator canister, forcing the wastegate flapper open at base spring pressure (approx. 5.5 to 7.0 psi). * 100% Duty Cycle (Solenoid Fully Pulsing / Venting): All pressure is bled off to atmosphere; the wastegate flapper stays held shut, producing maximum turbo spool.

DCWOT maps target boost pressure to the expected solenoid duty cycle required to hold that boost level. Closed-loop corrections then trim this baseline.

2. Operating Conditions (When Does This Take Effect?)

  • Wide-Open Throttle Boost Delivery:
  • In ControlWastegate:
  • When operating at full throttle, TargetBoost is looked up in DCWOT.
  • The resulting base duty cycle is combined with RPM adjustments (DCWADJ) and closed-loop feedback trims to set the final wastegate PWM output timer.

3. Tuner's Guide & Real-World Calibration

  • Scaling Mechanics: Duty cycle is scaled from 0 to 200 counts (0x00 = 0%, 0xC8 = 100%, 1 count = 0.5%).
  • Tuning for Higher Boost:
  • When raising boost targets in WSGRPM, you must ensure DCWOT provides sufficient duty cycle to hold that boost.
  • If the turbo cannot reach target boost despite raising target tables, raise the duty cycle values in DCWOT.
  • Actuator Spring Upgrades: If you install a stiffer aftermarket wastegate can (e.g. 10 psi spring instead of 5.5 psi spring), lower DCWOT across the board to prevent uncontrolled boost overshooting.
