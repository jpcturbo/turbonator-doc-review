1. Overview & Purpose

DCRPML_NoWastegateDutyCycleCorrectionBelowThisRpm defines the lower engine speed threshold below which adaptive wastegate duty cycle correction is completely inhibited.

Below 1504 RPM, engine exhaust flow is insufficient to generate meaningful boost. Adapting wastegate duty cycle at low lugging RPMs would corrupt the duty cycle tables. DCRPML locks adaptive duty cycle learning out below 1504 RPM.

2. Operating Conditions (When Does This Take Effect?)

  • Adaptive RPM Floor: Evaluated in ControlWastegate. If EngineRpm < DCRPML, adaptive boost learning is skipped.

3. Tuner's Guide & Real-World Calibration
