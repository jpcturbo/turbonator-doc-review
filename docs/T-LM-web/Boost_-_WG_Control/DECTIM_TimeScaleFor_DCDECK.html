1. Overview & Purpose

DECTIM_TimeScaleFor_DCDECK defines the time interval bitmask clock governing the rate at which wastegate duty cycle is steadily decremented while knock spark retard remains active.

Works as the time-base prescaler for DCDECK.

2. Operating Conditions (When Does This Take Effect?)

  • Timing Prescaler: Tested in ControlWastegate using loop counter Counter_MainLoop1.
