1. Overview & Purpose

MPDEL1_IncCounterWhenDeltaMapBelowThis defines the Stage 1 boost error threshold below which the adaptive wastegate timer increments.

If boost is lagging below target by at least MPDEL1 (0.35 psi), the ECU starts counting elapsed time toward an adaptive duty cycle increase.

2. Operating Conditions (When Does This Take Effect?)

  • Adaptive Underboost Tracking: Evaluated in ControlWastegate.
