1. Overview & Purpose

KDCMAX_WastegateDutyCycleIncreaseMaxWhenKnocking defines the maximum allowable cumulative duty cycle reduction permitted for knock protection.

Ensures that knock-driven duty cycle reduction does not wind up to an absurd level, capping total knock-driven duty cycle reduction to 40.0% (0x50), which typically drops boost straight down to base mechanical actuator spring pressure.

2. Operating Conditions (When Does This Take Effect?)

  • Knock Clamp: Clamps the knock duty cycle reduction accumulator in ControlWastegate.

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x50 (40.0% max reduction).
  • Guaranteed Failsafe: Dropping 40% duty cycle guarantees the wastegate drops to base actuator spring level (5–7 psi), instantly extinguishing high-load knock.
