1. Overview & Purpose

MAXERT (MaximumEngineRunningTimeforErrorCodeReset) defines the 45-second operational time window (stock calibration = 0x002D = 45 seconds) following engine start during which the ECU evaluates automated error code reset conditions.

Chrysler engineers designed the self-healing error reset routine to run early in the drive cycle. If a sensor passed all initial electrical and mechanical tests within the first 45 seconds of engine operation, the fault counters are decremented, allowing the ECU to extinguish dashboard lights promptly after a repair.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside Throttle_MM at line 1219.
  • Compares 16-bit KeyOnOrEngineRunningTime against MAXERT.
  • If running time exceeds MAXERT (bcc LCA31), the startup self-reset window closes.
