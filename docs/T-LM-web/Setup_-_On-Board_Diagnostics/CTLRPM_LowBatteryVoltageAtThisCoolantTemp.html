1. Overview & Purpose

CTLRPM (LowBatteryVoltageAtThisCoolantTemp) specifies the minimum engine operating temperature (stock calibration = 0xCD / ~195°F / 90°C) required before the ECU will flag oxygen sensor inactivity (Fault Code 21).

Until the engine block and exhaust manifold reach full operating temperature, unheated O2 sensors can drop out of closed loop during prolonged idling. CTLRPM prevents the ECU from setting false O2 sensor codes until the engine has achieved full, steady-state thermal maturity.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside VerifyOperationOfO2Sensor at line 1054.
  • Compares CoolantTemp against CTLRPM.
  • If CoolantTemp < CTLRPM (bcs LC8DA), O2 diagnostic monitoring is suspended.

3. Tuner's Guide & Real-World Calibration

  • 160°F / 180°F Thermostats: If running a 160°F or 180°F thermostat, coolant temperature may never reach 0xCD (195°F)! As a result, the ECU will NEVER run O2 sensor functional diagnostics, silently suppressing Code 21. If you want O2 diagnostics active with cooler thermostats, lower CTLRPM to 0xB0 (170°F).
