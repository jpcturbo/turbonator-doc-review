1. Overview & Purpose

O2MNRT (MiniumRunTimeForO2SensorDiag) defines the cumulative running time delay (stock calibration = 0xFF / 255 ticks / ~3.5 minutes) that must elapse after engine start before O2 sensor functional testing is permitted.

Even on a warm restart, exhaust gas velocity and sensor heater stabilization require several minutes of continuous engine operation before an O2 sensor reliably cycles between rich and lean. O2MNRT guarantees the sensor has had ample time to stabilize before evaluating switching performance.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside VerifyOperationOfO2Sensor at line 1060.
  • Compares KeyOnOrEngineRunningTime against O2MNRT.
  • If RunningTime < O2MNRT (bcs LC8DA), O2 diagnostic testing is inhibited.

3. Tuner's Guide & Real-World Calibration

  • Stock Setting: 0xFF (maximum 8-bit timer span).
  • Diagnostics: Explains why Fault Code 21 never sets immediately upon startup; the vehicle must be driven continuously for several minutes before the monitor runs.
