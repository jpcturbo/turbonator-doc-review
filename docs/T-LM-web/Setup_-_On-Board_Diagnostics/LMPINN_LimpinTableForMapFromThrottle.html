1. Overview & Purpose

LMPINN (LimpinTableForMapFromThrottle) is Chrysler's legendary emergency Alpha-N limp-home table.

If the Manifold Absolute Pressure (MAP) sensor is destroyed, unplugged, or blown off its vacuum nipple under boost, a speed-density engine management system would ordinarily stall and strand the vehicle. Chrysler engineers anticipated this failure mode: when Fault Code 14 is active, subroutine SimulateMapReadingFromTps engages LMPINN. This table models the physical relationship between throttle opening angle and engine intake airflow, generating a synthetic manifold pressure value that substitutes for the missing MAP sensor. This allows the driver to drive the vehicle normally without stalling.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside subroutine SimulateMapReadingFromTps at line 878.
  • Active exclusively when MAP sensor electrical failure (Code 14) is active.
  • Indexed by throttle delta: TpsVolts - MINTHR.
  • Interpolated via 5-byte table routine Lookup5ByteTable and offset by MPLMOF.

3. Tuner's Guide & Real-World Calibration

  • Limp-Home Drivability with Blown MAP Hoses: If a silicone vacuum hose blows off the MAP sensor at the racetrack, LMPINN allows you to drive the car back to the pits under its own power.
  • Large Throttle Bodies: If running an oversized 58mm throttle body, raising the lower points of LMPINN provides smoother limp-home off-idle recovery.
