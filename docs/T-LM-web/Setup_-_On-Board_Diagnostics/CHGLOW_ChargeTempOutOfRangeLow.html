1. Overview & Purpose

CHGLOW (ChargeTempOutOfRangeLow) defines the lower electrical threshold (stock calibration = 0x03 / ~0.06V) for the Intake Manifold Air Charge Temperature (ACT) sensor.

Like the coolant sensor, the charge temperature sensor is an NTC thermistor whose voltage drops as manifold air temperature increases. A voltage below 0.06V represents a dead short to ground (such as a wire pinched beneath an intake manifold runner). When detected, the ECU stores Fault Code 23 and substitutes DEFCHG_DefaultChargeTemp_Limpin.

2. Operating Conditions (When Does This Take Effect?)
