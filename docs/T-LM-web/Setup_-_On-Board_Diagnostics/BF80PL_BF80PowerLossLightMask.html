1. Overview & Purpose

BF80PL (BF80PowerLossLightMask) is an 8-bit diagnostic trigger mask (stock calibration = 0xDB / binary 11011011) evaluated inside WorkWithPowerLossLight_MM.

BitFlags_80 is the ECU's primary runtime status register tracking limp-home modes, sensor failure flags, and system error states. Inside WorkWithPowerLossLight_MM, the ECU executes a bitwise test: bita BF80PL_BF80PowerLossLightMask. If any of the masked error bits are active, the routine branches directly to LD4A1 and energizes the dashboard Power Loss / Check Engine warning light driver.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside subroutine WorkWithPowerLossLight_MM at line 2762.
  • Executes: ldaa BitFlags_80; bita BF80PL_BF80PowerLossLightMask.
  • If non-zero (bne LD4A1), illuminates dashboard lamp.
