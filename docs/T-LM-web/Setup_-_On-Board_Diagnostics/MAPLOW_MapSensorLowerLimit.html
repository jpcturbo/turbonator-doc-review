1. Overview & Purpose

MAPLOW (MapSensorLowerLimit) defines the absolute minimum electrical voltage boundary (stock calibration = 0x01 / ~0.02V) for the Manifold Absolute Pressure (MAP) sensor input.

Under physical driving conditions, even full trailing-throttle deceleration at 6,000 RPM cannot pull manifold absolute pressure below ~10-15 kPa (~0.25V). If the MAP signal pin reads below 0.02V, the ECU detects an electrical short to sensor ground or a broken 5V reference wire. When MAPVolts < MAPLOW, the ECU flags Fault Code 14, sets the MapAppearsToBeFaulty bit, illuminates the Power Loss light, and switches to Alpha-N limp-home mode (LMPINN) using throttle angle.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside subroutine VerifyOperationOfMapSensor_MM at line 1192.
  • Gated by engine speed (EngineRpm_HB < 0x1770).
  • If MAPVolts < MAPLOW, executes MapAppearsToBeFaulty.

3. Tuner's Guide & Real-World Calibration

  • Code 14 Diagnosis: If Code 14 is present and scan tool reads 0.0V, inspect the 3-pin MAP sensor connector for water intrusion, corrosion, or a broken 5V supply wire.
