1. Overview & Purpose

MAPHIG (MapSensorUpperLimit) establishes the maximum valid electrical ceiling (stock calibration = 0xFC / ~4.94V) for the MAP sensor.

If the 3-wire MAP sensor connector becomes unplugged or its ground wire is severed, the ECU's internal input circuitry pulls the signal up to 5.0V (> MAPHIG). When detected in VerifyOperationOfMapSensor_MM, the ECU flags Fault Code 14. Additionally, MAPHIG is referenced inside ControlEngineCutout_MM as a secondary overboost/sensor limit ceiling.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated in VerifyOperationOfMapSensor_MM at line 1187 and ControlEngineCutout_MM at lines 6370, 6372, and 6394.
  • Compares raw MAP ADC against MAPHIG.
  • If MAPVolts >= MAPHIG, flags Code 14 and clamps overboost accumulators.

3. Tuner's Guide & Real-World Calibration

  • 3-Bar MAP Sensor Calibration: When installing a 3-Bar MAP sensor, ensure wiring polarity is correct. If the sensor ground pin is improperly pinned, signal voltage will float at 5.0V, instantly triggering Code 14 and engine cutout.
