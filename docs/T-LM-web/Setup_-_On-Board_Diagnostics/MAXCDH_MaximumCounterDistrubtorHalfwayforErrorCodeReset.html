1. Overview & Purpose

MAXCDH (MaximumCounterDistrubtorHalfwayforErrorCodeReset) defines the ignition distributor pulse counter ceiling (stock calibration = 16 pulses / 0x10) evaluated inside Throttle_MM.

Chrysler's OBD system features an automated self-healing / self-clearing mechanism: if a transient fault (such as a temporary MAP or TPS glitch) resolves itself and passes multiple qualification tests while driving, the ECU decrements the fault counter and eventually clears the error code without requiring a scan tool. MAXCDH validates that the distributor pickup is providing stable timing pulses before permitting self-clear processing.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside Throttle_MM at line 1214.
  • Compares Counter_TimerPastHalfwayBetweenDistPulses against MAXCDH.
  • If counter is greater than or equal to MAXCDH (bcc LCA31), automated error clear is bypassed.
