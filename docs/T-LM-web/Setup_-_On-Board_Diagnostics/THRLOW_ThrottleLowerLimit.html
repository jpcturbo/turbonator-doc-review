1. Overview & Purpose

THRLOW (ThrottleLowerLimit) sets the absolute minimum valid electrical voltage (stock calibration = 0x08 / ~0.156V) for the Throttle Position Sensor (TPS) signal input.

Under normal mechanical adjustment, a healthy closed-throttle TPS outputs between 0.60V and 0.95V. A reading below 0.16V indicates that the signal wire is severed, shorted directly to sensor ground, or the internal wiper arm has broken off. When TpsVolts < THRLOW, the ECU immediately logs Fault Code 24 (ThrowCriticalError), illuminates the Check Engine light, forces MINTHR to a default value (0x40), and switches to Alpha-N limp-home mode based on manifold pressure (MPTHR).

3. Tuner's Guide & Real-World Calibration

  • Throttle Body Swaps: When installing an aftermarket throttle body, use a scan tool or voltmeter to confirm that closed-throttle TPS voltage rests safely between 0.65V and 0.90V, well above THRLOW (0.16V).
  • Code 24 Limp-Home Mode: When Code 24 is active, the ECU ignores the broken TPS and calculates synthetic throttle angle from MAP pressure (MPTHR / LMPINN).
