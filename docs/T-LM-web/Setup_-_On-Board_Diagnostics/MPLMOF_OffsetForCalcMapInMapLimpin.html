1. Overview & Purpose

MPLMOF (OffsetForCalcMapInMapLimpin) defines the baseline manifold pressure offset (stock calibration = 0x20 / ~25 kPa / ~22 inHg vacuum) added to the synthetic pressure looked up from LMPINN during MAP sensor failure mode.

At closed throttle, an engine does not operate at 0 kPa absolute pressure; it pulls steady idle vacuum (~25 to 30 kPa). MPLMOF provides this baseline vacuum floor so that when the throttle is fully closed, the synthetic MAP value accurately reflects real engine idle depression.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside subroutine SimulateMapReadingFromTps at line 881.
  • Added directly to the output of LMPINN: adda MPLMOF_OffsetForCalcMapInMapLimpin.

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x20 (~25 kPa).
  • Camshaft Tuning: If running a camshaft that idles with less vacuum (e.g. 45 kPa / 16 inHg), raising MPLMOF to 0x30 (~38 kPa) prevents the engine from idling overly lean if the MAP sensor fails.
