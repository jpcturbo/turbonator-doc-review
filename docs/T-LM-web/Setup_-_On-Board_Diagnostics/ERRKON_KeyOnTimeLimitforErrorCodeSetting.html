1. Overview & Purpose

ERRKON (KeyOnTimeLimitforErrorCodeSetting) enforces a key-on delay period (stock calibration = 128 ticks / ~1.8 minutes) before the ECU permits driving-mode diagnostic monitors to log fault codes into memory.

Ensures that transient battery voltage dips during starting or rapid ignition cycling do not cause erroneous trouble codes to latch into memory.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside VerifyOperationOfO2SensorAnd at line 1028.
  • Compares KeyOnOrEngineRunningTime against ERRKON.
  • If KeyOnOrEngineRunningTime < ERRKON (bcs LC8DA), diagnostic logging is inhibited.

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x80 (~1.8 minutes).
  • Diagnostics: Guarantees that diagnostic fault codes are only set after the vehicle has been running steadily.
