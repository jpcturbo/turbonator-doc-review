1. Overview & Purpose

ERRRPM (RPMLimitforErrorCodeSetting) provides an RPM offset (stock calibration = 0x0C / 12 × 8 = +96 RPM) added to TargetIdleSpeed_HB to define the boundary between curb idle and off-idle driving diagnostics inside VerifyOperationOfO2SensorAnd.

Certain diagnostic tests (such as vehicle speed sensor operation and dynamic MAP rationality) must only run when the vehicle is being actively driven, not while idling at a red light. ERRRPM establishes the engine speed threshold above which the ECU recognizes the vehicle is operating off-idle.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside subroutine VerifyOperationOfO2SensorAnd at line 1031.
  • Added to TargetIdleSpeed_HB: Threshold = TargetIdleSpeed + ERRRPM.
  • Compared against EngineRpm_HB.

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x0C (+96 RPM).
  • Tuner Usage: Works automatically with whatever target idle speed is configured in AISPN.
