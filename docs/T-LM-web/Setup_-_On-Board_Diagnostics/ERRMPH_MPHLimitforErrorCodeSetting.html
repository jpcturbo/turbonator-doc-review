1. Overview & Purpose

ERRMPH (MPHLimitforErrorCodeSetting) defines the minimum vehicle cruising speed (stock calibration = 18 MPH / 0x12) required to evaluate dynamic vehicle sensor diagnostics.

For example, to test whether the vehicle speed sensor (Distance Sensor / VSS) is functional, the ECU verifies whether the vehicle is operating at cruising RPM and load. If the vehicle is driven under cruising conditions and the distance sensor reports 0 MPH, the ECU flags Fault Code 15 ('No vehicle speed sensor signal detected'). ERRMPH ensures this test is only evaluated once road speed has safely exceeded 18 MPH.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside subroutine VerifyOperationOfO2SensorAnd at line 1038.
  • Compares scaled VehicleSpeed_HB against ERRMPH.
  • Enables dynamic sensor monitors when VehicleSpeed >= ERRMPH.

3. Tuner's Guide & Real-World Calibration

  • Code 15 Diagnostics: If a digital dash conversion or broken speedometer cable causes Code 15, the code is only logged after exceeding 18 MPH.
