1. Overview & Purpose

AMBLOW (BattTempLowWhenHot) establishes the lower electrical threshold (stock calibration = 0x02 / ~0.04V) for the ambient battery temperature thermistor located beneath the battery tray.

Lead-acid batteries require higher charging voltage in freezing weather (up to 14.8V) and lower charging voltage in hot summer weather (13.5V) to prevent boiling off electrolyte. The ECU reads the battery temperature sensor to adjust its internal field current pulsewidth. If the sensor wire shorts to ground (< AMBLOW), the ECU stores Fault Code 43 and locks alternator field control to a fixed nominal charging voltage.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside subroutine DetermineBattTemp at line 1046 and DetermineTargetBatteryVoltage_MM at line 1302.
  • Compares AmbientAirTempVolts against AMBLOW.
  • If AmbientAirTempVolts <= AMBLOW (bls LC94E), flags fault and bypasses temperature-compensated charging.

3. Tuner's Guide & Real-World Calibration

  • Battery Relocation to Trunk: When relocating the battery to the trunk in performance builds, the under-hood sensor is often disconnected or damaged, triggering Code 43. Tuners can install a 10k-ohm resistor across the harness pins to simulate 70°F or disable the fault in ERMSK3.
