1. Overview & Purpose

ACCTIM (AcDelayFromStartRunTransfer) enforces a brief delay (stock calibration = 4 ticks / ~0.4 sec) following engine startup before the ECU allows the A/C compressor clutch to engage.

When an engine starts with the dashboard A/C switch already ON, engaging the compressor clutch while the starter motor is disengaging and oil pressure is building would impose harsh mechanical shock on the starter drive and stall the engine. ACCTIM holds off A/C clutch activation until the engine has cleanly transitioned into run mode.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside ControlAirConditioning_MM at line 1766 and CalculateTargetIdleSpeedAndAisPosition_MM at line 5048.
  • Compares KeyOnOrEngineRunningTime against ACCTIM.
  • If RunningTime < ACCTIM (bcs LCDEE), A/C clutch is locked out.

3. Tuner's Guide & Real-World Calibration

  • Starter Protection: Retain stock setting. Gives the engine time to establish stable combustion before absorbing compressor load.
