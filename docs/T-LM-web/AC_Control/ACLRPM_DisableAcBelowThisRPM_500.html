1. Overview & Purpose

ACLRPM (DisableAcBelowThisRPM_500) provides an emergency anti-stall cutout for the air conditioning compressor clutch (calibrated around 500 RPM / 0xA2).

If engine RPM collapses due to sudden brake lockup, clutch drag, or low idle instability, dragging a mechanical A/C compressor will instantly kill the engine. When engine speed drops below TargetIdleSpeed * (ACLRPM / 256), the ECU immediately de-energizes the A/C clutch relay, dumping compressor drag so the engine can catch and revive.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside subroutine ControlAirConditioning_MM at line 1757.
  • Multiplied against TargetIdleSpeed_HB using 16-bit math (mul16bit).
  • If EngineRpm_HB < CalculatedCutout, A/C clutch is disengaged.

3. Tuner's Guide & Real-World Calibration

  • Anti-Stall Protection: Prevents stalling when coming to a panic stop with the A/C on.
  • Big Camshaft Lope: If an aftermarket camshaft causes idle RPM to lope deeply, ensuring ACLRPM is set around 500 RPM keeps the compressor from short-cycling during idle loping.
