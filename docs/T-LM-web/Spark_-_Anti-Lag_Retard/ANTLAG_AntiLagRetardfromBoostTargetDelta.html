1. Overview & Purpose

ANTLAG_AntiLagRetardfromBoostTargetDelta is the lookup table for the Turbonator Launch Control / Anti-Lag Boost Building System.

When a turbocharged car is staged on the starting line against a two-step launch rev limiter (or at initial wide-open throttle launch), the turbocharger normally struggles to spool because the engine is not under sufficient physical rolling load. Turbonator's Anti-Lag routine solves this by heavily retarding ignition timing when there is a large deficit between actual manifold boost and the target boost goal (\DeltaMAP = BoostTarget - MapValue).

Retarding the spark causes the air/fuel charge to finish combustion inside the exhaust manifold and turbine housing rather than inside the cylinder. This massive expansion of hot exhaust gas violently spools the turbocharger turbine, allowing the vehicle to build 5 to 15+ psi of boost while stationary on the starting line.

2. Operating Conditions (When Does This Take Effect?)

ANTLAG is evaluated on every main loop pass if enabled: 1. Option Bit Enabled: The cfg_AntiLag option bit in CONFIG_ConfigurationFlags must be set (1). 2. Launch Limiter or WOT Active: - Either the 2-step staging limiter is active (BitFlags_7f bit 5 = 1), OR - The engine is at Wide-Open Throttle (BitFlags_81 bit 0 = 1). 3. Boost Deficit Present: Actual boost is below target boost (BoostTarget > MapValue). Once actual boost reaches target boost, anti-lag retard drops automatically to zero.

3. Tuner's Guide & Real-World Calibration

The value looked up from ANTLAG is divided by 8 and subtracted directly from WOTMAP at line 6593 of CalculateSparkAdvance_MM:

WOT Timing = WOTMAP(MAP) - AntiLagRetard

  • Increasing Table Values (More Retard):
  • Effect on Total Timing: Pulls more timing (up to 16° retard) when boost is below target.
  • Real-World Driving Feel: Dramatically accelerates turbocharger spool on the starting line, building boost faster and louder with aggressive exhaust popping.
  • Cautions: Extreme exhaust gas temperatures (EGTs) are generated! Extended anti-lag operation (more than 3–5 seconds on the launch limiter) can overheat exhaust valves, crack turbocharger turbine housings, and damage catalytic converters.
  • Decreasing Table Values (Less Retard):
  • Effect on Total Timing: Pulls less timing during boost spool-up.
  • Real-World Driving Feel: Gentler on exhaust components, but builds starting-line boost more slowly.
  • Zeroing Out:
  • Setting all Y-axis values to 0x00 completely disables anti-lag timing retard while preserving normal two-step rev limiting.
