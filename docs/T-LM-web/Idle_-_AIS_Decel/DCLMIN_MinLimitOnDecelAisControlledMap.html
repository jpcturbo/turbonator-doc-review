1. Overview & Purpose

DCLMIN (MinLimitOnDecelAisControlledMap) provides a hard minimum lower clamp for the calculated deceleration target MAP floor.

During trailing-throttle overrun at high engine speeds, the calculated target MAP floor might theoretically calculate to an unrealistically low value. If this value were subtracted directly from live manifold pressure, it could produce an unintended negative delta. DCLMIN clamps the target MAP floor so that it can never fall below this absolute lower bound (stock calibration = 0x14 / ~15 kPa / ~25.5 inHg vacuum), guaranteeing consistent and bounded inputs to the DAISOP anti-stall table.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside CalculateAisPosition_MM at line 3660-3662.
  • Compares intermediate target MAP floor in Register A against DCLMIN.
  • If Register A is less than DCLMIN, it is overwritten with DCLMIN: ldaa DCLMIN_MinLimitOnDecelAisControlledMap.

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x14 (~15 kPa).
  • Extreme High-Vacuum Engines: Highly efficient tight-tolerance race engines with high static compression can pull massive vacuum on decel. Raising DCLMIN slightly (e.g. to 0x1C = ~21 kPa) provides an earlier air cushion on trailing throttle to catch aggressive decel drops.
