1. Overview & Purpose

DCLRF2 (TimeBetweenAisPulsesForDecelAis2) establishes the settling time interval between successive stepper motor corrections while operating in closed-loop idle speed control.

Once the ECU enters closed-loop idle feedback, it evaluates whether actual engine RPM matches target idle speed. If an error exists, the ECU commands forward (FWDAIS) or reverse (REVAIS) steps. However, engine speed takes several engine revolutions to respond to a change in bypass air mass. DCLRF2 ensures that Timer_AisChanges must exceed this threshold (stock calibration = 63 ticks / ~0.7 seconds) before another step pulse can be issued, preventing severe closed-loop hunting, surging, or overshoot.

2. Operating Conditions (When Does This Take Effect?)

  • Compares Timer_AisChanges against DCLRF2.
  • If Timer_AisChanges <= DCLRF2 (bcc LE5A7), closed-loop step corrections are bypassed for that loop cycle.

3. Tuner's Guide & Real-World Calibration

  • Idle Hunting / Cyclic Surging: If the engine surges up and down rhythmically at idle (750 RPM -> 1,100 RPM -> 750 RPM every 1-2 seconds), the idle control loop is reacting too fast. Increasing DCLRF2 dampens the closed-loop response.
  • Sluggish Idle Catching: If the idle takes too long to respond to electrical loads (headlights, blower motor), slightly reducing DCLRF2 (e.g. to 0x28 / ~0.45 sec) makes closed-loop idle recovery more agile.
