1. Overview & Purpose

DATHT2 (EngineTempToStartCalibratingDacal2) establishes the temperature threshold for the secondary decel control branch in CalculateAisPosition_MM.

If engine coolant temperature is below DATHT2, the ECU bypasses the secondary RPM gate (DDRPM2) and branches directly into the decel pulse timer check (LDA87), ensuring that colder engines receive full deceleration bypass air regardless of engine RPM overspeed margins.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated in CalculateAisPosition_MM at line 3647.
  • Compares CoolantTemp against DATHT2.
  • If CoolantTemp < DATHT2, branches directly to LDA87.

3. Tuner's Guide & Real-World Calibration

  • Low-Temp Thermostats: If running a 160°F or 180°F thermostat, match DATHT2 to DATHOT (e.g. set to 0xB5 for 180°F thermostats) so the thermal branches switch synchronously.
