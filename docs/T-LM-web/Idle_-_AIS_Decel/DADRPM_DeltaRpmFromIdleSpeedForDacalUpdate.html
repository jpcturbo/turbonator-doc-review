1. Overview & Purpose

DADRPM (DeltaRpmFromIdleSpeedForDacalUpdate) establishes the maximum allowable RPM error window for DACAL adaptive trim learning.

To guarantee that DACAL learns true mechanical airflow and not transient disturbances (such as a driver resting a foot on the pedal, power steering twitches, or electrical fan cycling), the ECU computes the absolute error between target idle speed and actual engine speed: |TargetIdleSpeed - EngineRpm|. DACAL learning is only permitted if this error is strictly less than or equal to DADRPM. In stock calibrations, DADRPM is set to 0x02 (2 × 32 = ± 64 RPM), ensuring learning occurs only under rock-solid, stable idle conditions.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated in CalculateAisPosition_MM at line 3608.
  • Calculates absolute difference between TargetIdleSpeed_HB and EngineRpm_HB.
  • If error is higher than DADRPM (bhi LDA48), DACAL timer updates are bypassed.

3. Tuner's Guide & Real-World Calibration

  • Lumpy Aftermarket Camshafts: Aggressive performance camshafts have natural cyclic idle speed variation (cam lope) that easily swings ±100 RPM or more. With a stock DADRPM of 64 RPM, the ECU will almost never allow DACAL to update because the idle RPM fluctuates outside the narrow window.
  • Tuning for Big Cams: Increase DADRPM to 0x04 (±128 RPM) or 0x05 (±160 RPM) on engines with performance camshafts to allow the adaptive decel system to successfully calibrate at idle.
