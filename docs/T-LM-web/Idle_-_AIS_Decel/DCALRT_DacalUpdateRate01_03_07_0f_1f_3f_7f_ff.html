1. Overview & Purpose

DCALRT (DacalUpdateRate01_03_07_0f_1f_3f_7f_ff) is a timing filter bitmask applied against Counter_MainLoop1 that controls how frequently the DACAL adaptive countdown timer can increment or decrement.

Adaptive airflow learning must be gradual. If adaptive decel memory adapted instantly to every minor manifold pressure fluctuation, the idle system would constantly oscillate and chase transient perturbations. By testing the main loop counter against DCALRT, the ECU enforces an integration time-constant on DACAL updates, ensuring smooth long-term baseline learning.

3. Tuner's Guide & Real-World Calibration

  • Valid Bitmask Patterns: Permissible values correspond to power-of-two bit patterns (0x01, 0x03, 0x07, 0x0F, 0x1F, 0x3F, 0x7E, 0x7F, 0xFF).
  • Faster Learning: Decreasing bitmask density causes the adaptive decel timer to adapt more rapidly to mechanical throttle stop changes.
  • Stability: Stock setting 0x7E provides excellent long-term stability and resistance to false learning.
