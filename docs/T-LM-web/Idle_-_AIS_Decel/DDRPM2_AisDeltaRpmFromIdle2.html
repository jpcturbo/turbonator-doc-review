1. Overview & Purpose

DDRPM2 (AisDeltaRpmFromIdle2) defines an RPM error threshold evaluated during the secondary deceleration control phase inside CalculateAisPosition_MM.

When the vehicle is decelerating with the throttle closed, the ECU monitors the difference between actual engine speed and target idle speed (EngineRpm_HB - TargetIdleSpeed_HB). DDRPM2 acts as a gatekeeper: if the engine speed is dropping and approaches target idle within DDRPM2, the routine exits decel control early, handing authority back to closed-loop idle speed control.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated in CalculateAisPosition_MM at line 3652.
  • Compares (EngineRpm_HB - TargetIdleSpeed_HB) against DDRPM2.
  • In stock cal, set to 0x00 (meaning decel mode persists until engine speed touches target idle).

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x00.
  • Tuner Recommendations: Leave at 0x00 unless customizing custom decel handover behavior. Setting higher forces an earlier handoff from decel dashpot mode into closed-loop idle regulation.
