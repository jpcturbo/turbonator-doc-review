1. Overview & Purpose

BARTIM (BaroReadMinTimeBetweenReadings179sec) defines the mandatory minimum time interval (stock calibration = 64 ticks / ~179 seconds / approx 3 minutes) between successive barometric pressure sampling events while driving.

Atmospheric barometric pressure changes very gradually as a vehicle ascends or descends mountain terrain (typically a few millibars per minute). Cycling the baro solenoid too frequently would subject the solenoid valve to unnecessary mechanical wear and introduce needless MAP sensor signal interruptions. BARTIM ensures the ECU updates ambient barometric reference at a sensible, metered 3-minute interval.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside HandleBaroReadRequirement_MM at line 1713.
  • Compares Counter_BaroReadTime against BARTIM.
  • If counter is less than BARTIM (bcs LCDAE), in-flight baro reading is inhibited.

3. Tuner's Guide & Real-World Calibration

  • Mountain Pass Racing: On hill-climb race courses with rapid elevation changes (such as Pikes Peak), reducing BARTIM to 0x15 (~60 seconds) allows the ECU to track rapid altitude changes and altitude fuel trim compensation more aggressively.
  • Street Driving: Stock 3-minute interval is ideal for component longevity.
