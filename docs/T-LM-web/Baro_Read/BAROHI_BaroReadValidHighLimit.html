1. Overview & Purpose

BAROHI (BaroReadValidHighLimit) establishes the upper physical and electrical sanity boundary for atmospheric barometric pressure.

Under real-world meteorological conditions on Earth, ambient sea-level barometric pressure rarely exceeds 30.5 - 31.0 inHg (even inside high-pressure cold Arctic air masses). If the MAP sensor returns an ADC reading exceeding BAROHI (stock calibration = 0x85 / ~31.2 inHg), the ECU recognizes that the sensor signal line is shorted to 5V reference, electrically biased, or defective. The out-of-bounds reading is rejected and overwritten with BARDFT_BaroReadDefaultValue (standard sea level), preventing corrupted fuel calculations.

3. Tuner's Guide & Real-World Calibration

  • 3-Bar MAP Sensor Upgrades: When converting from a factory 2-Bar MAP sensor to a 3-Bar sensor, the sensor transfer slope changes dramatically. If using custom scaling, BAROHI must be adjusted to match the new 3-Bar voltage transfer curve, otherwise valid ambient air pressures will exceed BAROHI and force the ECU permanently into default baro limp mode (BARDFT). In Turbonator codebases, 3-bar scaling tables (MAPMULT / MAPADD) manage this conversion.
