1. Overview & Purpose

BRDLAY (BaroReadDelayAfterThrottleClosed2sec) establishes the settling time delay (stock calibration = 45 ticks / ~2.0 seconds) that the engine must remain in a stable, closed-throttle state within the valid RPM window before the baro read solenoid is energized.

If the driver is rapidly pumping the throttle pedal or shifting gears, manifold pressure is undergoing turbulent transient swings. Venting the MAP sensor during rapid pedal movements would introduce severe signal noise. BRDLAY ensures the vehicle is in a steady, settled state before initiating a baro sample.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside HandleBaroReadRequirement_MM at line 1710.
  • Increments BaroReadTimeEngineWithinReadRange.
  • If counter is less than BRDLAY (bcs LCDAE), the baro update cycle is delayed.

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x2D (~2.0 seconds).
  • Transient Resistance: Increasing BRDLAY makes the system more conservative, requiring longer settled periods before taking a reading. Setting too low can cause baro readings to be triggered during erratic pedal movement.
