1. Overview & Purpose

BRPMH (BaroReadHighRPM66502) defines the absolute maximum engine speed (stock calibration = 6,650 RPM / 0x3E80) beyond which the ECU will never attempt an in-flight barometric pressure read.

At high engine speeds (approaching redline), cylinder intake events occur at frequencies exceeding 200 pulses per second. Venting the MAP sensor to atmospheric pressure at 6,000+ RPM would deprive the fuel calculation routine of actual manifold boost data during a maximum-power condition, risking catastrophic lean detonation. BRPMH acts as a fail-safe ceiling to lock out the baro read solenoid during high-RPM operation.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside HandleBaroReadRequirement_MM at line 1702.
  • Compares EngineRpm_HB against BRPMH.
  • If EngineRpm > BRPMH (bhi LCDAE), the baro reading cycle is bypassed.

3. Tuner's Guide & Real-World Calibration

  • High-Revving Engines: If an engine is built to rev to 7,500 - 8,000 RPM, keep BRPMH well below the maximum redline (stock 6,650 RPM is ideal) to guarantee baro updates never occur under high-stress operating conditions.
