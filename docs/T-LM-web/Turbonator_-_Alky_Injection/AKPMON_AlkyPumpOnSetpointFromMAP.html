1. Overview & Purpose

AKPMON (AlkyPumpOnSetpointFromMAP) establishes the manifold absolute pressure (MAP) turn-on threshold for the Turbonator water/methanol (alky) injection delivery pump.

Turbonator firmware includes native logic to repurpose unused ECU output drivers (such as the purge or EGR solenoid drivers) to control an external progressive water/methanol pump relay. AKPMON defines the boost pressure where the ECU energizes the pump relay to prime and pressurize the injection lines before injector solenoids open.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside AlkyPump_Control_MM at line 7388.
  • Active when cfg_AlkyInj bit is set in configuration flags and cfg_ShiftLight is clear.
  • Stock calibration is 0xFF (feature disabled).
  • When MapValue >= AKPMON, pump relay driver is commanded ON.

3. Tuner's Guide & Real-World Calibration

  • Enabling Alky Injection: Set cfg_AlkyInj in configuration flags. Calibrate AKPMON to roughly 3-5 psi of boost (approx 0x90 on a 2-bar or 3-bar MAP sensor).
  • Early Priming: Priming the high-pressure pump 2-3 psi before opening the injection nozzle solenoids (AKI1ON) prevents spray pressure lag and uneven atomization.
