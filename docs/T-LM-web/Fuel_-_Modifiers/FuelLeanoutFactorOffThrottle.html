1. Overview & Purpose

Despite its historical disassembly label containing the word "Leanout", FuelLeanoutFactorOffThrottle actually functions as a signed RPM-dependent fuel pulse width modifier curve applied during closed-throttle (off-throttle) conditions.

In the Chrysler Logic Module firmware, this table acts as a signed two's complement table: * Return values with the high bit clear (0x00 to 0x7F, 0 to +127 decimal) represent positive numbers that are scaled and added to the running base pulse width variable Temp0. * Return values with the high bit set (0x80 to 0xFF, -128 to -1 in two's complement) represent negative numbers that are sign-extended and, when added to Temp0, effectively subtract from the fuel pulse width.

In the factory calibration: 1. Low RPM Coast / Decel near Idle (Point 1, ~896 RPM): The table value is 0xFA (-6 in two's complement). This negative value subtracts fuel from Temp0 to prevent over-fueling and plug fouling as the engine drops down to idle. 2. Mid-to-High RPM Closed Throttle Deceleration (Points 2–4, 1440 to 2240+ RPM): The values transition to positive (0x0A = +10, 0x20 = +32, 0x22 = +34), adding fuel back to maintain combustion stability and catalytic converter thermal management during decel coast-down.

3. Tuner's Guide & Real-World Calibration

Because this table operates in signed two's complement math, tuners must understand the binary representation:

Hex Value Signed Decimal Arithmetic Effect on Fuel Delivery
0x00 0 Neutral (0 fuel added or subtracted)
0x01 – 0x7F +1 to +127 Adds fuel (increases pulse width by Value * 8 counts)
0x80 – 0xFF -128 to -1 Subtracts fuel (reduces pulse width by abs(Value - 256) * 8 counts)

Practical Tuning Tips:

  • Exhaust Pops / Overrun Burble:
  • To create an aggressive overrun "burble / crackle / pop" on throttle lift, change the higher RPM decel points (1500–3000 RPM) from positive values to slightly negative values (e.g., 0xFC = -4 or 0xF8 = -8) to lean the mixture into the misfire/afterfire window.
  • Alternatively, adding slightly more positive fuel on decel combined with ignition timing retard will dump unburned fuel into the turbine housing for aggressive antilag-style pops.
  • Decel Stumble / Stall Prevention:
  • If the engine dips and stumbles when popping the clutch or lifting off the throttle into neutral, check Point 1 (0x1C = 896 RPM). The factory negative value 0xFA (-6) pulls fuel; if large injectors are installed, leaving this too rich or too lean can cause an idle dip. Setting it closer to 0x00 or a small positive value can stabilize off-throttle idle catch.

Detailed Assembly Step Analysis:

  1. Lookup Output in Register B: Subroutine Lookup4ByteTable returns the interpolated Y-axis value in accumulator B.
  2. Two's Complement Sign Extension: - clra initializes A = 0x00. - tstb inspects bit 7 of B. - If bit 7 is 0 (0x00–0x7F), bpl LDB44 branches over deca. The 16-bit pair D (A:B) becomes 0x00:B (positive 16-bit integer). - If bit 7 is 1 (0x80–0xFF), deca decrements A from 0x00 to 0xFF. The 16-bit pair D (A:B) becomes 0xFF:B, which is the exact mathematical two's complement sign-extension into a negative 16-bit integer (Value - 256).
  3. Scaling Factor (asld x 3): - The signed 16-bit value in D is shifted left 3 times, multiplying the signed value by 8 (2^3 = 8).
  4. Application to Temp0 (addd Temp0): - If B was positive (0x0A = +10), D = +10 × 8 = +80. Adding $+80$ increases Temp0. - If B was negative (0xFA = -6), D = -6 × 8 = -48 (0xFFD0). Adding 0xFFD0 to Temp0 is mathematically equivalent to subtracting 48 counts from Temp0.
  5. Storage in LeanoutFactor_HB: - The result is saved to LeanoutFactor_HB, which is subsequently added into the final fuel pulse width calculation in CalculateFuelPW_MM (line 4334).
