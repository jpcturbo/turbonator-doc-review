1. Overview & Purpose

FuelLeanoutFactorOnThrottle defines an RPM-dependent signed fuel pulse width modifier curve active during open-throttle (on-throttle) driving.

Like its closed-throttle counterpart (FuelLeanoutFactorOffThrottle), this table is processed in firmware as a signed two's complement table: * Values below 0x80 (0x00–0x7F) act as positive modifiers, scaling and adding fuel to the base pulse width variable Temp0. * Values with the high bit set (0x80–0xFF) act as negative modifiers, sign-extending and subtracting fuel from Temp0.

In stock turbocharged calibrations (such as T_LM_22_MTX_A171_Stock), this curve is factory-set to a flat single point of (0xFF, 0x00). Because the factory return value is 0x00, it adds exactly 0 counts across all engine RPM when driving on-throttle.

3. Tuner's Guide & Real-World Calibration

Because the table is processed as signed two's complement math:

Hex Value Signed Decimal Arithmetic Effect on Fuel Delivery
0x00 0 Neutral (0 fuel added or subtracted — Factory Stock Setting)
0x01 – 0x7F +1 to +127 Adds fuel (increases pulse width by Value * 8 counts)
0x80 – 0xFF -128 to -1 Subtracts fuel (reduces pulse width by abs(Value - 256) * 8 counts)

Practical Tuning Tips:

  • Turbocharged Engines (Leave at Stock Zero): In turbocharged applications, it is strongly recommended to leave this table flat zero (0x00). Subtracting fuel while under load on-throttle invites lean detonation, while adding fuel should primarily be tuned through volumetric efficiency curves (MAPTBL), warm part-throttle curves (WARMPT), or full-throttle curves (WARMFT).
  • High-Speed Cruising Leanout (N/A Tuning): In naturally aspirated or high-mileage economy tuning, entering a small negative value (such as 0xFE = -2 or 0xFD = -3, subtracting 16–24 counts of pulse width) at highway cruising RPM (2,000–2,800 RPM) can produce a modest lean-burn fuel economy gain when cruising at light throttle.
