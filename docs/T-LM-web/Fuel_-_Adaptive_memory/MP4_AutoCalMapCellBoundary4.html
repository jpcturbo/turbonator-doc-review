1. Overview & Purpose

MP4_AutoCalMapCellBoundary4 defines the fourth manifold pressure load boundary, separating Adaptive Fuel Memory Cells 6/7 from Cells 8/9.

This transition point marks moderate acceleration and moderate hill-climbing under engine vacuum (approx. 7 inHg vacuum).

2. Operating Conditions (When Does This Take Effect?)

  • Cell Assignment:
  • If MP3 < MapValue <= MP4: Selects Cell 6 (low RPM) or Cell 7 (high RPM).
  • If MapValue > MP4: Moves toward heavy part-throttle cells (8/9 and 10/11).

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x61 (≈ 7.2 inHg vacuum).
  • Engine Dynamics: Cells 6 and 7 handle hill climbing and moderate vehicle acceleration prior to approaching atmospheric pressure.

4. Technical / Assembly Mechanics (Reference)

Element 3 in the MAP boundary array traversed in AdaptiveMemory_DetermineWhichCellApplies_MM.

5. Calibration Notes & System Dependencies

  • Must remain strictly lower than MP5 (0x78).
