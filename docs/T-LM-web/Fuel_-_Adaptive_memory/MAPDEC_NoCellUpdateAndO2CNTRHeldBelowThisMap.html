1. Overview & Purpose

MAPDEC_NoCellUpdateAndO2CNTRHeldBelowThisMap is the master manifold pressure boundary above which the closed-loop O2 controller is forced open-loop and adaptive memory updates are frozen.

This calibration constant serves as the definitive WOT / Boost Open-Loop switch. Even if coolant temperature, delay timers, and TPS thresholds are fully satisfied for closed-loop operation, if manifold pressure rises to or above MAPDEC, the ECU immediately freezes the closed-loop feedback loop and commands open-loop power enrichment.

2. Operating Conditions (When Does This Take Effect?)

  • The First Gate of O2 Processing:
  • Line 3080 in T-LMv13.asm is the very first check executed when entering HandleO2Processing_MM:
  • If MapValue >= MAPDEC: The routine immediately branches to LD6F2, clearing ramp counters and locking the ECU into open-loop mode!

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0xAA (170 counts ≈ 19.6 psia ≈ 4.9 psig boost).
  • Disabling Closed-Loop Control Entirely:
  • Master Open-Loop Trick: Setting MAPDEC = 0x00 (or 0x01) causes MapValue >= MAPDEC to evaluate TRUE 100% of the time, permanently disabling closed-loop feedback and adaptive memory updates under all driving conditions.
  • Extremely popular among tuners running aggressive cam setups, drag-race cars, or pure wideband open-loop tuning.
  • Lowering MAPDEC (e.g., to atmospheric / 0x8A):
  • Ensures the engine drops cleanly into open loop the moment boost begins, preventing any closed-loop feedback delay when rolling into boost.
