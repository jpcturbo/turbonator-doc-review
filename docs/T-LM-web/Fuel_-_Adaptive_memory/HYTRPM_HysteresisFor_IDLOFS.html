1. Overview & Purpose

HYTRPM_HysteresisFor_IDLOFS establishes the engine speed hysteresis band for entry and exit from the Closed-Throttle Idle Adaptive Cell (Cell 12).

Working in concert with IDLOFS, HYTRPM ensures that minor idle speed flares (such as when the radiator cooling fan turns on or the A/C compressor cycles) do not cause erratic toggling between idle adaptive memory and part-throttle cruise cells.

2. Operating Conditions (When Does This Take Effect?)

  • Base Idle Threshold: Added unconditionally to TargetIdleSpeed_HB whenever testing closed-throttle status in AdaptiveMemory_DetermineWhichCellApplies_MM.
  • Factory band: 2 × 32 = 64 RPM.

3. Tuner's Guide & Real-World Calibration

  • Stock Setting: 0x02 (64 RPM).
  • Tuning Recommendation: Leave at stock unless an aggressive camshaft creates large idle RPM fluctuations, in which case increasing HYTRPM to 0x03 or 0x04 stabilizes closed-loop idle adaptation.
