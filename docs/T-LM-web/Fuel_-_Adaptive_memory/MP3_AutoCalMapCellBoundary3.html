1. Overview & Purpose

MP3_AutoCalMapCellBoundary3 defines the third manifold pressure load boundary, separating Adaptive Fuel Memory Cells 4/5 from Cells 6/7.

This boundary corresponds to standard highway cruising loads (approx. 12 inHg vacuum), separating level-grade highway driving from slight incline or mild passing loads.

2. Operating Conditions (When Does This Take Effect?)

  • Cell Assignment:
  • If MP2 < MapValue <= MP3: Selects Cell 4 (< R1) or Cell 5 (> R1).
  • Above MP3, the pointer advances to Cells 6/7.

3. Tuner's Guide & Real-World Calibration

  • Stock Setting: 0x4B (≈ 12.4 inHg vacuum).
  • Real-World Impact: Cells 4 and 5 accumulate the vast majority of interstate highway cruising miles. Long-term fuel trims stored in these cells have the biggest impact on highway fuel economy.

4. Technical / Assembly Mechanics (Reference)

Parsed in AdaptiveMemory_DetermineWhichCellApplies_MM as element 2 of the 5-boundary array.

5. Calibration Notes & System Dependencies

  • Ensure adequate separation between MP2 and MP3 (stock difference is 20 ADC counts ≈ 2.3 psi) to allow stable learning.
