1. Overview & Purpose

R1_RPMCellBoundaryInRPMover32 is the engine speed boundary that bifurcates each of the 6 MAP load regions into a Low-RPM Cell (even numbers: 0, 2, 4, 6, 8, 10) and a High-RPM Cell (odd numbers: 1, 3, 5, 7, 9, 11).

Engines experience significantly different volumetric efficiencies and exhaust scavenging dynamics at low RPM (near idle / off-idle lugging) compared to higher cruising RPMs. R1 provides the RPM split that allows the adaptive fuel trim system to learn separate fuel corrections for low-RPM lugging vs. mid/high-RPM cruising.

2. Operating Conditions (When Does This Take Effect?)

  • Cell Selection (Part Throttle):
  • Once the MAP load zone (0, 2, 4, 6, 8, 10) has been established by MP1â€“MP5:
  • Current engine speed high-byte (EngineRpm_HB) is compared against R1.
  • If EngineRpm <= R1: The cell pointer remains at the base even cell index (Low RPM).
  • If EngineRpm > R1: The cell pointer is incremented by 1 to select the odd cell index (High RPM).
  • Hysteresis: Protected by DLTRPM.

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x1D (29 × 32 = 928 RPM).
  • Raising R1 (e.g., to 0x32 / 1600 RPM):
  • Real-World Impact: In stock form, R1 is set very low (928 RPM), meaning that almost all driving above 1000 RPM falls into the High-RPM cells (odd cells), while the even cells only capture off-idle crawl.
  • Raising R1 to 1500â€“1800 RPM divides low-speed city driving (under 1800 RPM) cleanly from highway cruising (above 1800 RPM), allowing much better adaptive fuel resolution.
