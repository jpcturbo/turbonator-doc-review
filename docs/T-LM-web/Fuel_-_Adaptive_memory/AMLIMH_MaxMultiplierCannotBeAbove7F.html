1. Overview & Purpose

AMLIMH_MaxMultiplierCannotBeAbove7F establishes the maximum positive (enrichment) authority limit permitted for any adaptive fuel memory cell.

To prevent runaway enrichment from an undetected vacuum leak or mechanical failure, the ECU caps the maximum correction any adaptive fuel cell can store. AMLIMH forms this positive clamp ceiling across all 13 adaptive memory cells.

2. Operating Conditions (When Does This Take Effect?)

  • Cell Value Clamping:
  • When updating an adaptive cell in AdaptiveMemory_UpdateCellIfRequired:
  • If adding CELCHG causes the cell value to exceed AMLIMH, the cell is clamped to AMLIMH.

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x7F (+127 decimal).

Max Multiplier = 1.0 + (AMLIMH / 512) = 1.0 + (127 / 512) ≈ 1.248\ (+24.8%)

  • Tuning Guidance: 0x7F is the maximum allowable positive number in an 8-bit signed two's complement integer. Never increase above 0x7F, as doing so will roll the value over into a negative number and trigger extreme lean-out!
