1. Overview & Purpose

MP5_AutoCalMapCellBoundary5 defines the fifth and highest manifold pressure load boundary, separating Adaptive Fuel Memory Cells 8/9 from Cells 10/11.

Located immediately below atmospheric pressure (approx. 1.8 inHg vacuum), MP5 separates moderate-to-heavy vacuum cruise from near-zero vacuum / zero-boost threshold driving.

2. Operating Conditions (When Does This Take Effect?)

  • Cell Assignment:
  • If MP4 < MapValue <= MP5: Selects Cell 8 (< R1) or Cell 9 (> R1).
  • If MapValue > MP5: Selects Cell 10 (< R1) or Cell 11 (> R1).
  • Load is capped from above by MAPLIM (0x8A ≈ 14.7 psia), above which all adaptive learning ceases.

3. Tuner's Guide & Real-World Calibration

  • Stock Setting: 0x78 (≈ -0.9 psig).
  • Near-Atmospheric Learning: Cells 10 and 11 represent the highest load cells where the ECU is permitted to adapt fuel trims. Once manifold pressure crosses into boost (> MAPLIM), closed loop and adaptive memory freeze, locking fuel delivery to open-loop base tables.

4. Technical / Assembly Mechanics (Reference)

Final element of the 5-point boundary array checked in AdaptiveMemory_DetermineWhichCellApplies_MM.

5. Calibration Notes & System Dependencies

  • Setting MP5 above atmospheric pressure (e.g. into boost) is forbidden, as closed-loop stoich feedback must never attempt to lean out boosted combustion.
