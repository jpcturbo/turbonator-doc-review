1. Overview & Purpose

AMLIML_MinMultiplierCannotBeBelow80 establishes the maximum negative (enleanment) authority limit permitted for any adaptive fuel memory cell.

This calibration constant prevents the adaptive system from pulling out dangerous amounts of fuel if an exhaust leak or failing sensor tricks the ECU into thinking the mixture is excessively rich. AMLIML represents the floor below which adaptive fuel cells cannot subtract fuel.

2. Operating Conditions (When Does This Take Effect?)

  • Cell Clamping:
  • When subtracting fuel in AdaptiveMemory_UpdateCellIfRequired:
  • If the cell calculation drops below AMLIML, the cell is hard-clamped to AMLIML.

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0xB3 (-77 signed counts).

Min Multiplier = 1.0 - (77 / 512) ≈ 0.850\ (-15.0%)

  • Asymmetric Safety: Consistent with short-term trims (O2LIML), adaptive memory allows +24.8% rich authority, but limits lean authority to -15.0% to safeguard against engine damage.
