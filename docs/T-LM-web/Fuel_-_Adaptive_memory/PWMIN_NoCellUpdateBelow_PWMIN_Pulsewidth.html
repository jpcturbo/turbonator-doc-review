1. Overview & Purpose

PWMIN_NoCellUpdateBelow_PWMIN_Pulsewidth establishes the minimum injector pulse width threshold below which adaptive memory cell updates are prohibited.

Fuel injectors exhibit severe non-linear flow characteristics at very short pulse widths (due to opening/closing dead times and mechanical ball/pintle inertia). Adapting fuel trims during near-zero pulse widths (such as during decel fuel cut or deep manifold vacuum) leads to corrupted fuel trims. PWMIN blocks adaptive learning unless total injector opening time is sufficiently long to guarantee linear injector delivery.

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x04B0 (4.80 ms).
  • Crucial Scaling for Larger Injectors:
  • When installing larger fuel injectors (+20%, +40%, +52 lb/hr), normal cruise pulse widths drop substantially (often into the 2.0 ms - 3.5 ms range)!
  • Critical Bug Warning: If PWMIN is left at the stock 4.8 ms setting with large injectors, normal cruise pulse width will never exceed 4.8 ms, completely disabling adaptive memory learning forever!
  • Tuning Recommendation: Scale PWMIN down proportionately with injector size (e.g. 2.4 ms â€“ 3.0 ms for +40% injectors).
