1. Overview & Purpose

IDLOFS_DeltaForIdleRPMForClosedThrottleCell specifies an upper RPM offset window above target idle speed within which the ECU is permitted to select and update the dedicated Closed-Throttle Idle Adaptive Cell (Cell 12 / AutoCalCell12idle).

When the throttle is closed, the engine should only adapt its idle fuel cell if it is actually operating at or near normal idle speed. If the car is coasting in gear with the throttle closed at 2500 RPM (engine braking), adapting the idle cell would severely corrupt idle fueling. IDLOFS (along with HYTRPM) enforces the maximum allowable RPM ceiling above target idle speed for Cell 12 qualification.

2. Operating Conditions (When Does This Take Effect?)

  • Idle Cell Qualification:
  • Throttle is fully closed (BitFlags_81 bit 7 = 0).
  • Compares current RPM against:

Idle Threshold = TargetIdleSpeed + HYTRPM + IDLOFS

  • If EngineRpm <= Idle Threshold: Pointer is set to Cell 0x0C (Cell 12 / Idle).
  • If EngineRpm > Idle Threshold (e.g. decel coasting in gear): Bypasses Cell 12 and branches to part-throttle grid selection.

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x01 (32 RPM above target idle).
  • Target Idle Relationship: Target idle speed is dynamically set by the AIS idle speed curve (e.g. 850 RPM).

Max RPM for Cell 12 ≈ 850 + (2 × 32) + (1 × 32) = 850 + 96 = 946 RPM

  • Tuning Guidance: If your modified engine has a lumpy idle with a high-lift camshaft, widening IDLOFS to 0x03 or 0x04 (96â€“128 RPM) prevents the idle cell from constantly dropping out during minor RPM hunting.
