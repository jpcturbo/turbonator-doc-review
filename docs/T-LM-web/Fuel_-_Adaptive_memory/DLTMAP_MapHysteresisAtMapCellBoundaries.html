1. Overview & Purpose

DLTMAP_MapHysteresisAtMapCellBoundaries provides manifold pressure hysteresis when transitioning between adjacent adaptive fuel memory cells.

Without hysteresis, driving at a steady load that hovers precisely on a cell boundary (e.g., exactly at MP2) would cause the cell pointer to oscillate rapidly back and forth between cells on every single engine revolution, resetting cell timers and preventing either cell from ever accumulating enough steady-state time to update. DLTMAP adds a deadband offset to the boundary check to lock the cell selection until pressure moves decisively past the boundary.

2. Operating Conditions (When Does This Take Effect?)

  • Boundary Comparison Check:
  • Evaluated on every execution of AdaptiveMemory_DetermineWhichCellApplies_MM.
  • If the previous cell index was lower than the current boundary being tested, DLTMAP is added to the boundary threshold:

Effective Boundary = MP_x + DLTMAP

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x01 (1 ADC step ≈ 0.12 psi).
  • Tuning Guidance: The stock 1-count hysteresis is generally optimal. Increasing to 2 or 3 counts can help vehicles with excessive intake manifold pulsation (e.g., individual runner intakes or radical camshaft overlap), stabilizing cell selection.
