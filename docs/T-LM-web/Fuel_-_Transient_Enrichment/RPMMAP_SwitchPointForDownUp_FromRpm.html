1. Overview & Purpose

RPMMAP (labeled RPMLMT_RPMLimitForManyThings in assembly) serves as a critical engine speed boundary (1856 RPM) and associated lookup curve that shifts fuel pulse width calculation and ignition advance between low-RPM lugging algorithms and mid/high-RPM running algorithms.

At low engine speeds (under 1856 RPM), air velocity through the intake manifold runners is low, requiring distinct pulse width calculation logic to maintain driveability. Above RPMMAP, the ECU switches to higher-velocity volumetric calculations.

2. Operating Conditions (When Does This Take Effect?)

  • Running Pulse Width Calculation:
  • In CalculateInjectorPulsewidthForEngineRunning:
  • Current engine speed is compared against 0x3A (1856 RPM).
  • If EngineRpm < RPMMAP: Takes the low-RPM pulse width scaling path.
  • If EngineRpm >= RPMMAP: Proceeds to high-RPM boost scaling equations.
  • Spark Advance:
  • Checked in CalculateSparkAdvance_MM to modify spark timing calculations.

3. Tuner's Guide & Real-World Calibration

  • Stock Breakpoint: 0x3A (58 × 32 = 1856 RPM).
  • Tuning Impact: Defines the boundary where the engine transitions from low-speed torque management to high-speed power delivery.
