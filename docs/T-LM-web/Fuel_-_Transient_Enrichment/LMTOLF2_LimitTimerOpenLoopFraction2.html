1. Overview & Purpose

LMTOLF2_LimitTimerOpenLoopFraction2 is one of the most pervasive gating thresholds in the Chrysler ECU, referenced across O2 processing, adaptive memory, fuel modifiers, EVAP purge solenoid control, and spark advance.

It establishes the maximum permissible open-loop fraction time before closed-loop fuel feedback, adaptive fuel trimming, and EVAP purge canister purging are allowed to engage. If transient driving conditions keep Timer_OpenLoopFraction >= LMTOLF2, all steady-state feedback systems remain frozen in open loop.

2. Operating Conditions (When Does This Take Effect?)

  • Gatekeeper Across Systems:
  • O2 Closed Loop: In HandleO2Processing_MM: if Timer_OpenLoopFraction >= LMTOLF2, closed loop is locked out (bcc LD6F2).
  • Adaptive Learning: In UpdateAdaptive_OffIdle: if >= LMTOLF2, adaptive memory learning is blocked.
  • EVAP Purge: In ControlPurgeSolenoid_MM: if >= LMTOLF2, canister purge solenoid is held closed.
  • Fuel Modifiers: Subtracted during composite fuel modifier calculation (line 3914).

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x2B (43 counts).
  • System Interdependence: Because LMTOLF2 intersects with so many subsystems, altering it affects transient-to-steady-state transitions across fuel, spark, and emissions. Leave at factory 0x2B for stable operation.
