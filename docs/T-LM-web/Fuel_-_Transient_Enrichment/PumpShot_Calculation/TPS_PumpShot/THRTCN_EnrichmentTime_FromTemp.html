1. Overview & Purpose

THRTCN_EnrichmentTime_FromTemp defines the decay time constant for TPS-based acceleration enrichment.

Following a throttle opening transient, this curve dictates how long the TPS fuel shot is sustained before decaying back to steady-state fuel delivery. It ensures smooth transition between the initial throttle stomp and steady-state manifold filling.

2. Operating Conditions (When Does This Take Effect?)

  • Transient TPS Filter Decay:
  • Updated in CalculatePTEFactors_MM based on current coolant temperature.

3. Tuner's Guide & Real-World Calibration

  • Increasing Table Values:
  • Lengthens the duration of the TPS enrichment pulse.
  • Decreasing Table Values:
  • Shortens duration, making throttle response snappier.
