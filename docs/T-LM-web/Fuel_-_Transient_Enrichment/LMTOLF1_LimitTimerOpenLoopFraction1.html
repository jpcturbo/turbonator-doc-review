1. Overview & Purpose

LMTOLF1_LimitTimerOpenLoopFraction1 defines the primary threshold for the Open Loop Fraction timer (Timer_OpenLoopFraction).

This timer tracks cumulative time spent in open-loop transient operating conditions. LMTOLF1 works in tandem with LMTOLF2 to control the gradual blending and transitions between open-loop transient enrichment and closed-loop steady-state fuel delivery.

2. Operating Conditions (When Does This Take Effect?)

  • Open-Loop Fraction Management:
  • Incremented and clamped in A2DScan_MM.
  • If Timer_OpenLoopFraction >= LMTOLF1, the timer value is capped to prevent numerical overflow.
