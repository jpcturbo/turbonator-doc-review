1. Overview & Purpose

O2LIML_O2RangeLimitLow establishes the maximum short-term enleanment authority permitted by the closed-loop O2 controller.

Just as O2LIMH limits how much fuel the ECU can add, O2LIML protects the engine from being leaned out dangerously if a malfunctioning O2 sensor gets stuck producing high voltage. O2LIML forms the floor beneath which short-term fuel feedback cannot reduce injector pulse width.

2. Operating Conditions (When Does This Take Effect?)

  • Active Short-Term Enleanment Clamping:
  • Active whenever the closed-loop controller pulls fuel out (negative ramp accumulator).
  • If the accumulator decreases past O2LIML, the value is clamped to O2LIML.
  • If the accumulator remains pinned at O2LIML without crossing stoich for LTHTIM, the ECU flags Fault 52 (O2 sensor stuck rich / fuel trim pinned at maximum lean authority).

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0xB3 (Hex 0xB3 in 8-bit signed two's complement = 179 - 256 = -77 decimal).

Min Multiplier = 1.0 + (Signed(0xB3) / 512) = 1.0 - (77 / 512) ≈ 1.0 - 0.1504 = 0.8496\ (-15.0%)

  • Safety Margin: Notice that the factory calibration allows +24.8% rich authority (0x7F), but only -15.0% lean authority (0xB3). This asymmetric bias is intentional: running slightly rich under error conditions is safe, while running excessively lean under load can melt pistons.
  • Tuning Note: Do not set below 0x80 (-128 counts / -25%), as that would trigger signed arithmetic underflow.
