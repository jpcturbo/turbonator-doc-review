1. Overview & Purpose

O2MIDH_HighLimitForInMiddleDetermination defines the upper voltage boundary of the O2 sensor "stuck-in-the-middle" fault zone.

During normal operation, an active narrow-band O2 sensor continuously toggles rapidly between rich (> 0.6V) and lean (< 0.3V). It should virtually never linger at mid-voltages (~0.45V). If the sensor voltage remains continuously trapped between O2MIDL and O2MIDH, it indicates that the sensor is disconnected, internally shorted/open, or that its heater has failed. O2MIDH guards the top edge of this inactive detection window.

2. Operating Conditions (When Does This Take Effect?)

  • Active Closed Loop Monitoring: Once closed-loop operation is established (lines 3120â€“3131 in T-LMv13.asm):
  • The ECU checks if O2MIDL <= O2SensorVolts < O2MIDH.
  • If the voltage falls inside this middle zone (0.352V - 0.547V), Timer_CLTIME_ClosedLoopTimer increments.
  • If the timer saturates (> 0x7F / 127 counts ≈ 355 seconds), the ECU branches to Save_CLTIME_ToOtherTimers_O2InMiddle:
    • Clears bit 4 of BitFlags_81 (forces immediate drop-out to Open Loop).
    • Sets diagnostic Fault Code 21 (Oxygen sensor circuit failure / signal stayed in neutral zone).
  • OBD Diagnostic Verification: Also queried during factory scan-tool and Miller diagnostic tool test routines (VerifyOperationOfO2Sensor).

3. Tuner's Guide & Real-World Calibration

  • Stock Value: 0x1C (28 counts ≈ 0.547V).
  • Diagnostic Indicator: If an engine intermittently kicks out of closed loop and throws Fault 21, check the sensor wiring for high resistance or a failed heater circuit that causes the sensor to cool off and drift into this 0.352V - 0.547V range at long idle.
  • Tuning Implications: Do not compress O2MIDH down toward switching thresholds (O2HSWP), or false-positive Fault 21 triggers will occur during slow sensor transitions.
