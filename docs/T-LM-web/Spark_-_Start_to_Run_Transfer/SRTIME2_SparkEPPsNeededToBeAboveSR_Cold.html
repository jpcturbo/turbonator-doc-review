1. Overview & Purpose

SRTIME2_SparkEPPsNeededToBeAboveSR_Cold defines the number of consecutive Engine Position Pulses (EPPs) above STRNTR required to transfer spark control into Run Mode when the engine is cold.

Cold engines suffer from thick engine oil drag, incomplete fuel vaporization, and uneven cylinder-to-cylinder combustion. A cold engine can experience a "false start" where one cylinder fires and spins the engine briefly, only to stall the moment cranking enrichment cuts out. SRTIME2 allows calibrators to set a distinct pulse-count requirement for cold conditions to ensure the engine is fully self-sustaining before switching from cranking spark to running spark.

2. Operating Conditions (When Does This Take Effect?)

SRTIME2 is selected when: 1. Engine is Cold: Coolant temperature is strictly below SRTMTP (typically < 176°F / 80°C). 2. Cranking Above Threshold: Engine speed is between STRNTR (~600 RPM) and SKAPRD (~813 RPM).

3. Tuner's Guide & Real-World Calibration

  • Increasing the Value (More Pulses):
  • What it does: Demands more consecutive pulses above 600 RPM before allowing cold running spark tables (CLDMAP) to engage.
  • Real-World Driving Feel: Prevents cold stall on start-up in freezing weather where engines tend to catch, stumble, and die if transferred to run spark too abruptly.
  • Decreasing the Value (Fewer Pulses):
  • What it does: Allows the ECU to transfer to cold running spark almost immediately upon firing.
  • Real-World Driving Feel: Faster startup, but increases the chance of stalling on freezing morning cold starts if base fueling is lean.
