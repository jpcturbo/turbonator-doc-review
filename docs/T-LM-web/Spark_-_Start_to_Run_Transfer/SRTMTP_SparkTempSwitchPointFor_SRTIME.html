1. Overview & Purpose

SRTMTP_SparkTempSwitchPointFor_SRTIME is the coolant temperature switch point that selects between the hot (SRTIME) and cold (SRTIME2) start-to-run transfer pulse counters.

It establishes what the ECU considers a "warm restart" versus a "cold start" specifically for the start-to-run spark transition.

2. Operating Conditions (When Does This Take Effect?)

SRTMTP is checked during engine starting when engine speed is within the intermediate start-to-run window (~600 to 813 RPM): * If CoolantTemp >= SRTMTP: The ECU uses SRTIME. * If CoolantTemp < SRTMTP: The ECU uses SRTIME2.

3. Tuner's Guide & Real-World Calibration

  • Increasing the Value (Higher Temp Threshold):
  • What it does: Classifies warm engines as "cold" until they reach a higher temperature.
  • Real-World Driving Feel: Applies the cold pulse counter (SRTIME2) across a wider operating temperature range.
  • Decreasing the Value (Lower Temp Threshold):
  • What it does: Allows engines that are still lukewarm to use the warm start counter (SRTIME).
  • Real-World Driving Feel: Enables faster restarts after brief heat soaks.
