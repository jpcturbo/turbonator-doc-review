1. Overview & Purpose

STRNTR_SparkStartRunTransferPointRpm defines the primary engine speed threshold required to transfer from Start Mode into Run Mode.

During starter cranking, engine rotation is slow (~150–250 RPM) and irregular. The ECU remains in cranking mode, holding fixed base spark timing and dwell until the engine catches and spins up past STRNTR. Once the engine crosses above STRNTR (approximately 600 RPM) for the duration specified by SRTIME or SRTIME2, the ECU formally transitions ignition control to Run Mode.

2. Operating Conditions (When Does This Take Effect?)

STRNTR is evaluated during every distributor pulse while the ECU is in Start Mode: * Measured Variable: TimerOverflowsBetweenDistPulses (16-bit pulse period). * Evaluation: If STRNTR - TimerOverflowsBetweenDistPulses >= 0 (meaning pulse period is less than or equal to STRNTR, or RPM ≥ ~600 RPM), the ECU branches to increment the consecutive start-to-run pulse counter (Timer_NormalDwell).

3. Tuner's Guide & Real-World Calibration

  • Increasing the Value (Lower RPM Threshold):
  • What it does: Allows the engine to transfer to Run Mode at a lower RPM (e.g., 500 RPM).
  • Real-World Driving Feel: Enables earlier engagement of dynamic spark advance and idle speed AIS stepper motor control. However, setting it too close to starter cranking speed can cause premature transfer while cranking, resulting in starter kickback or failure to catch.
  • Decreasing the Value (Higher RPM Threshold):
  • What it does: Requires the engine to reach a higher RPM (e.g., 700–800 RPM) before entering Run Mode.
  • Real-World Driving Feel: Ensures the engine is spinning with high momentum before transferring, but if set higher than the cold flare RPM, the engine can get "stuck" in Start Mode and fail to transition into normal running.
