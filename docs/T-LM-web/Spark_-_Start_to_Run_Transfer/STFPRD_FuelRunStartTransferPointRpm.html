1. Overview & Purpose

STFPRD_FuelRunStartTransferPointRpm is the fuel stall-detection hysteresis threshold that drops fuel injection back from running speed-density mode into cranking enrichment mode if engine RPM sags below ~450 RPM.

If an engine stalls or the driver lugs it down to near-zero speed, speed-density MAP readings become erratic and injectors cannot deliver stable fuel pulses. If engine RPM drops below STFPRD, the ECU re-engages starting/cranking fuel logic to prevent backfiring and assist the engine in catching or restarting cleanly.

2. Operating Conditions (When Does This Take Effect?)

STFPRD is evaluated while the engine is running: * If TimerOverflowsBetweenDistPulses increases past STFPRD (engine speed drops below ~450 RPM): The ECU drops out of running fuel mode and returns to cranking fuel logic.

3. Tuner's Guide & Real-World Calibration

  • Increasing the Value (Lower RPM Threshold):
  • Effect: Allows the engine to drop lower in speed before re-triggering cranking fuel.
  • Real-World Driving Feel: Prevents sudden rich bogging when lugging the engine at low speeds.
  • Decreasing the Value (Higher RPM Threshold):
  • Effect: Re-triggers cranking fuel at a higher speed.
  • Real-World Driving Feel: Drops back to cranking fuel sooner during stalls. If set too high, an abrupt idle dip can flood the engine with cranking fuel.

5. Calibration Notes & System Dependencies

  • Hysteresis Matching: RNFPRD (~705 RPM) and STFPRD (~450 RPM) form the fuel hysteresis loop, mirroring the spark hysteresis loop defined by STRNTR (~600 RPM) and RNSTTR (~410 RPM).
