1. Overview & Purpose

RVLSWS (StagingLimiterSwitchSelect) selects the physical hardware switch input used to arm and activate the Turbonator 2-step staging launch limiter.

T-LM allows flexible configuration of the launch limiter arming trigger: * 0x00: Speed-only arming (active automatically whenever vehicle speed is below RVLSPS). * 0x08 (Stock default): Clutch pedal switch input (Port C Bit 3). Limiter engages only when the clutch pedal is pressed to the floor. * Custom bitmasks allow mapping to a momentary steering wheel launch button, line-lock switch, or emergency brake switch.

2. Operating Conditions (When Does This Take Effect?)

  • Evaluated inside subroutine ControlEngineCutout_MM at line 6446.
  • If RVLSWS == 0, switch check is bypassed and the limiter is purely speed-gated.
  • If RVLSWS != 0, the limiter requires both speed below RVLSPS AND the configured switch input closed.

3. Tuner's Guide & Real-World Calibration

  • Manual Transmission (Clutch Switch): Leave at default 0x08. The 2-step arms when staged with the clutch depressed, and disengages the instant the clutch pedal begins releasing.
  • Automatic Transmission (Brake / Line-Lock): Wire a momentary line-lock button to the brake/clutch switch sense pin, allowing automatic cars to stall the converter against the brake at the staging line.
  • No Switch Setup: Setting RVLSWS to 0x00 enables pure speed mode; whenever the car is stopped (< 4 MPH), the 2-step is armed.
