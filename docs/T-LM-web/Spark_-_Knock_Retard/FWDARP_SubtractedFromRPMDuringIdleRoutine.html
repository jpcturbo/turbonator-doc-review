1. Overview & Purpose

FWDARP_SubtractedFromRPMDuringIdleRoutine defines the forward RPM deadband offset for the ECU's rapid idle speed stabilization system.

While the Automatic Idle Speed (AIS) stepper motor provides bulk airflow adjustments for idle speed control, mechanical stepper motors react slowly (hundreds of milliseconds). To achieve rock-solid idle stability, Chrysler employs rapid ignition timing and dwell dithering (often called "Spark Scatter"): if idle RPM surges above target, timing is retarded instantaneously; if RPM dips below target, timing is advanced immediately. FWDARP establishes the positive RPM deadband threshold (stock ~30 RPM above target) that must be exceeded before over-speed timing corrections are engaged.

2. Operating Conditions (When Does This Take Effect?)

FWDARP is evaluated in the idle timing control interrupt: * Operating State: Closed-throttle idle. * Evaluation: Engine RPM error is computed, divided by 2, and FWDARP is subtracted. * Action: If the error exceeds FWDARP, the ECU applies over-speed timing trims.

3. Tuner's Guide & Real-World Calibration

  • Increasing the Value (Wider Deadband):
  • Allows idle RPM to fluctuate further above target before timing is trimmed.
  • Real-world feel: Useful for aggressive aftermarket camshafts that naturally produce lumpy idle pulses, preventing the ECU from fighting the camshaft's natural lope.
  • Decreasing the Value (Tighter Deadband):
  • Causes immediate timing retards on the slightest upward RPM deviation.
  • Real-world feel: Ultra-tight idle RPM control on stock engines, but can cause hunting/surging on modified engines.
