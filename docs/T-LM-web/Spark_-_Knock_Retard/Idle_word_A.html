1. Overview & Purpose

Idle_word_A (IDLWA) is an internal 2-byte parameter structure utilized by the ECU's closed-throttle idle spark scatter / stabilization routine when engine speed is above target idle (EngineRpm_HB >= TargetIdleSpeed_HB).

Together with Idle_bytes_A, Idle_word_B, and Idle_bytes_B, it forms a 3-byte indexed lookup structure (0x00,x maximum clamp, 0x01,x proportional slope multiplier, 0x02,x base offset) used to calculate rapid idle spark timing corrections.

2. Operating Conditions (When Does This Take Effect?)

  • Active State: Engine at idle speed with throttle closed and EngineRpm_HB >= TargetIdleSpeed_HB.
  • Firmware Access: Loaded via ldx #Idle_word_A at line 4821.

3. Tuner's Guide & Real-World Calibration

  • Tuning Recommendation: DO NOT MODIFY.
    The high byte (0x16 = 22 counts = 11.0° max retard) and low byte (0xBC = 188/256 slope) govern the proportional over-speed spark scatter curve at idle.
