1. Overview & Purpose

Idle_bytes_A (IDLBA) is a companion byte constant to Idle_word_A in the ECU's idle spark scatter / stabilization parameter block. It provides the base offset byte (0x02,x) added after multiplying the idle RPM error slope when EngineRpm_HB >= TargetIdleSpeed_HB.

2. Operating Conditions (When Does This Take Effect?)

  • Active State: Closed-throttle idle when EngineRpm_HB >= TargetIdleSpeed_HB and the RPM error is within the FWDARP proportional band.
  • Firmware Access: Accessed via indexed offset adca 0x02,x when X points to Idle_word_A.

3. Tuner's Guide & Real-World Calibration

  • Tuning Recommendation: DO NOT MODIFY.
    Factory calibrated at 0x00. Modifying this value shifts the proportional idle spark scatter base offset.

5. Calibration Notes & System Dependencies

  • Contiguous 3-Byte Structure: Immediately follows Idle_word_A in ROM so that 0x00,x and 0x01,x reference Idle_word_A and 0x02,x references Idle_bytes_A.
