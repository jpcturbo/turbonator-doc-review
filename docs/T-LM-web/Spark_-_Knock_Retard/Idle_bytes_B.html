1. Overview & Purpose

Idle_bytes_B (IDLBB) is the companion byte constant to Idle_word_B in the ECU's idle spark scatter / stabilization parameter block, providing the base offset (0x02,x) when EngineRpm_HB < TargetIdleSpeed_HB.

2. Operating Conditions (When Does This Take Effect?)

  • Active State: Closed-throttle idle when EngineRpm_HB < TargetIdleSpeed_HB (under-speed condition).
  • Firmware Access: Accessed via indexed offset adca 0x02,x when X points to Idle_word_B.

3. Tuner's Guide & Real-World Calibration

  • Tuning Recommendation: DO NOT MODIFY.
    Factory calibrated at 0x00. Modifying this value alters the under-speed idle spark advance base offset.

5. Calibration Notes & System Dependencies

  • Contiguous 3-Byte Structure: Immediately follows Idle_word_B in ROM so that 0x00,x and 0x01,x reference Idle_word_B and 0x02,x references Idle_bytes_B.
