1. Overview & Purpose

THRKNK_DeltaAbove_MINTHR defines the throttle opening threshold above base idle position required to trigger the low-RPM knock retard limit (KNKLIM).

The ECU tracks the minimum historical TPS voltage recorded during the driving session (MINTHR_LowestSessionTPS). When the throttle is opened beyond MINTHR by more than THRKNK while operating below KLMRPM, the ECU activates the low-RPM knock protection ceiling.

2. Operating Conditions (When Does This Take Effect?)

THRKNK is evaluated inside KnockDetect_MM: * Evaluation: Delta TPS (TpsVolts - MINTHR) is compared against THRKNK. * Action: If Delta TPS ≥ THRKNK and RPM < KLMRPM, the ECU overrides the normal MAP knock retard curve with the constant KNKLIM.

3. Tuner's Guide & Real-World Calibration

  • Increasing the Value (Higher Throttle Delta):
  • Requires a larger throttle opening before the low-RPM KNKLIM clamp activates, allowing the standard RETMAX curve to operate over a broader throttle range.
  • Decreasing the Value (Lower Throttle Delta):
  • Engages the low-RPM KNKLIM retard clamp on lighter pedal movements.
  • Stock Setting:
  • 0x53 equals (83 / 255) × 5.0V ≈ 1.63 Volts above minimum idle TPS.

  • Adaptive Baseline: Because MINTHR dynamically learns the lowest TPS voltage on every key cycle, THRKNK represents a true relative delta regardless of mechanical throttle cable slack or TPS sensor installation angle.
