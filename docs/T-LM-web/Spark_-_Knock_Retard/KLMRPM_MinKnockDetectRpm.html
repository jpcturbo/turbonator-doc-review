1. Overview & Purpose

KLMRPM_MinKnockDetectRpm is the engine speed ceiling for the low-RPM knock retard clamp (KNKLIM).

While KNKRPM completely turns off knock retard below 1,024 RPM, KLMRPM establishes the transition boundary where the ECU switches from the restricted low-RPM knock ceiling (KNKLIM) to the full dynamic knock retard table (RETMAX).

2. Operating Conditions (When Does This Take Effect?)

KLMRPM is evaluated when throttle opening exceeds THRKNK: * If EngineRpm_HB < KLMRPM: The ECU clamps maximum retard to KNKLIM (stock 2.0°). * If EngineRpm_HB >= KLMRPM: The ECU branches to look up maximum allowable retard from RETMAX as a function of intake manifold pressure.

3. Tuner's Guide & Real-World Calibration

  • Increasing the Value (Higher RPM Threshold):
  • Extends the restricted low-RPM knock clamp (KNKLIM) to higher engine speeds (e.g., 1,500 or 2,000 RPM).
  • Useful for heavily cammed or mechanically noisy engines where false knock causes power hesitation during lower gear acceleration.
  • Decreasing the Value (Lower RPM Threshold):
  • Allows the full RETMAX curve to take effect at lower RPMs, providing maximum knock retard protection sooner.
