1. Overview & Purpose

KNKLIM_MaxKnockRetard specifies the maximum ceiling on knock retard applied during low-speed transient throttle transitions.

When accelerating from low RPM with significant throttle input, sudden mechanical load and engine movement can rattle engine mounts or exhaust heat shields, creating mechanical noise spikes. Under these low-RPM, high-throttle conditions (below KLMRPM with throttle delta above THRKNK), KNKLIM caps the maximum allowable knock retard to a modest limit (2.0° in stock calibrations) to prevent false vibration from triggering excessive, bog-inducing retard.

2. Operating Conditions (When Does This Take Effect?)

KNKLIM is enforced when: 1. EngineRpm_HB < KLMRPM (engine speed is below the knock detect RPM threshold, ~1,024 RPM). 2. Throttle delta (TpsVolts - MINTHR) ≥ THRKNK. 3. If both are true, MaxRetardFromMAP is capped directly at KNKLIM rather than using the full RETMAX curve.

3. Tuner's Guide & Real-World Calibration

  • Increasing the Value (Higher Low-RPM Retard Cap):
  • Effect: Allows more timing to be pulled during low-RPM tip-in if knock is detected.
  • Real-World Driving Feel: Extra safety if an engine experiences low-RPM tip-in detonation under heavy load, but risks deeper hesitation if false knock occurs.
  • Decreasing the Value (Lower Low-RPM Retard Cap):
  • Effect: Restricts how much timing can be pulled at low RPM.
  • Real-World Driving Feel: Prevents low-RPM bogs caused by false knock from noisy valvetrain or engine mounts.
