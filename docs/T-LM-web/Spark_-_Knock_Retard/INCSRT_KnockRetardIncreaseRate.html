1. Overview & Purpose

INCSRT_KnockRetardIncreaseRate controls the decay rate / recovery rate of ignition timing after a knock event has ended.

When the ECU detects knock, it retards ignition timing immediately. Once detonation ceases, the ECU must gradually return (decay) the timing back toward the normal advance curve. If timing is returned too quickly, the engine will immediately re-detonate; if returned too slowly, the vehicle remains sluggish with elevated exhaust temperatures long after the knock event has passed.

INCSRT acts as a loop counter bitmask: every time the main loop timer matches this mask, the ECU restores 0.5° of timing to each cylinder until all knock retard has decayed to zero.

2. Operating Conditions (When Does This Take Effect?)

INCSRT is evaluated in the 11-millisecond main background loop: * Trigger Condition: The main loop counter (Counter_MainLoop1) is bitwise-ANDed with INCSRT. * Action: When all masked bits are zero, the ECU decrements the knock retard accumulators for all four cylinders (Cylinder1Retard through Cylinder4Retard) by 1 unit (0.5° advance restored).

3. Tuner's Guide & Real-World Calibration

[!WARNING] Bitmask Rule: INCSRT is a binary bitmask. It MUST ONLY be set to binary power-of-two minus one values: 0x00, 0x01, 0x03, 0x07, 0x0F, 0x1F, 0x3F, 0x7F, or 0xFF. Using intermediate values (e.g., 0x10) will cause erratic, non-uniform timing recovery rates.

  • Increasing the Value (Larger Mask / Slower Recovery):
  • Effect: Timing decays more slowly (recovers fewer degrees per second).
  • Real-World Driving Feel: Prevents repeat detonation after severe knock events, but leaves the engine in a retarded state longer.
  • Decreasing the Value (Smaller Mask / Faster Recovery):
  • Effect: Timing recovers more rapidly back to base advance.
  • Real-World Driving Feel: Restores full horsepower quickly after transient knock (such as a bad gear shift or fuel splash), but risks rapid cyclic re-knock if the underlying cause is low fuel octane.
  • Stock Rate:
  • Mask 0x1F triggers once every 32 program loops. At ~11 ms per loop, timing recovers at 0.5° every ~352 milliseconds (~1.4° per second).
