1. Overview & Purpose

STRTFL_FuelStartFromCoolantTemp is the core cranking fuel delivery curve used while the engine is being turned over by the starter motor.

During cold cranking, cold intake manifold runners and cylinder head ports cause injected fuel to condense onto cold metal surfaces ("wall wetting"), preventing it from vaporizing and reaching the spark plug. To establish a combustible air/fuel mixture in the cylinder, the injectors must spray substantially more fuel at cold temperatures (often 4 to 8 times normal running fuel). As the engine warms up, fuel vaporizes readily and cranking fuel requirements decrease sharply. STRTFL defines this baseline fuel pulse width as a function of engine coolant temperature.

2. Operating Conditions (When Does This Take Effect?)

STRTFL is calculated only when the engine is in Start / Cranking Mode: * Engine Speed: Engine speed is below the start-to-run threshold (STRNTR / RNFPRD). * Throttle State: The accelerator pedal must not be floored to Wide-Open Throttle.

Clear Flood Mode: If the throttle is floored to WOT while cranking, the ECU bypasses STRTFL and delivers zero fuel (0x0000 pulse width) to allow a flooded engine to clear out. * Low-Temperature Clamping: If the throttle is closed, coolant temperature input into STRTFL is clamped from below by STRLMT.

3. Tuner's Guide & Real-World Calibration

  • Square-Root Math: STRTFL utilizes square-root pulse width scaling. The ECU squares the lookup value (STRTFL × STRTFL) to compute base pulse width. Small adjustments to high table values have a large exponential impact on fuel delivery!
  • Increasing Table Values (Richer Cranking):
  • Effect: Injects longer fuel pulses during cranking.
  • Real-World Feel: Helps engines that crank endlessly without catching in cold weather, or engines running E85 (which requires ~30% more cranking fuel).
  • Decreasing Table Values (Leaner Cranking):
  • Effect: Shortens cranking fuel pulses.
  • Real-World Feel: Crucial when upgrading to larger fuel injectors (+40%, +20%, or 52+ lb/hr). If STRTFL is not scaled down for big injectors, the engine will instantly foul spark plugs and flood during cranking.
