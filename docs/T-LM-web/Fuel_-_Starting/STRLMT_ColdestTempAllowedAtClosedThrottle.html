1. Overview & Purpose

STRLMT_ColdestTempAllowedAtClosedThrottle is a minimum temperature floor clamped onto the cranking fuel lookup when starting at closed throttle.

Because the cranking fuel table (STRTFL) uses square-root math, pulse widths explode exponentially as temperatures plunge into sub-zero freezing ranges. If a car is started in -20°F weather at closed throttle, delivering the un-clamped sub-zero fuel pulse width can instantly drown the intake runners, soak the spark plugs in liquid gasoline, and wash down cylinder walls. STRLMT prevents this by capping the coldest temperature input permitted into STRTFL at closed throttle to roughly 30°F (0x63).

2. Operating Conditions (When Does This Take Effect?)

STRLMT is checked during cranking: * Throttle State: Throttle is closed (BitFlags_81 bit 7 = 0). * Temperature Check: If CoolantTemp < STRLMT, CoolantTemp is replaced with STRLMT before calling STRTFL. * Off-Idle Bypass: If the driver presses the gas pedal slightly off-idle, this clamp is bypassed, allowing the driver to command richer sub-freezing starting fuel manually.

3. Tuner's Guide & Real-World Calibration

  • Increasing the Value (Warmer Clamp):
  • Caps cold cranking fuel at a warmer temperature. Prevents cold flooding in winter climates.
  • Decreasing the Value (Colder Clamp):
  • Allows the ECU to deliver richer cranking pulse widths at extreme sub-freezing temperatures.
  • Useful in extreme northern climates (e.g., -20°F to -40°F) if an engine struggles with dry-cranking lean-out.
