1. Overview & Purpose

T2MPDEL establishes a deadband hysteresis threshold subtracted from the rate of boost change before the controller calculates the dynamic response factor correction in T2 control.

If the rate of boost change is small and falls below T2MPDEL, the controller considers the boost rate stable and bypasses dynamic response factor multiplication, preventing minor sensor noise from perturbing baseline duty cycle lookups.

2. Operating Conditions (When Does This Take Effect?)

  • Subroutine & Line Numbers: CalcWGDutyCycleT2 (T-SMEC_v19.asm:9825-9828), called from CalcWGDutyCycle_MM (T-SMEC_v19.asm:9506-9510).
  • Gating Conditions: Reached when rate of boost rise does not exceed T2RATLIM.
  • Subtraction & Deadband Check:
  • Line 9825 clears accumulator B.
  • Line 9826 executes suba T2MPDEL_HysteresisForBoostCreep from absolute rate in accumulator A.
  • If result is lower or same (bls L7747 at line 9827), response factor multiplication is skipped.

3. Tuner's Guide & Real-World Calibration

  • Rate-of-Change Deadband Hysteresis:
  • Subtracted from absolute boost rate before multiplying by T2RESFAC.
  • Factory setting is 0 counts (no deadband; all non-zero rates are scaled).
  • Filtering Manifold Flutter:
  • Raising T2MPDEL to 1 or 2 counts ignores minor sensor noise and manifold pulsing during steady-state cruise.
  • T2 Response Factor Interlock:
  • If Boost Rate <= T2MPDEL, dynamic target correction MPCORR is bypassed entirely.
