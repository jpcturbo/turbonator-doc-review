1. Overview & Purpose

T2KDCMAX establishes the upper ceiling on cumulative knock duty cycle modification in T2 control.

When persistent detonation occurs under boost, repeated knock events accumulate additional duty cycle steps. T2KDCMAX prevents this penalty total from increasing indefinitely, capping total knock-induced duty cycle modification to a calibrated maximum that ensures the wastegate opens fully to base actuator spring pressure without over-driving the solenoid.
