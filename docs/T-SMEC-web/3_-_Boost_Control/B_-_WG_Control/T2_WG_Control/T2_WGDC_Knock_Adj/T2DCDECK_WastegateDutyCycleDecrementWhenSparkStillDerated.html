1. Overview & Purpose

T2DCDECK controls the rate at which wastegate duty cycle recovers toward normal operation after a detonation event has subsided in T2 control.

While cylinders are recovering from knock retard, the controller steadily bleeds down the knock reduction penalty by T2DCDECK counts at intervals governed by T2DECTIM, smoothly restoring baseline wastegate duty cycle and boost pressure without causing sudden torque surges.

3. Tuner's Guide & Real-World Calibration

  • T2 Knock Recovery Step Rate:
  • Sets the duty cycle counts subtracted from the knock penalty per recovery interval.
  • Factory setting is 2 counts (1.0 percent duty cycle recovery per step).
  • Balancing Recovery vs. Detonation Cycling:
  • Increasing T2DCDECK to 4 counts speeds up boost return on high-octane fuel.
  • Decreasing T2DCDECK to 1 count creates a gentle recovery that prevents secondary knock events.
  • Underflow Clamping:
  • Automatically clamps at zero counts when knock penalty has fully cleared.
