1. Overview & Purpose

T2DECTIM sets the timing prescaler bitmask that governs how frequently the knock duty cycle recovery decrement (T2DCDECK) is executed in T2 control.

The controller checks this bitmask against the main program loop counter; only when the masked bits equal zero does the routine decrement the knock reduction penalty. Pacing the recovery rate ensures that boost returns smoothly and gradually as cylinder knock retard subsides.

2. Operating Conditions (When Does This Take Effect?)

  • Subroutine & Line Numbers: T2WGDC_LookAtCylRetards (T-SMEC_v19.asm:9914-9916), called from CalcWGDutyCycleT2 (T-SMEC_v19.asm:9755-10040).
  • Gating Conditions: At least one cylinder must have knock retard exceeding T2WGKNRD.
  • Prescaler Masking:
  • Line 9914 loads Counter_MainLoop into accumulator B.
  • Line 9915 executes bitb T2DECTIM_TimeScaleFor_DCDECK.
  • If non-zero (bne L7763), execution branches past the decrement routine for this loop pass.

3. Tuner's Guide & Real-World Calibration

  • T2 Recovery Interval Prescaler:
  • Bitmask applied against Counter_MainLoop to control how often T2DCDECK is subtracted from knock penalty.
  • Factory setting is 7 (executes every 8th main loop pass, approximately every 88 milliseconds).
  • Preventing Knock Re-Triggering:
  • An 88 ms interval provides a cautious, stable recovery that prevents cycling back into detonation.
  • Fast Track Recovery:
  • Lowering bitmask to 3 (every 4th pass) or 1 (every 2nd pass) restores boost faster on race fuel.

  • Standard Bitmask: 0x07 = every 8th loop pass (approx 88 ms assuming 11 ms main loop rate).
  • T1 Comparison: T1 uses bitmask 0x01 (every 2nd pass); T2 is four times slower to ensure stable recovery.
