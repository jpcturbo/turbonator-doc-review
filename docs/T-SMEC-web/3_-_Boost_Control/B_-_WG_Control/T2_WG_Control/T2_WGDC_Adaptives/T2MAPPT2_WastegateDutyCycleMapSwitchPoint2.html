1. Overview & Purpose

T2MAPPT2 was designed to define the minimum manifold gauge pressure threshold required to activate wastegate duty cycle calculations in T2 control.

In factory calibration templates, T2MAPPT2 is set to 46 counts (approximately 5.3 psi of boost). However, as documented in firmware reverse engineering analyses, a copy-paste bug in stock T-SMEC v19 firmware causes the T2 routine at line 9764 to compare against the T1 constant (MAPPT2) instead of T2MAPPT2. As a result, this calibration constant is unreferenced by the executable assembly code in stock firmware.

2. Operating Conditions (When Does This Take Effect?)

  • Intended Subroutine & Line Numbers: CalcWGDutyCycleT2 (T-SMEC_v19.asm:9760-9766).
  • Firmware Anomaly: At line 9764, the CPU executes cmpa MAPPT2_WastegateDutyCycleMapSwitchPoint2 instead of T2MAPPT2.
  • Gating Logic:
  • Gauge boost is calculated in accumulator A as MapValue - BaroPressure (line 9762).
  • Compared against MAPPT2 at line 9764. If below, branches to T2WGDC_ClearWGDutyCycleVars (line 9767), zeroing WGDC.

3. Tuner's Guide & Real-World Calibration

  • Firmware Copy-Paste Anomaly:
  • Line 9764 of CalcWGDutyCycleT2 compares gauge boost against MAPPT2_WastegateDutyCycleMapSwitchPoint2 rather than T2MAPPT2.
  • Editing T2MAPPT2 in MPTune has no physical effect on stock v19 firmware.
  • Tuning Workaround:
  • To adjust the T2 activation threshold, modify MAPPT2 in the T1 group (T1_WGDC_Adaptives\).
  • Source Firmware Patch:
  • If rebuilding firmware from assembly source, update line 9764 to compare against T2MAPPT2_WastegateDutyCycleMapSwitchPoint2.

4. Technical / Assembly Mechanics (Reference)

Inside T-SMEC_v19.asm: In CalcWGDutyCycleT2 at line 9761, accumulator A loads MapValue and subtracts BaroPressure. At line 9764, the instruction cmpa MAPPT2_WastegateDutyCycleMapSwitchPoint2 compares the gauge boost against MAPPT2 rather than T2MAPPT2. If carry is set (bcs T2WGDC_ClearWGDutyCycleVars), the controller zeroes CurrentWastegateDutyCycle, WastegateDutyCycleIncreaseFromKnock, and Timer_Over5PsiBoostMaxFF. Consequently, T2MAPPT2 remains completely unreferenced in the binary unless patched.

; --- CalcWGDutyCycleT2 (T-SMEC_v19.asm:9760-9766) ---
        ldab Counter_MainLoop         ; load b with memory contents
        ldaa MapValue                  ; load a with memory contents
        suba BaroPressure
        bcs  T2WGDC_ClearWGDutyCycleVars                     ; branch if lower
        cmpa MAPPT2_WastegateDutyCycleMapSwitchPoint2    ; compare a with memory contents (data is 2e)
        bcc  L7739                     ; branch if greater or equal

5. Calibration Notes & System Dependencies
