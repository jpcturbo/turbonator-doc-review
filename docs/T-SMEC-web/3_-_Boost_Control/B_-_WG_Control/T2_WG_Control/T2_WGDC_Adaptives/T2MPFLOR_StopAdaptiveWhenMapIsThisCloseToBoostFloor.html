1. Overview & Purpose

T2MPFLOR defines the adaptive deadband threshold above target boost where adaptive duty cycle decrementing is halted in T2 control.

When actual boost is dropping back down toward the target, T2MPFLOR verifies whether manifold pressure has arrived within the calibrated tolerance band of the target ceiling. Once boost is within this margin, the controller terminates adaptive decrementing to prevent pulling duty cycle out of the baseline cells unnecessarily.

3. Tuner's Guide & Real-World Calibration

  • T2 Adaptive Deadband Floor:
  • Minimum error delta required to permit adaptive decrementing in T2 mode.
  • Factory setting is 0 counts (0.0 psi in ASM, 2 counts / 0.23 psi in template).
