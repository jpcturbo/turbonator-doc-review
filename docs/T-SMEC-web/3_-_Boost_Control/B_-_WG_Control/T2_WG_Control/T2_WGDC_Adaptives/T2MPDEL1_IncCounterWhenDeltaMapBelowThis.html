1. Overview & Purpose

T2MPDEL1 sets the rate-of-change stability threshold for manifold pressure required before the error timer can advance when boost is above target in T2 control.

T2 control actively tracks the signed rate of boost change (BoostDelta_Signed). If boost is changing too rapidly, the rate delta will be large, indicating an active transient. T2MPDEL1 requires the rate of boost change to fall below this threshold, verifying that manifold pressure has stabilized before allowing the error timer to count toward an adaptive duty cycle update.

3. Tuner's Guide & Real-World Calibration

  • T2 Rate-of-Change Stability Gate:
  • Requires absolute boost rate delta (Temp0 = |BoostDelta_Signed|) to be below T2MPDEL1 to advance error timer.
  • Factory setting is 2 counts (approximately 0.23 psi per loop pass).
  • Inhibiting Learning on Transients:
  • Blocks adaptive cell increments while boost is rapidly rising or spiking.
  • Plenum Harmonic Tuning:
  • If large intake plenums or aggressive cams create pressure fluctuations, increase T2MPDEL1 to 3 or 4 counts to permit steady-state learning.
