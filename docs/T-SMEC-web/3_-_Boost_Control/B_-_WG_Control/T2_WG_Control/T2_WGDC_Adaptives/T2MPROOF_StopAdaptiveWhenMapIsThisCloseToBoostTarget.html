1. Overview & Purpose

T2MPROOF defines the adaptive deadband threshold below target boost where adaptive duty cycle incrementing is halted in T2 control.

When manifold pressure approaches within T2MPROOF of the target boost, the controller considers boost sufficiently close to goal and freezes further upward duty cycle learning. This deadband prevents continuous adaptive hunting and cycling around the target boost level during steady-state wide-open throttle operation.

3. Tuner's Guide & Real-World Calibration

  • T2 Adaptive Deadband Ceiling:
  • Minimum error delta required to permit adaptive incrementing in T2 mode.
