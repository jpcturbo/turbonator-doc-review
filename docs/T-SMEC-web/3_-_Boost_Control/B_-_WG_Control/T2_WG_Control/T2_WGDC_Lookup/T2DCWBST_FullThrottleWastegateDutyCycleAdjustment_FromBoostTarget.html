1. Overview & Purpose

T2DCWBST provides an error-proportional duty cycle correction based on the difference between target boost and actual manifold pressure in T2 control.

Unlike the T1 routine where positive error adds duty cycle, the T2 routine explicitly negates the lookup result (using the assembly instruction nega) before applying it to the duty cycle total. This inversion matches T2 pressure-source plumbing, ensuring that when boost is below target, duty cycle is reduced to keep pressure off the actuator and hold the wastegate closed for fast spool-up.
