1. Overview & Purpose

T2DCWOT provides the open-loop base wastegate duty cycle curve as a function of target boost pressure for T2 wastegate control.

In T2 pressure-source plumbing, the solenoid modulates pressure applied directly to the wastegate actuator; higher duty cycle directs control pressure to push the wastegate open and limit boost, while lower duty cycle keeps pressure off the actuator to hold the gate closed. T2DCWOT provides the calibrated feed-forward duty cycle baseline from which RPM adjustments, boost error deltas, and adaptives operate, scaled so that 200 counts equals 100 percent duty cycle.
