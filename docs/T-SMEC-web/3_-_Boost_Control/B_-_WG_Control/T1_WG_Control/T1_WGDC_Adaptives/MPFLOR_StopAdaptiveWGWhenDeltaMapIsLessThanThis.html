1. Overview & Purpose

MPFLOR establishes a manifold pressure rate-of-change stability gate required to permit adaptive wastegate duty cycle decrementing in T1 control.

If manifold pressure is fluctuating rapidly due to gear shifting, aggressive throttle movement, or turbocharger compressor surge, the difference between instantaneous manifold pressure and rolling average manifold pressure will be large. MPFLOR verifies that boost has stabilized before allowing the error timer to accumulate, ensuring the controller never updates adaptive learning cells during chaotic transient events.

3. Tuner's Guide & Real-World Calibration

  • Manifold Stability Filter:
  • Requires instantaneous MAP to be within MPFLOR of rolling AverageMAPValue before allowing adaptive decrement.

  • Pulsation Damping:
  • If aggressive camshafts cause intake manifold pulsing that locks out adaptive learning, increase MPFLOR to 3 or 4 counts.
