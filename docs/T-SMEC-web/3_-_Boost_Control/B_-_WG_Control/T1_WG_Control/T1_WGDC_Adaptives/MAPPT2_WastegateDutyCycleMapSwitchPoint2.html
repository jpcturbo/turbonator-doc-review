1. Overview & Purpose

MAPPT2 establishes the minimum manifold gauge pressure threshold that must be reached before the engine controller activates electronic wastegate duty cycle calculations.

Below this threshold, manifold pressure is near or below atmospheric pressure, where modulating the wastegate solenoid is unnecessary and would cause needless solenoid wear and clicking. When manifold pressure is below atmospheric pressure plus MAPPT2, the controller zeros the wastegate duty cycle and clears all knock-reduction duty cycle offsets. In factory calibrations, this is set to 15 counts (approximately 1.7 psi of boost).

3. Tuner's Guide & Real-World Calibration

  • Boost Activation Threshold:
  • Minimum boost above barometric pressure required before the ECU begins modulating the wastegate solenoid.
  • Factory setting is 15 counts (approximately 1.7 psi boost above atmospheric pressure).
  • Quiet Solenoid Operation:
  • Below this pressure, duty cycle is held at 0%, preventing solenoid clicking during vacuum and light-throttle cruise.
  • Firmware Copy-Paste Anomaly:
  • Line 9764 in CalcWGDutyCycleT2 incorrectly references MAPPT2 instead of T2MAPPT2; modifying MAPPT2 alters the activation threshold in both modes.
  • 3-Bar MAP Scaling:
  • In 3-bar sensor calibrations, scale MAPPT2 to half its 2-bar count value to maintain the same 1.7 psi activation threshold.

5. Calibration Notes & System Dependencies

  • Cross-Algorithm Impact: Referenced in both CalcWGDutyCycleT1 (line 9553) and CalcWGDutyCycleT2 (line 9764).
  • Clear Routine Behavior: When boost is below MAPPT2, Timer_BoostTimer is decremented by 1 count every 32 main loop passes.
