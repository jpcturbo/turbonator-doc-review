1. Overview & Purpose

DCRPM3 sets the third and highest engine speed boundary in the adaptive wastegate grid, separating Cell 4 from Cell 5 (the high-RPM redline cell).

Approaching engine redline, exhaust backpressure often rises steeply while engine breathing demand reaches its peak, frequently causing boost to taper or creep depending on turbine housing sizing. DCRPM3 isolates this high-RPM region into dedicated Cell 5, allowing the controller to learn unique top-end duty cycle corrections. Shared between T1 and T2 control routines.

2. Operating Conditions (When Does This Take Effect?)

  • Subroutine & Line Numbers: WGDC_SelectAdaptiveWGCell (T-SMEC_v19.asm:9661-9664) in T1, and T2WGDC_SelectAdaptiveWGCell (T-SMEC_v19.asm:9941-9944) in T2.
  • Gating Conditions: Engine speed must exceed DCRPM2.
  • Boundary Comparison:
  • Index X points to Cell 4 (DCCOR4).
  • Line 9662 executes cmpb DCRPM3_WastegateDutyCycleRpmBoundary3.
  • If engine speed is below DCRPM3 (bcs), execution branches to WGDC_LoadAdaptiveWGCell (line 9663), selecting Cell 4.
  • If engine speed is greater or equal, index X increments at line 9664 to select top-end Cell 5 (DCCOR5).

3. Tuner's Guide & Real-World Calibration

  • Third RPM Adaptive Boundary:
  • Engine speed threshold separating adaptive Cell 4 from top-end Cell 5 in high-boost mode.
  • Factory setting is 163 counts (approximately 5216 RPM in template, or 5400 RPM in ASM).
  • Top-End Taper Isolation:
  • Isolates redline exhaust backpressure dynamics into Cell 5, preventing top-end boost sag from affecting mid-range trims.
  • Elevated Rev Limits:
  • If running rev limiters above 6500 RPM, raise DCRPM3 to 5600 to 6000 RPM to balance cell spans.
  • Shared Code Architecture:
  • Evaluated in both CalcWGDutyCycleT1 (line 9662) and CalcWGDutyCycleT2 (line 9942).
