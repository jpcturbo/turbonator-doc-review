1. Overview & Purpose

DCRPML sets the lower engine speed threshold below which adaptive wastegate duty cycle learning is completely inhibited.

At low engine speeds, exhaust mass flow is insufficient to spool the turbocharger to full boost, creating an unavoidable physical underboost condition. If the controller attempted to adapt duty cycle at low RPM, it would erroneously wind the adaptive cells up to maximum. DCRPML locks out adaptive learning below this RPM threshold, ensuring that the controller only adapts in engine operating regions where target boost is physically achievable. Shared between T1 and T2 control routines.

3. Tuner's Guide & Real-World Calibration

  • Low-RPM Adaptive Lockout:
  • Inhibits adaptive wastegate learning below this engine speed to avoid learning during natural turbo spool lag.
  • Factory setting is 84 counts (approximately 2688 RPM).
  • Large Turbo Upgrades:
  • Elevate DCRPML to match the real spool-up RPM of large turbochargers (e.g. 3500 to 4000 RPM) to prevent adaptive cell corruption.
  • Stock Turbo Response:
  • Small factory Mitsubishi or Garrett T3 turbos can lower DCRPML to 2200 to 2400 RPM for earlier closed-loop trimming.
  • Shared Code Usage:
  • Enforces low-RPM lockout in both CalcWGDutyCycleT1 (line 9715) and CalcWGDutyCycleT2 (line 9988).
