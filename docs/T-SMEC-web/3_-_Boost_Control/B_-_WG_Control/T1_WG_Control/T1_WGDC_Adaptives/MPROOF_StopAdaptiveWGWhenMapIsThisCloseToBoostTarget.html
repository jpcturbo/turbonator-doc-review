1. Overview & Purpose

MPROOF sets the underboost deadband threshold below target boost where the controller permits adaptive duty cycle incrementing in T1 control.

When manifold pressure is below target, the engine controller calculates the underboost delta. If manifold pressure is within MPROOF of target boost, the boost level is considered sufficiently accurate, and the controller freezes adaptive incrementing to avoid continuous hunting and trim oscillation around the target pressure.

3. Tuner's Guide & Real-World Calibration

  • Underboost Deadband Threshold:
  • Minimum error delta below target (Target - Actual) required to trigger an adaptive duty cycle increment.
  • Factory setting is 0 counts (adapts whenever actual boost is below target).
  • Eliminating Table Churn:

  • Upward Adaptation Gating:
