1. Overview & Purpose

TPSLIM defines the minimum throttle position sensor delta voltage above idle required to permit adaptive wastegate duty cycle incrementing in T1 control.

Adaptive duty cycle learning is designed to calibrate wide-open and heavy-throttle wastegate operation. At light to moderate throttle openings, the throttle blade restricts airflow, making target boost unattainable. TPSLIM prevents the controller from attempting to adapt duty cycle upward unless the accelerator pedal is pressed beyond this calibrated throttle threshold.

2. Operating Conditions (When Does This Take Effect?)

  • Subroutine & Line Numbers: WGDC_IncrementWGAdaptive (T-SMEC_v19.asm:9701-9705), called from CalcWGDutyCycleT1 (T-SMEC_v19.asm:9512-9753).
  • Throttle Delta Evaluation:
  • Line 9701 loads TpsVolts and subtracts MINTHR_LowestSessionTPS at line 9702.
  • If delta is zero or negative (bls), branches to WGDC_ClearBoostErrTimer at line 9703.
  • Line 9704 compares delta against TPSLIM_UpdateAdaptiveWGTPSUpperLimit (cmpa TPSLIM).
  • If delta is below TPSLIM (bcs), branches to WGDC_ClearBoostErrTimer (line 9705), inhibiting adaptive increment.

3. Tuner's Guide & Real-World Calibration

  • Throttle Gating for Adaptive Incrementing:
  • Minimum TPS voltage above idle required to permit adaptive duty cycle increases.
  • Factory setting is 112 counts (approximately 2.2 Volts above session minimum TPS).
  • Preventing Part-Throttle Corruption:
  • Prevents the controller from adding duty cycle when throttle is only partially open and airflow is throttled.
  • Heavy Throttle Lockout:
  • Raising TPSLIM to 3.0 to 3.5 Volts above idle restricts adaptive learning exclusively to wide-open throttle pulls.
  • T1-Specific Architecture:
  • Gated exclusively within the T1 adaptive increment routine (WGDC_IncrementWGAdaptive).
