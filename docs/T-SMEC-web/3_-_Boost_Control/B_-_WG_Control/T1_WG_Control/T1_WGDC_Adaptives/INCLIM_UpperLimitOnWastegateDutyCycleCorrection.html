1. Overview & Purpose

INCLIM establishes the upper clamp boundary for adaptive wastegate cell values, capping the maximum positive duty cycle correction that the adaptive system can add on top of the base table.

In Chrysler's 128-centered adaptive scheme, values above 128 add duty cycle to hold the wastegate closed and raise boost. INCLIM ensures that the adaptive learning loop cannot wind duty cycle up beyond a safe limit if a physical boost leak or wastegate actuator issue occurs. Shared between T1 and T2 control routines.

3. Tuner's Guide & Real-World Calibration

  • Maximum Upward Adaptive Authority:
  • Upper clamp ceiling on adaptive cell values (offset above 128 counts).
  • Factory setting is 255 counts (+127 counts offset, or +63.5 percent maximum duty cycle addition).
  • Safety Clamping for Boost Leaks:
  • Lowering INCLIM to 168 to 188 counts (+20% to +30% duty cycle) limits maximum runaway duty cycle if an intercooler coupler slips.
  • Shared Code Architecture:
  • Referenced in both CalcWGDutyCycleT1 (line 9721) and CalcWGDutyCycleT2 (line 9972).
