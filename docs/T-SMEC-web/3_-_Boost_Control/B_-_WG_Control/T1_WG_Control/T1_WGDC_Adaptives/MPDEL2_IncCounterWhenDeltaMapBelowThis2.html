1. Overview & Purpose

MPDEL2 defines the manifold pressure stability threshold required to permit adaptive wastegate duty cycle incrementing when boost is below target.

Similar to MPDEL1 on the overboost side, MPDEL2 verifies that manifold pressure is steady and not undergoing violent fluctuations or throttle transients before allowing the error timer to advance toward an adaptive duty cycle increase. If the difference between instantaneous manifold pressure and rolling average manifold pressure exceeds MPDEL2, adaptive learning is inhibited. Shared between T1 and T2 control routines.
