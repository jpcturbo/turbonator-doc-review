1. Overview & Purpose

IDLDEF defines the default target idle speed commanded by the engine controller when the coolant temperature sensor signal is invalid or disconnected.

During normal vehicle operation, the SMEC calculates target idle speed dynamically by indexing 2D temperature curves for in-gear and park or neutral states. If the coolant temperature sensor circuit develops a fault, such as a severed wire, high-resistance short, or disconnected harness plug, the controller cannot look up the appropriate warm-up idle target.

Under this failsafe condition, the SMEC replaces the temperature-dependent lookup tables with IDLDEF.

In factory calibrations, IDLDEF is set to 125 counts, which translates to a steady default idle target of approximately 976 RPM (nominally 1000 RPM). This elevated failsafe target ensures the engine remains running reliably without stalling, even if the engine is completely cold when the temperature sensor fails.

  • Enclosing Routine: LoadDiagIdleSpeed (T-SMEC_v19.asm:2080-2133) within CalculateTargetIdleSpeedAndAisPosition_MM.
  • Gating Conditions:

  • Transmission must be in Park/Neutral (b0c_ATXInGear clear at line 2086) or manual transmission.
  • Diagnostic motion flag b50_InMotion must be clear at line 2090.
  • Coolant temperature fault flag b45_BadCoolantTemp in b45_IPL1 must be set at line 2106. If set, branches to L1089, loading IDLDEF directly into accumulator A instead of performing the AISPN curve lookup.

3. Tuner's Guide & Real-World Calibration

  • Failsafe Stall Prevention:
  • For modified street or race engines with lumpy camshaft profiles, increase IDLDEF to 1050 to 1150 RPM to ensure the engine will idle cleanly if the coolant temperature sensor unplugs or fails.
  • Automatic Transmission Safety:
  • Avoid raising IDLDEF above 1150 RPM on automatic vehicles, as this can cause heavy torque converter transmission slam when shifting from Neutral into Drive while in limp mode.
  • Lowering & Cold Misfire:
  • Lowering IDLDEF below 900 RPM risks stalling during cold engine starts if sensor communication is lost.
