1. Overview & Purpose

DANOM defines the base nominal calibration offset utilized by the Chrysler SMEC deceleration airflow calculation.

To provide smooth throttle dashpot cushioning without holding engine speed artificially high, the SMEC calculates a synthetic decel control manifold absolute pressure threshold. This calculated threshold represents the expected intake manifold vacuum curve during closed-throttle overrun.

DANOM serves as the foundational base term to which the learned adaptive airflow integrator is added, followed by coolant temperature, run time, and air conditioning offsets.

In factory calibrations, DANOM is set to 18 counts (approximately 2.1 psi absolute / 4.2 inHg), providing an initial manifold pressure baseline for decel dashpot air calculations.

3. Tuner's Guide & Real-World Calibration

  • Curing Deceleration Stalls:
  • Increase DANOM from 18 to 22 to 26 counts if the engine tends to dip below idle and stall when releasing the throttle abruptly.
  • Lightweight Rotating Assemblies:
  • Raising DANOM provides a stronger electronic dashpot cushion to catch engines with lightened flywheels that lose momentum rapidly.
  • Eliminating High-RPM Decel Hang:
  • If engine speed refuses to drop cleanly when coasting, lower DANOM to reduce the baseline decel control threshold.
