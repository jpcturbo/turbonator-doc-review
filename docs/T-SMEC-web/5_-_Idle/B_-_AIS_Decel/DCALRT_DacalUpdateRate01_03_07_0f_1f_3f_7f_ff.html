1. Overview & Purpose

DCALRT defines the loop counter bitmask that paces the execution frequency of the DACAL adaptive idle airflow integrator.

Adaptive idle air learning compensates for long-term mechanical changes in the engine, such as throttle body carbon buildup, PCV valve wear, or minor vacuum leaks. Because these physical changes occur very slowly over weeks and months, the adaptive learning integrator must update at an extremely deliberate pace so that temporary intake manifold pressure fluctuations are ignored.

DCALRT masks the main program loop counter to enforce a slow learning rate.

In factory calibrations, DCALRT is set to 127 counts, representing a binary bitmask allowing the integrator to adjust only once every 128 main loop passes, or approximately every 1.4 seconds.

2. Operating Conditions (When Does This Take Effect?)

3. Tuner's Guide & Real-World Calibration

  • Dyno Tuning & Fast Learning:
  • Temporarily lower DCALRT to 31 or 15 counts during dyno calibration to accelerate adaptive airflow learning.
  • Street Stability:
  • Retain factory setting of 127 counts (every 128th loop) for normal driving to ensure long-term stability and filter out short-term vacuum perturbations.
  • Mask Formatting:
  • Must be configured as a power-of-two minus one value (15, 31, 63, 127, 255).
