1. Overview & Purpose

TIMEDC is a 2D lookup curve that provides a time-decaying manifold pressure offset added to the deceleration control calculation after engine start.

When an engine has recently started and is driven off-idle, intake manifold runners and cylinder heads are still absorbing heat, and fuel atomization is not yet fully optimized. If the driver lifts off the throttle abruptly during the first minute of driving, the engine is much more vulnerable to deceleration stalling than when fully warm.

TIMEDC is indexed by engine run time and adds an auxiliary boost to the calculated decel control manifold pressure, commanding extra dashpot opening steps from DAISOP.

In factory calibrations, TIMEDC supplies an auxiliary decel offset during the first 11 seconds that smoothly ramps to zero by 21 seconds of engine run time.

3. Tuner's Guide & Real-World Calibration

  • Cold Drive-Away Stall Elimination:
  • Increase TIMEDC offset values and extend the time axis to 30 to 45 seconds if the vehicle dies on gear changes immediately after starting.
  • Warm Restart High Idle Fix:
  • If warm engine restarts produce an extended floating idle during the first 20 seconds of driving, reduce TIMEDC offset points.
  • Table Interpolation:
  • Evaluated smoothly via Lookup4ByteTable using KeyOnOrEngineRunningTime.

5. Calibration Notes & System Dependencies

  • Dual-Table Architecture: Works in parallel with TIMED2; while TIMED2 adds RPM to target idle speed, TIMEDC adds MAP offset to the decel dashpot calculation.
  • Companion Parameter: Summed directly with TEMPDC (coolant offset) and DAACF (A/C offset).
