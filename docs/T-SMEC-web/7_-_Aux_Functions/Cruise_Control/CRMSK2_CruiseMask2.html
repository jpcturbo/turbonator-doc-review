1. Overview & Purpose

CRMSK2 defines the positive accumulated servo error threshold for incrementing the adaptive integrator trim.

While proportional gain curves respond immediately to transient speed changes, persistent highway grades require a steady increase in baseline throttle opening to prevent steady-state speed sag. When accumulated speed error exceeds CRMSK2, the engine controller recognizes that the vehicle is experiencing sustained resistance and increments the learned integrator trim by CRMSK7. In factory calibrations, CRMSK2 is set to 7 counts, establishing a tight threshold for initiating uphill compensation.
