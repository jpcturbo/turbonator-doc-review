1. Overview & Purpose

CRMSK3 defines the negative accumulated servo error threshold for decrementing the adaptive integrator trim.

When descending long highway grades or following sustained tailwinds, vehicle momentum causes speed to sit persistently above target. If accumulated error falls below CRMSK3, the engine controller recognizes that the vehicle is overspeeding and decrements the learned integrator trim by CRMSK4. In factory calibrations, CRMSK3 is set to 244 counts (representing negative 12 signed counts), establishing the trigger boundary for shedding learned uphill throttle trim.
