1. Overview & Purpose

CRSCN1 defines the evaluation interval timer threshold determining how frequently adaptive servo integration and cable slack updates occur.

In the SMEC cruise control algorithm, background counter Counter_Cruise increments on each execution pass. While Counter_Cruise is below CRSCN1, the controller updates cable adaptive delta calculations. Once Counter_Cruise reaches CRSCN1, the controller enters the adaptive integrator routine to evaluate speed error against CRMSK2 and CRMSK3, updates BitFlags_27, and resets the counter. In factory calibrations, CRSCN1 is configured to 21 counts.
