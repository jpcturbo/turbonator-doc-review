1. Overview & Purpose

SETIM1 defines the upper timer qualification boundary paired with SETIME to establish a precise deceleration pulse suppression window.

When the driver presses the coast switch, the deceleration timer increments. If the switch is held long enough to exceed SETIME but released before exceeding SETIM1, the controller recognizes a deliberate moderate coast event and sets status flags to prevent setup pulse lurching. If the switch is held beyond SETIM1, the timer transitions to extended deceleration mode. In factory calibrations, SETIM1 is set to 82 counts, representing approximately 0.91 seconds.

  • If higher or equal (bcc L1728), clears bit 2 (anda #~b2f_bit2).

3. Tuner's Guide & Real-World Calibration

  • Decel Window Boundary:
  • Works with SETIME to define the timed window between 0.61 and 0.91 seconds for coast qualification.
  • Prevents contact bounce or erratic button presses from corrupting cruise state logic.
  • Extended Coast Transition:
  • Once Timer_CruiseDecelerate exceeds SETIM1, bit 2 of CruiseStatus is cleared (anda #~b2f_bit2), returning the state machine to normal switch tracking.
  • Factory Value:
  • Calibrated to 82 counts in stock calibrations; keep stock for standard Chrysler cruise stalks.
