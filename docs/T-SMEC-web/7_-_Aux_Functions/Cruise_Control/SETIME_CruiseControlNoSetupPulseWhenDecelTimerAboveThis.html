1. Overview & Purpose

SETIME defines the deceleration elapsed timer threshold for suppressing or modifying the vacuum setup pre-charge pulse when the driver releases the coast button.

When holding down the coast or decelerate switch, the cruise servo vents and the vehicle slows down. Upon releasing the button, the driver intends to set a new, lower cruising speed. If the controller applied an aggressive vacuum pre-charge pulse immediately upon switch release, the vehicle would abruptly surge forward, causing an uncomfortable jerk. SETIME monitors the deceleration timer; if the button was held longer than SETIME, aggressive pre-charging is suppressed to ensure smooth engagement at the new lower speed.

3. Tuner's Guide & Real-World Calibration

  • Coast-to-Set Behavior:
  • Suppresses aggressive vacuum pre-charge when driver holds the coast button to decelerate.
  • Factory 55 counts (approx 0.61 seconds) ensures smooth handoff to the new lower speed setting.
  • Preventing Decel Surge:
  • If releasing coast causes an immediate forward lurch, lower SETIME to suppress setup pulsing earlier.
  • Secondary Use in Speed Calculation:
  • In CalculateVehicleSpeed (line 8842), if Timer_CruiseDecelerate exceeds SETIME, the servo commands continuous vent to maintain deceleration.
