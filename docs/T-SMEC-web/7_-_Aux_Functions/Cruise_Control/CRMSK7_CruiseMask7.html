1. Overview & Purpose

CRMSK7 defines the step increment added to the adaptive integrator trim when accumulated servo error exceeds CRMSK2.

When a vehicle begins climbing an extended highway grade, proportional gain increases throttle opening, but some speed droop may persist. To eliminate this steady-state offset, the cruise controller slowly steps up the baseline throttle trim by CRMSK7 on each evaluation pass. In factory calibrations, CRMSK7 is set to 1 count, delivering a gradual, steady ramp rate that prevents step-induced throttle oscillations.
