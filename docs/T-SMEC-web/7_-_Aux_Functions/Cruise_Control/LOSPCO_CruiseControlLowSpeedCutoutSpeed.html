1. Overview & Purpose

LOSPCO defines the absolute low-speed safety cutout threshold below which active cruise control will automatically disengage and vent the servo.

While MINSET prevents engaging cruise control below 35 miles per hour, LOSPCO monitors road speed during active cruising. If vehicle speed drops precipitously while cruise is active (for example, encountering sudden traffic congestion, wheel slippage on ice, or spinning the vehicle), LOSPCO immediately vents the servo and returns full throttle control to the driver. In factory calibrations, LOSPCO is set to 1920 counts, corresponding to approximately 30 miles per hour (or 1600 counts / 25 miles per hour in Stage IV calibrations).

3. Tuner's Guide & Real-World Calibration

  • Active Cruising Safety Failsafe:
  • Automatically vents the cruise servo if vehicle speed falls below this threshold during active cruise operation.
  • Prevents the servo from holding throttle open if the vehicle slows down drastically in highway traffic.
  • Stage IV Calibration Setting:
  • Stock 2.5L calibrations use 1920 counts ( ≈ 30 mph); Stage IV calibrations reduce LOSPCO to 1600 counts ( ≈ 25 mph).
  • Distinction from MINSET:
  • MINSET gates initial switch engagement, whereas LOSPCO monitors continuous runtime road speed.
