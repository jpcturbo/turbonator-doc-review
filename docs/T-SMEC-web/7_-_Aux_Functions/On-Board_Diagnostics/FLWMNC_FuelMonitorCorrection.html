1. Overview & Purpose

FLWMNC defines the fuel injector dead-time offset correction historically subtracted from calculated fuel pulse width prior to broadcasting fuel consumption data over the Chrysler Collision Detection network bus.

Electromechanical fuel injectors exhibit opening dead-time delays during which no fuel flows. To ensure that fuel consumption broadcast over the vehicle serial network reflects actual fuel mass rather than electrical opening delays, FLWMNC was subtracted before pulse widths were accumulated into the serial fuel register.

In factory calibrations, FLWMNC is set to 102 counts, corresponding to approximately 102 microseconds (0.102 milliseconds).

However, in Turbonator SMEC firmware v17.0 and later, the assembly instructions referencing FLWMNC are commented out to save CPU execution cycles, leaving the parameter inactive in firmware execution.
