1. Overview & Purpose

MPVACD defines the minimum intake manifold vacuum that the manifold absolute pressure sensor must indicate at closed-throttle idle to prove that it is physically connected to the intake manifold.

If a vacuum line falls off, splits, or the sensor port clogs, the sensor will read atmospheric barometric pressure rather than intake vacuum while the engine is running. Stored as a two-byte word constant, the high byte establishes the minimum vacuum required at sea level, while the low byte establishes the relaxed vacuum required at high altitudes above the BAROSW threshold.

In factory calibrations, MPVACD is configured with two thresholds, representing 17 counts (approximately 4.0 inHg or 2.0 psi vacuum) for the high byte and 8 counts (approximately 1.9 inHg or 0.9 psi vacuum) for the low byte. If measured idle vacuum below atmospheric pressure is less than the active MPVACD threshold, the engine controller flags Fault Code 13 and latches a stuck MAP failure.

3. Tuner's Guide & Real-World Calibration

  • Camshaft Idle Vacuum Accommodation:
  • Performance camshafts produce low idle vacuum that frequently trips false Fault Code 13 codes.
  • Lower the high byte of MPVACD from 17 counts (4.0 inHg) down to 8 to 10 counts (1.9 to 2.4 inHg) to accommodate low-vacuum cams.
  • 3-Bar MAP Sensor Rescaling:
  • Multiply both bytes by 0.667 when upgrading to a 3-bar MAP sensor (reducing 17 counts to 11 counts for sea level, and 8 counts to 5 counts for high altitude).
  • Pneumatic Diagnostics:
  • If Fault Code 13 sets on a stock engine, inspect the small vacuum line connecting the intake manifold to the MAP sensor nipple for cracks or disconnects.
  • Edge Cases:
  • Setting both bytes of MPVACD to zero disables pneumatic vacuum monitoring entirely.
  • Setting MPVACD higher than the engine's physical idle vacuum permanently locks the vehicle into Fault Code 13.
