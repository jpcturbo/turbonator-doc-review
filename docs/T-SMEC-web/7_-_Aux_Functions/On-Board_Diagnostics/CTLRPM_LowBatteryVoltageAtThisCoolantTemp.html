1. Overview & Purpose

CTLRPM specifies the minimum engine coolant temperature required before the engine controller enables diagnostic testing of the oxygen sensor middle-band circuit.

Although the parameter label contains a historical misnomer referring to battery voltage, firmware reverse engineering reveals that it functions as a coolant temperature gate. An unheated or single-wire zirconia oxygen sensor requires hot exhaust gases to reach its operating temperature, and cold-engine warm-up mixtures naturally hold the sensor rich.

To avoid falsely condemning an oxygen sensor while the engine is warming up, the controller suppresses the stuck-in-middle test until coolant temperature reaches CTLRPM.

In factory calibrations, CTLRPM is set to 205 counts, corresponding to approximately 170 deg F. If coolant temperature is below CTLRPM, the controller suspends the oxygen sensor diagnostic timer.

3. Tuner's Guide & Real-World Calibration

  • Low-Temperature Thermostat Tuning:
  • If running a 160 deg F thermostat, lower CTLRPM from 170 deg F down to 150 deg F so the oxygen sensor diagnostic check runs reliably.
  • Template Label Note:
  • Despite the name LowBatteryVoltageAtThisCoolantTemp, this parameter operates in firmware as the coolant temperature gate for oxygen sensor Fault Code 21.
  • Edge Cases:
  • Setting CTLRPM to maximum (255 counts) permanently disables the oxygen sensor middle-band diagnostic.
  • Setting CTLRPM to zero runs oxygen sensor diagnostics during freezing cold starts, triggering false codes.
