1. Overview & Purpose

FUELTR defines the fuel consumption conversion factor used by the engine controller to output fuel flow pulse signals to the dashboard electronic navigator, trip computer, or overhead console.

Chrysler trip computers calculate instant fuel economy, average miles per gallon, and fuel consumed by counting pulses transmitted from the engine controller. Inside the controller, actual commanded fuel injector pulse widths are accumulated into a running hardware timer.

Every time the accumulated injector pulse width reaches the threshold defined by FUELTR, the controller subtracts FUELTR and toggles a dedicated hardware output pin.

In factory calibrations, FUELTR is configured to 670 counts (equivalent to 0.670 milliseconds of injector on-time per output toggle). This conversion factor links physical fuel mass injected to dashboard fuel economy calculations.

3. Tuner's Guide & Real-World Calibration

  • Injector Upgrade Scaling Formula:
  • New FUELTR = Stock FUELTR * (Stock Injector Flow / New Injector Flow)
  • Example: upgrading from stock 33 lb/hr to +40% (46 lb/hr) injectors requires multiplying FUELTR by (33 / 46) ≈ 0.717 (e.g., from 670 down to 480 counts).
  • Restoring Navigator Accuracy:
  • Rescaling FUELTR restores factory accuracy to the dashboard overhead console, trip computer, and instant/average MPG displays.
  • Edge Cases:
  • Setting FUELTR to zero causes continuous pin toggling on every timer tick, freezing or crashing the dashboard trip computer.
  • Setting FUELTR to maximum causes the trip computer to calculate near-zero fuel consumption.

; How the Fuel Monitor works:
; (Geoff Allan)
; The "Navigator" module in the dash receives a signal for every engine rotation. The
; length of time of this signal is dependent on the injector open duration. This gives
; the Navigator the ability to precisely calculate how much fuel is being used for a
; given time or distance, since it now has RPM and injector duty cycle in addition to
; being tapped into the speed/distance sensor. In order to
; accomodate differing injector sizes, the Conversion factor can be changed. Stock T1
; conversion factor is $03a8, if you scale the injectors you need to scale this value
; by the same amount so the Navigator retains its accuracy.
