1. Overview & Purpose

LMPINN provides the engine controller with a synthetic manifold pressure estimate derived from throttle position whenever the primary manifold absolute pressure sensor fails or is disconnected.

Because turbocharged engines rely heavily on manifold pressure to calculate mass airflow demand, a failed pressure sensor would normally render the fuel and ignition algorithms inoperative. When an electrical open circuit or short circuit is detected on the sensor circuit, the engine controller flags Fault Code 14 and transitions to limp-home operation.

During this emergency mode, the controller calculates engine speed and throttle opening, then looks up LMPINN to estimate manifold density across five reference points from closed throttle at deep idle vacuum (-14.7 psi gauge or 0.0 psi absolute) up to approximately 27 percent throttle at light cruising load (-3.3 psi gauge or 11.4 psi absolute). This synthetic manifold pressure table allows the driver to safely navigate the vehicle to a service facility rather than being stranded by a sensor fault.

3. Tuner's Guide & Real-World Calibration

  • 3-Bar MAP Sensor Rescaling:
  • When converting from a factory 2-bar sensor to a 3-bar MAP sensor, the sensor voltage span expands from 29.4 psi absolute to 44.1 psi absolute.
  • Multiply all table pressure output values by 0.667 to maintain factory-equivalent limp-in manifold pressure estimates.
  • Camshaft and Throttle Body Modifications:
  • Large throttle bodies flow substantially more air at small opening angles, requiring higher intermediate points in LMPINN to avoid lean flat spots.
  • High-duration performance camshafts with reduced idle vacuum may require raising the lower table points to match the engine's true airflow.
  • Lowering & Edge Cases:
  • Lowering table points leans out limp-home fueling and advances ignition timing.
  • Setting points to zero produces severe lean misfires when the sensor faults, while setting points to maximum creates rich flooding.

  • Companion Identifiers: Works directly with MPLMOF (simulated MAP offset), THROFF (throttle voltage offset), MAPLOW (lower electrical limit), and MAPHIG (upper electrical limit).
  • Diagnostic Code: Triggered exclusively under DRB-II Fault Code 14 (MAP sensor voltage out of range).
  • Table Format: Type 0 2D curve containing 5 points formatted as 4-byte segments (x, y, dx, dy).
  • 3-Bar MAP Calibration: When upgrading from stock 2-bar to 3-bar MAP, scale all pressure values by 2/3 to prevent excessively rich fueling during limp-home operation.
