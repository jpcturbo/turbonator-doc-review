1. Overview & Purpose

MPDAGH defines the upper manifold pressure boundary for the steady-state manifold absolute pressure sensor rationality validation window.

When testing whether the pressure sensor is healthy and delivering plausible signals, the engine controller requires manifold pressure to stay below heavy load or boost levels. Under wide-open throttle or positive turbocharger boost pressure, rapid airflow changes make steady-state rationality validation unreliable.

In factory calibrations, MPDAGH is set to 129 counts, corresponding to approximately 14.9 psi absolute pressure (roughly 0.2 psi gauge boost or atmospheric barometric pressure). If manifold pressure equals or exceeds MPDAGH, the engine controller suspends the steady-state sensor rationality check, ensuring validation occurs strictly under light-load intake vacuum.

3. Tuner's Guide & Real-World Calibration

  • 3-Bar MAP Sensor Rescaling:
  • Crucial calibration requirement: rescale MPDAGH by multiplying by 0.667 (from 129 counts down to 86 counts) when converting to a 3-bar MAP sensor.
  • Without rescaling, the steady-state check remains active up into positive boost (22 psi absolute), causing false sensor errors.
  • Camshaft Compatibility:
  • Ensure MPDAGH is comfortably above the engine's warm idle manifold pressure.
  • Edge Cases:
  • Setting MPDAGH below normal idle manifold pressure prevents b47_MapOK from ever setting.
  • Setting MPDAGH to maximum (255 counts) allows steady-state validation during peak turbo boost.
