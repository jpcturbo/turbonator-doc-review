1. Overview & Purpose

PTUCNI defines the loop execution decimation bitmask for the Part Throttle Unlock control routine.

To measure meaningful rates of manifold pressure change without being distorted by high-frequency cylinder intake pulsations, the controller samples baseline manifold pressure into RAM variable PTU_MapTemp at a decimated rate. In factory calibrations, PTUCNI is configured to 7 counts (binary 00000111). In each pass through the main program loop, Counter_MainLoop is bitwise AND-ed with PTUCNI. When the result is zero, the controller saves current MapValue into PTU_MapTemp, creating an evaluation timebase that executes every 8th main loop pass (approximately every 80 to 100 milliseconds).

2. Operating Conditions (When Does This Take Effect?)

  • Subroutine & Line Numbers: ControlPTU_MM / PTU_Main (T-SMEC_v19.asm:10393-10401), instruction line 10397.
  • Masking Operation:
  • Loads Counter_MainLoop into accumulator A at line 10396.
  • Bitwise ANDs accumulator A with PTUCNI_PTUCounterTimerIntervalForLoop at line 10397.
  • If non-zero (bne PTU_CheckThrottleForLock), bypasses baseline update.
  • If zero, stores current MapValue into PTU_MapTemp at line 10400.

3. Tuner's Guide & Real-World Calibration

  • Execution Bitmask:
  • 7 counts represents binary mask %00000111, causing baseline MAP update on every 8th main loop pass.
  • Timebase Fidelity:
  • Retain factory setting of 7 counts to ensure all pressure delta thresholds (PTUMP1–PTUMP3) operate on the intended timebase.
  • Distortion Warning:
  • Altering PTUCNI scales apparent pressure change rate, requiring recalibration of all PTU threshold constants.

5. Calibration Notes & System Dependencies

  • Bitmask Behavior: Must be set to a power-of-two minus one (e.g. 1, 3, 7, 15, 31) for clean binary modulo timing.
  • Main Loop Coupling: Clocked by Counter_MainLoop which increments once per foreground main loop pass.
  • Baseline Refresh: Directly manages PTU_MapTemp which feeds all subsequent rate-of-change checks.
