1. Overview & Purpose

EGR15 (ExhGasRecircConstFromRPMLoLimit) establishes the lower engine speed boundary for the Phase 1 Exhaust Gas Recirculation diagnostic baseline sampling window.

The engine controller must verify that the engine is running within an appropriate speed range before recording baseline closed-loop oxygen sensor behavior with the EGR valve operating.

At line 5437, the high byte of engine speed is evaluated against EGR15. Each high-byte RPM count represents 32 RPM. In the factory calibration, EGR15 is set to 255 counts (corresponding to 8160 RPM). Because its companion upper limit is also set to 255, the factory calibration effectively disables engine speed window gating during Phase 1, allowing baseline sampling across the operating range.

3. Tuner's Guide & Real-World Calibration

  • Lowering EGR15: Establishes a real minimum RPM floor for Phase 1 baseline sampling. For example, 50 counts corresponds to 1600 RPM (50 x 32 RPM), preventing testing during slow low-gear residential driving.
  • Factory Bypass (255 counts): Acts as an open gate in stock firmware because both EGR15 and EGR15B are set to 255, relying on off-idle and vacuum checks to validate cruising state.
  • Scaling Mechanics: 1 count equals 32 RPM based on the high byte of the 16-bit engine speed calculation.
  • Window Pairing: Ensure EGR15B is configured higher than EGR15 whenever custom RPM windows are implemented.
