1. Overview & Purpose

EGR11 (ExhGasRecircConstFromMAP) establishes the manual transmission manifold absolute pressure enable threshold for Exhaust Gas Recirculation solenoid control.

On manual transmission configurations, if engine speed does not satisfy the primary RPM threshold, the engine controller evaluates intake manifold pressure as an alternate enable path.

At line 5394, the controller loads EGR11 and compares it against current manifold pressure (MapValue). If manifold pressure exceeds EGR11, the controller allows EGR operation even if engine speed is below the EGR13 threshold. The factory calibration setting of 0 counts disables pressure-based gating, allowing EGR at any manifold pressure on manual vehicles.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosing Routine: ExhGasRecirc_MM (lines 5383–5545), specifically at line 5394.
  • Precondition: cfg_ATX clear (manual transmission) and b4f_OffIdle set.
  • Evaluation Site: Line 5400 (cmpb MapValue).
  • Hysteresis Logic: If EGR is currently off, line 5397 adds EGR12 to accumulator B.
  • Branch Behavior: If MapValue < threshold (bhi L1457), branches to turn EGR off via EGR_SetEGRtoOff.

3. Tuner's Guide & Real-World Calibration

  • Manual Transmission Logic: Evaluated only on manual transmission vehicles (cfg_ATX clear). Bypassed on automatics.
  • Alternate Enable Gate: Serves as an alternate check at line 5400; if engine speed check fails, exceeding EGR11 permits EGR to continue.
  • 3-Bar MAP Sensor Scaling: For non-zero settings, multiply by 0.667 to compensate for 3-bar sensor calibration slope.
  • Factory Calibration: 0 counts allows EGR under any intake manifold pressure on stock manual vehicles.

4. Technical / Assembly Mechanics (Reference)

Inside T-SMEC_v19.asm: In ExhGasRecirc_MM, if cfg_ATX is clear, line 5394 loads EGR11_ExhGasRecircConstFromMAP into accumulator B. If EGR is currently off, line 5397 adds EGR12 to B (addb EGR12_ExhGasRecircConstFromMAP). At line 5398, if EngineRpm_HB was insufficient to branch to L1456, execution falls into line 5400, which executes cmpb MapValue. If B exceeds MapValue (intake pressure is below the threshold), line 5401 branches via bhi L1457 to set bit 4 in EGRVar2 and jump to EGR_SetEGRtoOff. If MapValue >= B, execution advances to L1456 to continue enable checks.
