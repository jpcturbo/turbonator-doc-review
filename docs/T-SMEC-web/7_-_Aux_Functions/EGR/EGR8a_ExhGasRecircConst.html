1. Overview & Purpose

EGR8A (ExhGasRecircConst8a) is an unreferenced single-byte calibration constant residing in the Exhaust Gas Recirculation calibration memory block. Positioned immediately following EGR8, this byte holds a factory value of 249 counts.

Comprehensive disassembly and reverse engineering of T-SMEC_v19.asm confirms that no executable CPU instruction loads, tests, or references this memory location. At line 5445 of the firmware, the CPU executes an 8-bit load of EGR8 and immediately proceeds to subtraction math, completely bypassing EGR8A.

Consequently, this parameter has no active function in the engine controller firmware.

4. Technical / Assembly Mechanics (Reference)

Inside T-SMEC_v19.asm: Inspection of the assembly source confirms that EGR8a_ExhGasRecircConst appears in the calibration template data table at org 0x8835 with value 0xF9 (249 decimal). However, in ExhGasRecirc_MM, line 5445 performs an 8-bit load ldab EGR8_ExhGasRecircConst from org 0x8834.
