1. Overview & Purpose

ADMEMA (ValueFromAdaptivememoryAdder1) establishes an adaptive memory fuel trim modifier offset applied specifically while Phase 2 of the Exhaust Gas Recirculation diagnostic verification routine is running.

During Phase 2, the engine controller commands the EGR valve closed to observe whether closed-loop oxygen sensor feedback registers a corresponding shift. In the adaptive memory calculation at line 6180, if Phase 2 is active, the controller adds ADMEMA directly to the closed-loop integrator before applying final fuel pulsewidth scaling.

The factory calibration setting of 0 counts injects zero offset, allowing the closed-loop feedback loop to respond naturally to the change in cylinder gas composition without artificial fuel trim bias.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosing Routine: INCLUDE_ADAPTIVE_MEMORY (lines 6160–6200), inside CalculateSumOfAllFuelModifiers_MM.
  • Instruction Line: Line 6180 (addb ADMEMA_ValueFromAdaptivememoryAdder1).
  • Precondition Flag: Bit 7 of EGRVar2 set (brclr *EGRVar2, #bit_bit7, L1527 falls through to line 6180).
  • Input Variable: Counter_PrimaryAndSecondaryRamp (RAM address 0x002B) loaded in accumulator B.
  • Clamping Logic: If addition overflows (bvc L1527 not taken), clamps accumulator B to 127 (ldab #0x7f).

3. Tuner's Guide & Real-World Calibration

  • Raising ADMEMA: Injects positive fuel trim offset into the closed-loop integrator during Phase 2 flow verification, enriching injector pulsewidth during the test.
  • Diagnostic Impact: Artificially inflating the integrator during Phase 2 distorts the delta calculation (EGR7), creating a risk of false pass results on vehicles with inoperative or blocked EGR valves.
  • Overflow Clamping: The assembly math clamps at 127 counts (signed 8-bit positive ceiling) if addition overflows the signed 8-bit limit.
  • Factory Recommendation: Keep at 0 counts to maintain accurate stoichiometric closed-loop feedback.

4. Technical / Assembly Mechanics (Reference)

Inside T-SMEC_v19.asm: In routine INCLUDE_ADAPTIVE_MEMORY, after applying adaptive memory cell fuel trim, the CPU initializes accumulator A to zero at line 6177 and loads Counter_PrimaryAndSecondaryRamp into accumulator B at line 6178. Line 6179 tests bit 7 of EGRVar2 (brclr *EGRVar2, #bit_bit7, L1527). During normal operation, bit 7 is clear, branching to L1527. When Phase 2 EGR diagnostic flow testing is active, bit 7 is set; execution falls into line 6180, which executes addb ADMEMA_ValueFromAdaptivememoryAdder1 (factory 0x00 = 0). Line 6181 tests for two's complement overflow (bvc L1527); if overflow occurred, line 6182 clamps B to positive maximum 0x7F (127 decimal). Execution then continues to scale pulsewidth.
