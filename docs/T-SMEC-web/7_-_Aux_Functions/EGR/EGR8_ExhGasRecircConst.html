1. Overview & Purpose

EGR8 (ExhGasRecircConst) establishes the exponential smoothing filter coefficient for the Phase 1 baseline oxygen sensor fuel trim calculation.

While operating steadily within the Phase 1 diagnostic window with the EGR valve open, the engine controller continuously samples the closed-loop fuel trim integrator (Counter_PrimaryAndSecondaryRamp). Because individual oxygen sensor switching transitions cause instantaneous fuel trim oscillations, the controller applies a first-order digital lag filter to establish a steady, reliable baseline (EGRVar5).

At line 5445, EGR8 is loaded as the multiplier for the filter delta. The factory calibration setting of 13 counts applies approximately 5.1 percent weighting per background loop iteration, providing smooth and stable baseline tracking.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosing Routine: ExhGasRecirc_MM (lines 5383–5545), specifically at line 5445.
  • Execution Path: Phase 1 active (EGRVar2 bit 7 clear) and all window checks (EGR18, EGR14, EGR15, EGR3) satisfied.
  • Filter Input: Counter_PrimaryAndSecondaryRamp evaluated against baseline accumulator EGRVar5 (RAM address 0x009F).
  • Filter Output: Updated EGRVar5 stored at line 5454.
  • Return Target: Branches via bra L1465 to jump to EGR_SetEGRtoOn.

3. Tuner's Guide & Real-World Calibration

  • Raising EGR8: Increases filter responsiveness, allowing EGRVar5 to track the closed-loop integrator more rapidly during Phase 1. Helpful if EGR1 has been reduced to shorten test duration.
  • Lowering EGR8: Increases baseline smoothing, heavily filtering out transient closed-loop oscillations. Requires longer cruising periods to reach a true steady-state baseline.
  • Filter Formula: EGRVar5_new = EGRVar5_old + ((Ramp - EGRVar5_old) * EGR8) / 256.
  • Factory Calibration: 13 counts (approx 5.1 percent weighting per loop pass) delivers excellent noise rejection.
