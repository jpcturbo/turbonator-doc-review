1. Overview & Purpose

EGR17A (ExhGasRecircConstHiLimit17a) establishes the upper engine speed boundary for the Phase 2 Exhaust Gas Recirculation diagnostic flow verification window (Fault Code 32).

Positioned immediately following EGR17 in calibration ROM, this constant caps the maximum engine speed allowed while the engine controller commands the EGR valve closed and tests for oxygen sensor response. If the driver downshifts or accelerates and engine speed exceeds EGR17A, the boundary checking routine aborts Phase 2 and resets the diagnostic sequence.

In the factory calibration, EGR17A is set to 255 counts (8160 RPM), allowing the shutoff flow test to execute across the entire engine speed cruising spectrum.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosing Routine: ExhGasRecirc_MM (lines 5383–5545), specifically via call at line 5499.
  • Subroutine Called: EGR_CheckHiLoLimits (lines 5462–5468), specifically line 5465.
  • Input Variable: EngineRpm_HB evaluated in accumulator A against offset 0x01,x.
  • State Condition: Phase 2 active (EGRVar2 bit 7 set).
  • Branch Behavior: If EngineRpm_HB > EGR17A (bhi L1464), subroutine discards stack frame (pulx) and branches to EGR_ResetEGRVars.

3. Tuner's Guide & Real-World Calibration

  • Lowering EGR17A: Caps the maximum RPM allowed during Phase 2 flow verification. Useful to prevent testing at high RPM where closed-loop fueling transitions are more dynamic.
  • Factory Ceiling (255 counts): Keeps the upper boundary wide open up to 8160 RPM in stock calibrations.
  • Window Logic: Must always be configured greater than or equal to EGR17.
  • Scaling: Scaled at 32 RPM per count based on the high byte of engine speed.
