1. Overview & Purpose

EGR17 (ExhGasRecircConstLoLimit) establishes the lower engine speed boundary for the Phase 2 Exhaust Gas Recirculation diagnostic flow verification window (Fault Code 32).

During Phase 2, the engine controller de-energizes the EGR solenoid to shut off exhaust gas flow and monitors closed-loop oxygen sensor feedback to confirm a corresponding shift in mixture. To ensure that exhaust gas flow shutoff produces a measurable and repeatable change, the engine speed must remain within the window bounded by EGR17 and EGR17A.

In the factory calibration, EGR17 is set to 255 counts (8160 RPM). Because companion high limit EGR17A is also set to 255, the factory calibration leaves the Phase 2 engine speed window open across all cruising speeds.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosing Routine: ExhGasRecirc_MM (lines 5383–5545), specifically at line 5498.
  • Subroutine Called: EGR_CheckHiLoLimits (line 5462).
  • State Condition: Phase 2 active (EGRVar2 bit 7 set).
  • Input Variable: EngineRpm_HB (RAM address 0x001B) loaded into accumulator A.
  • Branch Behavior: If EngineRpm_HB < EGR17 (bcs L1464), subroutine pulls stack and jumps to EGR_ResetEGRVars.

3. Tuner's Guide & Real-World Calibration

  • Lowering EGR17: Establishes a lower RPM boundary for Phase 2 flow verification. For example, 50 counts enforces 1600 RPM minimum.
  • Factory Calibration (255 counts): Operates as an open gate in stock firmware alongside companion EGR17A.
  • Camshaft Upgrades: On engines with long-duration performance camshafts, setting an active RPM floor (e.g. 60 counts / 1920 RPM) prevents testing in low-RPM ranges where reversion dilutes exhaust gas flow signals.
  • Pair Coordination: Must be calibrated lower than companion upper limit EGR17A.

5. Calibration Notes & System Dependencies

  • Paired Calibration Entry: Forms an indexed low/high limit pair with companion constant EGR17A at adjacent ROM address 0x1A89 (org 0x882C).
  • Phase 2 Specific: Evaluated exclusively during active EGR shutoff testing, independent of Phase 1 baseline tracking (EGR15).
  • Scaling: High-byte resolution of 32 RPM per integer count.
