1. Overview & Purpose

EGR3 (ExhGasRecircConst) establishes the maximum allowable closed-loop fuel trim ceiling during Phase 1 of the Exhaust Gas Recirculation diagnostic verification routine.

When evaluating EGR operation, the engine controller requires a stable baseline fuel mixture. If closed-loop oxygen sensor feedback is driving the fuel mixture excessively rich, the baseline calculation becomes unreliable because the feedback integrator is operating near its upper authority limit.

At line 5440, the controller compares its primary and secondary closed-loop ramp counter against EGR3. The factory calibration of 128 counts represents neutral closed-loop authority. If the fuel trim integrator reaches or exceeds 128 counts, the controller aborts Phase 1 and resets the diagnostic timer, preventing an invalid baseline.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosing Routine: ExhGasRecirc_MM (lines 5383–5545), specifically at line 5440.
  • Preconditions Checked: Vehicle operating in Phase 1 (EGRVar2 bit 7 clear), and all three Phase 1 window checks (EGR18 MAP, EGR14 TPS, EGR15 RPM) passed successfully.
  • Input Variable: Counter_PrimaryAndSecondaryRamp (RAM address 0x002B), the closed-loop O2 integrator.
  • Comparison: cmpa EGR3_ExhGasRecircConst.
  • Branch Behavior: If Counter_PrimaryAndSecondaryRamp >= EGR3 (bge EGR_ResetEGRVars), aborts Phase 1, resets EGRVar3 to zero, and clears diagnostic test flags. If below EGR3, increments EGRVar3 and proceeds with baseline filtering.

3. Tuner's Guide & Real-World Calibration

  • Raising EGR3: Permits Phase 1 baseline sampling under richer closed-loop integrator states. Helpful if aftermarket injectors or fuel pressure variations cause the closed-loop ramp counter to ride higher than stock during part-throttle cruise.
  • Lowering EGR3: Restricts Phase 1 testing to leaner or closer-to-neutral fueling conditions. If lowered too far (below 100 counts), normal transient fueling shifts may frequently abort Phase 1, preventing the EGR monitor from ever finishing.
  • Zeroing Edge Case: Setting EGR3 to 0 causes line 5441 to branch to EGR_ResetEGRVars whenever the ramp counter is positive, effectively locking the diagnostic monitor out of Phase 2 and preventing Fault Code 32 from setting on decat or modified vehicles.
  • Factory Setting: 128 counts represents half-scale of the signed 8-bit closed-loop ramp integrator, providing a balanced threshold for stock calibrations.
