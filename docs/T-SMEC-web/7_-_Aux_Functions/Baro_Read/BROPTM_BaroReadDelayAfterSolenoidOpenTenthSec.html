1. Overview & Purpose

BROPTM defines the pneumatic stabilization delay after the barometric read solenoid is energized before the engine controller reads the manifold absolute pressure sensor voltage.

When the baro solenoid is energized, it closes the port connecting the sensor to intake manifold vacuum and opens a vent to underhood atmospheric air. Because air must physically flow through the vacuum harness to fill the vacuum line and sensor cavity up to atmospheric pressure, an instantaneous reading would measure residual vacuum, falsely recording lower barometric pressure. In factory calibrations, BROPTM is set to 9 counts, providing approximately 0.10 seconds (100 milliseconds) of pressure equalization time before sampling.

  • Subroutine & Line Numbers: ReadBaroIfPossible / THROTTLE_HASNTCHANGED_STILLNOTPRESSED (T-SMEC_v19.asm:1518-1529), instruction line 1523.
  • State Context:
  • Solenoid energized; waiting for pressure equalization.
  • Timer Comparison:
  • Timer_BaroReadInterval is incremented each pass.
  • Compares timer against BROPTM_BaroReadDelayAfterSolenoidOpenTenthSec at line 1523.
  • If timer is less than BROPTM (bcs R1028), branches to exit while air fills the sensor line.
  • Once satisfied, sets b51_BaroSolEnergized and b54_BaroOkEngineStopped to trigger sensor read.

3. Tuner's Guide & Real-World Calibration

  • Long Vacuum Hose Routing:
  • Raise BROPTM to 14 to 18 counts (150 to 200 ms) if relocated pressure sensors use extended vacuum lines.
  • Pneumatic Dampener Installations:
  • Inline orifice restrictors or filters slow venting; increase BROPTM to allow complete atmospheric equalization.
  • Under-Reporting Prevention:
  • Never set BROPTM below 6 counts (~60 ms) to avoid sampling lingering manifold vacuum.
