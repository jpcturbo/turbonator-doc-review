1. Overview & Purpose

BRCLTM defines the pneumatic stabilization delay after the barometric read solenoid is de-energized before the engine controller resumes using sensor readings for manifold pressure calculations.

After the atmospheric barometric reading has been captured, the controller de-energizes the solenoid, closing the atmospheric vent and reconnecting the sensor to the intake manifold. Because the sensor cavity and vacuum line are filled with atmospheric air, manifold vacuum must draw this air out to restore true engine vacuum. In factory calibrations, BRCLTM is configured to 9 counts, providing approximately 0.10 seconds (100 milliseconds) for line vacuum re-establishment before the controller trusts MAP sensor data.

2. Operating Conditions (When Does This Take Effect?)

  • Subroutine & Line Numbers: ReadBaroIfPossible / L1025 (T-SMEC_v19.asm:1530-1539), instruction line 1533.
  • Precondition: Atmospheric reading complete; solenoid transitioning back to intake vacuum.
  • Delay Verification:
  • Compares Timer_BaroReadInterval against BRCLTM_BaroReadDelayAfterSolenoidClosedTenthSec at line 1533.
  • If delay is incomplete (bcs R1028), branches to exit while line re-evacuates.
  • When expired, clears active flags and zeroes interval timer at line 1538.

3. Tuner's Guide & Real-World Calibration

  • Preventing False Tip-In Enrichment:
  • If BRCLTM is too short, residual atmospheric air looks like manifold boost, triggering false acceleration enrichment.
  • Hose Volume Compensation:
  • Increase BRCLTM to 12 to 15 counts (130 to 160 ms) if relocated sensors use long vacuum plumbing.
  • Quick Throttle Recovery:
  • Retaining ~100 ms ensures rapid return to closed-loop fuel and spark tracking.
