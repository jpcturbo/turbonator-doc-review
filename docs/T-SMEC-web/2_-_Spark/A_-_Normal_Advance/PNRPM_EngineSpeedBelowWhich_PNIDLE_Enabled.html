1. Overview & Purpose

PNRPM defines the maximum engine speed threshold below which Park/Neutral idle spark trim (PNIDLE) is permitted to operate.

Park/Neutral spark compensation is designed strictly for low-speed idle stabilization when shifting between Drive and Neutral. If an automatic transmission vehicle is shifted into Neutral while coasting at speed or free-revved in Neutral, applying idle spark trims at high RPM could cause erratic timing jumps or disrupt deceleration engine braking. PNRPM enforces an engine speed ceiling to ensure that Park/Neutral trims are confined strictly to the low-speed idle window. In factory calibrations, PNRPM is set to 125 counts, corresponding to approximately 1000 RPM.

3. Tuner's Guide & Real-World Calibration

  • High-Idle Calibrations:
  • If target idle speed is raised above stock (e.g., 1100 RPM for race converters or large cams), raise PNRPM proportionally to ensure the controller recognizes the engine as being within the idle timing zone.
  • Disabling Park/Neutral Trims:
  • Setting PNRPM to 0 disables PNIDLE trims across all engine speeds.
  • Coasting Stability:
  • Keeping PNRPM near factory levels prevents timing fluctuations when shifting to Neutral while rolling.
