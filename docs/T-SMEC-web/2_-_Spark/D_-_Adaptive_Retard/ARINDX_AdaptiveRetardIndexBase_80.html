1. Overview & Purpose

ARINDX defines the increment step size added to the adaptive retard index (AdaptiveRetardIndex) whenever persistent combustion detonation under boost is confirmed.

The engine controller monitors cylinder knock retards while operating above 5 psi of turbocharger boost. When knock retards persist for the full duration of ARTM5P, the controller recognizes sustained detonation and adds ARINDX to AdaptiveRetardIndex (clamped at 255 = 100% adaptive authority). In factory calibrations, ARINDX is set to 128 counts, representing an immediate 50% jump in learned adaptive retard on the first confirmed persistent knock cycle.

3. Tuner's Guide & Real-World Calibration

  • Learning Aggressiveness:
  • Factory setting of 128 counts (50% step) reaches maximum adaptive retard after just two persistent knock detection cycles.
  • Softer Accumulation:
  • Lowering ARINDX to 64 counts provides four discrete 25% learning stages, preventing abrupt power loss on mild knock events.
  • Disabling Learning:
  • Setting ARINDX to 0 locks AdaptiveRetardIndex at zero, preventing any adaptive retard accumulation.
