1. Overview & Purpose

ARCMS2 defines a loop counter bitmask evaluated when all four cylinders have zero active knock retard during wastegate duty cycle processing.

When combustion is clean and no cylinders are knocking, the engine controller evaluates Counter_MainLoop against ARCMS2 before decaying the boost knock persistence timer (Timer_Over5PsiBoostMaxFF). In factory calibrations, ARCMS2 is set to 0 counts (binary mask 0), ensuring that the bit test passes unconditionally on every loop pass so that the boost knock timer is immediately cleared once knock ceases.

2. Operating Conditions (When Does This Take Effect?)

  • Subroutine & Line Numbers: WGDC_LookAtCylRetards (T-SMEC_v19.asm:9542-9544), called from CalcWGDutyCycleT1.
  • Gating Conditions:
  • Reached after checking all cylinders (from Cylinder2Retard to Cylinder4Retard) and finding zero active retard.
  • Bitmask Test:
  • bita ARCMS2_AdaptiveRetardCounterMask2_00 tests Counter_MainLoop.
  • If masked bits are non-zero (bne L2858), branches to skip timer decay.
  • If zero, falls through to line 9545 to decay the timer using ARCMS3.

3. Tuner's Guide & Real-World Calibration

  • Factory Setting Retention:
  • Leave ARCMS2 at 0 to ensure prompt, immediate evaluation of timer decay when knock ceases.
  • Bitmask Behavior:
  • If altered, must be configured as a valid 2^N - 1 bitmask.
  • Decay Gate:
  • Works in tandem with ARCMS3 to clear Timer_Over5PsiBoostMaxFF.

4. Technical / Assembly Mechanics (Reference)

Inside T-SMEC_v19.asm: In WGDC_LookAtCylRetards, after looping through all four cylinder retard variables and finding zero retard, line 9541 compares index register X to #Cylinder4Retard. Once past the last cylinder, line 9543 executes bita ARCMS2_AdaptiveRetardCounterMask2_00. If any masked bit in Counter_MainLoop is set (bne L2858), execution skips decay. With ARCMS2 set to 0, the branch is never taken, allowing immediate execution of line 9545.
