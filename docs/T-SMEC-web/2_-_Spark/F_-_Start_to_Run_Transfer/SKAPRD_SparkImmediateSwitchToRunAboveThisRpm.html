1. Overview & Purpose

SKAPRD defines the instantaneous engine speed distributor pulse period threshold that triggers immediate transfer from cranking Start Mode into running Run Mode, bypassing all pulse countdown timers.

Under normal cranking, the engine controller requires the engine to cross above STRNTR (approximately 612 RPM) for several consecutive cylinder firing events (SRTIME or SRTIME2) before authorizing dynamic ignition timing. However, if the engine flares vigorously upon firing and revs past SKAPRD (factory setting 36 counts, corresponding to approximately 833 RPM), waiting for multiple consecutive pulses is unnecessary. SKAPRD provides an immediate transfer bypass: once engine speed crosses 833 RPM, the controller switches instantly into Run Mode.

3. Tuner's Guide & Real-World Calibration

  • Immediate Flare Bypass:
  • If engine speed exceeds 833 RPM on start flare, SKAPRD bypasses SRTIME consecutive pulse counting and locks in Run Mode immediately.
  • Cold Start Flare Tuning:
  • On alcohol or cold weather setups that flare softly, raising SKAPRD to 42 counts (~714 RPM) ensures immediate engagement of dynamic idle ignition timing.
  • Period Scaling:
  • Period is inversely related to RPM: RPM ≈ 30,000 / count. Factory setting 36 counts = 833 RPM.
