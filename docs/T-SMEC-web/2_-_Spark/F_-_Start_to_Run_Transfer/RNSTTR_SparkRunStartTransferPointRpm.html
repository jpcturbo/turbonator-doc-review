1. Overview & Purpose

RNSTTR defines the stall-detection hysteresis distributor pulse period threshold that drops ignition control back from running Run Mode into cranking Start Mode.

Once an engine is running, sudden clutch engagement, severe electrical loading, or abrupt idle undershoot can cause engine speed to sag toward a stall. In period-based logic, a sagging engine speed produces an increasing pulse period. If the distributor pulse period exceeds RNSTTR (engine speed falls below approximately 422 RPM in factory calibrations), the engine controller recognizes that self-sustaining engine operation has ceased. It sets the dwell disable flag and transitions ignition back to cranking mode (fixed base trigger timing and full cranking dwell) to assist immediate restart.

3. Tuner's Guide & Real-World Calibration

  • Stall Recovery Hysteresis:
  • Factory setting of 422 RPM (71 counts) sits well below idle speed (850 to 950 RPM), providing a wide 400+ RPM buffer against accidental stall triggering.
  • Anti-Lug Drivability:
  • Raising RNSTTR allows manual transmission drivers to lug the engine down to 350 RPM without the controller abruptly switching to locked cranking spark advance.
  • Period Inversion Reminder:
  • Higher period values correspond to lower engine speeds (Period = 30000 / RPM).
