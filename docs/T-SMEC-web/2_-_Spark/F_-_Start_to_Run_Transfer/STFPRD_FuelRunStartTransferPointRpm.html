1. Overview & Purpose

STFPRD defines the fuel injection run-to-start stall hysteresis distributor pulse period threshold.

Once the engine is running on normal speed-density fuel calculations, if engine speed sags severely (such as during abrupt clutch release, severe load, or an impending stall), speed-density manifold pressure readings become erratic and fuel injectors cannot deliver stable small pulsewidths. If the distributor pulse period exceeds STFPRD (engine speed falls below approximately 460 RPM in factory calibrations), the engine controller recognizes an impending stall, drops running fuel mode, and re-engages starting/cranking fuel enrichment logic to catch the falling engine and prevent stalling.
