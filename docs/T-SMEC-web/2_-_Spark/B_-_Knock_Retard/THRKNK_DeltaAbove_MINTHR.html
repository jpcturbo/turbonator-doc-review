1. Overview & Purpose

THRKNK defines the throttle position sensor voltage delta above minimum session idle TPS (MINTHR) required to activate the low-RPM knock retard limit (KNKLIM).

The engine controller continuously tracks the lowest closed-throttle TPS voltage recorded during the driving session (MINTHR). When the throttle is opened beyond MINTHR by more than THRKNK while operating below KLMRPM, the controller recognizes a high-load low-speed acceleration event and activates the KNKLIM retard ceiling. In factory calibrations, THRKNK is set to 83 counts, corresponding to approximately 1.63 Volts above base idle position.

  • If delta >= THRKNK, execution continues to evaluate KLMRPM.

3. Tuner's Guide & Real-World Calibration

  • Throttle Threshold Tuning:
  • Factory setting of 1.63 Volts (~33% throttle opening) ensures KNKLIM only engages during substantial pedal tip-in.
  • Throttle Body Upgrades:
  • When installing larger aftermarket throttle bodies (e.g., 52mm or 58mm), airflow increases faster with pedal angle; raising THRKNK prevents premature clamping.
  • Gating Companion:
  • Works directly with MINTHR_LowestSessionTPS and KLMRPM to gate KNKLIM.

  • Relative Delta: Evaluated strictly as a delta above MINTHR, compensating automatically for throttle cable stretch or thermal drift.
  • Scaling: 1 count ≈ 0.0196 Volts (5.0V / 255). Factory setting 0x53 = 83 counts ≈ 1.63 Volts.
