1. Overview & Purpose

RPMLIM establishes the upper engine speed limit for closed-loop oxygen sensor feedback and adaptive fuel memory updates.

At high engine speeds, rapid valve timing and high exhaust gas velocity reduce the precision of narrowband oxygen sensor feedback, while engine load demands favor rich, open-loop power enrichment.

In factory calibrations, RPMLIM is configured to 86 counts in high-byte RPM scaling (where each count represents 32 RPM), setting the threshold at 2752 RPM. Above this speed, the engine controller locks out closed loop and operates in open loop.
