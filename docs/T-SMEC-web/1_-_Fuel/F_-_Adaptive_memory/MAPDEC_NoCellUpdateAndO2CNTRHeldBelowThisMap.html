1. Overview & Purpose

MAPDEC defines the minimum manifold absolute pressure floor below which closed-loop oxygen sensor feedback is held in open loop and adaptive cell updates are blocked.

During deep deceleration overrun, manifold pressure drops to high vacuum levels where combustion is unstable and deceleration fuel cutoff or extreme leanout may occur. The narrowband oxygen sensor reads false lean during overrun, which would corrupt adaptive trims if feedback remained active.

In factory calibrations, MAPDEC is set to 20 counts, corresponding to approximately 2.3 psia or 25.3 inHg of vacuum.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosing Subroutine: HandleO2Processing_MM (T-SMEC_v19.asm:2970-2980 and 3076-3080), instruction lines 2973 and 3079.
  • Gating Conditions: Evaluated at the very entrance of O2 feedback processing on every main loop pass.
  • Comparison & Branch Polarity:
  • MapValue is loaded into register B and compared against MAPDEC_NoCellUpdateAndO2CNTRHeldBelowThisMap via cmpb.
  • If MapValue <= MAPDEC (bls), execution branches to O2_SetStayOpenLoopFlag (line 2985), setting bit b50_StayOpenLoop.
  • In O2Signal_BelowToggle (line 3079), if MapValue <= MAPDEC (bls), execution branches to SwitchOrStayOpenLoop.

3. Tuner's Guide & Real-World Calibration

  • High-Vacuum Deceleration Overrun:
  • When lifting off the throttle at speed, manifold pressure plunges below MAPDEC, forcing open loop and freezing the O2 feedback counter to prevent false lean trims.
  • Disabling Closed-Loop Globally:
  • Setting MAPDEC to 255 counts locks the engine permanently in open loop across all operating conditions.
  • 3-Bar MAP Sensor Rescaling:
  • On a 3-bar sensor, 2.3 psia sits at approximately 13 counts; failing to rescale causes the decel threshold to shift upward into light cruise vacuum.
  • Camshaft Upgrades:
  • If a high-overlap cam reduces overrun vacuum, raise MAPDEC slightly to ensure deceleration fuel cut and open-loop lockout engage cleanly.

5. Calibration Notes & System Dependencies

  • Companion Parameters: Directly gates Counter_PrimaryRamp and works with MAPLIM (upper MAP limit) and BOOSTP.
  • Global Open-Loop Hack: Setting MAPDEC to 255 counts (0xFF) holds b50_StayOpenLoop permanently set, providing a clean method to run full open loop.
  • Sensor Scaling: 20 counts represents 2.3 psia (25.3 inHg vac) on a 2-bar sensor, and 3.5 psia on a 3-bar sensor.
