1. Overview & Purpose

DLTMAP establishes the directional manifold absolute pressure hysteresis added to each boundary point when determining whether to transition into a higher-load adaptive memory cell.

Without hysteresis, small manifold pressure pulses caused by intake valve events could cause the engine controller to rapidly bounce between adjacent cells when cruising precisely at a boundary line.

In factory calibrations, DLTMAP is set to 2 counts, corresponding to approximately 0.23 psi or 0.47 inHg of vacuum. This provides a stable deadband that prevents cell chatter and ensures consistent long-term fuel trim learning.

3. Tuner's Guide & Real-World Calibration

  • Camshaft and Pulsation Damping:
  • Increasing DLTMAP to 3 or 4 counts stabilizes cell selection on engines with erratic intake vacuum caused by high-overlap camshafts.
  • Cell Switching Responsiveness:
  • Lowering DLTMAP to 1 count allows faster cell transitions during throttle movement, but setting to zero causes boundary chatter.
  • 3-Bar MAP Sensor Rescaling:
  • Because each count on a 3-bar sensor represents 0.173 psi rather than 0.115 psi, leaving DLTMAP at 2 counts widens the physical hysteresis window to 0.35 psi.
