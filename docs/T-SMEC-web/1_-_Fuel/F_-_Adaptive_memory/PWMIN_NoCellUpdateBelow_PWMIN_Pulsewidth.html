1. Overview & Purpose

PWMIN establishes the absolute minimum injector pulse width required before the engine controller will permit an adaptive fuel memory cell update.

At very short pulse widths, such as during deceleration or light coastdown, fuel injector opening and closing dead times represent a large percentage of total injection duration, causing non-linear fuel flow delivery that does not represent accurate engine volumetric efficiency.

In factory calibrations, PWMIN is set to a 16-bit value of 275 counts, which corresponds to 1100 microseconds (1.10 milliseconds) of total effective injection time. If calculated pulse width falls below PWMIN, adaptive cell updating is blocked.

3. Tuner's Guide & Real-World Calibration

  • Large Injector Scaling:
  • When upgrading from stock 27 lb/hr injectors to 42 lb/hr or larger injectors, base idle pulse width drops below 1.10 ms. PWMIN must be reduced to 0.70-0.85 ms (175-212 counts) to allow adaptive learning at idle.
  • 16-Bit Word Units:
  • Stored as a 16-bit word where each count represents 4 microseconds (275 counts = 1100 us = 1.10 ms).
  • Non-Linear Injector Guard:
  • Blocks adaptive updates when injectors operate in their non-linear opening/closing dead-time regime.
