1. Overview & Purpose

AMTPSW is a two-dimensional lookup table that establishes the initial delay time before adaptive fuel memory learning is enabled, indexed against engine coolant temperature.

Because engines experience transient wall-wetting and changing mechanical friction during warmup, long-term fuel trim learning must be suppressed until combustion chamber temperatures reach stability.

In stock calibrations, AMTPSW specifies a brief delay of approximately 34 seconds at 106 degF and up to approximately 179 seconds near 196 degF. The output of this table initializes the adaptive countdown timer, ensuring that fuel trims do not adapt based on transient warmup conditions.

3. Tuner's Guide & Real-World Calibration

  • Dyno Tuning Strategy:
  • Increasing values across the table holds off adaptive learning, allowing raw wideband data collection without fuel trim corruption.
  • Street Calibration:
  • Lowering table values allows the engine controller to adapt to ethanol fuel blends and seasonal fuel variations more rapidly after engine start.
  • Zeroing Values:
  • Setting table outputs to zero enables adaptive learning immediately upon entering closed loop, provided coolant temperature conditions are met.
