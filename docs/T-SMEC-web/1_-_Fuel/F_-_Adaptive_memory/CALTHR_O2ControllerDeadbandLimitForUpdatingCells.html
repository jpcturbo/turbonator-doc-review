1. Overview & Purpose

CALTHR defines the deadband threshold evaluated against the short-term oxygen sensor feedback counter before determining whether closed-loop operation is stable.

When closed loop is active, the feedback counter accumulates rich and lean kicks. In factory calibrations, CALTHR is set to 9 counts, corresponding to approximately 1.76 percent of fuel trim authority.

If the short-term feedback counter moves beyond this calibrated limit relative to the toggle direction, the controller detects an out-of-range condition that can trigger an open-loop transition.

3. Tuner's Guide & Real-World Calibration

  • Header & Relocated Sensor Tuning:
  • Exhaust headers increase sensor transit delay, causing larger short-term trim swings. Raising CALTHR to 12-16 counts prevents unwarranted open-loop dropouts.
  • Deadband Authority:
  • Represents approximately 0.195% fuel trim per count (9 counts ≈ 1.76% deadband).
  • Tightening the Window:
  • Lowering CALTHR enforces tighter closed-loop tolerance, but setting too low causes erratic open-loop cycling.
