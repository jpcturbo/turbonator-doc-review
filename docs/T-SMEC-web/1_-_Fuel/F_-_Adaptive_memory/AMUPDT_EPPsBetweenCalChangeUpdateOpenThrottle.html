1. Overview & Purpose

AMUPDT specifies the number of engine pulse periods (distributor rising edges) that must accumulate while operating off-idle before the controller is permitted to update the active adaptive fuel memory cell.

On a four-cylinder engine, two distributor pulses occur per crankshaft revolution. In stock calibrations, AMUPDT is set to 26 counts, which corresponds to 13 crankshaft revolutions.

This update interval ensures that the short-term oxygen sensor feedback counter has integrated multiple combustion cycles before transferring a trim step into long-term memory.

3. Tuner's Guide & Real-World Calibration

  • Cruising Adaptation Pace:
  • Increasing AMUPDT slows down part-throttle learning, requiring longer steady-state operation before trims shift.
  • Rapid Calibration Learning:
  • Lowering AMUPDT to 10-15 counts enables faster learning during tuning sessions.
  • Distributor Pulse Units:
  • Measured in distributor rising edges (2 edges per crankshaft revolution on a 4-cylinder engine; 26 counts = 13 revolutions).
