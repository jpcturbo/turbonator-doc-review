1. Overview & Purpose

O2LIMH defines the absolute maximum positive fuel trim limit for short-term oxygen sensor feedback.

During closed-loop operation, the feedback counter accumulates primary and secondary ramp kicks to correct for lean conditions. O2LIMH acts as a hard upper clamp, preventing the short-term feedback counter from adding more fuel than calibrated.

In stock calibrations, O2LIMH is set to 127 counts, corresponding to approximately +24.8 percent maximum fuel enrichment above the current base and adaptive fueling calculation.
