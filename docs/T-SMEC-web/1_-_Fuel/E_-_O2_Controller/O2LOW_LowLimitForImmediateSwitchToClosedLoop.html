1. Overview & Purpose

O2LOW defines the lower voltage threshold for immediate validation of the narrowband oxygen sensor signal.

If the sensor produces a clear lean reading below O2LOW during warmup, the controller knows the sensor has reached operating temperature and is capable of full amplitude swings. The controller immediately validates the sensor flag without waiting for delay timers.

In stock calibrations, O2LOW is set to 15 counts, corresponding to approximately 0.29 volts.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosing Subroutine: HandleO2Processing_MM / O2_FullThrottle (T-SMEC_v19.asm:3008-3018), instruction line 3011.
  • Gating Conditions: Signal tested lower than O2HIGH.
  • Comparison & Branch Polarity:
  • Line 3011 executes cmpb O2LOW_LowLimitForImmediateSwitchToClosedLoop.
  • If O2SensorValue < O2LOW (bcs), execution falls through to O2_ValidSignal_OutsideMiddleRange (line 3013), setting bit b4f_O2Valid immediately.
  • If O2SensorValue >= O2LOW (bcc), execution branches to O2_InvalidSignal_InMiddleRange (line 3019).

3. Tuner's Guide & Real-World Calibration

  • Lean Signal Validation:
  • Any signal below O2LOW (approx 0.29V) proves the sensor is hot and swinging lean, immediately triggering closed loop.
  • Ground Offset Mitigation:
  • If wiring resistance creates a ground voltage offset, raising O2LOW to 18-20 counts (0.35-0.39V) prevents delayed closed-loop entry.
  • Interaction with O2HIGH:
  • Together, O2LOW and O2HIGH define the active boundaries outside the intermediate warmup zone.
