1. Overview & Purpose

O2LSWP defines the lean switching threshold for closed-loop oxygen sensor feedback.

When sensor voltage falls below O2LSWP, the mixture is classified as lean, instructing the controller to apply rich ramp kicks to add fuel. In factory calibrations, O2LSWP is set to 24 counts, corresponding to approximately 0.47 volts.

The difference between O2LSWP (24 counts) and O2HSWP (25 counts) forms a 1-count hysteresis deadband that prevents electrical noise from causing rapid toggle chatter when voltage passes through the center.

  • If O2SensorValue >= O2LSWP (inside deadband between 24 and 25 counts), line 3058 executes rts to exit without changing ramp state.

3. Tuner's Guide & Real-World Calibration

  • Hysteresis Widening:
  • Lowering O2LSWP to 22-23 counts (0.43-0.45V) widens the deadband against O2HSWP, filtering electrical noise from single-wire sensors.
  • Centering Stoichiometric Point:
  • Calibrated to 0.47V, immediately below the steep slope of the narrowband sensor voltage curve.
  • Polarity Requirement:
  • Must be strictly less than O2HSWP (O2LSWP < O2HSWP).
