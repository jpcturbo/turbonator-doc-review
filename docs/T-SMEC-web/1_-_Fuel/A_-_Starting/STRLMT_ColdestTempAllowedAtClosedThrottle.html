1. Overview & Purpose

STRLMT defines the minimum coolant temperature floor permitted for cranking fuel calculations when starting at closed throttle.

Because the STRTFL starting fuel calculation squares the table lookup result, unconstrained sub-zero temperature sensor readings could command excessive injector pulsewidths that flood the cylinders. In factory calibrations, STRLMT is set to 105 counts, corresponding to approximately 38 degF.

If an engine is cranked with the throttle closed at temperatures colder than 38 degF, the controller clamps the input temperature to 38 degF, preventing excessive cranking fuel accumulation.

3. Tuner's Guide & Real-World Calibration

  • Cold Cranking Protection:
  • Raising STRLMT caps the maximum cranking pulsewidth, preventing wet-fouling on large injectors in freezing weather.
  • Sub-Zero & E85 Cold Starts:
  • Lowering STRLMT allows richer fueling below 38 degF for cold northern climates or E85 conversions.
  • Closed-Throttle Gating:
  • STRLMT is only applied when the throttle is fully closed; cracking the throttle off-idle bypasses the clamp immediately.
  • Stock Calibration Matching:
  • Factory setting of 105 counts (38 degF) balances cold fuel vaporization against the risk of unburned fuel flooding.
