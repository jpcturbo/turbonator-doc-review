1. Overview & Purpose

FCRCVB defines an engine speed (RPM) scaling curve applied to warm-up enrichment Curve B during wide-open throttle operation.

If the driver floors the accelerator pedal while the engine is still warming up, full-throttle base fueling combined with unattenuated cold enrichment can cause combustion quenching from an overly rich air-fuel mixture. FCRCVB scales down Curve B enrichment as engine RPM increases, preventing spark plug fouling and preserving power delivery during full-throttle acceleration on a warming engine.

3. Tuner's Guide & Real-World Calibration

  • Cold WOT Protection:
  • Prevents excessively rich mixtures when wide-open throttle is applied before the engine reaches full 180 degF operating temperature.
  • Competition & Cold Weather:
  • If cold-engine full-throttle acceleration pops lean on cold track mornings, raise FCRCVB values.
  • High-Flow Injector Tuning:
  • Lower FCRCVB if upgraded injectors cause black smoke and bogging during cold wide-open throttle acceleration.
  • Single-Point Scaling:
  • Stock calibration uses a single-point table representing a universal multiplier across all engine speeds.
