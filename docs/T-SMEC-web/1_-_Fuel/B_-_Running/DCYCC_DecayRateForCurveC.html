1. Overview & Purpose

DCYCC defines the decay rate subtraction constant for intermediate cold enrichment (Curve C).

After intermediate hold time (CCURV) expires, DCYCC is subtracted from the enrichment decay register every 32 main loop passes. This stepwise subtraction progressively reduces intermediate warm-up enrichment down to zero, ensuring a seamless transition into steady-state warm-up operation.

In factory calibrations, DCYCC is set to 11 counts per step.

3. Tuner's Guide & Real-World Calibration

  • Accelerating Decay:
  • Increasing DCYCC causes Curve C enrichment to decay faster, reducing rich idle dwell.
  • Cold Drivability Smoothing:
  • Decreasing DCYCC provides a more gradual taper, preventing lean throttle sag during intermediate warm-up.
  • Stepwise Subtraction:
  • Subtracted from Factor_ACVDCY every 32 loop passes until zero is reached.
  • Timing Parameter Clustering:
