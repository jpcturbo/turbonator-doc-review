1. Overview & Purpose

MAPIDL defines the base fuel delivery curve indexed by intake manifold pressure when operating at closed throttle.

Chrysler speed-density engine controllers isolate closed-throttle fueling from part-throttle fueling to achieve ultra-smooth idle stability and clean coast-down decel without disturbing off-idle drivability. MAPIDL maps manifold absolute pressure directly to injector pulsewidth across deep intake manifold vacuum levels.

This table active whenever the throttle plate is fully closed and the engine is idling or coasting in gear.
