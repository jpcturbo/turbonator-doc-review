1. Overview & Purpose

PTENR establishes the engine position pulse countdown interval and step size governing how rapidly part-throttle enrichment ramps upward when manifold pressure exceeds the RPMMAP boundary curve.

Formatted as a 16-bit word, the high byte defines the number of distributor reference pulses that must elapse between enrichment steps, while the low byte defines the increment added to the open-loop enrichment fraction timer. This pulse countdown structure ensures that transient enrichment builds progressively with engine revolutions rather than jumping instantaneously, providing a smooth transition into boost.

The factory setting of 50 pulses and 1 count increment ensures that enrichment builds smoothly over approximately 25 engine revolutions on a four-cylinder engine.

3. Tuner's Guide & Real-World Calibration

  • Faster Enrichment Ramp: Lowering the pulse countdown value in the high byte causes the enrichment multiplier to ramp upward faster, curing hesitation, lean air-fuel ratio spikes, or sluggish turbocharger spool-up when rolling into the throttle.
  • Gentler Ramp and Fuel Economy: Raising the pulse countdown value slows down the rate of enrichment buildup, creating a more conservative ramp that conserves fuel during brief transient accelerations.
  • Step Size Adjustment: Increasing the low byte step value increases the percentage added on each countdown expiration, producing a more aggressive step-up.
  • Injector Upgrades: When running very large injectors, ensure the ramp-in rate is not overly rapid to prevent transient rich bogging.
