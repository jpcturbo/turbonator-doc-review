1. Overview & Purpose

PWADD provides barometric pressure fuel compensation by adding injector pulse width at high altitudes.

As ambient atmospheric pressure decreases when operating in elevated terrain, lower intake air density can destabilize idle combustion and cause lean engine surging. The engine controller looks up barometric pressure from PWADD during foreground latency updates and converts the resulting value into an additive microsecond fuel pulse.

At sea-level barometric pressure of approximately 14.7 psi or 29.9 inHg, the factory calibration delivers zero additional pulse width. As barometric pressure drops below 13.1 psi toward 10.5 psi at high elevations, the table progressively adds between 64 and 100 microseconds of injection pulse width to stabilize idle combustion and low-speed driveability.

3. Tuner's Guide & Real-World Calibration

  • High-Altitude Compensation: Raise table values if the engine experiences lean surging, rough idle, or hesitation when driving in high-altitude environments.
  • Over-Rich Altitude Correction: Lower or zero out table values if modified engines or large injectors run excessively rich at elevation.
  • Injector Sizing Adjustments: When upgrading to larger fuel injectors, scale down PWADD values inversely to match the percentage increase in injector flow rate so that total delivered fuel remains constant.
  • MAP Sensor Scaling Consideration: If tuning an engine converted to a 3-bar MAP sensor, confirm that initial key-on barometric pressure readings accurately align with real-world atmospheric conditions.
