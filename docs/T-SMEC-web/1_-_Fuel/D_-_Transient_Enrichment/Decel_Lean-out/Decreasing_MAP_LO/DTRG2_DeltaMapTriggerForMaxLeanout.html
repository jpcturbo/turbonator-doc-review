1. Overview & Purpose

DTRG2 defines the second manifold pressure drop threshold that triggers full, immediate deceleration lean-out.

While smaller manifold pressure drops between DECTRG and DTRG2 apply gradual incremental fuel leaning, sudden drops that exceed DTRG2 signal an abrupt throttle lift-off. In response, the engine controller immediately loads the full temperature-based fuel multiplier from DECEL and sets the oxygen sensor inhibit timer.

The factory setting of 8 counts corresponds to approximately 0.92 psi of rapid manifold pressure reduction.

3. Tuner's Guide & Real-World Calibration

  • Two-Stage Decel Transition: Set DTRG2 higher than DECTRG to create a smooth two-stage deceleration response.
  • Sharper Engine Braking: Lowering DTRG2 causes the engine controller to jump directly to maximum lean-out on moderate throttle releases, sharpening engine braking and cutting emissions quickly.
  • Softening Overrun Jerkiness: Raising DTRG2 keeps fuel delivery in the gradual incremental lean-out mode longer, softening deceleration transitions and helping prevent jerkiness in manual transmission vehicles.
  • 3-Bar MAP Scaling: Scale DTRG2 down by 33 percent when converting to a 3-bar MAP sensor to keep real-world pressure triggers aligned.
