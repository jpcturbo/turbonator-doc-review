1. Overview & Purpose

LOTIME establishes the digital filter time constant for rolling average throttle voltage during throttle closing transitions.

When the driver lifts off the accelerator pedal and throttle voltage drops below the rolling average, LOTIME dictates how quickly the rolling average decays downward to match the new, lower throttle position.

The factory setting of 40 counts provides smooth filtering that stabilizes throttle delta calculations during sudden lift-off transitions.

3. Tuner's Guide & Real-World Calibration

  • Filter Decay Speed: Lowering table values slows the decay of the rolling average, keeping the calculated throttle drop active across more engine cycles and prolonging throttle deceleration lean-out.
  • Shortening Decel Window: Raising table values causes the average to match the closed throttle position faster, terminating deceleration lean-out sooner.
  • Filter Tracking Stability: For most builds, leaving this parameter stock ensures proper filter tracking without lag.
  • Companion Parameter: Coordinates with THRTCN (which governs increasing throttle transitions).
