1. Overview & Purpose

FNSPHI defines the high vehicle speed transition threshold that switches the cooling fan logic between low-speed city mode and high-speed highway mode.

The engine controller monitors road speed via the transmission distance sensor, which stores the pulse period between speedometer pulses in high-byte variable VehicleSpeed_HB. Because this variable measures time duration between pulses, smaller count values represent faster road speeds. In factory calibrations, FNSPHI is set to 11 counts, representing approximately 44 MPH. When road speed exceeds this threshold, the controller switches from low-speed fan setpoints (FANTMP3/FANTMP4) to highway setpoints (FANTMP1/FANTMP2).

2. Operating Conditions (When Does This Take Effect?)

  • Subroutine & Line Numbers: ControlFan_MM / PreventRadSteaming (T-SMEC_v19.asm:1729-1744), instruction line 1731.
  • Variable Evaluated: VehicleSpeed_HB (speedometer pulse period high byte).
  • Comparison & Branch:
  • Compares VehicleSpeed_HB against FNSPHI_FanControlSpeedHi at line 1731.
  • If VehicleSpeed_HB >= FNSPHI (bcc Below44MPH), road speed is below ~44 MPH; branches to set flag b51_SpeedUnder40.
  • If VehicleSpeed_HB < FNSPHI, proceeds to evaluate FNSPLO.

3. Tuner's Guide & Real-World Calibration

  • Pulse Period Inversion:
  • Lower count values in FNSPHI represent higher road speeds in miles per hour.
  • Speed Hysteresis Window:
  • Works with FNSPLO to prevent fan threshold hunting when driving at moderate speeds (36 to 44 MPH).
  • Tire & Gear Ratio Changes:
  • Adjust FNSPHI if significant tire diameter or final drive gear changes alter speedometer pulse calibration.
