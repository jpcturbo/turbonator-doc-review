1. Overview & Purpose

BAUDLO defines the initial serial communication baud rate loaded into the on-chip serial communications interface during standard diagnostic tool communication.

Configured in factory calibrations to thirty-four counts, BAUDLO configures a data rate of seventy-eight twelve baud (7812 baud). This data rate represents the standard initialization and handshake speed used by Chrysler diagnostic readout box scan tools to query diagnostic trouble codes, actuate actuators, and inspect live vehicle sensor data.

2. Operating Conditions (When Does This Take Effect?)

  • Subroutine & Line Numbers: DRBIISerialCommunications_MM (T-SMEC_v19.asm:3541-3564), instruction lines 3551 and 3553. Also line 7316.
  • Baud Rate Enforcement:
  • Evaluated when fast serial and byte mode are inactive (DRBSerialMode bits clear).
  • Compares CPU_SerialBaudRate against BAUDLO_DRBBaudRateLo.
  • If unequal, stores BAUDLO into CPU_SerialBaudRate and returns to allow baud rate stabilization.

3. Tuner's Guide & Real-World Calibration

  • Preserve 7812 Baud Rate:
  • Retain factory setting of thirty-four counts (7812 Baud) for scan tool compatibility.
  • Scan Tool Lockout Prevention:
  • Modifying BAUDLO breaks communications with handheld diagnostic scan tools.
  • Standard Handshake Speed:
  • Governs initial connection before any high-speed datalogging command is issued.
