1. Overview & Purpose

FLTMSK defines the first configurable error suppression slot in the engine controller diagnostic subsystem.

In Chrysler nineteen eighty-nine engine controllers, diagnostic fault logging is managed through an internal fault code table. When an electronic sensor or actuator fault is detected, the error recording routine searches a sequential suppression array starting at FLTMSK. If an internal diagnostic code matching the detected fault is stored in this byte, the controller bypasses error recording completely, preventing the fault from being logged in memory or flashed on the check engine lamp. In factory calibrations, FLTMSK is initialized to zero, leaving all diagnostic fault reporting active.

  • Search Loop Mechanics:
  • The error routine iterates across the mask array starting at FLTMSK_ErrorBitsMask1.
  • If the array entry is zero (brclr 0, X, #$%11111111, L1321), the loop terminates and the error is processed.
  • If the entry matches the incoming error code (cmpa 0x00,x; beq L1323), the error is suppressed and the routine exits immediately.

3. Tuner's Guide & Real-World Calibration

  • Selective Fault Code Suppression:
  • Entering an internal error offset into FLTMSK prevents the controller from recording the corresponding diagnostic trouble code or illuminating the dashboard lamp for that failure.
  • Common Suppression Targets:
  • Wastegate solenoid elimination (Code 36): enter thirteen counts.
  • EGR solenoid elimination (Code 32): enter seventeen counts.
  • Baro read solenoid deletion (Code 37): enter twelve counts.
  • Purge solenoid deletion (Code 31): enter eighteen counts.
  • Factory Default:
  • Set to zero counts, keeping all factory fault reporting active.
