1. Overview & Purpose

PIBMSK defines the diagnostic output driver circuit mask for Port B of the Peripheral Interface Adapter.

Port B controls dedicated powertrain inductive solenoids and warning indicators, including the exhaust gas recirculation solenoid, turbocharger wastegate control solenoid, barometric read solenoid, and emissions maintenance reminder lamp. Configured in factory calibrations to two hundred twenty-four counts, PIBMSK dictates which of these output circuits are actively tested for open coils, wiring breaks, or driver circuit failures during vehicle operation.

2. Operating Conditions (When Does This Take Effect?)

  • Subroutine & Line Numbers: UPDATE_PIA1_A_PDR_DDR_REGISTER (T-SMEC_v19.asm:4331-4420), instruction line 4407 (bita PIBMSK_PIA1BDDRMask).
  • Driver Verification:
  • Executes sequentially following Port A verification.
  • Uses Counter_MainLoop & 0x07 to select the active Port B output pin.
  • Branch Execution:
  • If bita PIBMSK_PIA1BDDRMask is zero (beq R1318), testing on the pin is skipped.
  • If set and an open circuit is detected on the wastegate driver, calls ThrowNonCriticalError and sets b46_WGSolFault.

3. Tuner's Guide & Real-World Calibration

  • Wastegate Solenoid Circuit Testing:
  • Clearing the wastegate solenoid bit stops electrical driver line testing on Port B, preventing fault code 36 when the solenoid is removed.
  • EGR Solenoid Circuit Testing:
  • Clearing the EGR solenoid bit disables circuit feedback checks when deleting emissions components.
  • Barometric Solenoid Testing:
  • Allows disabling diagnostics on the baro read solenoid if non-stock atmospheric sensing is implemented.
  • Factory Default:
  • Set to two hundred twenty-four counts, actively monitoring EGR, wastegate, and baro read circuits.

5. Calibration Notes & System Dependencies

  • Bit Allocations: Bit 7: EGR Solenoid, Bit 6: Wastegate Solenoid, Bit 5: Baro Read Solenoid, Bit 4: Emission Light.
  • Wastegate Fault Latching: Sets b46_WGSolFault when an unmasked wastegate solenoid driver fault occurs.
  • Companion Mask: Works directly with PIAMSK.
