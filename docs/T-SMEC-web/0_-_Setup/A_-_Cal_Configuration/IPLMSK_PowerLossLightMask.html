1. Overview & Purpose

IPLMSK defines the primary dashboard warning lamp illumination mask register for analog electronic sensor faults.

In Chrysler engine controllers, sensor circuit diagnostics continuously update internal status flags in memory. Configured in factory calibrations to two hundred fifty-four counts, IPLMSK dictates which of these sensor faults command the dashboard power loss or check engine light to illuminate while the engine is running. The switches in IPLMSK govern warning light illumination for intake charge temperature sensor failures, engine coolant temperature sensor faults, charging system electrical failures, battery voltage sense faults, manifold absolute pressure electrical failures, throttle position sensor signal faults, and manifold pressure pneumatic tracking errors.

3. Tuner's Guide & Real-World Calibration

  • Sensor Warning Lamp Suppression:
  • Clearing individual bits in IPLMSK prevents specific sensor failures from illuminating the dashboard check engine light.
  • Charge Temperature & MAP Bypass:
  • If running an engine conversion without a charge temperature sensor, clearing the charge temp bit stops warning light activation.
  • Retains Diagnostic Codes:
  • Unlike FLTMSK, clearing a bit in IPLMSK leaves diagnostic trouble code storage intact for scan tool retrieval while silencing the instrument cluster light.
  • Factory Default:
  • Set to two hundred fifty-four counts, illuminating the lamp for all primary sensor faults.
