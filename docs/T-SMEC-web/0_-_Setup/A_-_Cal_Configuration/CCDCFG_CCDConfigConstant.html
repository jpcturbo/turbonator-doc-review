1. Overview & Purpose

CCDCFG defines the configuration constant for the Chrysler Collision Detection serial communication network bus.

In production Chrysler vehicles, the two-wire multiplexed serial bus interconnected the engine controller with other onboard microprocessors, including the body computer, digital instrument cluster, overhead trip computer, and compass. Configured in factory calibrations to one hundred sixty-two counts, CCDCFG designated bus arbitration priority and node operating parameters. In the Turbonator codebase, all executable instructions in the collision detection network routine were commented out to reduce main loop cycle overhead, though the constant remains defined in the calibration ROM image.
