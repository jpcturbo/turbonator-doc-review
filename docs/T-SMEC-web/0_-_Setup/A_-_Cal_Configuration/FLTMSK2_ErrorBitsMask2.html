1. Overview & Purpose

FLTMSK2 defines the second configurable error suppression slot in the eight-byte diagnostic fault mask array.

Positioned at index offset one from the base mask address, FLTMSK2 allows tuners to suppress a second distinct diagnostic error code. When a circuit failure or sensor out-of-range condition occurs, the controller iterates through the array; if the internal diagnostic code matches FLTMSK2, error logging is bypassed and no trouble code is stored. Factory calibrations initialize FLTMSK2 to zero counts, leaving normal diagnostic reporting enabled.
