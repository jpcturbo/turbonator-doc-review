1. Overview & Purpose

MAXCNT defines the debounce integration counter that governs how quickly the learned closed-throttle baseline voltage ratchets downward when throttle position sensor voltage drops below the current learned minimum.

If sensor voltage settles slightly lower than the stored minimum—such as after the throttle linkage warms up or when returning from high engine speeds—the controller does not jump to the new voltage immediately. Instead, it decrements the learned minimum by one count only after throttle voltage remains continuously below the stored value for the number of program loops specified by MAXCNT. Factory calibrations set MAXCNT to sixteen loops, representing approximately one hundred seventy-six milliseconds.

3. Tuner's Guide & Real-World Calibration

  • Downward Ratchet Speed:
  • Controls how many main loop passes (each ~11ms) sensor voltage must remain below MINTHR before MINTHR decrements by 1 count.
  • Electrical Noise Rejection:
  • Debounce delay filters out transient sensor ground bounce, ignition coil interference, and sensor wiper vibration.
  • Preserve Stock Value:
  • Sixteen loops provides the optimal balance between rapid initial adaptation and electrical noise immunity.
