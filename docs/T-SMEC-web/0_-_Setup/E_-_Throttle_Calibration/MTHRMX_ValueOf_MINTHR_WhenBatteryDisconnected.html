1. Overview & Purpose

MTHRMX defines the default closed-throttle position baseline voltage loaded into memory whenever the vehicle battery is disconnected, keep-alive memory power is lost, or the engine controller undergoes a hard reset.

In factory calibrations, MTHRMX is calibrated to ninety-two counts, corresponding to approximately one point eight zero volts. Because physical throttle position sensors typically rest between zero point eight and one point zero volts at idle, initializing the learned minimum throttle register to MTHRMX establishes a safe upper ceiling. Once the engine starts and enters closed-throttle deceleration, the adaptive ratcheting logic steps the learned baseline downward until it matches the physical resting voltage.

3. Tuner's Guide & Real-World Calibration

  • Battery Disconnect Fallback:
  • Default voltage baseline written to MINTHR_LowestSessionTPS during power-up when battery memory is cleared.
  • Aftermarket Throttle Bodies:
  • If an aftermarket throttle body rests at or above 1.8 Volts, increase MTHRMX so the reset ceiling remains higher than resting closed-throttle voltage.
  • Upper Clamp for Upward Ratchet:
  • Also functions as the maximum permissible voltage cap when the deceleration self-calibration routine increments MINTHR.
  • Factory Setting:
  • Set to ninety-two counts (~1.80 Volts) in factory calibrations.
