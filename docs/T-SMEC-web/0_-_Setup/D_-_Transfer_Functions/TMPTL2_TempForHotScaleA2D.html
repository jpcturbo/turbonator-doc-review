1. Overview & Purpose

TMPTL2 is the hot-range non-linear transfer table converting raw voltage counts from the engine coolant temperature sensor into engineering temperature units under warm running conditions.

When coolant temperature warms past approximately one hundred forty degrees Fahrenheit, the controller hardware toggles the thermistor pull-up resistor to its low-resistance mode and the firmware switches lookup from the cold scale to this four-point hot scale curve. Because all normal operating temperatures (one hundred eighty to two hundred ten degrees Fahrenheit) reside on TMPTL2, this table directly governs radiator fan cycling, closed-loop fuel trim engagement, adaptive purge flow, and warmup spark modifiers.
