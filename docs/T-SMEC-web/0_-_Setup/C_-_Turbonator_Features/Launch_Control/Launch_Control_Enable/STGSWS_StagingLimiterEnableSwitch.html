1. Overview & Purpose

STGSWS defines the digital input switch bitmask used to arm the launch control staging limiter.

Rather than requiring staging control to be permanently engaged at low vehicle speeds, this parameter allows the driver to trigger launch control via an external electrical switch, such as a clutch pedal switch, handbrake switch, steering wheel push-button, or cruise control switch.

When set to zero (the factory default), no external switch is required; the engine controller automatically arms launch control whenever vehicle speed and throttle position meet the staging criteria.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosed in subroutine LaunchControl_CheckSwitch at lines 10138-10146 of cals/SMEC/T-SMEC_v19.asm (invoked via LaunchControl_MM at line 7537 in the main engine loop).
  • Evaluated only when custom option flag opt_StageLim is set in OPTN2_CalCustomOptionConfigFlags2 (line 10134).
  • If STGSWS is zero (beq LaunchControl_CheckTPS at line 10141), the switch check is bypassed and launch control relies purely on speed and throttle thresholds.
  • If STGSWS is non-zero, instruction bitb SwitchPortAccessReg tests the input register (line 10144). If the bit is clear (beq LaunchControl_Off), launch control is aborted.

3. Tuner's Guide & Real-World Calibration

  • Clutch Interlock Wiring: Wire a clutch pedal switch to a digital input (such as Brake Switch or Cruise Control On/Off) and select that bitmask in STGSWS for seamless manual transmission staging.
  • Hands-Free Automatic Arming: Setting STGSWS to zero allows automatic arming whenever vehicle speed is below STGSPD and throttle exceeds STGTPS, requiring no external switches.
  • Diagnostic Verification: Datalog the staging flag in MPScan to confirm that the selected switch reliably engages and disengages launch control logic.
