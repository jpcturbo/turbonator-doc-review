1. Overview & Purpose

ANLGRP defines the engine speed threshold required before anti-lag ignition timing takes effect during staging launch control.

When staging a turbocharged engine, ignition timing must remain normal at low speeds to allow the engine to rev cleanly off idle without stumbling. Once engine speed surpasses ANLGRP, the engine controller activates the anti-lag absolute timing schedule, transferring combustion heat into the exhaust manifold to spool the turbocharger.

The factory setting of 69 counts corresponds to approximately 2208 RPM, providing a smooth transition window well below the staging rev limiter.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosed in subroutine CalulateLaunchAdvance at lines 10262-10277 of cals/SMEC/T-SMEC_v19.asm.
  • Evaluated when flag Turbonator_Staging is asserted in Turbonator_Flags and opt_AntiLag is enabled in OPTN2.
  • Threshold comparison: cmpb EngineRpm_HB against ANLGRP_AntiLagRetardRPM (lines 10266-10267).
  • If EngineRpm_HB <= ANLGRP_AntiLagRetardRPM, the branch bcc AntiLag_Return is taken, bypassing anti-lag retard.
  • If EngineRpm_HB > ANLGRP_AntiLagRetardRPM, execution continues to line 10269 to load ANTLAGX.

3. Tuner's Guide & Real-World Calibration

  • Threshold Placement: Set ANLGRP approximately 200 to 400 RPM below the lower staging limiter threshold (STGRON). For example, if staging launch speed is set to 3800 RPM, configure ANLGRP between 3400 and 3600 RPM.
  • Setting Too Low: Retards ignition timing immediately off idle, causing hesitation, severe misfiring, and poor throttle response while trying to stage.
  • Setting Too High: Setting this threshold higher than the lower staging limiter prevents anti-lag from ever activating, resulting in lack of boost on the starting line.

4. Technical / Assembly Mechanics (Reference)

Inside T-SMEC_v19.asm: At line 10266 within CalulateLaunchAdvance, accumulator B loads ANLGRP_AntiLagRetardRPM. The CPU executes cmpb EngineRpm_HB against the high-byte engine speed variable (scaled at 32 RPM per count). If EngineRpm_HB is less than or equal to ANLGRP_AntiLagRetardRPM, the condition bcc AntiLag_Return branches out, retaining normal spark advance. Once EngineRpm_HB strictly exceeds ANLGRP, execution proceeds to load ANTLAG_AntiLagRetardAbs.

CalulateLaunchAdvance:
        ldx  #OPTN2_CalCustomOptionConfigFlags2
        brclr 0x00, X, #opt_AntiLag, AntiLag_Return

        ldab ANLGRP_AntiLagRetardRPM
        cmpb EngineRpm_HB
        bcc  AntiLag_Return ; branch if
        ldaa ANTLAG_AntiLagRetardAbs
        asra
        asra ; divide by 4 - min/max = +/-16 deg
        adca #0x00 ; round up any remainder
        ldx  #Turbonator_Flags
        bset 0x00, x, #Turbonator_AntiLag ;just to indicate that the anti-lag is active, for logging purposes

AntiLag_Return:
        rts

5. Calibration Notes & System Dependencies

  • RPM Scaling: Scaled at 32 RPM per count. The factory setting of 69 counts equals 2208 RPM.
  • Hysteresis Coordination: Must always be calibrated lower than STGRON and STGROF to ensure anti-lag engages before the rev limiter begins cycling.
  • Option Dependency: Depends on option flag opt_AntiLag in OPTN2.
