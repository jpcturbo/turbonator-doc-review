1. Overview & Purpose

LNCPDT defines the eight-bit spark cut patterns that govern cylinder-by-cylinder ignition enabling during launch control staging.

By rotating through an eight-bit mask on each distributor reference pulse, the engine controller selectively fires or suppresses ignition for each consecutive cylinder. A binary one bit permits spark, while a binary zero bit cuts coil firing. This rotating approach prevents cutting the same cylinder consecutively, protecting spark plugs from fouling and evening out exhaust runner heating while unburnt mixture drives the turbine wheel.

The factory table provides eight distinct patterns ranging from mild 1/3 cut up to aggressive 6/7 cut.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosed in subroutine StoreSparkCutCounter at lines 10290-10298 of cals/SMEC/T-SMEC_v19.asm.
  • Executed whenever Counter_SparkCut reaches zero during active staging spark cut (Turbonator_SparkCut set).
  • Memory indexing: SPKFRC_SparkCutFraction offsets pointer #LNCPDT_PatternDataTable in index register Y via aby (lines 10293-10294).
  • The indexed pattern is stored into RAM variable Pattern_SparkCut at line 10296.
  • In RotateSparkCutPattern (line 10254), instruction rol Pattern_SparkCut shifts the highest bit into the Carry flag. If Carry is set, spark is allowed for that cylinder; if clear, spark is suppressed.

3. Tuner's Guide & Real-World Calibration

  • Selection Mechanism: Patterns are chosen via SPKFRC (choices 0 through 7) in calibration software.
  • Standard Bitmask Options: Pattern 0 (1/3 cut) fires two out of three cylinders; Pattern 3 (4/5 cut, factory setting) fires one out of five cylinders; Pattern 7 (6/7 cut) fires one out of seven cylinders.
  • Exhaust Energy Trade-off: Lower cut ratios provide higher firing frequency and maximum exhaust expansion to spool massive turbos. Higher cut ratios clamp engine speed tightly with lower exhaust temperatures.

4. Technical / Assembly Mechanics (Reference)

Inside T-SMEC_v19.asm: At line 10290 in StoreSparkCutCounter, Counter_SparkCut is initialized. Accumulator B reloads SPKFRC_SparkCutFraction at line 10292 and adds it to index register Y (aby), which points to #LNCPDT_PatternDataTable at line 10293. The selected byte is fetched and stored into RAM variable Pattern_SparkCut at line 10296. The rol instruction shifts the most significant bit into the Carry flag. If Carry is clear (bcc CalulateLaunchAdvance), spark is withheld.         stab Counter_SparkCut
        ldab SPKFRC_SparkCutFraction ; this is now an offset value -- oops, this was left off, made the pattern wrong

        ldab 0x00, Y ; b now contains the pattern
        stab Pattern_SparkCut 
        bra  CalulateLaunchAdvance
