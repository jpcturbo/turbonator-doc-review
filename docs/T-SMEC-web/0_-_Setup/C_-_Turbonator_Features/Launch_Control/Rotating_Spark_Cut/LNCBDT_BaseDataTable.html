1. Overview & Purpose

LNCBDT stores the counter initialization values that define the cycle length for each of the eight rotating spark cut patterns in launch control.

Turbonator firmware cuts ignition events in a rotating sequence across cylinders to distribute thermal loading and prevent raw fuel accumulation in any single combustion chamber. Each pattern operates over a specific cycle length: 3 cylinder events for 1/3 and 2/3 cuts, 5 cylinder events for 3/5 and 4/5 cuts, and 7 cylinder events for 3/7 through 6/7 cuts.

LNCBDT provides the cycle length for each selectable ratio so the controller knows when to reset the counter and reload the bitmask pattern.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosed in subroutine SetBaseandPattern at lines 10279-10289 of cals/SMEC/T-SMEC_v19.asm.
  • Evaluated when Counter_SparkCut decrements to zero (beq SetBaseandPattern at line 10252) while Turbonator_Staging and Turbonator_SparkCut are active.
  • Offset lookup: SPKFRC_SparkCutFraction is added to base address #LNCBDT_BaseDataTable in index register Y via instruction aby (line 10282).
  • Bang-bang modification: If option flag opt_BangBang is set in OPTN2, instruction decb at line 10288 reduces the base counter by one before storing into Counter_SparkCut.

3. Tuner's Guide & Real-World Calibration

  • Factory Calibration Matching: Standard calibrations use base values of 3, 3, 5, 5, 7, 7, 7, and 7 for pattern indices 0 through 7. These match the bit patterns in LNCPDT.
  • Bang-Bang Rev Limiter: When opt_BangBang is enabled in OPTN2, the firmware automatically decrements the selected base value by one, shortening the cycle and producing an aggressive staccato limiter sound.
  • Pattern Customization: Modifying these values is only required when authoring specialized firing sequences for alternative engine configurations.
