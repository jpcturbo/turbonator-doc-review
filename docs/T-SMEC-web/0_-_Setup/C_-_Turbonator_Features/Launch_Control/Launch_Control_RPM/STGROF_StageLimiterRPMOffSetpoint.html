1. Overview & Purpose

STGROF establishes the upper engine speed limit where launch control cuts ignition and/or fuel injection while staging.

When staging at wide-open throttle, the engine revs rapidly toward this setpoint. The instant engine speed reaches STGROF, the engine controller triggers rotating spark cuts and/or fuel cuts depending on configured options, arresting engine acceleration and locking RPM within the staging window.

The factory setting of 125 counts corresponds to 4000 RPM, providing a solid rev limit ceiling for turbo boost generation on the starting line.

2. Operating Conditions (When Does This Take Effect?)

  • Enclosed in subroutine LaunchControl_CheckUpperRPM at lines 10175-10191 of cals/SMEC/T-SMEC_v19.asm.
  • Evaluated when Turbonator_Staging is active and neither spark nor fuel cut is currently asserted (brclr 0, x, #Turbonator_FuelOff | Turbonator_SparkCut, LaunchControl_CheckUpperRPM at line 10172).
  • High-byte engine speed EngineRpm_HB is compared against STGROF_StageLimiterRPMOffSetpoint (line 10177).
  • If EngineRpm_HB < STGROF, execution branches to LaunchControl_AllowFuelSpark.
  • If EngineRpm_HB >= STGROF, execution advances to LaunchControl_ShutOffFuelSpark, asserting Turbonator_FuelOff and/or Turbonator_SparkCut.

3. Tuner's Guide & Real-World Calibration

  • Target Staging RPM: Calibrate to desired launch ceiling (3200-3600 RPM for street tires, 4200-4800 RPM for drag slicks or high-stall converters).
  • Pairing With Resume Point: Always maintain STGROF strictly higher than STGRON by roughly 150 to 250 RPM to establish proper hysteresis.
  • Rev Limit Strategy: Enable opt_SprkRevLim in OPTN2 for boost building via rotating spark cut. Fuel cut (opt_FuelRevLim) halts turbine drive energy and slows boost spool.

	cmpa  STGROF_StageLimiterRPMOffSetpoint ; compare a with memory at index + value

LaunchControl_ShutOffFuelSpark:

        bita  #opt_FuelRevLim
        beq   LaunchControl_CheckSparkCut       ; don't turn off the fuel...

        bita  #opt_SprkRevLim
        beq   LaunchControl_Return              ; don't turn off the spark...

        bra   LaunchControl_Return

5. Calibration Notes & System Dependencies

  • RPM Scaling: Scaled at 32 RPM per count. The factory setting of 125 counts equals 4000 RPM.
  • Hysteresis Window Upper Bound: Governs the peak cut point in the staging hysteresis loop with STGRON.
  • Option Flags: Activates fuel cut if opt_FuelRevLim is enabled in OPTN2 and spark cut if opt_SprkRevLim is enabled in OPTN2.
