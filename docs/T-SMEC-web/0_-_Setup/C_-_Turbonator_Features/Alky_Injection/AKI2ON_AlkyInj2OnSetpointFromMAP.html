1. Overview & Purpose

AKI2ON establishes the manifold pressure turn-on threshold for the secondary stage water or alcohol injection solenoid.

In a dual-nozzle auxiliary injection setup, stage two provides high-volume fluid delivery under peak boost and heavy engine load, delivering additional charge cooling and supplemental fueling when turbocharger compressor discharge temperatures are highest. In Turbonator firmware, an auxiliary output driver (such as Cruise Vacuum) can be assigned to trigger the stage two injection solenoid when boost meets this threshold.

The factory setting is 255 counts (disabled).

2. Operating Conditions (When Does This Take Effect?)

  • Enclosed in subroutine AlkyInj_CheckInj2 at lines 10621-10628 of cals/SMEC/T-SMEC_v19.asm.
  • Evaluated in MM_AlkyInjector_Control after primary stage evaluation.
  • In active firmware, this subroutine is commented out with semicolons in T-SMEC_v19.asm (as documented in smec_anomaly.md), meaning the controller does not execute these instructions unless uncommented in source.
  • Comparison: cmpa AKI2ON_AlkyInj2OnSetpointFromMAP against MapValue (line 10623).
  • When MapValue >= AKI2ON, bit PortA_CruiseVac in Z83_PortA_copy is asserted to energize secondary injector solenoid. If below setpoint, branches to AlkyInj2_CheckHysteresisAndTurnOff.

3. Tuner's Guide & Real-World Calibration

  • Staged Boost Threshold: Typically set between 14 and 18 psi of boost, roughly 5 to 8 psi higher than primary stage AKI1ON.
  • Combustion Quenching Prevention: Progressive staging prevents sudden over-saturation of the intake charge at intermediate boost.
  • Single-Stage Setups: Keep set to 255 counts (factory setting) if running only a single injection nozzle.
