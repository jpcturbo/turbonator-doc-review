1. Overview & Purpose

NO2SWS selects the digital input switch bitmask that signals nitrous oxide activation to the engine controller.

When nitrous oxide is sprayed into an engine, cylinder combustion pressure and flame speed rise sharply, requiring instantaneous ignition timing retard to prevent severe detonation. NO2SWS links a hardware input (such as a wide-open throttle switch, nitrous arming switch, or relay trigger) to the controller's nitrous timing retard routine.

When the selected switch activates, the controller immediately subtracts the retard angle defined by NO2RET from total spark advance.

3. Tuner's Guide & Real-World Calibration

  • Hardware Input Selection: Select the digital input wired to your nitrous activation circuit (e.g., Speed Control On/Off, A/C Switch, or Brake Switch).
  • Polarity Configuration: Toggle opt_NO2Pol in OPTN1 to match switch polarity (active-low ground signal vs. active-high 12V signal).
  • Safety Testing: Datalog NO2Retard in MPScan with the engine off to verify that the retard value activates when the nitrous switch engages and clears when released.
