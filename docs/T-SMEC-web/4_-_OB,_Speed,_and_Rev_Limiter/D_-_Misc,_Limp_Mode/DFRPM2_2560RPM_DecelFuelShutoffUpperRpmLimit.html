1. Overview & Purpose

DFRPM2 defines the minimum engine speed required to qualify for deceleration fuel shutoff through the secondary over-rev deceleration pathway.

While standard closed-throttle deceleration fuel cut is handled earlier in the controller logic based on idle RPM deltas, DFRPM2 guards an auxiliary highway and high-RPM deceleration cut routine that checks vehicle speed, engine warmup temperature, and runtime. In the 2.5L stock automatic calibration, DFRPM2 is set to 219 counts, which places the threshold at approximately 7000 RPM. This high setting effectively deactivates this auxiliary branch under normal driving, reserving it for severe high-speed trailing-throttle conditions.

2. Operating Conditions (When Does This Take Effect?)

  • Subroutine & Line Numbers: Cutout_CheckMPHLimitingValues (T-SMEC_v19.asm:5713-5730), called from Cutout_CheckRevLimitingValues (T-SMEC_v19.asm:5709).
  • Gating Conditions:
  • Reached after passing rev limiter and vehicle speed limiter checks, and b50_FallToIdle in BitFlags_50 is set.
  • RPM Test:
  • EngineRpm_HB is compared against DFRPM2 (cmpa DFRPM2_2560RPM_DecelFuelShutoffUpperRpmLimit).
  • If EngineRpm_HB < DFRPM2 (bcs R1487), execution returns without cutting fuel.
  • If EngineRpm_HB >= DFRPM2, execution continues to test DFSMPH, DFSTMP, and DFSTMR.

3. Tuner's Guide & Real-World Calibration

  • Activating Secondary Decel Cut:
  • Lower DFRPM2 to 80 counts (2560 RPM) to arm deceleration fuel shutoff during street driving.
  • Disabling Auxiliary Decel Cut:
  • Setting DFRPM2 to 255 counts disables this pathway, preserving fueling during aggressive trail-braking or gear changes.
  • Label vs Factory Setting:
  • Note that while the label specifies 2560 RPM, the factory 2.5L automatic template data contains 219 counts (7008 RPM) to bypass this check.

  • Companion Threshold: Entry threshold paired with DFRPM1 as the recovery threshold.
