1. Overview & Purpose

MPSHFA defines the instantaneous or absolute overboost fuel cutout threshold in the Chrysler engine controller.

While MPSHFT allows a temporary boost spike by decrementing a countdown timer, MPSHFA serves as an emergency upper boundary where fuel injection is cut immediately without waiting for any timer to expire. In factory 2.5L calibrations, MPSHFA is calibrated to 153 counts, representing approximately 17.6 psi of boost above atmospheric pressure. If severe turbocharger runaway occurs and boost shoots past this absolute ceiling, the controller bypasses all timer delays, stores non-critical diagnostic fault code 45, and shuts off fuel injection for the current engine rotation to protect pistons, head gasket, and valvetrain.

2. Operating Conditions (When Does This Take Effect?)

  • Subroutine & Line Numbers: Cutout_CheckNormalOB (T-SMEC_v19.asm:5656-5666), called from ControlEngineCutout_MM (T-SMEC_v19.asm:5607-5671).
  • Gating Conditions:
  • Reached only after MPSHFT has been subtracted from gauge boost and carry is clear (MapValue - BaroPressure >= MPSHFT).
  • Wastegate solenoid fault flag b46_WGSolFault in b46_IPL2 must be clear.
  • Comparison & Branch:
  • Compares remaining gauge boost delta against MPSHFA (cmpa MPSHFA_OverboostFuelShutoffEnablePointFromMap_Absolute).
  • If higher (bhi Cutout_SetOBCodeAndShutdown), branches immediately to store fault code 0x0708 via ThrowNonCriticalError and cuts fuel for this rotation via Cutout_ShutOffEngineForThisRotation.

3. Tuner's Guide & Real-World Calibration

  • Raising for High-Boost Tuning:
  • When targeting 18+ psi boost, MPSHFA must be elevated above planned boost overshoot levels, or set to 255 counts to prevent instant fuel shutoff.
  • Leaving MPSHFA at stock 17.6 psi on an upgraded turbo results in harsh, sudden fuel cuts on rapid spool.
  • 3-Bar MAP Sensor Calibration:
  • Rescale MPSHFA to reflect the 44.1 psi total sensor span when upgrading from the factory 2-bar MAP sensor.
  • Lowering & Protection:
  • Lowering MPSHFA provides an immediate cutoff ceiling for engine dyno testing or conservative safety configurations.

5. Calibration Notes & System Dependencies

  • Second-Stage Mechanism: Evaluates the boost excess beyond MPSHFT. Because suba MPSHFT precedes cmpa MPSHFA, MPSHFA acts as an offset ceiling above MPSHFT.
  • Hysteresis Pair: Paired with MPSHFT. During fuel restoration in Cutout_UseHysteresisToDetermineWhenToTurnFuelBackOn (T-SMEC_v19.asm:5765-5775), MPSHFA is re-evaluated; if boost still exceeds MPSHFA, error 0x0708 is re-thrown and fuel remains off.
  • 3-Bar Calibration: In Stage IV calibrations, MPSHFA is calibrated to 12 counts (approx 2.1 psi above MPSHFT on the 44.1 psi scale).
